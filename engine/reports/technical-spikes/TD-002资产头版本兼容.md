# TD-002：资产头版本兼容

状态：已采用；macOS／Windows 原生复现通过。

## 决定

资产头的 `contract_version` 与载荷的 `schema_id`、`schema_version` 分离：

- 缺少 `contract_version` 的旧资产视为资产头 v0；
- v0 可以读取，并在内存中迁移为 v1；
- v0 摘要校验使用迁移前的规范头字节，迁移不能改变旧资产的语义身份；
- v1 直接读取；
- 高于当前实现的未来版本明确拒绝，不猜测字段语义；
- v1 拒绝未知字段，避免拼写错误或未协商字段被静默忽略；
- 新写入资产只生成 v1。

## 夹具

- `EC01-V0`：缺少契约版本，必须迁移并保留旧语义摘要规则；
- `EC01-V1`：当前版本，必须原样读取；
- `EC01-V2`：未来版本，必须返回不支持版本错误。

`release-store` 另有集成测试，证明旧版头和字段块可以按迁移前字节重算摘要，随后返回 v1 内存对象。

## 跨平台入口

macOS 和 Windows 在 `engine` 目录运行：

```text
python tools/verify_platform.py
```

将两份报告放在同一目录后运行：

```text
python tools/compare_platform_reports.py <macOS报告> <Windows报告>
```

比较器对工具链、能力状态、立方体旋转、规范 JSON 原文及摘要作精确比较；L8 面积闭合误差按显式容差比较。
