## 三、Python 支持边界决定

Python 只承载无第三方运行时依赖的独立 Oracle 和验证编排，不进入正式引擎核心。Windows Python 3.11.9 与 macOS Python 3.13.14 产生相同 Oracle 结论和跨平台证据，因此支持范围冻结为 Python `>=3.11`，不要求两端补丁版本一致。

`reference/python/pyproject.toml`、平台验证器和报告比较器已经采用这一边界。低于 Python 3.11 的平台报告会被拒绝。

## 四、E0 冻结结论

T0/E0 退出条件已经满足：

- TS01—TS05 均有可执行证据；
- macOS 与 Windows 原生验证通过；
- 规范 JSON、资产头版本迁移、双摘要和原子发布规则具备测试；
- Rust/Cargo 工具链一致，Python 落在明确支持范围；
- 未实现能力保持显式不可用；
- 核心未引入桌面、渲染、网络、气候或水文依赖。

因此 E0 于 2026-10-08 正式冻结。后续若修改规范 JSON、资产头兼容规则、球面身份、摘要语义或最低工具链，必须形成新的版本化技术决定和迁移证据。
