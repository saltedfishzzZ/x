# T0 技术验证报告

本目录只保存 TS01—TS05 的实际证据与决定。当前代码仍是技术验证和 E0 底座，不表示构造、材料、地形、水文或桌面应用已经实现。

## 首次本机基线

- 工具链：Rust/Cargo 1.90.0；Python 支持 `>=3.11`，本次覆盖 3.11.9 与 3.13.14。
- 目标平台：macOS Apple Silicon 与 Windows AMD64；两端原生报告均已产生。
- Rust 单元测试：33 个通过，0 个失败。
- Python 独立 Oracle：3 个通过，0 个失败。
- `cargo fmt --check`：通过。
- `cargo clippy --workspace --all-targets -- -D warnings`：通过，0 个警告。

补充工程证据：

- `--locked --offline` 发布模式全量测试通过。
- `x86_64-pc-windows-msvc` 目标离线 `cargo check` 通过；这只证明条件编译可通过，不代替 Windows 原生运行。
- 锁文件包含 50 个第三方包，许可证元数据缺失数量为 0。
- CLI 诊断报告 24 个立方体旋转，L8 全球相对面积闭合误差在当前平台输出为 `0.0`。
- 资产头 v0 迁移、v1 直读、v2 拒绝和旧摘要校验通过；决定见 [TD-002](TD-002资产头版本兼容.md)。
- 统一验证器生成的当前原生报告为 [platform-darwin-arm64.json](platform-darwin-arm64.json)。

## 跨平台复验结果

- Windows AMD64 原生报告的全部检查通过，双平台机器比较返回 `PASS`，规范 JSON、Rust/Cargo、离散证据和连续误差一致。
- Python 支持范围已明确为 `>=3.11`；Windows 3.11.9 与 macOS 3.13.14 均满足契约。
- 详细结论见 [E0 冻结验收报告](E0冻结验收报告.md)。

## 当前限制

- E0 已于 2026-10-08 通过双平台验收并正式冻结。
- 规范 JSON 已形成 [TD-001](TD-001规范JSON.md) 的 E0 有限子集决定；Unicode 标量保留、负零归一、指数、嵌套非有限数拒绝及 Windows 原生字节复现均有证据。

- 球谐实验只验证了低阶基函数和确定性键，尚未进行 P2/P3 全波段性能实验。
