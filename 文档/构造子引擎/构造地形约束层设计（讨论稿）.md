# 构造地形约束层设计

> **文档状态**
>
> - 文档类型：分层设计
> - 决策状态：已确认
> - 实现状态：未实现；定量参数待校准
> - 版本：0.1
> - 说明：L5 架构决定已确认。

本文讨论构造子引擎的 L5“构造地形约束层”。L5 读取已经通过验收的 L3 板块状态和 L4 边界动力学快照，将壳体背景与边界资格转换为连续、带方向、可组合和可解释的构造地形约束，为后续地形与材料模块提供稳定骨架。

关联：[构造引擎前置条件清单](构造引擎前置条件清单（讨论稿）.md) · [球面空间底座设计](球面空间底座设计（讨论稿）.md) · [板块状态层设计](板块状态层设计（讨论稿）.md) · [边界动力学代理层设计](边界动力学代理层设计（讨论稿）.md)。

## 一、L5 的职责与边界

### L5 负责

- 将大陆性、壳体厚度、浮力和相对热成熟代理转换为板块内部基底高程倾向。
- 将汇聚边界转换为缩短、增厚、抬升、海沟侧和弧侧等连续响应资格。
- 将离散边界转换为大陆张裂、过渡张裂、洋中脊和相对热沉降资格。
- 将走滑、压扭、张扭和三重点转换为方向性结构约束。
- 定义边界作用在球面两侧的距离衰减、非对称性和空间可解析范围。
- 组合多个构造来源，控制饱和、冲突和重复计权。
- 保存每个场值的来源、状态、置信和模型边界。
- 输出不可变、可验证的构造地形约束快照。

### L5 不负责

- 生成最终山峰、山脊、峡谷、河谷、海岸或岛屿几何。
- 模拟侵蚀、沉积、河流切割、冰川和风化。
- 指定具体岩性、土壤、植被或水体。
- 把构造资格直接当成最终高程或景观名称。
- 因为后续地图“不够壮观”而回写 L3 板块或 L4 边界类型。
- 将无历史代理解释为真实造山年代、板片深度或地质事件序列。

### 输入

```text

L2 earthlike-v1、世界规格与模型清单

├─ 壳体连续属性、壳体域和稳定核心候选

├─ BoundaryKinematicConstraint
├─ 汇聚／离散／走滑及混合资格
├─ 极性、三重点和更新代理
└─ 强度、置信、状态和组合策略
K01–K04 固定测试输入（测试模式下）
```

### 输出

```text
TectonicTerrainConstraintSnapshot
├─ 板块内部构造基底场
├─ 抬升／增厚连续资格场
├─ 沉降／张裂连续资格场
├─ 海沟侧／弧侧／洋中脊方向约束
├─ 走滑、压扭与张扭方向结构场
├─ 构造来源贡献账本

```

## 四、L5-D01：约束场语义、单位与来源账本

### 4.1 L5 输出的是条件，不是完成地形

L5 回答的是：

```text
哪里具有较高或较低的构造基底资格？
哪里更可能受到抬升、缩短、沉降或伸展影响？
影响倾向沿什么方向排列？
这些判断来自哪块板块、哪段边界和什么壳体组合？
```

它不直接回答“这里最终海拔多少”“有几座山峰”或“河流从哪里经过”。最终地形还要叠加多尺度起伏、材料响应、侵蚀沉积和水文调整。

### 4.2 四类权威输出

建议把构造地形状态分为四类：

| 类别 | 示例 | 数值语义 |
| --- | --- | --- |
| 背景倾向 | `basementElevationTendency` | 板块内部相对高／低基底资格，可有符号 |
| 作用资格 | `upliftQualification`、`subsidenceQualification` | 非负 `0～1` 或等价有界范围 |
| 方向约束 | `preferredStructureDirection`、`anisotropyStrength` | 球面切向方向／张量及强度 |
| 参考贡献 | `referenceElevationContribution` | 可选、带米单位的类地标定参考量，不是最终高程 |

背景倾向与作用资格是模型语义的核心。参考高程贡献用于让后续地形具有合理的垂向尺度，但必须保留“参考贡献”名称、模型版本、适用范围和置信状态。

### 4.3 为什么同时保留无量纲资格和参考米值

只保存无量纲资格，会让后续模块难以确定山地、洋盆和裂谷的垂向尺度；直接保存“最终海拔米数”又会制造虚假精确性。因此采用双层表达：

```text
无量纲构造资格
  = 稳定、可组合、可跨模块解释的核心状态

类地参考高程贡献
  = earthlike-v1 标定下的有界派生量
  = 后续地形求解的输入之一
  ≠ 最终地表高程
```

改变类地标定曲线会产生新模型版本，但不必改变原始资格来源。

### 4.4 标量、方向和对象引用的空间布局

遵循 L1：

- 基底倾向、抬升资格、沉降资格和参考贡献保存在单元中心；
- 来源边界和构造段保持独立线性对象身份；
- 方向约束保存为球面切平面向量或无向二阶结构张量；
- 跨单元传播或积分使用共享边通量／权重，不把投影像素当作距离；
- 网格覆盖是可重建索引，来源对象与场语义不依附某一固定分辨率。

对于“山系可能沿边界延伸”这类无首尾方向的约束，优先使用无向结构张量，避免同一轴线因向量正负翻转产生接缝。

### 4.5 正负倾向和非负资格分开

建议：

```text
basementElevationTendency：可正可负
referenceElevationContribution：可正可负
upliftQualification：非负
subsidenceQualification：非负
deformationQualification：非负
anisotropyStrength：非负
```

抬升和沉降资格不能提前相减成一个净值。若两者都较高，说明存在冲突或多过程叠加，需要由 D06 组合，而不是让 `+0.8` 与 `-0.8` 静默抵消成“没有构造作用”。

### 4.6 每个来源单独记账

每个单元或查询位置的构造状态都应能展开为来源贡献：

```text
ConstraintContribution
├─ contributionId
├─ sourceType：壳体背景／汇聚段／离散段／走滑段／三重点
├─ sourceObjectId：plateId / segmentId / junctionId
├─ responseKind
├─ rawQualification
├─ spatialWeight
├─ weightedQualification
├─ preferredDirection
├─ confidenceComponents
├─ combinationGroupId / additivityPolicy
├─ valueStatus / reasonCodes
└─ modelVersion / evidenceRef
```

来源账本是解释和调试的权威依据。为了渲染生成的合成场是派生缓存，不能覆盖来源明细。

### 4.7 避免重复计权

L4 已规定压扭、张扭、碰撞和俯冲是原始运动与壳体组合的派生资格。L5 必须继承 `combinationGroupId` 与 `additivityPolicy`：

- 汇聚和压扭不能被当作两个独立抬升来源无条件相加；
- 离散和张扭不能被重复计为两份沉降；
- 俯冲资格与缩短资格可以驱动不同空间响应，但共享同一运动来源预算；
- 三重点的三条边界需要联合限幅，不能在一个点堆叠三次最大响应。

D01 先确认数据语义，具体组合函数在 D06 决定。

### 4.8 置信度与作用强度分离

每项贡献同时保存：

```text
qualificationStrength
spatialWeight
confidenceComponents
valueStatus
```

低置信不能静默变成低资格，`UNKNOWN` 也不能编码为零。正式模式可以阻断必需输入不足的响应；预览模式可显示降权结果，但必须保留原始资格和降权原因。

### 4.9 参考高程贡献的标定边界

若输出带米单位的 `referenceElevationContribution`，必须满足：

- 只在固定 `earthlike-v1` 范围内有效；
- 使用版本化、有界的响应曲线；
- 保留未限幅前资格和限幅原因；
- 不宣称等于现实同类构造的唯一高度；
- 不直接参与海陆判定，海陆还需最终地形、水量和连通性；
- 不允许显示层的高程夸张回写该值。

未来开放重力、半径或其他行星预设时，需要重新标定，不能简单复用类地米值。

### 4.10 场值状态

沿用 L4 的明确状态：

```text
ZERO            已计算且资格／贡献接近零
UNKNOWN         适用但证据不足
NOT_APPLICABLE  当前来源或响应不适用
FAILED          应计算但模型或契约失败
```

另外可使用 `CLAMPED` 标记某个参考贡献因模型上限被限幅。`CLAMPED` 不是失败，但必须保留限幅前输入和上限版本。

### 4.11 不允许的直接分类

L5-D01 输出不能直接标记：

```text
山峰、山巅、山岭、山谷、峡谷
海沟、裂谷、洋中脊的完成地形对象
岛屿、海岸、湖盆或河流
最终海拔、坡度和地表材料
```

可以输出相应构造现象的空间资格和方向约束，但对象名称必须等待后续地形、材料及水文证据。

### 4.12 D01 建议规则

```text
L5 输出构造地形条件和参考贡献，不输出完成地形
背景倾向、作用资格、方向约束和参考高程贡献分开保存
无量纲资格是核心状态，类地米值只是版本化有界派生量
标量位于单元中心，线性来源保持对象身份，方向使用球面切向向量／张量
抬升与沉降资格分别保存，不能提前相减掩盖冲突
所有贡献进入来源账本，合成场只是可重建派生结果
继承 L4 组合组，防止汇聚／压扭等派生资格重复计权
资格、空间权重、置信和数值状态分别保存
ZERO、UNKNOWN、NOT_APPLICABLE、FAILED 和 CLAMPED 语义明确
L5 不能直接输出山峰、峡谷、海沟、裂谷、海岸或最终海拔
```

## 五、L5-D02：板块内部构造基底与壳体背景响应

板块边界响应叠加之前，L5 需要先建立连续的板块内部构造基底。该基底不是最终高程，而是壳体大陆性、厚度、浮力和相对热成熟状态共同形成的低频高低倾向。它为大陆、洋盆、过渡边缘和稳定核心提供不同的起始资格。

### 5.1 固定参考基准，不按世界重新居中

构造基底参考 `earthlike-v1` 的行星参考椭球和版本化垂向响应尺度：

```text
basementReferenceContribution
= f(continentality,
    crustThicknessProxy,
    buoyancyProxy,
    relativeMaturityProxy,
    oceanicThermalMaturityProxy,
    confidence)
```

不能按每个世界的最低值、最高值或平均值重新映射到固定高程范围，否则同一局部壳体状态会因远处大陆比例变化而获得不同基底。世界整体均值可以自然不同，最终水量和海平面在后续求解。

### 5.2 大陆性、厚度和浮力的基本方向

首版确认以下方向关系：

- 大陆性较高通常提高相对高基底资格；
- 海洋性较高通常提高相对低基底资格；
- 壳体较厚、浮力代理较高通常提高基底贡献；
- 壳体较薄、浮力代理较低通常降低基底贡献；
- 各关系使用有界响应，不能线性外推到无限高低；
- 属性冲突时保存分项与冲突状态，不由单一分类覆盖全部连续属性。

这些只是大尺度构造基底趋势。大陆壳仍可形成低盆地或被淹没，洋壳仍可因边界作用获得局部高地资格。

### 5.3 海洋性壳体的相对热成熟响应

若 L4 提供可信的 `renewalProximityProxy` 和 `thermalMaturityProxy`：

- 更新源附近的洋壳获得相对热隆升基底资格；
- 沿允许运动路径远离更新源时，相对热成熟度提高，基底倾向逐渐降低；
- 变化应平滑、受 plateId 和壳体域约束；
- 无可信更新源时保持 L3 海洋性背景，并将热状态标为未知，不能生成随机年龄梯度；
- 相对热响应没有绝对年代含义。

D02 负责将已有热成熟代理映射为基底贡献；D04 只处理扩张轴附近额外的边界响应，避免对同一热隆升重复计权。

### 5.4 过渡壳连续性

大陆性域与海洋性域之间应形成可解释的连续基底变化：

- 使用 L3 的过渡壳宽度和连续属性，不重新画一条零宽度边缘；
- 过渡响应按球面真实距离和壳体属性渐变；
- 不能直接等同于海岸、大陆架或陆坡；
- 过渡带低于当前可解析宽度时请求细化或降低置信；
- 跨立方球面接缝保持值和梯度连续。

最终大陆架和海岸还需要地形细节、沉积、水量和海洋连通。

### 5.5 稳定核心不等于高原

L3 的稳定核心候选主要影响：

- 基底场的低频连续性；
- 对短波构造扰动的响应上限；
- 后续形变较难穿透或更倾向沿边缘集中的资格；
- 结构置信和来源解释。

稳定核心本身不直接增加显著正高程，也不自动生成高原、山地或平原。其当前高低仍由大陆性、厚度、浮力和边界历史代理共同决定。

### 5.6 结构继承对基底的作用边界

`structuralInheritanceProxy` 主要调节空间连续性和后续边界响应定位，不应成为独立的大幅正负高程噪声。建议它可以：

- 调整局部响应容易集中还是分散；
- 提供低频方向性或域边缘资格；
- 影响 D03–D05 的响应形状参数范围；

但不能仅凭结构继承值制造一条山脉、盆地或断层。

### 5.7 场生成与平滑约束

基底场从权威壳体连续属性直接计算，再执行受域约束的有限平滑：

```text
1. 逐位置计算未平滑壳体贡献
2. 在同一壳体域和允许过渡带内进行球面低频正则化
3. 在真实壳体边缘保留可解释梯度
4. 检查面积加权均值、极值、梯度和接缝
5. 保存平滑前后分量及误差
```

平滑不能跨越不允许的壳体边界混合大陆和洋壳，也不能因 plateId 边界自动制造跳变：相邻板块若壳体连续，可保持基底连续；壳体确实不同则保留属性驱动的变化。

### 5.8 来源分解

每个位置至少保存下列分项：

```text
continentalityContribution
thicknessContribution
buoyancyContribution
oceanicThermalContribution
transitionBlendContribution
stableCoreModifier
structuralInheritanceModifier
combinedBasementTendency
referenceBasementContribution
confidence / valueStatus / evidence
```

修饰项与高程贡献分开，避免稳定核心或结构继承被误当作额外垂向能量。

### 5.9 D02 建议规则

```text
板块内部基底使用固定类地参考尺度，不按单世界极值或均值重标
大陆性、厚度和浮力提供有界的高低基底方向
洋壳热成熟只读取 L4 有来源代理，无源时保持未知而非随机填充
过渡壳形成连续基底梯度，但不等于海岸、大陆架或陆坡
稳定核心主要调节连续性和形变响应，不自动生成高原
结构继承调节定位和方向，不作为独立大幅高程噪声
有限平滑受壳体域约束，不因 plateId 边界强制跳变
所有分项、修饰、置信和限幅进入来源账本
```

## 六、L5-D03：汇聚边界的空间响应核

L4 已提供缩短、碰撞、俯冲、极性和斜向走滑资格。D03 将这些线性边界条件展开为球面上的连续空间响应，但仍只输出抬升、增厚、海沟侧、弧侧和方向结构资格。

### 6.1 从边界线到球面响应

每个汇聚子段建立局部坐标：

```text
s = 沿边界弧长
d = 到该子段的有符号球面横向距离
```

响应概念化为：

```text
response(s,d)
= alongBoundaryWeight(s)
 × crossBoundaryKernel(d, sideState)
 × qualificationStrength(s)
```

距离使用球面真实距离。最近点、方向和有符号侧别必须引用 L4 局部坐标，不能在地图投影平面测量。

### 6.2 响应宽度不是固定画笔

横向响应尺度应由版本化类地范围及以下输入共同限定：

- 汇聚强度和斜向程度；
- 碰撞或俯冲资格；
- 两侧壳体厚度、浮力和大陆性；
- 稳定核心与结构继承；
- 极性和极性置信；
- 当前空间分辨率和定位误差。

首版不求解真实岩石圈流变，因此输出的是受约束宽度资格和核参数，不宣称唯一现实宽度。不能让每段边界生成同宽、同高的人工山带。

### 6.3 大陆碰撞响应

高碰撞资格通常产生：

- 较宽的双侧缩短和壳体增厚资格；
- 沿边界连续的抬升资格；
- 受壳体差异影响的非对称响应；
- 与边界走向相关的无向结构张量；
- 斜向碰撞时与剪切方向共同作用的压扭资格。

若两侧都是高大陆性，响应不需要指定一条狭窄海沟。稳定核心可限制形变深入核心内部，使响应更偏向边缘，但不能简单把所有抬升推到核心外形成硬环。

### 6.4 已知极性的俯冲响应

极性可靠时，分别在下沉侧和上覆侧形成不同资格：

```text
下沉侧近边界：trenchDepressionQualification
上覆侧近边界：overridingMarginDeformationQualification
上覆侧偏移带：arcAlignmentQualification / upliftQualification
更远区域：受限衰减与可选弧后响应资格
```

偏移距离、宽度和强度由有界模型决定。`arcAlignmentQualification` 只表示构造对齐和热／岩浆相关响应的空间资格，不直接生成火山链或岛弧。

### 6.5 极性未知时的处理

若汇聚和俯冲资格可靠但极性为 `UNKNOWN`：

- 保留一般缩短和边界局部形变资格；
- 不生成单侧高置信海沟和弧侧偏移；
- 可以输出双侧低置信方向候选，但必须标为互斥假设；
- L5 不能随机选择一侧以获得更丰富地形。

当只有碰撞资格时，按碰撞核处理，不使用俯冲方向模板。

### 6.6 洋—洋、洋—陆和过渡组合

- 洋—洋俯冲可产生下沉侧海沟资格和上覆侧弧形对齐资格，但不自动生成岛屿。
- 洋—陆俯冲可产生海洋侧下沉资格与大陆边缘侧抬升／弧形对齐资格，但不自动保证陆地山脉。
- 过渡组合使用连续混合核，降低方向性细节置信，不强制选纯模板。
- 大陆碎片只有满足 L4 子段门槛时才改变核类型，不能造成高频左右跳变。

### 6.7 斜向汇聚和压扭

斜向汇聚需要同时保留：

- 法向缩短／抬升资格；
- 沿边界剪切资格；
- 合成的压扭方向结构；
- L4 的组合组和禁止重复相加策略。

D03 生成法向响应分量和压扭引用；具体剪切结构由 D05 统一处理，避免同一走滑分量在两个模块重复创建垂向贡献。

### 6.8 沿边界连续和端部衔接

相邻且兼容的汇聚子段应在端部连续衔接。不能让每个 segmentId 两端都机械衰减到零，否则会沿长山带形成周期性缺口。

建议：

- 相同父 boundaryId、类型兼容且信号连续的子段共享端部权重；
- 类型转换处使用过渡核；
- 三重点端部交给 D05 联合处理；
- 真实未解析缺口保留低置信，不由邻段跨越填满；
- 短碎片子段不产生独立最大响应峰。

### 6.9 最近边界歧义

某位置可能同时接近多条汇聚边界，或在弯曲边界内侧存在多个最近点。D03 必须：

- 保留所有达到贡献门槛的来源；
- 不只选择欧氏最近的一条线；
- 使用球面距离、侧别、弧长范围和来源置信计算空间权重；
- 把重叠交给 D06 有界组合；
- 在几何歧义处降低方向置信而不制造尖峰。

### 6.10 输出贡献

每个汇聚来源可产生：

```text
shorteningContribution
crustalThickeningQualification
upliftQualification
trenchDepressionQualification
overridingMarginQualification
arcAlignmentQualification
convergenceStructureTensor
spatialKernelParameters
confidence / valueStatus / evidence
```

其中只有通过类地响应标定的部分才生成参考米值；其余保持无量纲资格。

### 6.11 D03 建议规则

```text
汇聚响应以球面弧长和有符号真实横向距离展开
响应尺度由运动、壳体、结构和置信共同约束，不使用统一宽度画笔
大陆碰撞产生较宽双侧缩短／增厚资格，不强制狭窄海沟
可靠俯冲极性允许区分下沉侧海沟资格与上覆侧偏移响应
极性未知时保留一般缩短，不随机选择单侧海沟／弧侧
洋洋、洋陆和过渡组合使用不同但连续的资格核
斜向汇聚保留法向与剪切来源并防止重复计权
兼容子段端部连续衔接，不逐段机械衰减到零
多边界和最近点歧义保留多来源，交由 D06 有界组合
L5 不直接生成山脉、海沟、岛弧、火山链或最终高程
```

## 七、L5-D04：离散边界的裂谷、洋中脊与热响应核

D04 读取 L4 的伸展、大陆张裂、过渡张裂、海底扩张和张扭资格，将离散边界展开为空间连续的轴部、肩部和方向约束。洋壳大尺度热成熟基底已由 D02 处理；D04 只负责边界源附近的额外构造响应，避免重复计算。

### 7.1 通用伸展响应

所有可信离散段均可形成：

```text
extensionQualificationField
divergenceNormalDirection
riftOrRidgeAlignmentTensor
localizationConfidence
```

伸展方向主要沿边界法向，轴线方向沿边界切向。斜向离散同时保留剪切方向，交给 D05 形成张扭组合。

### 7.2 大陆张裂响应

大陆张裂资格可以产生：

- 轴部伸展与沉降资格；
- 两侧裂谷肩部的受限抬升资格；
- 沿边界方向的结构张量；
- 受结构继承控制的局部集中／分散；
- 两侧大陆壳不对称时的非对称核。

轴部沉降和肩部抬升必须属于同一 `combinationGroupId`，不能被当成多个独立最大过程。L5 不直接生成裂谷断崖、断陷盆地或具体裂谷宽度。

### 7.3 过渡张裂响应

过渡壳背景下：

- 大陆裂谷核与洋壳扩张核按连续资格混合；
- 可保留不对称轴部和两侧不同衰减；
- 响应置信度受过渡壳覆盖和历史未解析状态限制；
- 不能通过一次分类把过渡带全部改为洋盆；
- 相邻兼容子段应连续衔接。

### 7.4 洋中脊资格响应

高海底扩张资格和更新源可产生：

- 扩张轴附近的相对热隆升资格；
- 轴线方向结构约束；
- 两侧大致相反的扩张方向；
- 沿板块内部逐渐转交给 D02 热成熟基底的连续衔接；
- 斜向扩张时的张扭引用。

中央裂谷是否显著取决于扩张强度和未来更细模型，首版不强制每条洋中脊都有中央凹槽。

### 7.5 D02 与 D04 的防重复边界

职责固定为：

```text
D02：板块内部的低频热成熟基底趋势
D04：扩张轴附近的局部离散响应和轴向结构
```

二者共享更新源谱系，但使用不同 `responseKind` 和组合组。D06 组合时检查同源预算，避免热隆升背景与轴部隆升无上限相加。

### 7.6 无更新源或低置信源

若边界有离散运动但不满足洋壳更新源条件：

- 仍可保留一般伸展、张裂或过渡资格；
- 不生成高置信洋中脊轴部热隆升；
- 不向板块内部传播新的热成熟梯度；
- 缺失状态必须是 `UNKNOWN` 或 `NOT_APPLICABLE`，不能用零值伪装。

### 7.7 沿线和横向核

离散响应同样使用球面弧长 `s` 和有符号横向距离 `d`：

- 兼容段端部连续拼接；
- 类型转换处使用过渡核；
- 三重点端部由 D05 联合处理；
- 核宽受壳体组合、扩张强度、结构继承和分辨率约束；
- 不按投影像素或固定画笔宽度绘制。

### 7.8 输出贡献

```text
extensionContribution
riftAxisSubsidenceQualification
riftShoulderUpliftQualification
transitionRiftQualification
ridgeAxisUpliftQualification
ridgeAlignmentTensor
divergenceSpatialKernelParameters
sourceAndThermalStateRefs
confidence / valueStatus / evidence
```

### 7.9 D04 建议规则

```text
离散边界输出伸展、轴部、肩部和方向资格，不直接生成裂谷／洋中脊地形
大陆张裂可同时产生轴部沉降和受限肩部抬升，二者共享来源预算
过渡张裂使用连续混合核，不把过渡带一次改成洋盆
高置信洋壳扩张源才产生洋中脊轴部热隆升资格
D02 负责低频热成熟基底，D04 负责扩张轴局部响应
无可信更新源时保留一般伸展，但不生成高置信轴部热响应
响应宽度使用真实距离及壳体／结构条件，不使用固定像素画笔
斜向离散保留剪切来源并交给 D05 组合
```

## 八、L5-D05：走滑、压扭、张扭与三重点方向约束

纯走滑主要改变结构方向和局部形变组织，并不天然产生大幅净抬升或沉降。D05 只有在压扭、张扭或可靠的局部组合证据存在时，才增加相应垂向资格。

### 8.1 走滑方向结构场

走滑段产生：

```text
shearAlignmentTensor
shearLocalizationQualification
signedShearDirectionRef
structuralLinearityQualification
```

无向结构张量表示沿边界的线性组织，带符号切向速度另存，用于解释相对滑动方向。张量不能直接变成一条精确断层线。

### 8.2 近纯走滑的垂向边界

近纯走滑状态默认：

- 提高方向结构和局部形变资格；
- 不自动产生显著净抬升或沉降；
- 可以允许低幅、成对或未定号的局部垂向候选，但必须低置信且不进入正式高程贡献；
- 不生成断层谷、拉分盆地、陡崖或地震破裂对象。

这样避免所有走滑边界都被画成山脉或沟槽。

### 8.3 压扭响应

压扭资格由汇聚与剪切共同产生：

- 继承 D03 法向缩短和抬升资格；
- 增加沿边界方向的剪切局部化和各向异性；
- 可使抬升响应沿结构方向偏移或分段集中；
- 不增加一份独立“压扭能量”；
- 保留碰撞／俯冲及极性证据。

垂向贡献预算仍来自相同汇聚组合组，D05 主要调整形状、方向和局部化。

### 8.4 张扭响应

张扭资格由离散与剪切共同产生：

- 继承 D04 的轴部沉降、肩部或洋中脊资格；
- 增加斜向剪切和分段局部化；
- 可以提高局部沉降候选和方向性，但不直接生成拉分盆地；
- 不重复增加离散来源预算。

### 8.5 转换边界

具有高转换资格的走滑段连接扩张体系时：

- 提供连接两个扩张段的线性结构约束；
- 不沿转换段延续洋中脊轴部热隆升；
- 不把更新源从一条扩张段穿过转换段随意传播；
- 端点和连接方向必须引用 L4 拓扑证据；
- 具体转换断层地形等待后续局部地形模型。

### 8.6 方向张量的组合

多个方向约束相遇时不能简单平均角度。建议累加球面切平面中的无向二阶张量，再提取：

```text
主结构轴
次结构轴
directionalCoherence
anisotropyStrength
```

若两个同强度方向近似正交，方向一致性应降低并保留多源，而不是得到一条没有物理来源的对角线。

### 8.7 三重点联合响应

三重点附近：

```text
1. 分别计算三条边界的未组合贡献
2. 通过共同 junctionId 建立联合组合组
3. 检查速度闭合与各端部置信
4. 对同类垂向响应执行有界联合
5. 对方向张量计算一致性和冲突
6. 保留每条分支来源及未解析区
```

三重点不能把三条最大响应简单相加形成尖峰，也不能用一条主边界覆盖另外两条。若闭合失败或端部退化，联合区降低置信或标为未知。

### 8.8 结构继承的调制

结构继承可以调整走滑、压扭和张扭响应的局部化程度及方向连续性，但：

- 不能改变 L4 原始切向速度符号；
- 不能凭空创建走滑段；
- 不能绕过组合组增加额外能量；
- 调制幅度必须有界并进入贡献账本。

### 8.9 输出贡献

```text
shearAlignmentContribution
structuralLinearityQualification
transpressionLocalizationModifier
transtensionLocalizationModifier
transformConnectorQualification
junctionBlendConstraint
directionTensor / coherence / anisotropy
confidence / valueStatus / evidence
```

### 8.10 D05 建议规则

```text
纯走滑主要产生方向结构和局部化资格，不自动制造显著高差
压扭继承汇聚预算、张扭继承离散预算，不增加独立能量
转换段连接扩张体系，但不延续洋中脊轴部热隆升
方向使用无向球面结构张量，并另存有符号剪切方向
多个方向冲突时降低一致性并保留多源，不简单平均成假方向
三重点逐支计算后联合限幅，防止一点叠加出构造尖峰
闭合失败和退化端部显式降低置信或未知
结构继承只调节局部化和方向连续性，不创建新走滑来源
L5 不直接生成断层、地震破裂、断层谷或拉分盆地
```

## 九、L5-D06：多来源组合、冲突、饱和与跨尺度一致性

一个位置可能同时受到壳体基底、碰撞、俯冲、张裂、洋中脊、走滑和三重点影响。D06 负责把这些贡献组合为稳定场，同时保留每个来源和冲突，避免简单相加、强者覆盖或因正负抵消丢失过程信息。

### 9.1 固定组合顺序

建议执行：

```text
1. 计算每个来源的未组合 ConstraintContribution
2. 按 combinationGroupId 处理同一运动来源的派生资格
3. 在每种 responseKind 内组合兼容贡献
4. 计算抬升／沉降等相反资格的共存和冲突
5. 组合方向结构张量和一致性
6. 产生有界参考高程贡献
7. 生成多尺度摘要和来源账本索引
```

不能先把全部来源相加后再猜测它们来自什么过程。

### 9.2 同源组合预算

同一 L4 运动来源可能派生多个解释。例如斜向汇聚同时拥有缩短、碰撞、俯冲和压扭资格。建议每个组合组具有：

```text
sourceBudget
allowedResponseKinds
sharedComponents
exclusiveHypotheses
normalizationPolicy
```

- 压扭共享汇聚和走滑来源，不增加新预算；
- 张扭共享离散和走滑来源；
- 极性未知的 A／B 两侧响应假设互斥，不能同时按满强度实现；
- 裂谷轴部和肩部是同一张裂系统的成对响应；
- 三重点分支共享联合上限，但各来源仍保留。

### 9.3 同类贡献的有界组合

多个独立来源产生同类资格时，使用交换律成立、顺序无关的饱和组合，例如版本化的有界并集或响应曲线。基本要求：

- 两个中等来源可以增强结果；
- 结果不能因来源数量无限增长；
- 增加一个极弱来源不会显著改变强场；
- 组合顺序、线程和区块不影响结果；
- 原始贡献与组合前后值全部可追溯。

具体函数留待原型校准，不默认简单求和、最大值或平均值适用于所有字段。

### 9.4 相反过程和冲突指数

抬升与沉降资格分别组合：

```text
combinedUpliftQualification
combinedSubsidenceQualification
conflictIndex
```

参考高程贡献可以通过有界响应得到净值，但不能覆盖前两项。若两项都高而净值接近零，应表现为高 `conflictIndex`，表示多个强过程竞争，而不是“无构造作用”。

冲突处理需要保存：

- 各侧来源和组合组；
- 哪些资格可共存、互斥或待后续材料模型解决；
- 净参考贡献的求解方式；
- 限幅和置信传播。

### 9.5 参考高程的有界求解

参考贡献由：

```text
板块内部基底
+ 有界边界响应
+ 成对／非对称结构关系
→ referenceTectonicElevationContribution
```

求解不能按当前世界极值重新缩放，也不能因为多个边界接近就线性无限叠加。上限和下限是 `earthlike-v1` 的模型响应边界，并保留 `CLAMPED` 证据。

这仍不是最终高程；后续地形、材料与侵蚀可以改变局部高度，但必须保留构造来源。

### 9.6 方向结构组合

方向贡献在同一球面切平面中转换为无向二阶张量并加权组合。输出：

```text
principalDirection
secondaryDirection
anisotropyStrength
directionalCoherence
directionConflictIndex
```

- 同向来源提高一致性和各向异性；
- 正交或多方向来源降低一致性；
- 低一致性时不能只输出一条高置信主轴；
- 跨单元比较使用平行移动或等价球面方法，不能直接比较不同切平面的二维角度。

### 9.7 三重点与近邻边界联合限幅

共同 junctionId 的三条边界先分别计算，再进入联合组合组。对同一空间邻域：

- 垂向资格执行有界组合；
- 方向张量保留多分支；
- 闭合或端部置信限制联合结果；
- 不以距离最近的一条边界覆盖其他分支；
- 不生成点状无限尖峰。

靠近但不属于同一三重点的独立边界仍可共同贡献，其关系通过来源账本而不是强制合并拓扑表达。

### 9.8 场函数与网格采样分离

边界响应应尽可能由来源对象、球面距离和版本化核定义为可查询场函数，再采样到 L1 单元。这样：

- 局部细化重新采样同一来源函数；
- 不因子单元随机生成新的构造信号；
- 边界跨立方球面接缝仍连续；
- 缓存删除后可从来源和模型重建；
- 误差可以由场梯度和采样尺度估计。

### 9.9 不同字段使用不同聚合规则

父级摘要不能对所有字段只做一次平均：

| 字段 | 建议聚合 |
| --- | --- |
| 基底／参考高程贡献 | 按真实面积加权均值，同时保存极值范围 |
| 抬升／沉降等资格 | 面积均值＋最大值＋超过门槛的覆盖率 |
| 方向约束 | 面积和强度加权结构张量，再计算一致性 |
| 冲突指数 | 面积统计、最大值和高冲突覆盖率 |
| 置信度 | 分项统计、最低必要置信和未知覆盖率 |
| 来源账本 | 按 sourceObjectId 聚合贡献份额，不丢失主要来源 |

资格峰值若只占极小面积，不能让整个父单元都表现为最大资格；只保存均值又会遗漏狭窄强带，因此需要多统计量并存。

### 9.10 细化请求

L5 可以向 L1 协调器提交细化请求，常见条件包括：

- 场梯度或插值误差过高；
- 边界核宽接近当前单元尺寸；
- 抬升与沉降冲突集中；
- 方向一致性快速变化；
- 极性、类型或壳体组合发生转换；
- 三重点联合区当前无法解析。

细化请求遵循 L1 优先级和预算，不得自行拆网格。预算不足时保存误差和未解析状态。

### 9.11 跨尺度稳定和父级不可变

同一模型下细化应揭示更多空间细节，但：

- 父级权威快照不被原地改写；
- 子级补丁引用相同来源对象和组合版本；
- 子级面积聚合应在容差内回到父级摘要；
- 发现结构冲突时创建新上游快照或失败，不静默修补来源；
- 显示缩放不触发重新组合；
- 地貌级细节不能反向改变全球构造基底。

### 9.12 确定性归约

并行组合必须按稳定 sourceObjectId、responseKind 和 contributionId 排序，使用规定的数值归约方式。随机访问、线程数量和区块边界不能改变：

- 贡献身份；
- 组合组预算；
- 合成资格和参考贡献；
- 方向张量；
- 限幅和冲突状态。

### 9.13 D06 建议规则

```text
先保留逐来源贡献，再按组合组、响应类型和冲突顺序组合
同源派生资格共享预算，互斥假设不能同时满强度实现
同类独立贡献使用顺序无关的有界组合，不无限线性叠加
抬升和沉降分别组合，并用 conflictIndex 表达强过程竞争
参考高程在固定类地范围内有界求解，不按单世界极值重标
方向以球面结构张量组合，正交冲突降低一致性而非生成假方向
三重点和近邻来源联合限幅但保留所有来源
场函数与网格采样分离，细化重采样同一来源
不同字段按各自语义聚合，资格保留均值、峰值和覆盖率
细化通过 L1 协调器，父级不可变，聚合在容差内闭合
并行归约使用稳定顺序和版本化数值规则
```

### 10.2 身份和原子提交

快照身份至少绑定：


### 10.3 状态体系

```text

validationStatus = NOT_RUN / PASSED / CONDITIONAL / FAILED
```

权威场缺口、来源引用断裂、非有限值、组合不确定性被编码为零、跨尺度不闭合等属于阻断错误。可选参考米值或低置信局部细节缺失，只有契约明确允许时才可能形成条件快照。正式 L6 默认只接收 `COMPLETE + PASSED`。

### 10.8 关系测试

至少包括：

- 整体旋转世界后标量等价、方向张量随旋转正确变换；
- 改变地图投影和显示高程夸张不改变权威场；
- 改变海平面不改变构造基底和边界响应；
- 移除某个来源只影响其依赖贡献和组合结果；
- 交换俯冲极性时非对称响应正确翻转；
- 只改变米值标定不改变无量纲资格；
- 提高空间精度后子级聚合回父级摘要；
- 线程、区块、缓存和访问顺序不改变贡献及组合结果。
