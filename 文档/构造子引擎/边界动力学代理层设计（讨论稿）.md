# 边界动力学代理层设计

> **文档状态**
>
> - 文档类型：分层设计
> - 决策状态：已确认

本文讨论构造子引擎的 L4“边界动力学代理层”。L4 读取已经通过验收的 L3 板块状态快照，在共享边界上计算两侧板块的局部相对运动、连续强度、分类资格和置信状态，为 L5 构造地形约束层提供有方向的边界条件。

关联：[构造引擎前置条件清单](构造引擎前置条件清单（讨论稿）.md) · [球面空间底座设计](球面空间底座设计（讨论稿）.md) · [全球规格层设计](全球规格层设计（讨论稿）.md) · [板块状态层设计](板块状态层设计（讨论稿）.md)。

## 一、L4 的职责与边界

### L4 负责

- 沿每条共享边界建立稳定的球面局部坐标。
- 计算两侧板块在边界位置的相对切向速度。
- 将相对速度分解为边界法向和沿边界切向分量。
- 保存汇聚、离散和走滑的连续强度资格。
- 派生低活动、汇聚、离散、走滑、斜向混合和不确定状态。
- 沿长边界提取有稳定起止位置的动力学分段。
- 结合两侧壳体倾向，形成汇聚、离散等边界的后续细分类资格。
- 显式处理三重点、短边界、低速区和低置信区。
- 输出可验证、可追溯的不可变边界状态快照。

### L4 不负责

- 求解真实地幔对流、岩石圈应力或黏弹性形变。
- 模拟地震、火山喷发和精确断层几何。
- 直接生成山脉、海沟、裂谷、洋中脊或断层盆地。
- 用分类标签直接写入最终高程。
- 在分类不清时为了地图完整而强制指定边界类型。
- 修改 L3 的板块区域、plateId、boundaryId、壳体域或运动代理。

```

├─ 相对速度及法向／切向连续分量
├─ 汇聚／离散／走滑连续资格

```

## 四、L4-D01：局部相对运动与连续分类基础

### 4.1 连续分量是权威数据

边界运动不应先被压缩成一个互斥标签。L4 首先保存连续的相对运动分量，再派生便于查询和显示的类别：

```text
权威连续量
├─ relativeVelocity
├─ normalRate
├─ tangentRate
├─ relativeSpeed
└─ obliquity
        ↓ 版本化分类规则
派生标签和连续资格
```

这样可以表达斜向汇聚、斜向张裂、汇聚—走滑转换和低速过渡，而不会因为一个标签丢失另一方向的运动信息。

### 4.2 边界采样位置

L3 保存权威共享边界及其多尺度球面几何。L4 在边界弧段内部建立采样点，不直接在尖角顶点上计算唯一方向，因为顶点可能连接两段不同切线，在三重点处更不存在单一边界方向。

每个采样至少保存：

```text
boundaryId
sampleId
沿边界的规范弧长参数 s
球面单位位置 r
分析用边界切向 t
从板块 A 指向板块 B 的边界法向 nAB
局部几何尺度和来源层级
两侧 plateId 与壳体状态引用
```

`s` 使用从边界规范起点出发的球面弧长或归一化弧长。边界显示折线加密不能改变已有采样点身份。

### 4.3 稳定的局部坐标

在采样点 `r` 处：

- `t` 位于球面切平面，并沿 boundaryId 的规范方向；
- `nAB` 位于球面切平面，垂直于 `t`，从板块 A 内部指向板块 B 内部；
- `r` 是向外的球面法向。

方向可概念化为：

```text
nCandidate = normalize(r × t)
通过边界两侧稳定归属查询，选择真正从 A 指向 B 的符号
```

板块 A、B 按 L3 的稳定 plateId 顺序确定，不能按屏幕左右、折线绘制顺序或当前地图投影确定。交换 A/B 时，`nAB`、相对速度和有符号分量应按约定一致变号，而物理分类保持等价。

### 4.4 分析几何与显示几何分离

若直接使用最高分辨率折线的逐段法向，细小锯齿会让法向分量正负反复跳变，制造虚假的汇聚—离散交替。因此 L4 使用版本化的“分析几何尺度”：

- 从 L3 保拓扑的多尺度边界几何中选择适合动力学计算的层级；
- 用球面弧长窗口估计稳定切向，而不是用单个像素化短边；
- 在真实高曲率、速度变化或壳体交会处请求加密采样；
- 显示层可以进一步细分曲线，但不得改变分析法向和分类；
- 分析尺度改变属于模型版本或新快照，不能随缩放即时改变结果。

这不会抹去真实边界弯折；它只防止网格和渲染细节被误解为构造信号。

### 4.5 相对速度计算

对共享边界两侧的板块 A、B：

```text
vA(r) = R × (ωA × r)
vB(r) = R × (ωB × r)
vRelative = vB - vA

normalRate  = vRelative · nAB
tangentRate = vRelative · t
relativeSpeed = length(vRelative)
```

在此方向约定下：

- `normalRate < 0`：两侧相向；
- `normalRate > 0`：两侧分离；
- `tangentRate` 的正负：表示沿边界的相对滑动方向；
- `abs(tangentRate)`：表示走滑分量强度。

`vRelative` 应位于局部球面切平面；法向和切向分解应在数值容差内重建原相对速度。

### 4.6 三个连续资格

建议从有符号分量派生三个非负连续资格：

```text
convergenceSignal = max(0, -normalRate)
divergenceSignal  = max(0,  normalRate)
strikeSlipSignal  = abs(tangentRate)
```

经过活动尺度归一化和低速死区处理后，它们形成 `0～1` 或等价范围的强度资格。归一化只用于模型比较和下游权重，不覆盖原始有单位速度。

同一点可以同时具有较高的汇聚资格和走滑资格，这表示斜向汇聚；离散资格与走滑资格并存则表示斜向张裂。汇聚和离散来自同一个有符号法向量，在同一点不会同时为正。

### 4.7 标签体系

建议的派生状态为：

| 状态 | 连续信号特征 | 含义 |
| --- | --- | --- |
| 低活动 | 总相对速度低于低速门槛 | 运动关系可计算，但当前信号很弱 |
| 汇聚 | 相向法向分量明确占主导 | 为后续碰撞／消减分析提供资格 |
| 离散 | 分离法向分量明确占主导 | 为后续张裂／扩张分析提供资格 |
| 走滑 | 切向分量明确占主导 | 为后续线性结构分析提供资格 |
| 斜向汇聚 | 相向与切向分量均显著 | 两种已知分量共同存在 |
| 斜向离散 | 分离与切向分量均显著 | 两种已知分量共同存在 |
| 过渡／混合 | 主导关系在稳定门槛之间 | 信号存在，但不适合压缩为单一主类 |
| 不确定 | 输入、几何、尺度或数值证据不足 | 无法可靠判断，不等于真实混合 |

“混合”与“不确定”必须分开：混合表示多个可信分量并存；不确定表示证据质量不足。低活动也不等于不确定，低速关系可以被高置信地识别为低活动。

### 4.8 门槛的基本结构

D01 暂不冻结具体速度数字，但确认分类不能只比较分量大小，还要同时使用：

```text
绝对低速门槛：判断信号是否足够显著
分量占比门槛：判断法向或切向是否主导
混合区间：避免 49% 与 51% 导致类别剧烈翻转
数值误差门槛：覆盖几何与浮点误差
最小持续长度：由 D02 判断短暂越界是否形成独立分段
```

门槛来自 `earthlike-v1`、运动模型版本和分析尺度，并进入证据。高级偏好不能直接修改分类门槛；活动度偏好改变上游运动尺度，分类规则仍保持一致。

### 4.9 强度和置信度分离

运动信号强度回答“相对运动有多明显”，置信度回答“这个判断有多可靠”。二者不能合并成一个数值。

置信度至少考虑：

- L3 运动代理置信度；
- 边界几何和局部法向的稳定性；
- 当前分析尺度是否足以解析短边界或高曲率；
- 数值是否接近低速或分类门槛；
- 两侧壳体状态是否完整；
- 是否临近三重点或退化拓扑。

强信号也可能低置信，例如极短边界的法向方向不稳定；弱信号也可能高置信，例如两板块确实近似共动。

### 4.10 特殊情况

- **欧拉轴附近**：一侧或两侧局部速度可以很低，按真实相对速度处理，不从邻区复制方向。
- **近似共动板块**：稳定输出低活动，不强制走滑或汇聚。
- **高曲率边界**：增加采样并使用稳定分析切线，不能按单个顶点分类。
- **很短的边界**：若不足以稳定估计方向，降低置信或标为未解析。
- **三重点附近**：每条入射边界分别建立局部坐标，三重点本身不拥有单一分类。
- **分量过零点**：保留连续零点和邻近变化，是否形成分段由 D02 决定。
- **边界方向反转**：有符号量按约定反转，汇聚／离散／走滑物理状态不得改变。

### 4.11 D01 证据

每个采样点或连续采样区间至少保存：

```text
boundaryId、两侧 plateId 和规范弧长位置
分析几何版本、采样尺度、r／t／nAB
两侧局部速度与相对速度
normalRate、tangentRate、relativeSpeed
三个连续资格和派生标签
强度、置信度及其组成原因
适用门槛和分类模型版本
低速、过零、短边界或三重点邻近标记
```

这些证据回答“为什么这一段被视为斜向汇聚”，但不回答“这里一定形成多高的山脉”；后一个问题属于 L5。

### 4.12 D01 建议规则

```text
边界动力学以连续相对速度和法向／切向分量为权威数据
边界局部坐标使用球面向量和稳定 A/B 方向，不依赖地图投影
分析几何与显示几何分离，避免折线锯齿制造虚假分类
分别保存汇聚、离散和走滑三个非负连续资格
斜向关系保留多分量，不能强制压成单一标签
混合表示可信多分量，不确定表示证据不足，低活动表示可信弱信号
绝对低速、分量占比、误差和持续长度门槛分别管理
信号强度与模型置信度分开
三重点逐边计算，短边界和近轴低速允许降置信或未解析
L4 只提供边界条件，不直接生成构造地形和高程
```

## 五、L4-D02：长边界采样、动力学分段与尺度稳定

一条 L3 共享边界可能跨越数千公里，其局部法向、相对运动方向和强度会沿线变化。L4 不能给整条 boundaryId 只保存一个类别，也不能把每个采样点都变成独立短段。D02 的目标是在保留连续运动场的同时，提取数量有限、位置稳定、具有明确证据的动力学分段。

### 5.1 三个层次分开

建议把边界表达分成三层：

```text
L3 boundaryId
└─ 一条权威共享边界及其拓扑身份
   ├─ L4 连续采样场
   │  └─ normalRate、tangentRate、置信度等连续量
   └─ L4 kinematicSegment
      └─ 从连续场派生的稳定动力学区间
```

连续采样场是分类证据，动力学段是查询、显示和下游消费单位。分段不能替代原始 boundaryId，也不能反向修改 L3 邻接关系。D03—D05 可以在动力学段内部继续细分壳体组合或构造资格，但不应破坏 D02 的基础运动证据。

### 5.2 规范弧长参数

每条边界沿用 D01 的规范方向，以球面真实弧长定义参数：

```text
s = 从规范起点到当前位置的球面弧长
u = s / boundaryLength，范围 0～1
```

采样、最小段长和变化尺度使用真实距离，不使用折线点数量或屏幕像素。规范起点、方向和长度来自固定边界几何版本；显示折线加密不能改变 `s`、`u` 或分段位置。

### 5.3 初始采样与三重点端部

每条边界首先建立确定性的基础采样：

- 包含边界内部的固定弧长节点和几何控制点；
- 在高曲率候选区预置额外节点；
- 边界端点若连接三重点，在三重点两侧分别保留端部邻域标记；
- 不在三重点本身强求唯一切线和分类；
- 短边界至少保留满足局部坐标估计所需的采样，但不足时必须降低置信。

端部缓冲距离按真实尺度和分析层级版本化，不能因当前缩放级别改变。

### 5.4 自适应加密条件

在相邻采样点之间评估中点或误差估计，满足任一条件时请求加密：

```text
边界切向旋转超过几何容差
normalRate 或 tangentRate 的插值误差超过容差
相对速度大小变化超过容差
法向分量可能发生可信过零
分量占比可能穿过分类门槛
置信度或输入完整性发生明显变化
存在三重点邻域、短边界或后续壳体交会候选
```

加密是有界的：同时受最小采样间距、最大递归层级、误差预算和 L1 细化能力限制。达到上限仍无法解析时，相关区间标为 `UNRESOLVED` 或降低置信度，不能继续无限细分或猜测类别。

候选计算可以并行，但加密树、并列裁决和样本标识必须按规范弧长及稳定规则提交，避免线程顺序改变分段。

### 5.5 硬断点与软断点

分段候选点分为两类：

**硬断点**不得被普通平滑或合并跨越：

- boundaryId 的起点和终点；
- 三重点端部及其显式未解析邻域边缘；
- 持续且高置信的 `normalRate` 正负转换；
- 输入数据或分析几何版本的不连续处；
- 适用模型状态从有效转为失败／未解析的位置。

**软断点**只有达到持续距离和显著性门槛才形成正式分段：

- 主导分量比例穿过汇聚、离散、走滑或混合门槛；
- 强度等级发生持续变化；
- 置信度等级发生持续变化；
- 边界曲率或运动斜向角出现显著但连续的转折。

单个采样点越过门槛只能成为候选，不能自动创建新段。

### 5.6 空间迟滞与防闪烁规则

这里的“迟滞”是沿空间区间稳定分类的规则，不是时间演化。建议同时使用进入门槛、退出门槛和最小持续长度：

```text
进入某主导状态：信号超过较高进入门槛并持续足够距离
保持该状态：允许在较低退出门槛以上短暂波动
离开该状态：低于退出门槛达到足够距离，或遇到硬断点
```

为避免结果依赖从边界哪一端开始扫描，正式实现应使用对称区间判定：先提取所有超过进入门槛的核心区，再向两侧扩展到退出门槛，最后按真实距离处理短缺口。规范方向只用于标识和有符号量，不应改变无符号分类区间。

### 5.7 短暂异常怎样处理

小于最小持续长度的短区间不能一律删除。建议按原因处理：

| 短区间类型 | 处理 |
| --- | --- |
| 低幅门槛抖动 | 合并到两侧一致的主段，并保留抖动摘要 |
| 两侧类别不同的短过渡 | 保存为过渡区，不强行归入任一侧 |
| 高置信法向过零 | 保留零点或转换事件，即使不形成宽分段 |
| 低置信／未解析区 | 保留置信缺口，不能被高置信邻段吞掉 |
| 强而窄的真实异常候选 | 保存为局部事件候选，等待更高空间证据，不立即升级为独立段 |

最小段长是表达门槛，不是物理上否认所有更小结构。无法解析的窄现象可以保存候选和升级条件。

### 5.8 相邻分段的合并

相邻候选段只有同时满足以下条件时才允许合并：

- 主状态和斜向资格兼容；
- 中间没有硬断点；
- 连续分量、斜向角和置信度差异在合并容差内；
- 合并不会覆盖可信的正负法向转换；
- 合并后的段内变化仍可由摘要和误差上限表达。

若一个短段夹在两个不同类别之间，不按“较长一侧获胜”简单吞并，而应结合连续量形成过渡区或保留未解析状态。

### 5.9 分段摘要不覆盖连续证据

每个 `kinematicSegment` 至少保存：

```text
segmentId / boundaryId
sStart、sEnd 和球面端点
主状态与斜向／混合资格
normalRate、tangentRate、relativeSpeed 的最小／最大／长度加权均值
三个连续资格的统计与覆盖比例
置信度范围和主要降级原因
内部过零点、局部异常和未解析区引用
采样密度、误差上限和停止原因
来源模型、门槛版本和对象谱系
```

段标签来自整个区间的连续证据，不能只取中点标签或采样点多数票。L5 可使用分段摘要进行快速查询，也可在需要时读取连续采样场。

### 5.10 分段身份与谱系

`segmentId` 建议由以下稳定信息派生：

```text
boundaryId
+ 分段模型版本
+ 规范化区间锚点
+ 创建原因／断点身份
```

同一快照中，缓存删除、线程数、显示缩放和访问顺序不能改变 segmentId。若模型版本、分析尺度或门槛改变导致分段移动、合并或拆分，应创建新快照，并记录：

- 延续：新段主要对应一个旧段；
- 拆分：一个旧段对应多个新段；
- 合并：多个旧段对应一个新段；
- 新增／消失：由新证据或模型边界造成。

不能假设不同模型版本中的第 N 段天然是同一个对象。

### 5.11 跨尺度一致性

分段权威结果绑定固定的分析尺度和误差预算：

- 地图缩放只改变显示，不触发重新分段；
- 更细显示几何不改变动力学段；
- L1 计算细化若只是提高同一连续场精度，应在容差内保持既有硬断点和主段；
- 若新精度证明旧段无法成立，应生成新 L4 快照并保留谱系，而不是静默改写；
- 粗视图可以合并显示多个短段，但查询仍返回权威分段和 boundaryId。

分段端点使用球面位置和规范弧长保存，不绑定某一层级的网格顶点。

### 5.12 后续细分类的层级

D02 只依据运动连续性、基础置信和必要几何形成 `kinematicSegment`。后续层可以创建子区间：

```text
boundaryId
└─ kinematicSegment（D02）
   ├─ convergenceSubtypeSegment（D03）
   ├─ divergenceSubtypeSegment（D04）
   └─ transformOrJunctionSegment（D05）
```

壳体边缘恰好穿过一个运动稳定段时，D03/D04 可以按壳体组合细分，但不能篡改 D02 的原始速度摘要。这样可以区分“运动类型变化”和“相同运动下两侧材料组合变化”。

### 5.13 失败与降级

以下情况不能发布为普通高置信段：

- 达到最大采样层级仍无法稳定估计法向；
- 分类在小尺度持续振荡且无法满足误差预算；
- 短边界没有足够弧长建立可靠局部坐标；
- 采样遗漏了已知硬断点；
- 分段覆盖出现空洞、重叠或顺序错乱；
- 细化或线程变化导致同一快照分段身份改变。

局部问题可形成明确的未解析区间；若整条边界无法形成连续、无重叠的区间覆盖，L4 快照应失败，而不是只输出看起来最合理的几段。

### 5.14 D02 建议规则

```text
boundaryId、连续采样场和动力学分段是三个不同层次
采样及分段长度使用球面真实弧长，不使用像素或点数
按几何、速度分量、门槛穿越和置信变化确定性自适应加密
采样有最小间距、最大层级和误差预算，无法解析时显式降级
硬断点不可跨越，软断点必须满足显著性和持续长度
使用对称空间迟滞避免门槛抖动和扫描方向依赖
可信过零、过渡和低置信缺口不能被简单短段合并吞掉
分段摘要基于区间连续证据，不使用单点标签或简单多数票
后续壳体细分类创建子区间，不改写基础运动分段
模型或尺度变化通过新快照和分段谱系表达
```

## 六、L4-D03：汇聚边界的壳体组合、作用资格与极性

D01、D02 只能说明两侧板块正在相向或斜向相向。仅凭汇聚运动，无法判断这里更接近大陆碰撞、洋壳俯冲还是复杂过渡边界。D03 需要结合两侧壳体连续属性，输出碰撞、缩短增厚和俯冲／消减的资格，以及可能的下沉侧和上覆侧；这些仍是 L5 的构造输入，不是已经生成的海沟、岛弧或山脉。

### 6.1 汇聚运动是必要条件，不是完整成因

D03 只处理满足以下前提的动力学段或子区间：

```text
convergenceSignal 超过适用门槛
运动分类为汇聚、斜向汇聚或可信混合中的汇聚分量
基础运动和边界几何置信度达到最低要求
两侧壳体状态可读取
```

若只有很弱的相向分量，应保留低活动汇聚资格，不升级为活跃碰撞或俯冲。若运动关系不确定，则壳体组合再清晰也不能单独制造汇聚类型。

### 6.2 两侧壳体必须向板块内部取样

边界线上常是过渡壳、混合单元或几何插值位置，不能只读取边界点的一个壳体标签。建议分别沿 `-nAB` 和 `+nAB` 向板块 A、B 内部建立取样带：

```text
A 侧取样带 ← 边界中心 → B 侧取样带
```

每侧取样带应：

- 使用球面真实距离和版本化宽度；
- 只读取本侧 plateId 内部，不跨入其他板块；
- 在多个距离层统计大陆性、厚度、浮力、成熟度和置信度；
- 排除边界恰好落在网格归属线上的单点偏差；
- 在窄微板块或三重点附近因可用宽度不足而降低置信度；
- 不使用最终海陆、海岸线或地图颜色判断壳体类型。

取样带宽属于分析参数，不是 L5 构造影响带宽。前者只用于识别边界两侧的背景壳体，后者要在 L5 根据地形响应另行决定。

### 6.3 连续壳体组合优先

D03 读取的主要属性包括：

```text
continentalityA / continentalityB
crustThicknessProxyA / B
buoyancyProxyA / B
relativeMaturityProxyA / B
structuralInheritanceProxyA / B
各属性的取样覆盖率和置信度
```

“洋—洋”“洋—陆”“陆—陆”是连续属性的派生摘要，不覆盖原始数值。过渡壳较宽、属性冲突或取样不足时，应保留“过渡／混合组合”，而不是按最近阈值强制变成纯洋壳或纯大陆壳。

### 6.4 汇聚作用的连续资格

建议至少输出三个相互关联但不互斥的连续资格：

```text
shorteningQualification
  = 相向运动产生缩短／增厚响应的总体资格

subductionQualification
  = 一侧相对更适合下沉时的俯冲／消减资格

collisionQualification
  = 两侧高大陆性、较高浮力壳体相遇时的碰撞资格
```

- `shorteningQualification` 是最一般的汇聚结果，可在多种壳体组合中存在。
- `subductionQualification` 需要至少一侧具有足够的海洋性、低浮力或其他下沉资格。
- `collisionQualification` 需要两侧都具有持续的高大陆性和较高浮力背景。

斜向汇聚同时保留 D01 的走滑资格。D03 不因为建立汇聚子类型而删除切向分量。

### 6.5 洋壳—洋壳汇聚资格

当两侧都以海洋性壳体倾向为主时：

- 通常具有较高的俯冲资格；
- 下沉侧需通过两侧相对可俯冲性比较判断；
- 两侧差异很小时，极性可以未知；
- 不能随机选择一侧只为生成岛弧；
- L4 不直接生成海沟、岛弧、弧后盆地或火山链。

洋—洋组合并不保证必然形成现实中的完整俯冲系统。它只是向 L5 提供相向运动、壳体组合、可能极性和置信度。

### 6.6 洋壳—大陆壳汇聚资格

一侧明显海洋性、另一侧明显大陆性且相向运动充分时，通常由海洋性一侧获得较高下沉资格，大陆性一侧获得较高上覆资格。判断依据是壳体连续属性，而不是哪一侧当前位于海面以下。

仍需允许例外和降级：

- 大陆边缘可能是宽过渡壳，导致极性置信下降；
- 小型大陆碎片可能位于海洋性板块中，不应让单个碎片翻转整段极性；
- 海洋性一侧若浮力代理异常高或证据不完整，应降低俯冲资格；
- 极窄微板块可能无法提供足够的两侧取样宽度；
- 斜向汇聚需同时保留走滑分量和沿线变化。

最终是否形成海沟、陆缘山系和火山弧由 L5 及后续材料、热状态模型决定。

### 6.7 大陆壳—大陆壳汇聚资格

当两侧都具有持续的高大陆性、较厚和较高浮力壳体倾向时：

- `collisionQualification` 提高；
- `shorteningQualification` 保持，并可为 L5 提供增厚和宽变形带资格；
- `subductionQualification` 通常降低；
- 首版不强制指定一个完整大陆板块俯冲到另一个大陆板块之下；
- 可以保留低置信的下插／不对称缩短方向候选，但不能伪装成已求解的深部结构。

大陆碰撞资格不会直接规定山脉高度，也不会自动使整条边界成为同宽高原。L5 还要结合汇聚强度、斜向分量、结构继承和空间衰减。

### 6.8 过渡与混合壳体组合

以下情况应输出过渡／混合组合：

- 一侧或两侧 continentality 长期落在过渡范围；
- 取样带跨越大陆碎片、过渡带和洋壳背景；
- 属性之间冲突，例如大陆性较高但厚度／浮力代理异常低；
- 沿线组合变化尺度低于当前稳定分段门槛；
- 壳体取样覆盖率或置信度不足。

过渡组合仍可具有缩短资格，也可能同时具有一定碰撞和俯冲资格。L4 应输出连续数值与原因，不必强行选出唯一现实类比。

### 6.9 下沉倾向与俯冲极性

对具有俯冲资格的区间，分别计算两侧的下沉倾向：

```text
subductabilityA = f(
  oceanicityA,
  低 buoyancyProxyA,
  相对厚度倾向,
  relativeMaturityProxyA,
  可选的 oceanicRenewalProxyA,
  各输入置信度
)

subductabilityB = 同理
```

这里的函数是有界、版本化的代理组合，不是真实岩石圈力学求解。D04 若产生可信的洋壳更新／热成熟代理，可以作为可选输入；缺少该输入时仍可根据 L3 壳体状态给出较低置信判断，不能伪造绝对壳龄补齐。

只有两侧下沉倾向差异超过极性门槛并持续足够距离时，才输出：

```text
subductingSideCandidate = A 或 B
overridingSideCandidate = 另一侧
polarityConfidence
```

差异不足时输出 `polarity = UNKNOWN`。未知极性不会抹掉汇聚和俯冲资格，只表示 L5 不能可靠决定海沟侧、弧侧等有方向的响应。

### 6.10 极性沿线变化

同一条长汇聚边界的壳体组合和下沉倾向可能沿线变化，但极性不能在相邻采样点间无代价地频繁翻转。建议：

- 极性变化需要连续差异穿过中性区，并满足最小持续长度；
- 明确极性 A、未知过渡、明确极性 B 应作为三个连续区间表达；
- 不允许直接从 A 下沉跳到 B 下沉而没有中性／复杂转换证据；
- 三重点或壳体组合硬变化可以成为极性子段断点；
- 极性分段是 D02 运动学段的子层，不改变基础汇聚段身份。

一块板块可以在某条边界作为下沉侧，在另一条边界作为上覆侧；极性属于边界局部关系，不是板块的永久属性。

### 6.11 输出的汇聚子段

每个 `convergenceSubtypeSegment` 至少保存：

```text
subtypeSegmentId / parentKinematicSegmentId / boundaryId
sStart、sEnd
两侧壳体取样带和统计摘要
派生壳体组合及混合程度
shorteningQualification
subductionQualification
collisionQualification
subductabilityA / subductabilityB
下沉侧／上覆侧候选及极性置信度
斜向走滑分量引用
输入缺失、过渡组合和降级原因
门槛、模型版本和证据
```

若一个 D02 汇聚段内部壳体组合改变，D03 可以建立多个子段。子段总区间必须覆盖其适用的父汇聚段，无法分类处使用显式过渡或未解析子段。

### 6.12 不允许的直接推断

D03 输出不能直接等同为：

```text
俯冲资格 = 已存在海沟
上覆侧 = 已存在火山弧
大陆碰撞 = 必然是最高山脉
洋—洋汇聚 = 必然出现岛链
汇聚强度 = 地震震级或频率
下沉倾向 = 真实板片角度和深度
```

这些现象需要 L5 的构造响应、后续材料与热状态，部分还超出首版范围。

### 6.13 置信度组成

汇聚子类型的置信度至少分为：

- `kinematicConfidence`：相向与斜向运动是否可靠；
- `crustSamplingConfidence`：两侧壳体取样是否完整且有代表性；
- `subtypeConfidence`：碰撞／俯冲资格是否稳定；
- `polarityConfidence`：哪一侧更可能下沉是否可靠。

总置信可以派生，但不能覆盖分项。某段可以高置信地判断为汇聚和洋—陆组合，同时因两侧浮力差异不足而保持低极性置信。

### 6.14 特殊情况

- **淹没大陆壳**：仍按大陆性壳体处理，不能因位于海下改判为洋壳。
- **抬升洋壳／岛屿**：仍按洋壳倾向处理，不能因露出海面改判为大陆壳。
- **大陆碎片**：只有达到持续长度和取样覆盖门槛时才形成壳体组合子段。
- **微板块**：使用与主板块相同规则，但因宽度不足可能降低取样与极性置信。
- **三重点端部**：逐条边界计算，不把另两条边界的极性复制过来。
- **低活动汇聚**：保存资格和低强度，不升级为强碰撞或强俯冲。
- **输入冲突**：保留连续属性、冲突原因和不确定状态，不靠随机选择消除矛盾。

### 6.15 D03 建议规则

```text
相向运动是汇聚子类型的必要条件，但不能单独决定碰撞或俯冲
壳体属性从边界两侧板块内部的真实距离取样带获得
使用大陆性、厚度、浮力、成熟度及置信连续属性，不读取最终海陆颜色
分别输出缩短、俯冲和碰撞连续资格，三者不被单一标签覆盖
洋—洋和洋—陆组合可提高俯冲资格，陆—陆组合提高碰撞资格
下沉侧通过两侧有界可俯冲性比较产生，不随机指定
极性差异不足时允许 UNKNOWN，且与汇聚／俯冲资格分开
极性变化需要中性过渡和持续长度，极性是边界局部属性
斜向汇聚始终保留走滑分量
L4 不把汇聚资格直接宣称为海沟、火山弧、岛链或山脉
```

## 七、L4-D04：离散边界、张裂资格与洋壳更新代理

离散运动说明两侧板块正在分离，但不同壳体背景会产生不同的构造资格。大陆内部的分离更接近张裂，过渡壳区可能处于破裂与扩张转换阶段，稳定洋壳之间的分离才具有较高的洋中脊／海底扩张资格。D04 同时负责产生由离散源约束的相对更新代理，但不伪造绝对洋壳年龄。

### 7.1 离散运动前提

D04 只处理满足以下条件的动力学段：

```text
divergenceSignal 超过适用门槛
分类为离散、斜向离散或可信混合中的离散分量
运动和几何置信度达到最低要求
两侧壳体取样可用
```

壳体组合不能在没有显著分离运动时单独制造裂谷或扩张中心。低活动分离可以保存弱资格，但不能升级为活跃洋中脊源。

### 7.2 使用与 D03 相同的双侧壳体取样

D04 复用 D03 的边界双侧取样框架，读取：

```text
continentalityA / B
crustThicknessProxyA / B
buoyancyProxyA / B
relativeMaturityProxyA / B
structuralInheritanceProxyA / B
覆盖率与置信度
```

取样带只用于识别壳体背景，不代表裂谷或洋中脊最终影响宽度。若 D03 与 D04 对同一位置读取相同属性，应共享规范取样缓存和证据，避免不同模块使用不一致的两侧壳体状态。

### 7.3 三种主要连续资格

建议输出：

```text
extensionQualification
  = 分离运动产生伸展响应的总体资格

continentalRiftQualification
  = 高大陆性壳体在伸展下形成大陆张裂的资格

seafloorSpreadingQualification
  = 低大陆性、海洋性壳体在持续分离下形成扩张中心的资格
```

另保存 `transitionRiftQualification`，表达大陆张裂向海底扩张过渡或壳体组合混合的情况。这些资格可以在空间上渐变，不必强行把边界切成纯大陆裂谷和纯洋中脊两类。

### 7.4 大陆—大陆离散

两侧均为持续高大陆性壳体时：

- 大陆张裂资格提高；
- 伸展资格保留；
- 海底扩张资格通常较低；
- 结构继承可以影响未来裂谷定位资格，但不直接生成断层几何；
- 不能因为分离强度高就立刻把该段改成海洋壳或生成新海洋。

是否最终形成裂谷低地、断陷盆地或破裂大陆边缘属于 L5 及后续地形／材料过程。

### 7.5 过渡壳与不对称张裂

一侧或两侧为过渡壳，或者沿线 continentality 正在持续下降时：

- `transitionRiftQualification` 提高；
- 大陆张裂和海底扩张资格可以同时处于中等水平；
- 两侧壳体不同允许保存不对称张裂资格；
- 取样混合或尺度不足时降低子类型置信，而不是硬切为某一类；
- 首版不模拟完整的大陆破裂、岩浆增生和被动大陆边缘演化时间线。

### 7.6 洋壳—洋壳离散

两侧均为持续海洋性壳体、分离信号明确时：

- 海底扩张资格提高；
- 可建立洋壳更新源候选；
- 斜向分离仍保留走滑分量；
- L4 不直接生成洋中脊高程、中央裂谷或热液活动；
- 两侧属性异常、取样不足或分离不持续时降低源置信度。

“洋中脊资格”表示 L5 可以据此建立有方向的扩张构造响应，不表示已有一条固定宽高的海底山脉。

### 7.7 洋—陆离散和混合组合

洋壳与大陆壳直接出现在分离边界两侧时，可能代表复杂继承边缘、微板块关系或当前静态状态无法还原的历史。首版应：

- 保留伸展资格；
- 根据过渡壳覆盖和连续性给出过渡／不对称资格；
- 不把大陆一侧自动改为新生洋壳；
- 不从当前组合反推确定的大陆破裂年代；
- 若缺少连续过渡证据，则降低模型置信并标明历史未解析。

### 7.8 更新源候选

只有同时满足下列条件的区间才能成为 `oceanicRenewalSource`：

```text
高置信持续离散运动
足够的 seafloorSpreadingQualification
两侧海洋性或可信的海洋化过渡背景
达到最小持续长度
不处于未解析三重点端部
```

每个更新源保存位置、分离方向、相对扩张速度、两侧 plateId、源置信度和适用壳体域。大陆张裂段不能仅凭较强分离直接成为洋壳更新源。

### 7.9 无绝对年代的更新传播

在更新源识别后，可以在同一板块的海洋性壳体域内，沿当前运动方向的反向路径或等价受约束距离传播，形成：

```text
renewalProximityProxy
thermalMaturityProxy
sourceReachability
```

建议流程：

```text
1. 从高置信扩张源建立两侧源边界
2. 只在对应 plateId 和海洋性／过渡性允许域中传播
3. 使用球面距离、当前板块速度方向和障碍条件计算传播代价
4. 多个源到达时保存主来源及竞争／歧义
5. 距源越远，更新接近度降低、相对热成熟度提高
6. 无可信源可达时输出 UNKNOWN，而不是填充随机年龄
```

这只是“如果当前运动关系代表持续背景时”的相对代理。它不积分真实历史，不计算形成时间，也不能输出 Ma／Ga。

### 7.10 D03 与 D04 的执行依赖

D01—D07 是讨论编号，不代表严格执行顺序。建议 L4 内部执行为：

```text
D01/D02：完成所有边界的连续运动和基础分段
    ↓
D04：识别离散源并传播可选更新／热成熟代理
    ↓
D03：计算汇聚子类型和极性，可选读取更新代理
    ↓
D05：统一走滑、混合和三重点关系
```

若更新传播失败，D03 仍可依据 L3 壳体浮力、厚度和成熟度给出较低置信极性；不得形成循环重算，不能让汇聚极性反过来改变离散源。

### 7.11 更新传播的边界

传播不得：

- 跨越 plateId 边界进入另一板块；
- 穿过不允许的大陆性核心而不降级；
- 因地图投影接缝中断；
- 把最近球面距离直接冒充沿运动路径的历史距离；
- 在没有源的封闭洋壳域中编造年轻中心；
- 用相对代理直接修改 L3 权威成熟度。

更新代理属于 L4 派生状态，并带独立版本和置信度。未来真实历史模型应替换其消费路径，而不是把代理重新命名为绝对年龄。

### 7.12 输出的离散子段

每个 `divergenceSubtypeSegment` 至少保存：

```text
subtypeSegmentId / parentKinematicSegmentId / boundaryId
sStart、sEnd
双侧壳体统计和组合
extensionQualification
continentalRiftQualification
transitionRiftQualification
seafloorSpreadingQualification
斜向走滑分量引用
是否为 oceanicRenewalSource
源方向、强度、置信和适用域
过渡、混合、未解析与历史缺失原因
```

### 7.13 D04 建议规则

```text
分离运动是张裂／扩张资格的必要条件，壳体组合决定细分类倾向
复用规范双侧壳体取样，不读取最终海陆标签
分别保存伸展、大陆张裂、过渡张裂和海底扩张连续资格
大陆张裂不能因强分离而立即变成洋壳扩张源
只有高置信持续洋壳离散段才能成为更新源候选
更新代理沿同板块允许壳体域和当前运动路径受约束传播
无可信源可达时保持 UNKNOWN，不生成随机壳龄
更新／热成熟代理无年代单位，不宣称真实扩张历史
D04 更新源可辅助 D03 极性，但 D03 不反向修改离散源
L4 不直接生成裂谷、洋中脊高程、盆地或热液地貌
```

## 八、L4-D05：走滑、斜向混合、转换关系与三重点

走滑分量表示两侧沿边界方向发生相对运动。它可以主导一段边界，也可以与汇聚或离散同时存在。D05 负责保留这些组合、识别一般走滑与转换关系的区别，并在三重点检查三个边界分支的运动相容性。

### 8.1 走滑仍以连续切向分量为权威

D05 不重新生成走滑强度，而是读取 D01 的：

```text
signed tangentRate
strikeSlipSignal
relativeSpeed
局部 t / nAB / r
```

有符号切向量表示板块 B 相对板块 A 沿规范边界方向的运动。界面若显示左旋／右旋等名称，必须由固定几何约定派生并附说明；权威数据仍是三维速度和有符号切向分量。

### 8.2 一般走滑与转换边界分开

并非所有走滑边界都是“转换断层”。建议区分：

```text
strikeSlipQualification
= 切向运动主导或显著的通用走滑资格

transformQualification
= 走滑段与两个扩张段、扩张中心偏移或其他受支持边界体系形成拓扑连接时的转换资格
```

只有存在相邻离散源、稳定连接关系和足够置信时，才能提高 `transformQualification`。孤立的切向主导边界仍是一般走滑资格，不能为了命名完整自动称为转换断层。

### 8.3 斜向汇聚与压扭资格

当汇聚和走滑分量都显著时：

```text
transpressionQualification
= convergenceSignal 与 strikeSlipSignal 的有界组合
```

它表示压缩与剪切共同作用的资格。D03 的碰撞／俯冲子类型保持有效，D05 增加斜向剪切关系，不把它们互相覆盖。

压扭资格不能直接生成线性山脉、断层或花状构造，只向 L5 提供缩短方向、剪切方向、强度和置信度。

### 8.4 斜向离散与张扭资格

当离散和走滑分量都显著时：

```text
transtensionQualification
= divergenceSignal 与 strikeSlipSignal 的有界组合
```

它表示伸展与剪切共同作用的资格。D04 的大陆张裂／海底扩张资格仍然保留；张扭资格只描述运动组合，不直接生成拉分盆地、菱形断陷或裂谷几何。

### 8.5 近纯走滑状态

当切向分量显著、法向分量稳定处于低值范围时，可以派生“近纯走滑”状态。其成立需要：

- 总相对速度超过低活动门槛；
- 切向占比超过走滑进入门槛并持续足够距离；
- 法向分量没有可信的持续汇聚或离散信号；
- 局部法向和切向几何稳定。

“近纯”是相对门槛下的模型状态，不宣称现实边界具有严格零法向速度。

### 8.6 走滑方向与沿线变化

切向速度可能沿长边界减弱、过零或改变方向。可信的切向过零应保存为方向转换事件，但不能因为边界规范方向改变或折线反转制造假过零。

走滑方向子段应遵循 D02 的硬断点、空间迟滞和最小持续长度。短暂符号抖动保留为异常摘要；持续的高置信符号转换建立子段或过渡区。

### 8.7 三重点没有单一边界类型

三重点连接三块板块和三条边界分支。L4 在三重点邻域分别计算：

```text
A 相对 B
B 相对 C
C 相对 A
```

每条分支保留自己的汇聚、离散和走滑状态。三重点对象保存的是三分支组合和相容性摘要，不能把点本身标成“汇聚”或“走滑”。

### 8.8 三重点速度闭合

若三块板块速度都来自同一球面位置和同一参考系，则理论上：

```text
vAB + vBC + vCA = 0
```

L4 应在三重点邻域检查闭合残差。残差超过数值和采样容差，通常说明：

- 使用了不一致的采样位置；
- 某条分支方向或 A/B 约定错误；
- 引用了不同参考系或快照；
- 三重点几何退化；
- 数值精度或缓存状态不一致。

闭合测试验证输入和实现自洽，不代表已经求解三重点迁移速度或长期稳定性。

### 8.9 三重点组合与置信度

三分支可以形成多种组合，例如离散—离散—走滑、汇聚—走滑—走滑或复杂混合。首版建议保存：

```text
junctionId
三个 boundaryId / segmentId
各分支连续资格和主状态
速度闭合残差
端部几何稳定性
组合签名
junctionConfidence
未解析原因
```

组合签名用于查询和测试，不自动对应现实中的稳定三重点分类。若分支过短、极性在端部未知或采样位置无法统一，应降低置信或标为未解析。

### 8.10 转换区和三重点端部

D02 已为三重点设置端部邻域。D05 在此基础上：

- 不把一条分支的主状态延伸覆盖三重点；
- 不从相邻分支复制走滑方向；
- 保存各分支接近端部时的连续变化；
- 对无法稳定解析的极短端部使用未解析区；
- 防止三个 L5 影响核在同一点简单叠加形成尖峰，具体组合由 D06 向 L5 提供限制信息。

### 8.11 输出状态

每个适用子段至少保存：

```text
strikeSlipQualification
signedShearDirection
nearPureStrikeSlipState
transformQualification
transpressionQualification
transtensionQualification
父汇聚／离散子类型引用
走滑方向过零与转换事件
运动、几何、拓扑和组合置信度
```

三重点另存独立对象，但引用 L3 的稳定 junctionId，不新建相互冲突的拓扑身份。

### 8.12 不允许的直接推断

D05 不能直接输出：

- 精确断层线和断层宽度；
- 地震震级、频率或破裂长度；
- 拉分盆地、断层谷和山脉的完成几何；
- 三重点未来移动轨迹；
- 未经连接证据的一般走滑段“转换断层”名称。

### 8.13 D05 建议规则

```text
走滑以 D01 有符号切向速度和连续资格为权威输入
一般走滑与具有扩张中心连接证据的转换资格分开
汇聚加走滑形成压扭资格，离散加走滑形成张扭资格
混合资格不覆盖 D03/D04 原始壳体子类型和连续分量
近纯走滑需要显著总速度、持续切向主导和稳定低法向分量
可信走滑方向转换保留事件和过渡，不接受折线方向造成的假翻转
三重点逐分支计算，并检查 vAB + vBC + vCA 的速度闭合
三重点保存组合签名和置信度，但不拥有单一边界类型
短端部和退化几何允许未解析，不能从邻段复制结果
L4 不直接生成断层、地震、拉分盆地或三重点迁移历史
```

## 九、L4-D06：强度、置信度与 L5 输入契约

L4 已形成原始运动量、基础分段和构造资格，但 L5 需要一个不会丢失单位、不会重复计权、不会把不确定性伪装成弱信号的稳定接口。D06 将“实际计算量”“归一化比较量”“构造响应资格”和“模型置信度”分层输出。

### 9.1 四类量严格分开

| 层次 | 示例 | 用途 |
| --- | --- | --- |
| 原始运动量 | `normalRate`、`tangentRate`、`relativeSpeed` | 可重建、带单位的权威运动证据 |
| 归一化信号 | 汇聚、离散、走滑强度 `0～1` | 跨边界使用统一参考尺度比较 |
| 构造资格 | 碰撞、俯冲、张裂、扩张、转换、压扭、张扭 | 表示特定响应是否具备前提 |
| 置信状态 | 运动、几何、壳体、子类型、极性置信 | 表示判断可靠性与缺失原因 |

这四类字段不能互相覆盖。L5 可以根据任务读取合适层次，但不能把归一化强度当成真实应力，也不能把低置信误解为低物理强度。

### 9.2 使用固定参考尺度归一化

归一化应使用 `earthlike-v1` 和运动模型版本冻结的参考速度／角速度尺度，以及有界饱和函数：

```text
normalizedSignal = boundedMap(rawRate / referenceRate)
```

具体函数和参考值留待原型校准，但确认：

- 不按当前世界最大值或分位数归一化；
- 不因远处出现更快边界而改变某一局部段的强度；
- 原始带单位值始终保留；
- 超过典型范围时可以趋于饱和，但必须记录超范围状态；
- 模型版本改变参考尺度时创建新快照。

### 9.3 构造资格不是额外能量

碰撞、俯冲、压扭等字段是由原始分量和壳体组合派生的条件资格，不能与原始信号作为相互独立的强度直接相加。例如：

```text
压扭资格 = 汇聚信号与走滑信号的组合解释
不是：汇聚 + 走滑 + 第三份“压扭能量”
```

建议每个派生资格保存：

```text
derivedFrom：来源信号和属性
combinationGroupId：互相关联的组合组
additivityPolicy：禁止直接相加／可独立组合／由 L5 决定
```

L5 必须按照契约组合，避免斜向边界被重复放大。

### 9.4 强度与置信度不相乘覆盖

首版不把：

```text
effectiveStrength = strength × confidence
```

作为唯一输出。这样会把“强信号但证据不足”和“弱信号但证据可靠”压成相同数字。应同时保存：

```text
rawStrength
normalizedStrength
confidenceComponents
overallConfidence（派生摘要）
status / reasonCodes
```

L5 若在预览模式中使用置信加权，必须保留原始值和降权原因；正式模式遇到低于门槛的必要输入时，应输出低置信或未解析响应，而不是静默变弱。

### 9.5 零、未知、不适用和失败

四种状态具有不同含义：

| 状态 | 含义 |
| --- | --- |
| `ZERO` | 已计算且物理信号在容差内为零／极低 |
| `UNKNOWN` | 理论上适用，但证据不足或尚未解析 |
| `NOT_APPLICABLE` | 对当前边界类型不适用，例如走滑段没有俯冲极性 |
| `FAILED` | 应能计算但模型、数据或契约发生错误 |

禁止用数值零代替后三种状态。否则 L5 会把“未知俯冲极性”误解为“确定没有方向性”。

### 9.6 方向信息

L5 输入应同时携带：

- 球面位置 `r`；
- 沿边界切向 `t`；
- A 指向 B 的法向 `nAB`；
- 有符号法向和切向速率；
- 汇聚／离散作用的两侧方向；
- 可用时的下沉侧和上覆侧候选；
- 走滑方向与方向置信度；
- 分段起止和三重点邻域标记。

方向使用球面三维向量作为权威表示。地图箭头、局部东西南北和屏幕法线是显示派生值。

### 9.7 L4 不决定跨边界地形宽度

L4 可以输出：

- 边界位置和沿线持续长度；
- 运动方向与强度；
- 壳体组合和结构继承引用；
- 空间定位误差；
- 当前最小可解析尺度；
- 三重点或转换区的组合限制。

但不能直接输出“山带宽 300 公里”或“裂谷深 2 公里”。跨边界的影响核、宽度、非对称衰减和高程响应属于 L5。这样可以避免把运动分类与具体地形公式绑定死。

### 9.8 L5 边界约束记录

建议向 L5 输出 `BoundaryKinematicConstraint`：

```text
constraintId
boundaryId / kinematicSegmentId / subtypeSegmentId
sStart / sEnd / 球面几何引用
localFrame：r / t / nAB
rawKinematics：带单位原始速度分量
normalizedSignals：汇聚／离散／走滑
qualifications：缩短、碰撞、俯冲、张裂、扩张、转换、压扭、张扭
sideState：两侧壳体摘要、下沉／上覆候选
renewalState：更新源或相对热成熟引用
confidenceComponents
valueStatus / reasonCodes
combinationGroupId / additivityPolicy
resolutionAndLocalization
evidenceRef / modelVersion
```

记录只引用 L3/L4 权威对象，不复制一份可能失去同步的板块与壳体身份。

### 9.9 三重点组合限制

三重点附近向 L5 额外输出：

```text
junctionId
三个入射 constraintId
速度闭合残差
端部未解析范围
允许独立处理／需要联合归一化的标记
```

这用于提醒 L5 不要把三个边界响应在一个点无上限相加。D06 不规定具体联合核函数，但要求 L5 能识别共同 junctionId 和组合组。

### 9.10 版本、缺失传播和查询

L5 契约必须锁定：

- L3 输入快照和 L4 快照标识；
- 原始量单位与参考尺度版本；
- 分类、子类型和资格模型版本；
- 置信度组成规则；
- 组合策略语义版本；
- 可选字段及缺失处理方式。

任何必需字段缺失都应显式传播为 `UNKNOWN` 或 `FAILED`。查询接口需解释某项资格来自哪些运动分量、壳体属性和门槛，而不是只返回一个最终颜色。

### 9.11 D06 建议规则

```text
原始运动量、归一化信号、构造资格和置信状态分层保存
使用固定类地参考尺度归一化，不按单世界最大值重标
派生资格保存来源和组合组，不能与原始信号重复相加
强度与置信度分别输出，不用一个乘积掩盖两种语义
ZERO、UNKNOWN、NOT_APPLICABLE 和 FAILED 严格区分
所有方向以球面三维向量和稳定 A/B 约定表达
L4 输出定位误差和可解析尺度，但不决定山带／裂谷宽高
L5 通过 BoundaryKinematicConstraint 读取稳定对象引用和证据
三重点输出联合处理提示，防止多个响应在一点无上限叠加
缺失、降级和契约版本必须向下游显式传播
```

## 十、L4-D07：边界动力学快照、固定测试与发布门槛

L4 的最终产物是不可变 `BoundaryDynamicsSnapshot`。它绑定唯一 L3 输入快照，保存连续边界运动、动力学段、子类型、三重点、更新代理和 L5 契约记录，并以固定测试、关系测试和种子组统计共同验收。

### 10.1 快照结构

```text
BoundaryDynamicsSnapshot
├─ SnapshotHeader
│  ├─ snapshotId / parentSnapshotId
│  ├─ WorldId / PlateStateSnapshotId
│  ├─ L4ContractVersion / modelManifest
│  ├─ generationStatus
│  └─ validationStatus
├─ BoundarySampleFields
│  ├─ 局部坐标
│  └─ 原始／归一化运动连续量
├─ KinematicSegments
├─ ConvergenceSubtypeSegments
├─ DivergenceSubtypeSegments
├─ StrikeSlipAndMixedSegments
├─ JunctionDynamics
├─ OceanicRenewalState
├─ L5ConstraintRecords
├─ EvidenceBundle
└─ DerivedCaches
```

采样加速索引、显示几何和查询缓存属于 `DerivedCaches`，可删除重建。其余权威结果不可原地修改；模型、门槛或输入变化创建新快照并保存分段谱系。

### 10.2 输入绑定和身份

`snapshotId` 的规范化输入至少包括：

```text
WorldId
PlateStateSnapshotId
L4 数据契约和完整模型清单
分析几何尺度与误差预算
分类／分段／壳体取样／更新传播参数
权威 L4 状态规范摘要
```

视图、显示样式、缓存布局和验证运行耗时不参与身份。L3 输入快照改变后，旧 L4 快照保持可读但标为依赖旧版本，不能悄悄重绑新 L3 数据。

### 10.3 状态体系

沿用 L3 的正交状态：

```text
generationStatus = COMPLETE / PARTIAL / FAILED
validationStatus = NOT_RUN / PASSED / CONDITIONAL / FAILED
```

边界覆盖、速度分解、区间顺序、对象引用或数值有限性失败属于 P0，不能以 `PARTIAL` 发布。只有明确可选的更新代理或低置信细分类缺失、且 L5 契约允许时，才可能形成条件快照。正式 L5 默认只接收 `COMPLETE + PASSED`。

### 10.4 K02 汇聚固定世界

K02 在 L4 至少包含以下单因素变体：

| 变体 | 固定条件 | 主要断言 |
| --- | --- | --- |
| K02-A 洋—洋对称 | 相向速度明确，两侧可俯冲性近似相等 | 汇聚与俯冲资格高，极性 UNKNOWN |
| K02-B 洋—洋非对称 | 只降低一侧浮力／更新成熟状态 | 下沉倾向按预期转向，其他输入不变 |
| K02-C 洋—陆 | 洋壳与大陆壳相向 | 洋壳侧下沉资格较高，海陆水位变化不影响判断 |
| K02-D 陆—陆 | 两侧高大陆性和浮力 | 碰撞／缩短资格提高，完整俯冲极性降低 |
| K02-E 斜向汇聚 | 在 K02-C 增加切向分量 | 汇聚子类型保留，同时提高压扭资格 |

K02 不在 L4 验收山脉、海沟、岛弧或火山，这些由 L5 及其后续测试扩展。

### 10.5 K03 离散固定世界

K03 至少包含：

| 变体 | 固定条件 | 主要断言 |
| --- | --- | --- |
| K03-A 大陆张裂 | 两侧大陆性高且明确分离 | 张裂资格提高，不建立洋壳更新源 |
| K03-B 过渡张裂 | 一侧或两侧为连续过渡壳 | 过渡资格提高，保留不对称和低置信原因 |
| K03-C 洋壳扩张 | 两侧海洋性高且持续分离 | 扩张资格和更新源成立 |
| K03-D 更新传播 | 固定洋壳域、源和板块速度 | 更新接近度从源向允许路径衰减，不跨板块 |
| K03-E 无源洋壳域 | 移除可信扩张源 | 更新状态为 UNKNOWN，不生成绝对壳龄 |
| K03-F 斜向扩张 | 在 K03-C 增加切向分量 | 扩张资格保留，同时提高张扭资格 |

### 10.6 K04 走滑与三重点固定世界

K04 至少包含：

| 变体 | 固定条件 | 主要断言 |
| --- | --- | --- |
| K04-A 一般走滑 | 切向主导，无扩张连接 | 走滑资格高，转换资格不被强制提高 |
| K04-B 转换连接 | 走滑段连接受控扩张源 | 转换资格按拓扑与方向提高 |
| K04-C 压扭 | 切向加相向分量 | 走滑、汇聚和压扭资格同时保留 |
| K04-D 张扭 | 切向加分离分量 | 走滑、离散和张扭资格同时保留 |
| K04-E 三重点闭合 | 三板块同点速度来自统一欧拉代理 | 闭合残差处于容差内，各分支独立分类 |
| K04-F 退化端部 | 缩短一条分支或降低几何质量 | 相应端部降置信／未解析，不污染其他分支 |

### 10.7 关系与变形测试

除 K02–K04 外，还应验证：

- 整颗行星和全部运动向量共同旋转后结果等价；
- 给所有板块增加统一参考系旋转后相对状态不变；
- 交换稳定 A/B 查询视角后有符号量等价映射，物理资格不变；
- 调整海平面不改变壳体组合和边界动力学；
- 显示折线加密、视图切换和地图缩放不改变权威分段；
- 增减线程、缓存和遍历顺序不改变 sampleId、segmentId 和规范摘要；
- 单独提高活动度只改变速度尺度，不改变 L3 边界拓扑；
- 单独替换一侧壳体属性，只影响依赖该属性的子类型与置信；
- 移除更新源只使相关更新代理未知，不反向改写运动分段。

### 10.8 固定种子组统计

种子组统计用于发现系统偏差，而不是规定每个世界必须集齐所有边界：

```text
各主状态和斜向状态的边界长度分布
段长、段数、短段拒绝率和未解析比例
壳体组合与子类型的联合分布
极性 UNKNOWN 比例及主要原因
更新源数量、覆盖率、歧义和无源区域比例
三重点组合、闭合残差和低置信端部比例
立方球面接缝、面中心、角点和极区的分类偏差
活动度等高级偏好的统计方向
重试、降级和失败率
```

不要求某个随机世界同时拥有汇聚、离散、走滑、碰撞、俯冲和转换边界。若某种类型缺失，应能由板块运动和壳体组合解释，而不是为了配额重写结果。

### 10.9 确定性和规范摘要

要求分级如下：

- boundaryId、sampleId、segmentId、junctionId 和对象引用完全一致；
- 分段顺序、父子区间、类别和状态完全一致；
- 连续浮点值在版本化容差内一致，不能跨门槛改变分类；
- 对稳定排序、单位规范化和量化后的权威数据计算跨平台规范摘要；
- 原始浮点逐位一致只在实现明确承诺时要求。

### 10.10 失败代码

首批建议包括：

```text
L4_INVALID_LOCAL_FRAME
L4_VELOCITY_DECOMPOSITION_ERROR
L4_SEGMENT_COVERAGE_GAP
L4_SEGMENT_OVERLAP
L4_UNSTABLE_SEGMENTATION
L4_INVALID_CRUST_SAMPLING
L4_POLARITY_CONTRADICTION
L4_INVALID_RENEWAL_SOURCE
L4_RENEWAL_PROPAGATION_ESCAPE
L4_JUNCTION_CLOSURE_FAILURE
L4_CONSTRAINT_CONTRACT_ERROR
L4_NONDETERMINISTIC_RESULT
L4_RETRY_LIMIT_REACHED
```

失败记录包含对象、球面位置或弧长区间、实际值、门槛、上游快照、模型版本、随机来源、已执行修复和最小复现输入。局部低置信可以形成未解析区；权威区间覆盖或引用闭合失败必须阻断快照。

### 10.11 验证顺序

```text
1. 数据契约、引用闭合和有限数值检查
2. 局部坐标、速度分解和参考系检查
3. 采样树、分段覆盖、硬断点和迟滞检查
4. 汇聚、离散、走滑及三重点子类型检查
5. 更新源和传播域检查
6. BoundaryKinematicConstraint 组合与缺失语义检查
7. K02–K04 固定测试
8. 关系测试、确定性和跨平台摘要
9. 固定种子组统计回归
10. L5 输入契约检查并原子提交
```

未运行、不适用、条件通过和失败分别记录。前序 P0 失败后可继续只读诊断，但后序测试通过不能覆盖阻断结论。

### 10.12 查询与解释

快照应支持：

- 某边界位置的原始法向／切向速度是什么？
- 为什么这一段是斜向汇聚而不是近纯走滑？
- 两侧是什么壳体组合，取样范围和置信如何？
- 为什么下沉侧确定、未知或沿线变化？
- 某离散段为什么能或不能成为洋壳更新源？
- 某走滑段为何具有或不具有转换资格？
- 三重点闭合是否通过，哪个端部未解析？
- L5 得到的资格是否可相加，缺失状态是什么？
- 快照通过了哪些测试，哪些结果仍是代理？

### 10.13 L5 发布门槛

正式发布至少要求：

```text
generationStatus = COMPLETE
validationStatus = PASSED
所有适用 P0 和 L4-B01 至 B78 硬约束通过
K02–K04 的 L4 断言通过
对象引用、分段覆盖和三重点闭合通过
关系测试和确定性检查通过
种子组统计无阻断回归
L5 契约版本匹配
不存在未解释的 UNKNOWN／FAILED 值被编码为零
```

诊断模式可以显式加载失败或条件快照，但不能混入正式世界缓存。

### 10.14 D07 建议规则

```text
L4 输出不可变、原子提交并绑定唯一 L3 输入的 BoundaryDynamicsSnapshot
连续场、基础段、子类型段、三重点、更新代理和 L5 记录分层保存
生成状态和验证状态分离，P0 错误不能用 PARTIAL 掩盖
K02 验汇聚组合，K03 验离散和更新，K04 验走滑与三重点
固定测试、关系测试和固定种子统计互不替代
身份与分类要求确定，连续值使用版本化容差和规范摘要
失败使用稳定代码并保存对象、区间、门槛和最小复现输入
随机世界不要求集齐所有边界类型，也不使用类型配额回写运动
查询必须追溯原始速度、壳体取样、资格、置信和组合策略
正式 L5 默认只接收 COMPLETE + PASSED 且契约匹配的快照
```
