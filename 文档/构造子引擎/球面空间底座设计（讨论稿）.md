# 球面空间底座设计

> **文档状态**
>
> - 文档类型：分层设计
> - 决策状态：已确认
> - 实现状态：E1 双平台验收通过，已于 2026-10-08 正式冻结
> - 版本：1.0
> - 说明：L1 架构决定已确认。

本文讨论整体行星引擎的 L1“球面空间与可重现性底座”。它不负责生成板块、地形、气候或水文；它负责让后续所有模块对“世界上的同一个位置、邻居、面积、距离和局部细节”拥有一致定义。

关联：[构造引擎前置条件清单](构造引擎前置条件清单（讨论稿）.md) · [引擎重设计蓝图](../总体架构/引擎重设计蓝图（讨论稿）.md) · [测试世界矩阵与验收顺序](../验收体系/测试世界矩阵与验收顺序（讨论稿）.md)。

## 一、L1 必须解决的问题

L1 应在全引擎中一次性解决以下问题：

1. **全球无缝覆盖**：任何位置都属于一个稳定空间单元；没有经线接缝、极区退化、重叠或空洞。
2. **相邻关系正确**：能查询单元的边、角、邻居、方向、面积和球面距离，供板块、流域、气候输送和河网使用。
3. **跨尺度一致**：全球看到的山脉、流域、海岸和板块，在放大到区域与地貌级时保留稳定身份和边界来源。
4. **局部可细化**：只有在需要观察或计算区域地貌时才增加细节，不要求一开始将整个行星计算到最高精度。
5. **适配多种显示**：球体、二维地图、局部三维都从同一权威空间状态读取，显示投影不改变世界本身。
6. **可重复和可审查**：同一个世界规格在任何运行顺序下都能得到相同空间标识、细化规则和局部结果。

## 二、候选方案比较

| 方案 | 优点 | 主要问题 | 与本项目的匹配度 |
| --- | --- | --- | --- |
| 等经纬网格 | 容易理解、二维地图和纹理直接、实现很快 | 极区单元挤压；面积和邻接失真；局部三维及全球物理计算较弱 | 适合作为显示投影，不适合作为权威计算空间 |
| 二十面体等面积网格 | 单元形状较均匀，适合全球场和邻接计算 | 分层与局部细化规则较复杂；五边形缺陷需要专门处理；贴图与局部网格适配成本较高 | 适合追求全球均匀采样的科学计算方案 |
| 分层立方球面网格 | 六个正方形面覆盖球面；支持四叉细化；局部三维和纹理适配直接；极区无退化 | 面接缝、跨面邻接和角点映射必须一次性处理正确；单元面积并非严格相等 | 最符合连续缩放、局部三维和桌面可视化的首版目标 |
| 不规则三角网 | 可直接贴合地形与任意细节 | 难以维持确定性层级、邻接和跨尺度规则；实现及验证成本很高 | 不作为首版权威空间体系 |

### 已确认方案：分层立方球面网格

已确认选择六个面组成的立方球面，每个面是一个二维正方形参数空间。面内使用四叉分层细化：每个父单元拆分为四个子单元，再投影到球面。

```text
             ┌───────┐
             │ 北面  │
     ┌───────┼───────┼───────┬───────┐
     │ 左面  │ 前面  │ 右面  │ 后面  │
     └───────┼───────┼───────┴───────┘
             │ 南面  │
             └───────┘

每个面 → 四叉层级 → 球面单元 → 区域／地貌细化
```

这不是显示用的立方体。每个单元的中心、边界、面积、距离和方向都在球面上计算；六个正方形面只提供稳定的层级索引和局部参数坐标。

### 已确认的 L1 基线

```text
分层立方球面
+ 四叉细化
+ 相邻活动区域最多相差一个细化等级
+ 单元保存或可计算真实球面面积、边长与距离
+ 三维单位向量作为权威几何
+ 经纬度与地图投影只用于显示、标注和查询
```

这意味着后续模块可以按二维块状数据组织计算，但所有守恒量和方向量必须使用真实球面几何，不能假设六个面上的网格单元面积、边长和方向完全相同。

## 三、L1 的职责与边界

### L1 负责

- 球面坐标与面坐标的双向转换。
- 六个面之间的跨面邻接、方向变换和边界连续性。
- 单元标识、父子关系、面积、中心点、边界和邻居查询。
- 全球层、区域层、地貌层及局部三维预留层的细化规则。
- 对任意点、线、区域对象的归属、覆盖和跨尺度映射。
- 空间查询中的球面距离、方位、坡度方向所需局部切平面。
- 与世界规格绑定的空间版本和稳定随机流入口。

### L1 不负责

- 把单元直接解释为大陆、海洋、板块、山脉、河流或气候带。
- 决定某个区域是否细化；这一决定来自计算需求、对象复杂度或用户观察请求，但细化结果必须遵守 L1 的确定性规则。
- 保存地图颜色、贴图坐标、相机位置或桌面应用交互状态。
- 用局部网格精细程度暗示更高的物理可信度。

## 四、空间单元与稳定标识

每个权威单元应有可排序、可复现且可追溯的标识：

```text
单元标识 = 空间版本 / 面编号 / 层级 / 四叉路径

示例：cs1/F2/L5/03122
```

含义：

- `cs1`：立方球面空间规范版本；变更投影或邻接规则时必须升级。
- `F2`：六个面之一。
- `L5`：细化层级。
- `03122`：从面根单元按 0、1、2、3 的四叉子序列得到的路径。

该标识不包含种子，也不包含地形分类。空间标识描述“位置与尺度”，世界种子描述“该位置上的自然状态”。因此不同种子的同一单元可被直接比较，而同一种子的不同模型版本不会被误认为同一份状态。

## 五、层级与细化策略

### 5.1 四个观察／计算层

| 层 | 主要用途 | 允许的状态 | 细化触发 |
| --- | --- | --- | --- |
| G 全球层 | 板块、海陆、大型高程、主气候带、主流域 | 覆盖全行星，始终存在 | 创建世界时生成 |
| R 区域层 | 山脉、盆地、材料区、湖泊、大河与区域气候 | 只细化重要区域或所有被选定区域 | 板块／流域边界、用户观察或验收场景 |
| M 地貌层 | 河谷、峡谷、瀑布、湿地、海岸、崖壁、泉水候选 | 局部按需存在 | 对象资格需要更精细的坡度、容量或连接判断 |
| V 局部三维预留层 | 观察地表形态的网格与纹理 | 仅为已选区域构建 | 用户放大、导出或局部三维查看 |

层级名称是逻辑层，不等于固定的四个网格级别。每一层可以使用多个四叉等级；具体分辨率须在性能和验收目标确定后设定。

### 5.2 细化原则

1. **父级先存在**：子单元只能从已有父单元派生，不能绕开全球／区域骨架独立随机生成。
2. **细化不改父级事实**：子级能细化形态、材料或连续场插值，但不能改变父级板块、海陆、主流域或已冻结的边界身份。
3. **边界一致**：相邻区域精度不同，必须通过明确的聚合／插值规则交换通量和对象连接，不能让河流在分辨率边界断裂。
4. **确定性按需生成**：同一单元在何时被访问不影响其内容；它只由世界规格、单元标识、上游快照和模型版本决定。
5. **为计算而细化**：细化原因应记录为“验收需要”“对象复杂度”“用户查看”或“导出要求”，不能只因画面空白而随机加细节。
6. **限制等级差**：共享边界的活动单元最多相差一个细化等级。若某次细化将造成更大等级差，系统应同步细化邻接区域或拒绝该次细化。

### 5.3 粗细单元之间的守恒交换

当一个粗单元与两个或多个细单元共享边界时，细单元流量之和必须与粗单元在该边界上的总交换一致：

```text
粗单元边界总通量
= Σ（相邻细单元对应边界通量）
```

这项规则适用于水、水汽、热量、沉积物及未来其他守恒量。细化可以提高空间表达精度，但不能产生或删除总量。

连续场在父子层之间需要两类操作：

- **细化／延拓**：根据父单元状态、邻域梯度和模型规则，为子单元建立初值；子单元的面积加权平均应与父级状态一致。
- **聚合／限制**：将子单元结果按真实面积或边界通量聚合回父级，用于全球统计和跨层交换。

具体插值公式可以后定，但守恒要求属于 L1 与数值模块的共同契约。

## 六、几何计算与跨面规则

### 6.1 权威坐标

每个单元同时保存或可计算：

- 面内参数坐标：用于四叉索引和局部网格。
- 三维单位球向量：用于距离、夹角、方向和球体显示。
- 局部切平面基向量：用于坡向、河流局部流向、风向投影和局部三维。
- 球面面积与边界弧段：用于守恒量按面积汇总。

经纬度可以作为用户可读和二维投影的派生坐标，但不应作为跨极区邻接和面积计算的权威依据。

球面位置的权威几何表示为三维单位向量：

```text
P = (x, y, z)，且 |P| = 1
世界表面位置 = P × 行星半径
```

两个单位向量 `A`、`B` 之间的球面距离为：

```text
θ = acos(clamp(A · B, -1, 1))
球面距离 = 行星半径 × θ
```

风、水流和板块运动等方向量应位于当前位置的局部切平面。若 `P` 是表面法向、`V` 是切向运动方向，则：

```text
V · P = 0
```

方向量跨越立方球面接缝时，应通过三维切向量转换到新单元的局部切平面，不直接沿用某个面的“上、下、左、右”。因此面坐标负责索引，单位向量负责几何，经纬度负责人与地图之间的表达。

### 6.2 真实几何量与有限体积语义

立方球面单元不是严格等面积单元。每个单元必须保存或稳定计算：

- 球面面积；
- 各边的球面弧长；
- 单元中心至邻居中心的球面距离；
- 公共边的外法向切向量；
- 单元中心及边／角点的三维单位向量。

后续气候与水文模块应按有限体积语义处理总量。例如区域降水体积为：

```text
区域降水体积 = Σ（单元降水深度 × 单元真实面积）
```

跨单元输送则按公共边的真实长度、局部法向和时间尺度计算。这样既可使用规则块状数据，又不会把网格形变误当成自然差异。

### 6.3 面接缝

面接缝是索引问题，不是世界中的物理边界。L1 必须提供：

- 任意边缘单元到相邻面的邻居映射。
- 穿越接缝时的方向旋转／翻转规则。
- 连续的线对象拆分与重接规则，例如跨面的山脊、板块边界、河流和海岸。
- 接缝两侧相同球面位置的唯一归属，避免双重计数。

所有跨面逻辑必须在 L1 一次实现并由测试覆盖；上层模块不得自行判断“是否到了面边缘”。

## 七、状态在单元中心、边和顶点上的分工

球面空间中的数据不应全部存放在同一种位置。对于一个四边形单元，可以区分：

```text
顶点 ───── 边 ───── 顶点
  │                   │
  │      单元中心      │
  │                   │
顶点 ───── 边 ───── 顶点
```

三种位置各自适合不同性质的数据：

| 位置 | 适合保存 | 原因 |
| --- | --- | --- |
| 单元中心 | 高程状态、温度、降水、雪水、土壤水、地下储量、材料比例等标量 | 每个单元对应明确面积，便于统计、守恒和父子聚合 |
| 单元边 | 水、水汽、热量和沉积物的法向通量；边界类型与跨单元连接 | 两个相邻单元共享同一条边，最适合表达“从谁流向谁、流过多少” |
| 单元顶点 | 球面网格几何、显示网格顶点和派生的平滑地表 | 顶点定义四边形形状，便于生成球体与局部三维网格 |

### 7.1 单元中心状态

首版建议把自然系统中的权威标量放在单元中心。每个中心值代表该单元覆盖面积内的平均值或代表值，例如：

- 平均地表高程；
- 单元平均温度与降水深度；
- 单元内总雪水、土壤水和地下储量；
- 岩性／表层材料的主类别或比例；
- 水体覆盖比例和平均水位状态。

采用中心状态后，区域总量可按真实面积聚合：

```text
区域总量 = Σ（单元平均密度或深度 × 单元真实面积）
```

四叉细化时，四个子单元的面积加权平均应与父单元保持一致，除非某个自然模块明确执行了新的过程计算。

### 7.2 边界通量

水、空气和热量的交换发生在单元之间，因此将法向通量放在共享边上：

```text
单元 A ── 公共边通量 F ──→ 单元 B
```

同一条公共边只保存或计算一次通量。对 A 来说是流出，对 B 来说是等量流入：

```text
A 的变化量 = -F
B 的变化量 = +F
```

这样可以天然避免两个单元分别计算同一条边、却得到不一致结果。跨立方球面面接缝时，公共边仍是同一个球面边对象；在粗细网格交界处，细边通量之和必须等于粗边总通量。

### 7.3 顶点几何与三维显示

单元顶点保存或派生球面单位向量，用于定义网格几何。三维显示顶点可由下式得到：

```text
三维顶点位置 = 球面单位向量 ×（行星半径 + 顶点显示高程）
```

顶点显示高程可以由相邻单元中心高程做受约束插值，并保留山脊、海岸和断崖等不能被任意平滑的边界。它服务于可视化和局部地表网格，不取代中心高程的权威状态。

### 7.4 高程为什么建议放在中心

高程既用于显示，也参与水文和地形计算。若只放在顶点，单元内部的平均高程、储水容量和父子聚合会较难统一；立方球面角点处的共享关系也更复杂。

因此建议：

- 权威地形状态使用单元中心高程及必要的单元内形态摘要。
- 坡度和流向根据中心高程、邻居距离及局部切平面计算。
- 山脊、海岸、河流和崖壁作为独立对象／约束，不依赖显示插值猜测。
- 三维网格的顶点高程由中心状态和对象约束派生。

这会使守恒与水文计算更清晰，同时仍能生成连续的三维表面。

### 7.5 向量状态

板块运动、风和表面流速属于切向量。建议将其权威方向保存为三维切向量，并根据数值模型选择采样位置：

- 板块运动代理可以作为板块对象属性，在任意单元中心查询。
- 气候中的风可以保存在单元中心；进行输送计算时投影到各边的法向。
- 水、水汽、热量和沉积物的实际跨单元交换保存在边上。

因此，中心负责“单元当前有什么”，边负责“单元之间交换多少”，顶点负责“表面怎样连接和显示”。

## 八、局部细化的请求与裁决

任何自然模块都可以发现当前分辨率不足，但不能直接拆分空间单元。所有需求统一提交给“空间细化协调器”，由它合并请求、检查预算、补齐邻接等级、创建确定性的细化计划并产出新的派生快照。

```text
构造／地形／气候／水文／地貌／用户观察／导出
                    ↓ 提交细化请求
              空间细化协调器
                    ↓
       合并区域 → 排序 → 预算 → 2:1 平衡
                    ↓
              确定性细化计划
                    ↓
       创建子单元 → 延拓初值 → 模块重算
                    ↓
            校验并冻结派生快照
```

### 8.1 谁可以提出细化请求

| 请求来源 | 典型原因 | 是否直接获得细化权 |
| --- | --- | --- |
| 构造模块 | 板块边界、三重点或复杂构造区分辨率不足 | 否，只提交请求 |
| 地形与材料模块 | 海岸、山脊、盆地、材料边界需要更细表达 | 否，只提交请求 |
| 气候模块 | 地形抬升或海陆边界使温度／水汽梯度过大 | 否，只提交请求 |
| 水文模块 | 分水岭、湖盆出口、分流或湿地水量无法稳定判断 | 否，只提交请求 |
| 地貌分类模块 | 瀑布、峡谷、河曲、天坑等资格需要更细证据 | 否，只提交请求 |
| 验收系统 | 固定测试世界规定最低空间层级 | 否，但具有最高优先级之一 |
| 用户观察 | 放大某区域，希望查看地貌级或局部三维 | 否，属于交互需求 |
| 导出系统 | 用户要求指定范围与精度的地图或三维数据 | 否，受导出预算约束 |

模块只能说明“哪里、为什么、需要多细、误差或失败是什么”，不能自行分配内存、改变邻居层级或创建子单元。

### 8.2 细化请求的数据结构

每个请求至少包含：

```text
请求标识
来源模块与模型版本
目标球面区域／对象标识
当前层级与请求层级
原因类型
误差指标或条件依据
优先级
有效期与适用季节
预计资源量（若可估算）
```

请求标识由来源、对象、目标层级和模型版本稳定派生。相同请求重复提交只合并一次，不因运行顺序增加额外细化。

### 8.3 四级优先级

| 优先级 | 含义 | 示例 | 预算不足时 |
| --- | --- | --- | --- |
| P0 正确性必需 | 不细化就会破坏拓扑、守恒或测试前提 | 湖盆出口无法判定；粗细通量不守恒；固定测试最低层级 | 当前过程停止并报告资源不足，不能悄悄降级 |
| P1 模型精度 | 当前误差超过已声明容差 | 海岸梯度、地形雨影、分水岭位置不稳定 | 延迟或降低目标层级，并标记条件通过／未验证 |
| P2 用户观察 | 地貌查看、局部三维或对象查询需要 | 用户放大河谷或山峰 | 在交互预算内执行；不足时先显示父级状态 |
| P3 预取与美化 | 预测用户浏览方向或改善远景 | 相邻区块预加载、远处网格细化 | 可直接取消，不影响世界状态 |

P0 不等于无限资源。如果最低正确性所需的细化超过预算，引擎应明确失败，而不是生成看似完整但无法验证的结果。

### 8.4 裁决顺序

协调器按以下固定顺序处理请求：

1. 将请求区域转换为稳定单元集合并去重。
2. 合并重叠请求，对同一区域取必要的最高目标层级。
3. 按优先级、稳定对象标识和请求标识排序，不按提交时间排序。
4. 添加计算缓冲圈，避免梯度或通量在细化边界被截断。
5. 补齐相邻单元，使活动区域满足最多一级的层级差。
6. 估算内存、计算时间和缓存需求，并按预算形成细化计划。
7. 创建子单元，以稳定随机流和父级状态建立初值。
8. 让受影响模块在依赖顺序中重算，并执行守恒、接缝和对象连续性检查。
9. 校验通过后冻结新的派生快照；失败则保留原快照并返回原因。

使用稳定标识排序，能够保证“先查看 A 再查看 B”和“先查看 B 再查看 A”在相同最终细化集合下得到相同结果。

### 8.5 计算细化与显示细分必须区分

用户放大地图时可能发生两类不同操作：

- **显示细分**：增加三角形或纹理采样，使表面更平滑；不增加自然模型精度，不创建新的科学结论。
- **计算细化**：创建新的权威子单元，重新计算局部高程、气候、水文或地貌证据，形成新的派生快照。

界面必须能区分二者。显示更细不能让一个“候选瀑布”自动变成“已计算瀑布”；只有相应计算细化和验收完成后，对象状态才可升级。

### 8.6 细化对父级状态的影响

细化遵循三条规则：

1. 父级的板块、主海陆、主流域和稳定对象身份不被子级随机结果改写。
2. 子级结果可以通过面积加权或通量聚合更新父级的派生统计，例如区域平均降水、总储水量和已细化覆盖率。
3. 子级发现父级分类证据不足时，可以把对象状态从“候选”提升、降级或标为冲突，但必须产生新的版本化派生快照和证据，不能静默覆盖原结论。

### 8.7 卸载与降级

局部细节可从内存卸载或从活动计算集中移出，但这属于缓存管理，不等于删除世界事实：

- 稳定对象标识、父级状态和细化快照摘要继续保留。
- 再次加载同一区域时，根据相同规格、单元标识和模型版本重建相同结果。
- 若模型版本改变，应创建新快照，不混用旧细化缓存。
- P0／P1 需要的活动细化在相关计算完成前不能因界面切换而被回收。

## 九、子级结果与父级状态

四叉细化后，子单元会提供更精细的高程、气候、水文和地貌证据。D04 要解决的是：这些新信息如何反映到全球／区域层，同时避免用户浏览顺序改变世界骨架。

### 9.1 三类父级信息

父级信息按是否允许子级影响分为三类：

| 类别 | 示例 | 子级能否改变 |
| --- | --- | --- |
| 稳定身份与硬边界 | 单元标识、所属板块、主海陆身份、主流域标识、已冻结的构造边界 | 不能直接改变；发现冲突时必须触发上游重算或报告错误 |
| 可聚合的自然状态 | 总水量、总雪水、平均温度、材料比例、覆盖比例、边界总通量 | 可以形成更精确的派生统计，但必须按面积或通量守恒聚合 |
| 分类与证据状态 | 湖泊候选、湿地资格、山地类型、对象可信度、已细化覆盖率 | 可以升级、降级或补充证据，但要生成版本化结论并保留旧状态 |

这里的“不能改变”是指不能由局部子单元静默回写。若子级证明父级主海陆或主流域确实错误，应将其标为结构冲突，并从造成冲突的上游模块开始创建新的世界快照。

### 9.2 原始父快照保持不可变

细化不原地修改父级快照，而是产生一个“细化补丁”：

```text
父快照 V1
├─ 原始父单元状态
└─ 细化补丁 R1
   ├─ 四个或更多子单元
   ├─ 子级对象与连接
   ├─ 向父级聚合的派生摘要
   └─ 输入版本、证据与校验结果
```

查询世界时，解析器读取父快照和当前有效的细化补丁，返回“当前解析视图”。这样可以做到：

- 不细化的区域仍使用父级状态。
- 已细化区域使用子级状态或由子级汇总的结果。
- 删除缓存不会改变原始世界。
- 同一父快照可以比较不同模型版本的细化结果。
- 用户先访问哪个区域不会改变其他区域的父级数据。

### 9.3 聚合规则

不同类型的数据不能使用同一种“平均值”处理。

| 数据类型 | 子级到父级的聚合方式 |
| --- | --- |
| 守恒总量 | 子级总量直接求和，例如水量、雪水量、沉积物质量 |
| 面积平均场 | 按子单元真实面积加权，例如温度、降水深度、平均高程 |
| 边界通量 | 与父边重合的子边通量求和，例如出流、水汽和热量交换 |
| 比例／覆盖 | 各子级覆盖面积求和后除以父级真实面积 |
| 极值 | 保存有效子级最小值和最大值，例如最低鞍部、最高峰候选 |
| 分类 | 按分类规则重新判断，不能简单用多数票 |
| 对象数量 | 按稳定对象标识去重，跨子单元对象不能重复计数 |

例如父单元的平均高程可以按面积加权，但水文不能只读取平均高程。父级地形摘要还应保留：

- 最低与最高高程；
- 关键出口／鞍部高程；
- 水体或高地覆盖比例；
- 已知跨边流向；
- 子级高程分布的简化摘要。

这样全球层可以保持紧凑，又不会因为平均值掩盖湖盆出口或狭窄山脊。

### 9.4 守恒约束

对水、雪、热量、沉积物等守恒或准守恒量，细化前后应满足：

```text
父级初始总量 = Σ 子级初始总量

父边总通量 = Σ 与该父边对应的子边通量
```

若子级执行了一个时间步的自然过程，则允许总量按已声明的输入、输出、损失和储量变化改变，但账本必须闭合：

```text
新储量 - 旧储量
= 输入 - 输出 - 损失
```

超过容差时，细化补丁不能进入有效快照。

### 9.5 地貌分类如何更新

子级可能发现父级无法辨认的对象。例如父级只有“山地河段候选”，细化后发现了明确陡坎和持续水源，因而满足瀑布条件。

更新过程应是：

```text
父级：瀑布候选
       ↓ 子级计算与证据补充
细化补丁：满足坡降、水源和河道连接
       ↓ 规则重新判定
解析视图：受约束生成的瀑布
```

旧的父级候选状态仍保留在 V1，新的状态属于带 R1 的解析视图。若子级发现条件不成立，也可以降级为一般陡坡河段，并记录所缺条件。

### 9.6 子级发现骨架冲突时怎么办

以下情况不能靠局部补丁悄悄修正：

- 父级判定为陆地，子级在检查海平面、通向全球海洋的连续路径、阻隔地形和最低鞍部后，证明该区域应与海洋连通。
- 父级主流域出口向东，子级证明唯一有效出口向西。
- 子级板块边界与父级稳定板块身份不相容。
- 局部细化导致跨区域水量、边界通量或对象连接无法闭合。

此时应：

1. 将细化补丁标记为结构冲突，不进入有效解析视图。
2. 追踪冲突依赖，定位到海平面、地形、构造或其他上游模块。
3. 从相应上游输入创建新世界快照，例如 V2。
4. 使受影响的气候、水文、地貌和显示缓存失效并按依赖顺序重算。

这保证局部细节能发现全球骨架问题，却不能在没有版本记录的情况下改写世界。

低于海平面本身不构成海陆冲突。一个单元或盆地即使低于全球海平面，只要被较高地形围闭且没有低于海平面的连续通道连接全球海洋，就可以保持为陆地低地、干盐盆、季节湖或内流湖。它是否积水还需要结合水量收支、蒸发、入渗、湖盆容量与溢流高程判断。

### 9.7 何时形成新的正式快照

下列事件可形成新的版本化世界快照：

- P0／P1 计算细化完成并影响正式模型结论。
- 固定测试世界要求保存本次细化及验收证据。
- 用户明确保存、导出或比较当前精细状态。
- 子级发现需要上游重算的结构冲突，并完成新一轮依赖计算。

仅用于相机缩放的显示细分不形成自然状态快照。P2 观察请求产生的计算细化可先作为缓存补丁；一旦被对象查询、导出或正式验收采用，就应连同模型版本与证据保存。

### 9.8 D04 建议规则

```text
父级原始快照不可变
子级结果以版本化细化补丁存在
守恒量按总量或通量聚合
连续场按真实面积聚合
分类依据规则和证据重新判断
稳定身份不能被局部结果静默改写
结构冲突触发新的上游快照
```

## 十、跨层对象、拓扑与多尺度几何

D05 处理河流、海岸、板块边界、山脊等对象如何在全球、区域和地貌层中保持同一个身份。核心原则是：**对象不是一串被涂色的网格单元**。对象拥有独立身份、拓扑关系和球面几何；网格只负责自然场计算和空间索引。

```text
对象身份与拓扑               多尺度几何
河流 R17                     全球层：主干概化线
├─ 上游节点 N1               区域层：弯曲与主要支流
├─ 汇流节点 N2               地貌层：河曲、分汊、岸线
└─ 入湖节点 N3               局部层：显示网格与河岸细节
           ↘
       各层单元覆盖索引（派生缓存）
```

### 10.1 对象注册表

所有具有独立意义的点、线、区域对象进入统一注册表。每个对象至少保存：

```text
稳定对象标识
对象类型与模型状态
稳定父级／所属系统
拓扑节点和连接关系
权威球面几何及其版本
不同层级的几何表达
季节状态与活动范围
证据、依赖与生成版本
网格覆盖索引（可重建缓存）
```

对象标识不使用当前网格单元编号直接拼接。否则单元细化、合并或重新索引会改变河流和海岸的身份。对象标识应由世界、对象类型、稳定生成来源及父级关系确定。

### 10.2 身份、拓扑、几何和覆盖索引分离

| 层面 | 回答的问题 | 示例 |
| --- | --- | --- |
| 身份 | 它是不是同一个对象？ | 这是河流 R17，而不是另一条河 |
| 拓扑 | 它连接谁、从哪里到哪里？ | 支流汇入主流，主流进入湖泊后从出口流出 |
| 几何 | 它在球面上具体经过哪里？ | R17 在区域层的球面折线和地貌层河岸 |
| 网格索引 | 哪些单元与它相交或受它影响？ | R17 穿过的 L8、L10 单元集合 |

网格索引可以随层级重新计算，身份和拓扑不能因此改变。几何可以细化，但必须记录它对应的对象版本和父级几何。

### 10.3 对象的基本几何类型

| 几何类型 | 对象示例 | 权威表达 |
| --- | --- | --- |
| 点／锚点 | 峰顶、泉眼、瀑布位置、洞口、河网节点 | 三维单位向量、高程／深度与稳定锚点标识 |
| 线／网络边 | 河流、山脊、板块边界、崖壁边缘 | 由球面向量控制点组成的有向或无向曲线 |
| 区域／多区域 | 板块、湖泊、岛屿、湿地、材料区 | 球面闭合边界、内部／外部规则与可能的孔洞 |
| 体／地下连接 | 地下储层、洞穴候选范围、暗河连接 | 水平范围、深度范围与连接图；首版不要求完整体网格 |

对象几何跨越立方球面面接缝时保持同一条球面曲线或区域。为索引和显示可以在接缝处分段，但分段不产生新对象。

### 10.4 多尺度几何

同一对象可以拥有多个几何精度：

```text
对象 R17
├─ G：全球概化主干，保证主要连接和去向
├─ R：区域几何，加入主要弯曲、支流与河谷关系
├─ M：地貌几何，加入河曲、分汊、岛体和河岸
└─ V：局部显示几何，不增加未经计算的自然事实
```

从低层级到高层级必须满足：

- 端点、汇流点、分流点、入湖／出湖点和入海点等拓扑锚点不因几何细化消失。
- 更精细曲线可以在锚点之间增加控制点，但不能无证据改变对象连接。
- 低层级几何由高层级几何按保拓扑概化得到，不能用普通平滑算法删除狭窄海峡、河流汇合或岛屿孔洞。
- 精细几何尚未计算时，显示层使用已知的粗几何，并明确其泛化状态。

### 10.5 河网对象

河流使用有向图表达：

```text
节点：源头、汇流、分流、湖泊入口／出口、入海口
边：节点之间的河段
属性：流向、季节状态、水量、河段等级、几何版本
```

细化一条主河的弯曲形状，不会创建一条新河。发现一条新的支流时，则创建新的河段或支流对象，并连接到已有汇流节点。分流和再汇合必须保留独立河段标识及水量分配关系。

### 10.6 海岸与低于海平面的内陆盆地

海岸线不是简单的“高程等于海平面”的等值线。正式海岸至少需要：

```text
水面达到该高程
+ 水体与全球海洋连通
+ 中间不存在高于水面的封闭屏障
+ 当前世界快照中的海平面状态成立
```

因此：

- 低于海平面但与海洋隔绝的盆地不生成海岸线。
- 该盆地可以是干盆地、盐沼、季节湖或内流湖，取决于气候与水文收支。
- 若盆地通过低于海平面的通道与海洋相连，才进入海洋连通域并改变海岸拓扑。
- 狭窄海峡或低鞍部是否连通不明确时，应提交 P0／P1 细化请求，不能仅按父级平均高程判断。

海岸对象使用闭合或多段球面曲线表达，并保存相邻的海洋对象、陆地区域、岛屿／孔洞关系和海平面版本。

### 10.7 板块边界与山脊

板块边界由相邻板块对和球面曲线共同定义。同一条边界可跨越多个面和细化层，但相邻板块身份不能改变。三重点作为稳定拓扑节点保存，边界几何细化不能使其断开或重复。

山脊、崖壁等线状地貌也采用独立对象。它们可以约束地形插值和局部三维，避免单纯插值把山脊磨平或把崖壁变成缓坡。

### 10.8 季节变化与对象身份

稳定对象和季节几何需要分开：

- 河流对象保持不变，但河段可以处于常流、季节流、断流或漫流状态。
- 湖盆对象保持不变，但湖面边界可随代表季节变化。
- 湿地候选区保持不变，但实际淹水范围和水文状态可变化。
- 全球海岸在固定海平面下属于稳定骨架；若未来启用海平面情景，则每个情景产生版本化海岸几何。

季节切换不能创建一个没有来源关系的“新河流”，也不能让湖泊和岛屿失去稳定父级身份。

### 10.9 D05 建议规则

```text
对象拥有独立于网格的稳定标识
拓扑连接与几何形状分开保存
权威几何使用球面向量表达
每个尺度拥有保拓扑的几何版本
单元覆盖关系只是可重建的空间索引
跨面分段不产生新对象
季节改变状态和范围，不随意改变身份
海岸由海洋连通与水面条件共同确定
```

## 十一、显示投影与视图适配

D06 决定首版怎样观察同一份球面世界数据。显示适配器只把权威球面几何转换为屏幕坐标、三维网格、标签和交互命中结果；它不拥有板块、海岸、河流或高程等自然状态。

```text
世界快照与对象注册表
          ↓
     视图适配器
    ↙      ↓       ↘
 球体   等经纬图   局部平面／三维
```

### 11.1 首版三种视图

| 视图 | 主要用途 | 几何方式 | 明确限制 |
| --- | --- | --- | --- |
| 交互球体 | 世界探索、全球关系、跨极区和跨经线观察 | 直接使用球面向量和立方球面网格生成曲面 | 屏幕背面不可同时观察；远景细节有限 |
| 等经纬图 | 全球总览、调试、对比图层、保存二维纹理和数据导出 | 经度映射横轴、纬度映射纵轴 | 极区面积和形状严重拉伸，左右边界是显示接缝 |
| 局部切平面／三维 | 区域和地貌级观察、地形网格、局部测量 | 以选定锚点建立东—北—上局部坐标 | 只适合有限范围，范围扩大后球面误差增加 |

首版不必立即支持墨卡托、莫尔威德、兰伯特等更多投影。以后若需要航向观察、等面积统计图或专题地图，再添加相应适配器；新增投影不改变 L1 权威空间。

### 11.2 球体视图

球体是地图探索的主要入口，直接读取单元角点和对象的三维球面向量：

```text
表面位置 = 球面单位向量 ×（行星半径 + 显示高程）
```

球体视图负责：

- 旋转、缩放、选取位置和对象；
- 按屏幕误差选择合适的显示层级；
- 显示板块、地形、气候、水文、材料和对象图层；
- 将点击射线与球面相交，得到权威球面向量，再查询空间单元和对象。

球体视图的网格可以为了画面平滑而细分，但这属于显示细分。只有当用户需要更精确的自然状态时，才由 D03 流程提交 P2 计算细化请求。

### 11.3 等经纬图

等经纬图采用简单映射：

```text
x = 经度
y = 纬度
```

它适合：

- 同时查看整颗行星；
- 对比高程、温度、降水、流域和材料等连续场；
- 输出规则二维栅格；
- 检查接缝、对象连接和全球统计。

它不适合直接判断面积、距离或形状，尤其是高纬地区。面积与距离工具必须查询球面权威几何，不能使用屏幕像素估算。

等经纬图在正负 180° 经线处有显示接缝。跨越该经线的河流、海岸或板块边界可以为绘制而临时拆成两段，但两段共享同一对象标识；显示接缝不能写回对象拓扑。

### 11.4 局部切平面与局部三维

选定球面锚点 `P` 后，建立局部东、北、上三个方向：

```text
上：球面法向 P
东：局部切向 E
北：局部切向 N
```

附近球面点可转换为局部坐标：

```text
X：沿 E 的局部距离
Y：沿 N 的局部距离
Z：相对高程
```

这一坐标系用于区域平面图、地貌测量和局部三维网格。它不会把局部世界真正压平；所有对象仍保留球面向量，局部坐标只是当前视图的派生表达。

当观察范围扩大到局部平面误差超过容差时，适配器应切换锚点、分块显示或返回球体视图，不能继续把大范围球面当作无限平面。

### 11.5 三种视图之间的同步

三种视图共享以下状态引用：

- 世界快照和代表季节；
- 选中的对象标识或球面位置；
- 当前自然图层及其模型状态；
- 已加载的细化补丁；
- 时间、单位和高程显示设置。

例如在等经纬图中点击河流 R17，应通过反投影得到球面位置并选中对象 R17；切换到球体或局部三维后仍选中同一对象，而不是通过颜色重新猜测对象。

### 11.6 高程夸张

真实行星半径远大于地形高差。若严格按比例绘制，山脉在全球球体上几乎不可见。因此显示层可以提供高程夸张：

```text
显示高程 = 真实／模型高程 × 显示倍率
```

高程倍率必须作为视图设置明确显示，并满足：

- 不写回权威高程、坡度或水流方向；
- 测距、坡度和对象查询使用未夸张数据；
- 导出时记录是否应用显示夸张；
- 局部三维可根据观察尺度使用不同倍率，但不能暗示物理高差发生变化。

### 11.7 投影、采样与对象显示

连续场显示时，适配器从当前解析快照采样，并记录来源层级和模型状态。线与区域对象则直接投影其多尺度球面几何。两者不能混用：河流不应仅靠给若干像素染蓝来替代对象几何，海岸也不应由显示纹理反向提取后写回世界。

| 显示行为 | 是否允许 | 原因 |
| --- | --- | --- |
| 为抗锯齿增加采样 | 允许 | 只影响画面 |
| 为远景概化曲线 | 允许 | 保留对象标识和拓扑锚点 |
| 在接缝处分割绘制 | 允许 | 仅是投影处理 |
| 依据屏幕像素重算海陆 | 不允许 | 海陆来自自然快照和连通关系 |
| 为美观随机抬高山峰 | 不允许 | 会伪造自然状态 |
| 使用高程夸张 | 允许 | 必须标明倍率，计算仍用权威高程 |

### 11.8 D06 建议规则

```text
球体是首版主要探索入口
等经纬图用于全球总览、调试与规则栅格导出
局部切平面服务区域观察和局部三维
所有视图共享世界快照、对象标识与季节状态
投影接缝只存在于显示层
高程夸张只影响显示
更多专题投影后置为可插拔适配器
```

## 十二、L1 的最小验收集

在建立任何板块、地形或气候模型前，L1 应先通过以下测试：

| 编号 | 测试 | 通过条件 |
| --- | --- | --- |
| S01 球面覆盖 | 六个面在球面上无空洞、无重叠；每个采样点有唯一单元归属 |
| S02 跨面邻接 | 每个边缘单元都能找到正确邻居；跨接缝方向可逆 |
| S03 父子一致 | 子单元完全覆盖父单元；聚合面积与父单元面积在容差内一致 |
| S04 距离与面积 | 极区、接缝和面中心的距离／面积误差在预设容差内，并能被报告 |
| S05 对象连续 | 人工构造的跨面线和区域对象没有断裂、重复或方向翻转 |
| S06 按需确定性 | 先细化 A 再细化 B，与先细化 B 再细化 A，得到相同单元标识与属性输入 |
| S07 显示隔离 | 改变投影、相机、贴图分辨率后，权威空间快照摘要不变 |
| S08 请求顺序无关 | 相同请求集合以不同顺序提交，得到相同细化单元、结果摘要和对象状态 |
| S09 预算与优先级 | 预算不足时 P0 明确失败、P1 标记降级、P2 返回父级结果、P3 可取消 |
| S10 计算／显示隔离 | 只增加显示细分不会改变自然字段、对象证据或计算层级 |
| S11 父子聚合 | 子级总量、面积平均、边界通量和覆盖比例能按规定还原父级摘要 |
| S12 快照不可变 | 加载、卸载或更换细化补丁不会修改原始父快照摘要 |
| S13 结构冲突 | 子级与父级硬边界冲突时拒绝补丁，并正确定位需要重算的上游依赖 |
| S14 对象身份 | 同一河流、海岸或板块边界在细化、概化、跨面和重新加载后保持稳定标识 |
| S15 拓扑保持 | 概化与细化不会删除汇流、分流、三重点、狭窄海峡或区域孔洞等关键关系 |
| S16 海洋连通 | 低于海平面的封闭盆地不被误判为海洋；打开低鞍部通道后连通域和海岸正确变化 |
| S17 视图一致 | 同一球面位置或对象在球体、等经纬图和局部三维中查询到相同稳定标识与状态 |
| S18 接缝隔离 | 跨越等经纬图接缝的对象只在绘制时分段，不改变权威几何和拓扑 |
| S19 显示参数隔离 | 改变高程夸张、相机、抗锯齿和显示层级后，权威高程、坡度、流向和对象证据不变 |
| S20 局部平面范围 | 超出局部投影误差容差时正确分块、切换锚点或返回球体，不继续使用失真的局部坐标 |

## 十三、已确认事项与剩余决定

### 13.1 已确认

- 首版权威空间采用分层立方球面网格。
- 面内采用四叉细化，相邻活动区域最多相差一个细化等级。
- 球面三维单位向量是距离、方向、边界与局部切平面的权威几何。
- 每个单元使用真实球面面积、边长和中心距离参与计算。
- 经纬度、等经纬图和球体贴图是派生显示方式，不修改世界状态。
- 全球使用较低层级完整覆盖，区域、地貌和局部三维按需细化；细化不改变父级稳定身份和已经冻结的全球骨架。
- 粗细网格之间的水、热量、水汽和沉积物等交换必须守恒。
- 立方体到球面的投影采用等角立方球面：面内均匀划分角度，以正切映射到立方体面，再归一化为三维球面向量。
- 权威标量位于单元中心，跨单元通量位于共享边，球面与显示几何位于顶点；三者共同组成空间状态。
- 所有模块只提交细化请求，由统一空间细化协调器按 P0 正确性、P1 模型精度、P2 用户观察、P3 预取美化裁决；计算细化与显示细分严格分离。
- 父级原始快照保持不可变，子级结果以版本化细化补丁存在；可聚合状态更新派生统计，稳定身份和硬边界不能被局部结果静默改写，结构冲突触发上游新快照。
- 海陆不能只按高程与海平面比较；低于海平面的封闭内陆盆地可保持为陆地低地、干盆地或内流湖候选，必须结合海洋连通、阻隔地形、最低鞍部与水量条件判断。
- 河流、海岸、板块边界等对象独立于网格保存稳定身份、拓扑关系和多尺度球面几何；单元覆盖只是可重建索引，跨面或投影分段不产生新对象。
- 首版采用三种共享世界状态的视图：交互球体作为主要探索入口，等经纬图用于全球总览、调试和规则栅格导出，局部切平面用于区域地图与局部三维；投影接缝和高程夸张只影响显示。

### 13.2 L1 实现状态

L1-D01 至 L1-D06 均已确认。目前没有未决的 L1 架构事项。E1 已把等角立方球面、稳定身份、权威几何、跨面拓扑、L8/L10 补丁、查询与空间发布实现为正式模块，并通过 macOS Apple Silicon 与 Windows AMD64 原生验收。

双平台离散证据、规范清单摘要和测试数量完全一致，E1 已冻结。下一步为 E2 构造／M1 实施方案；未经单独确认不修改 E2 代码。

### 13.3 可通过原型和性能试验再确定

- 全球基础层级、区域层级和地貌层级的具体分辨率。
- 最大细化层级、同时活动区块数量、内存和磁盘缓存预算。
- 面积、距离、邻接与守恒测试的具体数值容差。
- 几何量使用 64 位还是混合精度；当前倾向权威几何使用 64 位，主要连续场按误差测试选择精度。
- 区块尺寸、压缩方式、序列化格式和缓存淘汰策略。
- 细化与聚合使用的具体插值、限制器和通量修正算法。

这些数字应在 S01–S07 空间测试和第一个构造测试世界上通过基准数据决定，不需要在概念阶段凭直觉固定。
