# 板块状态层设计

> **文档状态**
>
> - 文档类型：分层设计
> - 决策状态：已确认
> - 实现状态：未实现；定量参数待校准
> - 版本：0.1
> - 说明：L3 架构决定已确认。

本文讨论构造子引擎的 L3“板块状态层”。L3 在 L1 球面空间和 L2 世界规格之上，生成覆盖整颗行星的板块对象、稳定拓扑、壳体倾向和运动代理，为 L4 边界动力学代理层提供输入。

关联：[构造引擎前置条件清单](构造引擎前置条件清单（讨论稿）.md) · [球面空间底座设计](球面空间底座设计（讨论稿）.md) · [全球规格层设计](全球规格层设计（讨论稿）.md)。

## 一、L3 的职责与边界

### L3 负责

- 创建稳定板块对象及其标识。
- 形成覆盖完整球面的无缝板块分区。
- 保存板块面积、代表位置、邻接关系和共享边界身份。
- 为板块分配陆壳、洋壳和过渡壳的空间倾向。
- 保存板块级运动／活动代理，供 L4 计算相对边界关系。
- 区分主板块、微板块及其状态边界。
- 输出可重现、可查询和可验证的板块快照。

### L3 不负责

- 判断边界最终属于汇聚、离散还是走滑；这是 L4 的职责。
- 直接生成山脉、裂谷、海沟或火山；L5 才把边界关系转换为构造地形约束。
- 把陆壳倾向直接当成陆地，把洋壳倾向直接当成海洋。
- 计算真实地幔对流、板块速度历史、地震或火山喷发。
- 因为用户想看更多山脉而直接修改板块边界。

## 二、L3 的输入与输出

### 输入

```text
L1 球面空间、稳定单元和球面几何
L2 WorldSpec、earthlike-v1 与命名随机流
板块数量、大陆破碎度、构造活动度等解析偏好
K01–K04 固定测试输入（测试模式下）
```

### 输出

```text
PlateSetSnapshot
├─ 板块对象注册表
├─ 完全球面分区
├─ 板块邻接图
├─ 共享边界与三重点拓扑
├─ 壳体倾向场
├─ 板块运动／活动代理
└─ 证据、版本和验证结果
```

## 三、L3 拟议决定

| 编号 | 需要确定的问题 | 当前建议 |
| --- | --- | --- |
| L3-D01 | 板块对象和全球覆盖怎样定义 | 板块是具有稳定身份、连通球面区域和邻接拓扑的对象；覆盖必须无空洞、无重叠 |
| L3-D02 | 初始板块怎样生成 | 稳定板块核＋加权球面分区＋受约束生长／松弛，避免直接使用规则噪声切块 |
| L3-D03 | 陆壳、洋壳与过渡壳怎样表达 | 壳体倾向是板块内部的连续／区域属性，不与板块类型或海陆结果绑定 |
| L3-D04 | 板块运动代理怎样保存 | 每板块保存球面刚体旋转代理或等价切向场，L4 再计算相邻板块相对运动 |
| L3-D05 | 主板块、微板块和碎片怎样区分 | 主板块满足面积与连通门槛，微板块数量受限；不允许无意义碎片泛滥 |
| L3-D06 | 板块状态还需要哪些历史代理 | 首版只保留当前运动活动度和结构继承／相对成熟度代理；不伪造绝对壳龄和真实地质历史 |
| L3-D07 | 板块快照怎样验收 | 覆盖、连通、面积、邻接、拓扑、确定性和偏好方向均有独立测试 |

## 四、L3-D01：板块对象与完整球面分区

### 4.1 板块不等于大陆

板块是构造分区，大陆和海洋是地壳倾向、地形与海平面共同作用的结果。一块板块可以同时包含：

- 大陆壳倾向区；
- 洋壳倾向区；
- 大陆边缘和过渡壳区；
- 最终高于或低于海平面的不同区域。

因此禁止使用：

```text
continentalPlate = land
oceanicPlate = ocean
```

更合适的关系是：

```text
板块对象
└─ 板块内部壳体倾向场
       ↓ 与构造高程、侵蚀和水量共同作用
最终地形与海陆
```

### 4.2 板块对象最低数据

每个板块至少保存：

```text
plateId
板块级别：主板块／微板块
球面区域与边界版本
面积、球面质心和代表锚点
邻接板块标识
共享边界标识
壳体倾向摘要
运动／活动代理引用
稳定随机来源
模型状态、证据与版本
```

板块名称属于显示和世界设定层，可后续生成；名称不能参与板块身份、邻接和物理计算。

### 4.3 身份、分区、几何与单元索引分开

板块沿用 L1-D05 的对象规则：

| 层面 | 内容 | 是否权威 |
| --- | --- | --- |
| 身份 | plateId、级别、版本和来源 | 是 |
| 拓扑 | 邻接图、共享边界、三重点 | 是 |
| 球面分区 | 任意球面位置属于哪块板块的唯一规则 | 是 |
| 边界几何 | 不同层级的球面边界曲线 | 是，按几何版本管理 |
| 单元覆盖索引 | 各 L1 层级中与板块相交／归属的单元 | 派生缓存，可重建 |
| 地图颜色和名称 | 显示属性 | 否 |

板块不能仅由某一层级的单元列表定义。四叉细化后，子单元应通过权威球面分区查询归属；边界附近可以请求更高精度，而板块身份和邻接不随网格层级改变。

### 4.4 完整覆盖的不变量

PlateSetSnapshot 必须满足：

```text
所有板块区域的并集 = 完整球面
任意两个板块的内部没有面积重叠
任意非边界球面点只属于一个板块
边界点按固定规则拥有唯一索引归属，同时保留共享边界关系
```

具体要求：

- 不存在未分配空洞。
- 不存在面积重叠。
- 立方球面面接缝和角点不是板块边界，除非构造分区恰好经过那里。
- 每段普通共享边界连接恰好两个板块。
- 三重点连接三个边界分支和至少三个板块关系。
- 四块或更多板块精确共点通常应拆成相距很近的多个三重点，除非测试世界明确要求特殊退化拓扑。
- 不允许边界在球面内部无故终止。

### 4.5 连通性

首版建议每个主板块的球面区域必须连通。这里的连通指板块区域在球面上存在连续路径，与最终海陆无关；一块板块可以通过洋壳区连接两个大陆壳碎片。

若一个生成结果包含两个完全断开的区域：

- 如果它们在构造上应独立运动，应拆成两个板块对象。
- 如果只是壳体性质不同但板块仍连续，应由板块内部壳体倾向表达。
- 不能为了减少板块数量，把两个无连接区域强行共享同一个 plateId。

微板块也应连通。板块内部允许孔洞的情况会使邻接和运动解释显著复杂，首版不建议允许“一个板块完全包围另一个板块”的普通随机结果；若未来支持，应作为显式拓扑能力单独验证。

### 4.6 面积、形状和碎片约束

D01 暂不冻结具体面积数字，但确认以下规则：

- 主板块必须超过版本化最小面积门槛。
- 微板块使用更低门槛，但数量和总面积占比受限。
- 禁止单单元宽度、长距离蛇形和无构造意义的碎片区域。
- 板块形状允许不规则，不能退化为完美圆形或规则多边形集合。
- 板块边界的几何细节应与当前空间层级相匹配，不能在全球层制造大量像素锯齿。
- 面积与紧凑度限制属于生成约束，不表示现实板块都近似圆形。

具体阈值由 L3 原型在固定种子组上统计后确定，并进入板块模型版本。

### 4.7 边界对象与所有权

边界应作为独立对象保存：

```text
boundaryId
相邻 plateA / plateB（按稳定规则排序）
球面曲线与多尺度几何
端点／三重点
长度与邻接证据
L4 边界状态引用（尚未计算时为空）
```

边界不“属于”某一侧板块，而由两侧共同共享。对恰好落在边界上的空间查询，L1 可以用稳定 plateId 排序规则返回唯一单元归属，但对象查询必须同时返回共享边界和两侧板块。

### 4.8 稳定标识

plateId 和 boundaryId 由固定命名随机流、创建角色和稳定候选索引派生，不使用显示名称、当前颜色、数组内存位置或遍历顺序。

建议在生成完成后按稳定球面锚点、对象来源和确定性排序冻结标识。后续细化只更新几何版本，不改变 plateId。若新模型改变板块拓扑，则按 L2-D06 创建升级分支和对象谱系。

### 4.9 主板块与微板块

首版对象类型可以先分为：

| 类型 | 含义 | 约束 |
| --- | --- | --- |
| 主板块 | 构成全球一级构造分区 | 数量和面积服从类地预设及偏好，必须连通 |
| 微板块 | 位于复杂边界附近的较小独立运动分区 | 数量受限，需要明确形成规则和独立运动代理 |

小岛、陆壳碎片、海山和岛弧不自动成为微板块。是否是微板块取决于构造区域和运动身份，不取决于它是否露出海面。

### 4.10 D01 建议规则

```text
板块是独立的连通球面区域对象，不等于大陆或海洋
板块身份、拓扑、分区、几何和网格索引分开保存
全部板块无空洞、无面积重叠地覆盖完整球面
普通边界共享两个板块，三重点保存稳定拓扑
主板块和微板块均需满足面积、连通和形状约束
小岛与大陆碎片不自动成为板块
边界由两侧共享，L4 再赋予相对运动分类
细化不改变 plateId，模型升级通过谱系表达变化
```

## 五、L3-D02：板块核、球面分区与受约束生长

首版不模拟板块从远古时代运动到当前的完整历史，因此板块生成器的目标是构造一个满足拓扑、尺度和形态约束的代表性构造分区。结果状态是“受约束生成”，不是“已计算的真实板块演化”。

### 5.1 为什么不能只使用球面 Voronoi

最简单的做法是在球面放置若干中心点，把每个位置分给最近中心：

```text
球面板块核
    ↓ 最近距离
球面 Voronoi 分区
```

它有良好的完整覆盖和连通起点，但直接作为最终结果会出现：

- 板块尺寸过于接近；
- 边界像规则多边形；
- 三重点和边界曲率缺少层次；
- 大量边界仅由“离哪个中心最近”决定，无法表达方向性和区域结构；
- 调整板块数量时，整个分区可能过度跳变。

因此 Voronoi 适合生成初始候选，不适合作为最终板块模型。

### 5.2 建议的混合流程

```text
1. 解析主板块数量与面积先验
2. 放置稳定板块核
3. 生成加权球面初始分区
4. 在 L1 邻接图上受约束连通生长
5. 执行有限次数的面积／形态松弛
6. 用低频连续场调整边界形态
7. 修复碎片、狭颈和退化拓扑
8. 冻结板块、边界、邻接与证据
```

微板块可在主板块骨架稳定后、依据 D05 规则插入复杂边界区；它们不应与主板块在同一无约束步骤中随机竞争全球面积。

### 5.3 板块数量和目标面积

板块数量来自 `earthlike-v1` 的合理范围、种子样本和“板块数量”高级偏好。D02 暂不冻结具体数量区间，由 D05 与固定种子统计共同决定。

每个板块在生成前获得一个目标面积权重：

```text
所有目标面积之和 = 完整球面面积
每块目标面积位于主板块允许范围内
```

权重允许产生少数大型板块和若干中小型板块，不能默认所有板块等面积。权重分布、上下限和归一化方式属于板块模型版本。

目标面积是生长约束，不是最终必须精确达到的配额。最终面积可在容差内偏离，以容纳连通性、形状和拓扑要求。

### 5.4 稳定板块核

板块核是生成分区的起点，不等于最终板块质心、火山中心或大陆中心。

核的放置建议采用球面上的受控蓝噪声／最小间距候选：

- 大型板块核通常需要更大的邻域空间。
- 核不能在球面某一面、极区或接缝处产生算法偏见。
- 最小间距防止两个主板块在生成开始时几乎重合。
- 候选由命名随机流和稳定索引产生。
- 有界重试、接受条件和实际尝试编号进入证据。

不要求核均匀分布；面积权重和种子可以产生疏密变化，但不能形成无法满足最小面积的拥挤区域。

### 5.5 加权球面初始分区

初始分区根据球面距离和板块面积权重决定候选归属。大型目标板块具有更强的空间影响，小型目标板块影响范围较小。

这一阶段只需要得到：

- 完整无空洞的初始分区；
- 每个板块从核开始的连通候选区；
- 初始邻接图和边界候选；
- 距离目标面积的偏差。

它不直接决定最终边界形状，也不生成边界类型和构造地形。

### 5.6 受约束连通生长

随后在 L1 全球基础层的邻接图上，从每个板块核向外扩展。单元归属代价可以概念化为：

```text
归属代价
= 球面距离项
+ 目标面积偏差项
+ 低频方向场项
+ 形状／狭颈惩罚
+ 拓扑约束项
```

- 球面距离避免板块无意义地跳过附近区域。
- 面积项使板块总体接近目标尺度。
- 低频方向场让边界出现大尺度弯曲和方向性。
- 狭颈惩罚减少单单元宽度的长蛇形连接。
- 拓扑项保证板块连通、无空洞且边界关系合法。

使用从板块核连续扩张的前沿，比对每个单元独立选择最低代价更容易保证连通性。并列代价必须按稳定 plateId 和单元标识裁决，不能依赖线程完成顺序。

### 5.7 有限松弛

初始生长可能产生面积偏差或过度尖锐的形状。可以执行有限次数的确定性松弛：

1. 计算每块板块的实际面积、球面质心、周长和形状指标。
2. 在不破坏连通和拓扑的前提下调整边界附近候选归属。
3. 降低过大面积偏差、单元锯齿和极端狭颈。
4. 达到容差或固定迭代上限后停止。

松弛不能无限运行到所有板块近似等面积圆形。停止条件和最大迭代数必须版本化；未达到门槛时应重试、降级或报告失败。

### 5.8 低频边界形态场

板块边界需要不规则但连续的形态。建议使用球面连续的低频场调整生长代价和边界位置：

- 场由稳定球面基函数或可跨区块连续采样的随机场构成。
- 只在较大空间尺度上影响板块轮廓。
- 不使用每单元独立噪声制造锯齿。
- 不把视觉噪声解释为真实断层或板块运动历史。
- 区域／地貌层可进一步细化几何，但不得改变 L3 邻接拓扑。

边界弯曲只能让分区更自然，不能预先把某段边界指定为山脉、裂谷或海沟。

### 5.9 拓扑和形态修复

冻结前必须检查：

- 所有板块连通；
- 没有未分配单元和面积重叠；
- 没有低于最小面积的主板块；
- 没有过长的单单元狭颈和孤立碎片；
- 普通边界连接两个板块；
- 三重点关系一致；
- 没有因立方球面接缝产生的异常折线；
- 面积、周长和紧凑度处于允许范围。

修复顺序必须固定。例如先处理孤立碎片，再处理狭颈，最后处理退化三重点。每次合并、重分配或重试都记录原因。

若修复需要改变板块数量或破坏目标面积范围，应回到候选生成阶段使用下一个有界尝试，而不是在最终结果中静默删除板块。

### 5.10 确定性与并行

板块生长可以并行计算候选代价，但最终归属提交必须使用稳定顺序或确定性批次：

- 随机样本由 plateId、cellId、属性和尝试编号派生。
- 相同代价按固定规则裁决。
- 面积统计使用规定的归约顺序或数值容差。
- 松弛每轮使用上一轮冻结状态，不读取同轮未完成修改。
- 不同线程数和区块处理顺序应得到相同拓扑、标识和离散归属。

### 5.11 生成证据

PlateSetSnapshot 应保存：

```text
请求和解析后的板块数量
每块目标面积与实际面积
板块核和接受尝试编号
生长／松弛模型版本
实际迭代次数和停止原因
低频边界场版本
拓扑修复记录
被拒绝候选及原因摘要
覆盖、连通、面积和形态检查结果
```

这些信息用于解释板块为什么具有当前尺度和轮廓，不用于编造真实地质年代。

### 5.12 D02 建议规则

```text
球面 Voronoi 只提供初始候选，不直接作为最终板块
板块数量和目标面积来自预设、偏好与稳定随机样本
稳定板块核使用球面最小间距候选
加权初始分区后执行受约束连通生长
有限松弛平衡面积、形态和狭颈问题
低频连续场提供大尺度边界不规则性
拓扑修复有固定顺序并完整记录
微板块在主板块骨架稳定后按专门规则处理
线程、区块和访问顺序不改变最终离散分区
```

## 六、L3-D03：大陆壳、海洋壳与过渡壳倾向

板块说明地表由哪个构造区域携带，壳体倾向说明该位置具有怎样的大尺度地壳背景。二者是不同维度：同一板块可以包含大陆壳、过渡壳和海洋壳；同一片大陆性区域也可能在板块边界两侧相接。

### 6.1 壳体倾向不等于岩性

L3 的壳体状态描述大尺度地壳性质，例如相对厚度、浮力和大陆性程度。它不直接表示花岗岩、石灰岩、玄武岩、土壤或沉积物等具体材料；详细岩性与表层材料由后续材料模块生成。

```text
壳体倾向：大陆性／海洋性／过渡性及厚度、浮力代理
材料属性：具体岩性、可溶性、渗透性、抗侵蚀性等
```

两者可以相关，但不能把“大​​陆壳倾向”直接翻译成某一种岩石。

### 6.2 连续属性与分类标签

建议先保存连续属性，再从连续属性派生便于查询的分类：

```text
continentality：大陆性倾向，范围 0～1
crustThicknessProxy：相对壳体厚度
buoyancyProxy：相对浮力／基底抬升倾向
confidence：模型置信或混合程度
```

分类可以按版本化门槛派生：

| 派生分类 | 典型连续状态 | 含义 |
| --- | --- | --- |
| 海洋壳倾向 | continentality 较低 | 通常较薄、相对低浮力的壳体背景 |
| 过渡壳倾向 | continentality 居中或属性混合 | 大陆边缘、裂解过渡区或性质未完全明确区域 |
| 大陆壳倾向 | continentality 较高 | 通常较厚、相对高浮力的壳体背景 |
| 不确定／混合 | 证据不足或多属性冲突 | 保留连续值和原因，不强制三分类 |

具体阈值和数值范围留待壳体原型校准。分类标签不能覆盖原始连续属性。

### 6.3 壳体域对象

连续场之外，还应提取稳定壳体域对象：

```text
crustDomainId
主要壳体倾向
球面区域与多尺度几何
所属板块片段／相交板块
面积、连通分量和边缘带
厚度与浮力摘要
来源随机流、模型状态和证据
```

一个全球大陆性背景区若被板块边界穿过，应在拓扑上记录它与多个板块片段的关系。各片段随所属板块拥有独立构造身份，但可通过共同来源或相邻大陆域谱系说明它们在当前快照中连续相接。

### 6.4 生成顺序

建议采用以下流程：

```text
1. 解析全球大陆性壳体面积先验
2. 放置大陆性壳体域核与少量碎片候选
3. 用低频球面场和受约束生长形成大陆性背景
4. 以海洋性背景填充剩余区域
5. 在大陆性—海洋性边界生成可变宽度过渡带
6. 与板块分区叠加，形成每块板块内部的壳体片段
7. 生成厚度、浮力和置信连续属性
8. 检查面积、连通、碎片和跨尺度一致性后冻结
```

壳体域核不是板块核。二者可以相关，但不应一一重合，否则每块板块会机械地变成“纯大陆板块”或“纯海洋板块”。

### 6.5 全球大陆性壳体先验

`earthlike-v1` 提供大陆性壳体面积和典型尺度的先验范围，而不是最终陆地面积。生成器允许：

- 少数大型大陆性壳体域；
- 分离的大陆碎片；
- 大片海洋性壳体背景；
- 大陆性域跨越一个或多个板块边界的当前接触关系；
- 一块板块同时携带多个大陆碎片和大片洋壳。

大陆破碎度偏好影响域的数量、连接机会和碎片尺度，但不能直接指定岛屿数量。最终岛屿还取决于基底高程、构造抬升、侵蚀、海平面和海洋连通。

### 6.6 大陆边缘不等于板块边界

大陆性域与海洋性域之间的壳体边缘，可以位于：

- 板块内部的被动大陆边缘；
- 接近活动板块边界的大陆边缘；
- 被板块边界切割的大陆碰撞／裂解候选区；
- 当前低于海平面的大陆架和淹没陆块周围。

因此禁止：

```text
大陆边缘 = 板块边界
海岸线 = 大陆边缘
```

板块边界由构造分区决定，大陆边缘由壳体性质变化决定，海岸线由最终地形、水量和海洋连通决定。三者可以局部接近，也可以相距很远。

### 6.7 过渡壳带

大陆性和海洋性背景之间不应总是一条零宽度硬线。建议生成具有可变宽度的过渡带：

- 宽度受域尺度、低频场和模型先验约束。
- 过渡带保持跨尺度连续，不能随网格层级忽宽忽窄。
- 宽度不得小于当前计算层可稳定表达的门槛；不足时提升为候选或请求细化。
- 过渡壳只表达性质渐变，不自动生成大陆架、陆坡、裂谷或海岸。

后续地形模块可结合过渡带、构造边界和海平面形成大陆架与陆坡候选。

### 6.8 厚度与浮力代理

壳体倾向通过厚度和浮力代理影响 L5 的基底高程，但不直接输出最终高程：

```text
大陆性较高、壳体较厚／浮力较高
→ 提高相对高基底资格

海洋性较高、壳体较薄／浮力较低
→ 提高洋盆基底资格
```

最终地形仍要叠加：

- L4 边界相对运动；
- L5 造山、裂谷、洋中脊和结构约束；
- 材料与后续地貌过程；
- 海平面与水量闭合。

因此大陆性壳体可以被淹没，海洋性壳体也可以因构造抬升形成岛屿候选。

### 6.9 与板块运动的关系

L3 保存当前快照中的“板块携带哪些壳体片段”关系，但首版不连续模拟大陆漂移历史。运动代理改变的是 L4 对边界关系的判断，不在同一快照中把壳体域实时拖动到新位置。

如果未来支持长期构造演化，需要新增壳体随板块输运、裂解、碰撞、增生和消减的历史模型；不能用首版静态壳体域伪装这一过程。

### 6.10 壳体碎片与防噪规则

生成器应限制无意义碎片：

- 大陆性主域有版本化最小面积和连通门槛。
- 小型大陆碎片数量、面积分布和间距受限。
- 不允许每个单元独立分类导致椒盐噪声。
- 狭长碎片若低于可表达宽度，应合并、拒绝或标为未解析候选。
- 过渡带和边缘细节使用连续低频场，不随线程和细化顺序变化。

大陆碎片是壳体域，不自动成为微板块、岛屿或独立大陆名称。

### 6.11 D03 建议规则

```text
壳体倾向独立于板块、海陆和具体岩性
连续保存大陆性、厚度、浮力和置信属性，再派生分类
大陆性域核与板块核不一一对应
大陆性和海洋性域之间生成可变宽度过渡带
大陆边缘、板块边界和海岸线是三个不同对象
同一板块可包含多种壳体，同一大陆性区域可与多个板块片段相交
厚度与浮力只提供基底高程倾向，不直接决定最终地形
大陆碎片受面积与连通门槛限制，不自动成为微板块或岛屿
首版表达代表性当前状态，不模拟大陆漂移和壳体长期演化
```

## 七、L3-D04：板块运动代理与球面刚体表达

L3 需要给 L4 提供可以比较的板块运动状态，但首版不重演数亿年的板块漂移。这里的“运动”表示当前代表性构造状态：它应符合球面刚体运动的几何关系，并能产生自洽的边界相对速度；它不是对真实历史、未来位置或地幔动力过程的直接模拟。

### 7.1 为什么不能给整块板块一个二维方向

在平面地图上给板块保存“向东移动”之类的统一向量，会产生三个问题：

- 球面没有全局统一的东、北切平面；
- 同一刚性板块不同位置的局部运动方向本来就不同；
- 穿过极区、日期变更线或立方球面接缝时，二维方向会出现不连续或投影偏差。

球面上的刚体运动可由一根穿过球心的旋转轴和绕轴角速度表示，这在板块运动学中通常称为欧拉旋转表达。对板块上任意单位球面位置向量 `r`，局部线速度为：

```text
ω = 欧拉旋转向量
R = 行星半径
v(r) = R × (ω × r)
```

叉乘结果天然位于该点的球面切平面，因为：

```text
v(r) · r = 0
```

旋转轴附近速度接近零，距离旋转轴九十度附近速度最大。这是球面刚体运动的正常结果，不应把近轴低速误判成数据缺失。

### 7.2 权威运动状态

每个板块建议保存：

```text
plateId
eulerAxis：三维单位旋转轴
angularRate：带方向的角速度或等价三维角速度向量
motionFrameId：参考系版本
activityPrior：生成该速度的活动度先验
confidence：代理适用性与不确定性
sourceStream：命名随机来源
attemptIndex：有界候选尝试编号
modelVersion：运动代理模型版本
```

权威值使用三维角速度向量及明确单位。`earthlike-v1` 的角速度范围应采用版本化类地先验，数值留待原型统计和资料校准；界面可把局部派生速度显示为厘米／年，但在校准完成前必须标为模型代理值。

经纬方向、地图箭头和各立方球面面内分量都是派生结果，不能反过来成为权威运动状态。

### 7.3 参考系与整体旋转自由度

如果给所有板块的角速度同时加上同一个全球刚体旋转，相邻板块在同一边界点的相对速度不会改变。因此绝对旋转包含一个任意的参考系自由度。

首版建议采用版本化的零净旋转约定：

```text
生成各板块候选角速度
    ↓
按板块面积权重计算共同旋转分量
    ↓
从所有板块角速度中减去该共同分量
    ↓
保存修正后的代理及修正证据
```

这是一种确定参考系的计算约定，不表示行星必须满足某种简化的角动量定律。L4 的主要依据始终是边界相对运动；改变统一参考系不应改变边界分类结果。

### 7.4 运动候选的生成

建议流程为：

```text
1. 从构造活动度先验解析角速度尺度范围
2. 为主板块生成稳定欧拉轴和角速度候选
3. 为已存在的微板块生成独立但受限的候选
4. 执行零净旋转参考系修正
5. 在代表点和全部共享边界上派生局部速度
6. 检查速度范围、退化候选和相对运动可辨识度
7. 有界重试或冻结运动代理与证据
```

欧拉轴应从无球面方向偏差的稳定分布中取得，不能直接在经纬度上均匀抽样纬度。角速度大小、轴和旋转正负号由独立命名随机属性派生，避免改变活动度偏好时无故改变旋转轴。

构造活动度偏好主要调整角速度尺度的先验分布，不直接增加山脉、火山或某类边界的配额，也不重画板块轮廓。是否形成明显构造地形还取决于 L4 的相对运动和 L5 的壳体组合与地形响应。

### 7.5 从绝对代理得到边界相对运动

对板块 A 与 B 的共享边界采样点 `r`：

```text
vA = R × (ωA × r)
vB = R × (ωB × r)
vRelative = vB - vA
```

L1/L3 为边界提供稳定方向的切向基：

- `nAB`：位于球面切平面内、垂直于边界并从 A 指向 B 的法向；
- `tBoundary`：沿边界有稳定方向的切向。

相对速度可分解为：

```text
normalRate = vRelative · nAB
tangentRate = vRelative · tBoundary
```

在上述方向约定下：

- `normalRate < 0` 表示两侧相向，为汇聚候选；
- `normalRate > 0` 表示两侧远离，为离散候选；
- 切向分量占主导时为走滑候选；
- 两者都很小或在误差门槛附近时保留为低活动／不确定状态。

最终阈值、混合型边界和沿线分段属于 L4-D01 之后的决定。L3 只提供角速度、局部速度和可重复的分解输入，不在此层冻结边界类型。

### 7.6 同一条边界可以沿线变化

由于球面刚体速度随位置改变，一对板块的长边界沿线可能出现：

- 汇聚强度逐渐变化；
- 法向运动与走滑运动的比例变化；
- 局部接近零速的转换位置；
- 不同分段具有不同的主导关系。

因此不能只给整条 `boundaryId` 保存一个分类。L4 应沿共享边界计算连续状态，再按稳定门槛提取有起止位置的边界段；这些分段共享原始 boundaryId，不破坏 L3 的板块邻接拓扑。

### 7.7 刚性假设和首版边界

首版把每块主板块和微板块视为球面刚体：

- 板块内部不保存任意局部速度噪声；
- 不模拟板内连续变形、断块旋转和弹性应变；
- 不按速度把板块多边形推进到未来位置；
- 不据此反推出大陆曾经的位置或边界年龄；
- 不把一次生成的运动状态宣称为地幔对流解。

若某区域需要独立运动，应由 D05 判断是否形成微板块，而不是在主板块内部叠加无法解释的随机速度场。未来若支持长期演化，需要引入时间积分、壳体输运、边界迁移和拓扑事件，形成新的模型层与版本。

### 7.8 退化情况和失败处理

以下情况需明确处理：

- 欧拉轴附近局部速度很小：合法状态，保留方向不确定标记。
- 两相邻板块具有近似相同角速度：边界可能低活动，不能强制分类。
- 相对法向和切向分量都接近门槛：输出混合／不确定证据。
- 所有板块整体速度过低或边界关系几乎不可辨识：候选可按版本化条件有界重试。
- 某板块速度超过类地先验：拒绝候选，不通过显示缩放掩盖。
- 三重点附近：分别沿各条边界计算，不为三重点虚构单一速度类型。

重试只更换运动代理候选，不应重画已经冻结的板块和壳体分区。若多次尝试仍失败，应产生明确的 L3 失败状态和证据，而不是放宽硬门槛直到通过。

### 7.9 确定性与证据

运动快照至少记录：

```text
每块板块的原始候选角速度
零净旋转修正量和参考系版本
修正后的权威角速度
活动度先验及实际速度统计
边界采样方案和局部速度摘要
低速、近轴、不确定和被拒绝候选
重试次数、停止原因与模型版本
```

局部速度由权威角速度随时重算；地图投影、观察位置、网格细化和线程顺序不得改变结果。边界采样加密可以提高分段定位精度，但不能改变同一球面位置已有的解析速度。

### 7.10 D04 建议规则

```text
每块板块以三维欧拉旋转向量表达球面刚体运动
局部速度使用 v(r) = R × (ω × r) 派生并天然位于切平面
采用版本化零净旋转约定消除任意整体旋转自由度
L3 保存板块运动代理，L4 才按边界法向／切向分量分类
同一长边界允许沿线改变汇聚、离散和走滑比例
构造活动度偏好调整速度先验，不直接指定边界或景观配额
近轴低速、低相对运动和门槛附近状态允许保持不确定
首版不模拟板内变形、边界迁移或长期板块历史
运动候选有界重试，失败和修正必须进入证据
```

## 八、L3-D05：主板块、微板块与构造碎片

主板块和微板块都是真正的板块对象，具有独立身份、连通区域、边界拓扑和运动代理。二者的差别主要在于全球结构中的层级、典型尺度和生成职责，而不是“大的是真板块，小的是装饰”。构造碎片则是壳体或地形材料对象，不因面积较小就自动获得板块身份。

### 8.1 四类容易混淆的对象

| 对象 | 是否拥有独立 plateId | 是否完整参与球面分区 | 是否拥有独立运动代理 | 主要含义 |
| --- | --- | --- | --- | --- |
| 主板块 | 是 | 是 | 是 | 构成全球一级板块骨架 |
| 微板块 | 是 | 是 | 是 | 位于复杂构造区、尺度较小但可独立运动的板块 |
| 大陆／壳体碎片 | 否 | 否，附着于所属板块 | 否 | 与周围壳体倾向不同的小型壳体域 |
| 岛屿、岛弧、海山等地形对象 | 否 | 否 | 否 | 后续由壳体、构造高程和海平面形成的地形结果 |

“碎片”描述材料或壳体连续性，“板块”描述构造分区和运动身份。一个大陆碎片可以随主板块一起运动；一块微板块可以大部分位于海下，也可以同时携带大陆性和海洋性壳体。

### 8.2 主板块的职责

主板块在微板块出现之前形成全球骨架，应满足：

- 独立覆盖球面的主要面积份额；
- 每块区域连通，并具有稳定板块核；
- 数量、面积和形状满足 D01、D02 的全局约束；
- 邻接图足以构成完整的一级构造网络；
- 即使关闭微板块生成，也仍能得到合法、可运行的世界。

“主板块”是生成层级，不表示它永远比所有现实意义上的板块更重要。首版不在生成完成后因某块面积变化而自动改写其主／微身份；身份来源和模型版本应保持稳定。

### 8.3 微板块的最低资格

一个候选区域只有同时满足以下条件，才能成为微板块：

1. **空间独立**：具有连通且可解析的球面区域，不是几个断开的斑点。
2. **拓扑独立**：拥有闭合的合法边界网络，并与相邻板块形成明确共享边界。
3. **运动独立**：可以获得与相邻主板块可区分的欧拉旋转代理；若长期只能复制宿主运动，则没有必要成为独立板块。
4. **尺度可解析**：面积、最小宽度、边界长度和持续层级均超过版本化门槛。
5. **形状有效**：不是单单元细条、椒盐碎片、极端狭颈或数值接缝产物。
6. **形成位置合理**：通常位于既有板块边界、三重点或复杂边界带附近，而不是在主板块内部任意打洞。
7. **模型收益明确**：它的存在能表达独立边界关系；不能只为了让地图更复杂而增加 plateId。

面积只是资格之一。达到某个面积不会自动成为微板块，低于门槛的候选也不能仅凭独立随机速度保留。

### 8.4 为什么首版不允许任意板内微板块

若在一块主板块内部直接挖出封闭微板块，宿主板块会形成孔洞，并产生一圈无法由当前构造历史解释的封闭边界。D01 已决定首版普通随机结果不支持板块孔洞，因此微板块优先从以下位置插入：

- 两块主板块的既有共享边界；
- 三重点附近；
- 边界弯折、分叉资格或局部复杂度较高的区域；
- 多个壳体域在板块边界附近交会的区域。

微板块一般应与至少两个其他板块相邻。完全位于板内的独立旋转块、构造窗和更小断块属于未来的板内变形模型，不进入首版普通生成。

### 8.5 微板块生成顺序

D01—D07 是讨论编号，不等于严格执行顺序。建议实际生成顺序为：

```text
1. D02 生成主板块骨架
2. D03 生成并叠加壳体倾向域
3. D05 在合法边界区提出微板块候选
4. 执行连通、面积、宽度和拓扑筛选
5. 从相邻主板块区域中确定性地重分配微板块区域
6. 重建受影响的共享边界和三重点
7. D04 为全部主板块与微板块分配运动代理
8. 检查微板块相对运动的可辨识度
9. 冻结最终 PlateSetSnapshot
```

若运动检查表明某微板块没有可区分的相对关系，可以只重试该候选的运动代理；达到上限后撤销该微板块插入，恢复冻结前的主板块边界补丁。不得为了保留候选而静默降低所有门槛。

### 8.6 候选区域如何形成

微板块候选应来自低频、受约束的边界复杂度场，而不是逐单元随机标记。候选代价可以考虑：

```text
既有边界邻近度
三重点邻近度
边界曲率与可容纳尺度
壳体倾向交会关系
目标面积偏差
最小宽度和紧凑度
重建后拓扑合法性
```

这些条件只提供形成资格，不提前规定汇聚、离散或走滑类型。边界类型仍由 D04 的相对运动输入交给 L4 判断。

微板块区域可以从一侧主板块切出，也可以重分配原共享边界两侧的局部区域，但必须通过原子拓扑操作完成：旧边界被替换为带谱系的新边界段，面积无丢失或重叠，相关 plateId、boundaryId 和三重点变更都有记录。

### 8.7 数量、面积和总复杂度预算

首版应分别限制：

- 主板块数量范围；
- 单个微板块的最小／最大面积；
- 微板块最小宽度和最短有效边界；
- 微板块总数量；
- 微板块占全球面积的总比例；
- 单个主板块边界附近可容纳的微板块密度；
- 三重点及短边界的最小间隔。

具体数字留待固定种子组和球面分辨率原型校准。限制的目的在于让复杂度有地理意义并保持可解析，而不是把现实中的所有板块强行压成相同尺寸。

高级偏好若允许调节“边界复杂度”或“微板块倾向”，只能在这些硬门槛内改变候选率、尺度先验和接受概率。它不能指定必须生成多少微板块，也不能让每段主边界都出现微板块。

### 8.8 构造碎片的归属规则

未达到微板块资格的小型区域应根据性质处理：

- 壳体性质不同：保留为所属板块内的壳体碎片或过渡壳域。
- 只是最终露出海面：保留为岛屿／岛弧／海山等地形候选。
- 只在更高分辨率出现局部断裂：记录为未解析构造候选，不授予 plateId。
- 由网格噪声或修复产生：合并回合法邻区并记录修复原因。
- 具有潜在独立运动但当前尺度不足：保存置信和升级条件，未来细化不能自动改变当前快照身份。

这样可以保留地理细节，而不让全球板块邻接图被大量没有独立动力意义的小对象淹没。

### 8.9 身份稳定与跨尺度表达

微板块一旦进入冻结快照，就与主板块一样拥有稳定 plateId。缩放或细化只能提高边界几何精度，不能把它临时合并、拆分或改成壳体碎片。

在较粗视图中，微板块可能小到无法绘制完整形状。此时可以：

- 用聚合标记或专题符号提示其存在；
- 把面积属性聚合进父级显示单元；
- 在查询中仍返回真实 plateId 和邻接关系。

不能因为屏幕像素不足就在权威数据中删除微板块。反过来，局部细化发现的新纹理也不能自动创建板块；新增板块属于新快照或模型升级。

### 8.10 证据与失败状态

每个微板块至少保存：

```text
候选来源与形成位置
涉及的原主板块和旧边界
面积、最小宽度、周长与形状指标
邻接板块和新边界谱系
壳体倾向摘要
独立运动可辨识度
接受／拒绝门槛和实际结果
拓扑重建记录
尝试编号、随机来源和模型版本
```

若候选会产生板块孔洞、悬空边界、面积重叠、无法解析的细条或退化三重点，应拒绝并说明主因。候选数量不足可以作为偏好未完全满足记录；不能通过破坏 P0 拓扑正确性来补足数量。

### 8.11 D05 建议规则

```text
主板块与微板块都是真正的独立板块对象
微板块必须同时满足空间、拓扑、运动和尺度独立性
大陆碎片、岛屿、岛弧和海山不自动拥有 plateId
主板块先构成合法全球骨架，关闭微板块后世界仍可运行
首版微板块主要插入既有边界和三重点附近，不任意挖出板内孔洞
微板块插入通过原子区域重分配和边界谱系完成
数量、面积、宽度、总占比和局部密度均受版本化预算限制
粗视图可聚合显示，但不能删除微板块身份
局部细化不能在同一快照中自动创建新板块
不合格候选保留为壳体碎片、地形候选、未解析结构或被拒绝噪声
```

## 九、L3-D06：活动度、结构继承与年龄语义

首版需要让后续模块区分“构造上较活跃的区域”和“较稳定、具有长期结构继承倾向的区域”，但没有连续模拟板块生成、扩张、输运、碰撞和消减。因此 D06 必须把当前运动量、相对状态代理和真实年代严格分开，避免给随机字段贴上“地壳年龄”的科学标签。

### 9.1 三种不同语义

| 语义 | 示例 | 首版处理 |
| --- | --- | --- |
| 当前运动状态 | 板块角速度、边界相对速度 | 可以由 D04 和 L4 计算 |
| 相对结构代理 | 稳定性、结构继承、相对成熟度 | 可以生成，但必须标为无年代代理 |
| 绝对地质年代 | 洋壳 80 Ma、大陆基底 2.5 Ga | 首版不生成权威值 |

“活动度高”不等于“地壳年轻”，“稳定性高”也不等于某个确定年代。它们可能相关，但需要构造历史、热状态和材料证据才能转换为真实年龄解释。

### 9.2 当前活动度不再独立随机

板块级当前运动活动度应直接由 D04 的欧拉旋转代理派生，例如：

```text
plateKinematicActivity
= 角速度大小及板块代表点线速度的版本化摘要
```

边界级活动度则必须由 L4 在共享边界上根据相对速度计算：

```text
boundaryActivity(r)
= 法向相对速度与切向相对速度的组合摘要
```

不能再额外生成一张独立的“构造活动噪声图”，否则可能出现板块几乎不相对运动、活动度却很高的自相矛盾状态。L3 可以保存派生缓存和统计摘要，但其权威来源仍是 D04 运动代理。

### 9.3 结构继承代理

建议 L3 在壳体域内部保存连续的 `structuralInheritanceProxy`，表示某一区域具有多强的既有大尺度结构记忆，以及后续构造作用沿既有结构重新集中的倾向。它可以帮助 L5 避免山系、裂谷和断裂响应完全均匀。

该代理应满足：

- 以壳体域为背景生成低频连续区域，不逐单元撒噪声；
- 与大陆性、壳体厚度和稳定核心资格存在受限相关，但不由其中任一项完全决定；
- 跨板块边界和壳体边缘时按来源与连续性分别处理；
- 只调节后续形变定位倾向，不直接生成山脉、断层或峡谷；
- 没有年份单位，也不宣称记录某次真实造山事件。

“结构继承高”表示后续响应更可能受已有大尺度结构控制，并不必然表示地壳更软、更硬、更高或更古老。具体如何影响 L5，需要在构造—地形契约中单独定义。

### 9.4 相对成熟度代理

若后续地形确实需要区分较稳定的大陆内部与较易重组的壳体区域，可保存 `relativeMaturityProxy`：

```text
范围：0～1
语义：模型内部的相对成熟／稳定背景排序
单位：无
适用范围：同一模型版本和同一世界内比较
```

生成时可以参考：

- 壳体域类型和尺度；
- 大陆性域内部的稳定核心候选；
- 距离过渡壳边缘的相对位置；
- 低频结构继承场；
- 版本化类地先验。

它不能直接显示为“年轻／古老多少年”，也不能跨模型版本当作同一物理量比较。后续 L4 的活动边界可以形成当前重加工状态，但不能简单把附近壳体的成熟度全部重置为零。

### 9.5 大陆稳定核心资格

大陆性壳体域可包含少量宽广、连续的稳定核心候选，用于表达类似稳定大陆内部的背景差异。候选需满足：

- 位于大陆性较高且尺度足够的壳体域内部；
- 与过渡壳边缘保持可解析距离；
- 面积和最小宽度达到版本化门槛；
- 形态平滑、数量受限，不形成椒盐斑点；
- 只提高相对成熟／稳定资格，不自动生成高原、平原或特定岩性。

首版建议称为“稳定核心候选”，不直接命名为现实地质学意义上的克拉通。若未来具备年代、热状态、岩性与构造历史证据，才能升级为更具体的地质对象。

### 9.6 为什么洋壳年龄不能在 L3 随机生成

现实中的洋壳年龄与洋中脊形成、板块扩张、输运以及消减密切相关。仅在海洋性壳体域中铺一张随机年龄图，会导致：

- 年龄等值线与离散边界无关；
- 洋中脊两侧缺乏合理的年龄递增关系；
- 老洋壳可能无缘无故出现在新生扩张中心；
- 壳龄无法与板块速度和距离共同解释；
- 海底热沉降和基底高程获得虚假的物理依据。

因此首版 L3 不生成 `crustAgeMa`。如果 L4 识别出可信的离散边界，后续可以派生“距扩张中心的相对更新／热成熟代理”：

```text
离散边界位置
+ 当前相对扩张方向和速度
+ 沿板块内部的受约束传播距离
→ oceanicRenewalProxy
```

该结果仍只是当前运动场下的相对代理，不等于完成了历史积分。除非未来模型真的追踪形成时间和输运路径，否则不能换算成百万年并作为权威壳龄。

### 9.7 历史代理不改变对象历史

相对成熟度和结构继承只描述当前快照中的背景状态，不能用于宣称：

- 某两块大陆过去何时相连；
- 某座山脉经历过几次造山运动；
- 某片洋壳形成于多少百万年前；
- 某板块将于何时碰撞或裂解；
- 某种具体岩石必然存在。

这些问题需要时间轴、事件记录、材料转换和板块拓扑演化。未来若加入历史模型，应创建独立的 `GeologicHistorySnapshot` 或等价层，而不是重新解释首版随机代理。

### 9.8 对后续模块的作用边界

| 代理 | 可影响 | 不可直接决定 |
| --- | --- | --- |
| 板块运动活动度 | L4 边界相对运动强度的输入摘要 | 火山数量、山脉高度、地震事件 |
| 结构继承代理 | L5 形变优先位置、方向连续性和响应非均匀性 | 具体断层、峡谷、岩性 |
| 相对成熟度 | 稳定核心资格、背景热／形变响应倾向的后续参数 | 绝对年龄、海陆、最终高程 |
| 洋壳更新代理（后续派生） | 洋盆基底热状态和相对沉降资格 | 真实壳龄、历史扩张速率 |

任何代理进入下游公式时，都必须写明作用方向、适用范围和上限。代理不能绕过 L4/L5 的因果步骤直接映射为景观标签。

### 9.9 数据状态和命名要求

每个非物理年龄字段必须携带：

```text
semanticKind = proxy
单位 = 无或明确的派生单位
validScope = 世界内／模型版本内
sourceModelVersion
sourceFields
confidence
禁止解释列表
```

界面和导出格式应使用“结构继承代理”“相对成熟度”“稳定核心候选”等名称。不得把这些字段缩写成“地质年龄”“古老大陆”或带有 `Ma`、`Ga` 的数值。

### 9.10 跨尺度与确定性

结构继承和成熟度场需要满足：

- 使用球面连续低频场和稳定对象来源；
- 父子层级按面积或规定统计聚合；
- 细化只揭示同一场的更多细节，不重抽区域身份；
- 立方球面接缝处数值和梯度连续；
- 板块、壳体域和稳定核心身份不受浏览顺序影响；
- 代理模型升级通过新分支处理，不回写旧快照。

### 9.11 证据与解释

L3 快照应能解释：

```text
活动度由哪个欧拉旋转代理派生
结构继承场来自哪个壳体域和随机流
稳定核心候选通过了哪些尺度与位置门槛
相对成熟度使用了哪些输入及相关性限制
哪些字段是代理、哪些是物理量
为什么没有提供绝对壳龄
哪些更新／热状态需要等待 L4 或历史模型
```

当用户查询某地“为什么比较稳定”时，可以回答其大陆性背景、稳定核心资格和结构继承代理；不能回答一个未经模拟的确切形成时代。

### 9.12 D06 建议规则

```text
当前活动度由 D04/L4 运动关系派生，不另造独立活动噪声场
L3 可保存低频连续的结构继承代理和相对成熟度代理
大陆内部只生成稳定核心候选，不直接宣称为克拉通
首版不生成带 Ma/Ga 单位的权威地壳年龄
洋壳更新／热成熟代理必须等待 L4 识别离散边界后派生
相对成熟度不能跨版本当作统一物理年龄比较
所有代理明确标记语义、范围、来源、置信和禁止解释
代理只调节下游响应，不能直接映射成海陆、高程或景观标签
首版快照不宣称板块漂移、碰撞、造山和壳体形成历史
未来真实历史模型使用独立快照与版本，不重新包装现有代理
```

## 十、L3-D07：板块状态快照、测试体系与失败保存

L3 的最终产物不能只是一组内存中的板块数组，而应是可重现、可查询、可验证的不可变 `PlateStateSnapshot`。快照既要向 L4 提供权威输入，也要保存足够证据，让测试系统判断失败来自球面覆盖、板块拓扑、壳体倾向、运动代理还是历史代理语义。

### 10.1 快照的正式结构

建议结构如下：

```text
PlateStateSnapshot
├─ SnapshotHeader
│  ├─ snapshotId / parentSnapshotId
│  ├─ WorldId / WorldSpecVersion
│  ├─ L1SpaceSnapshotId
│  ├─ L3ContractVersion
│  ├─ modelManifest
│  ├─ generationStatus
│  └─ validationStatus
├─ PlateRegistry
│  ├─ 主板块对象
│  └─ 微板块对象
├─ SphericalPartition
│  ├─ 权威球面归属规则
│  └─ 可重建网格覆盖索引引用
├─ BoundaryTopology
│  ├─ 共享边界
│  ├─ 三重点
│  └─ 邻接图
├─ CrustState
│  ├─ 壳体连续属性场
│  ├─ 壳体域与过渡带
│  └─ 稳定核心候选
├─ MotionState
│  ├─ 欧拉旋转向量
│  ├─ 参考系与修正量
│  └─ 派生活动摘要
├─ RelativeStateProxies
│  ├─ 结构继承代理
│  └─ 相对成熟度代理
├─ EvidenceBundle
│  ├─ 随机流与尝试记录
│  ├─ 生成和修复日志
│  ├─ 指标与验证报告
│  └─ 警告、降级和失败原因
└─ DerivedCaches
   ├─ 分层网格覆盖
   ├─ 查询加速索引
   └─ 显示几何
```

`DerivedCaches` 可以删除和重建，不参与板块身份。其余权威数据一旦提交便不可变；需要修复或升级时创建新快照并通过 `parentSnapshotId` 和对象谱系关联。

### 10.2 快照身份和原子提交

`snapshotId` 应由以下内容的规范化摘要产生：

```text
WorldId
+ L1 权威空间快照
+ L3 数据契约版本
+ L3 模型清单与参数
+ 权威板块／壳体／运动状态摘要
```

显示样式、缓存布局、当前视角和验证报告的运行时间不能改变快照身份。生成时先写入临时快照，依次完成结构检查、P0 验证和摘要计算后再原子提交；中断或崩溃不能留下被误认为完整世界的半成品。

完整的失败证据可以单独保存为 `FailedGenerationRecord`，但不能获得可供 L4 使用的正式 `PlateStateSnapshot` 身份。

### 10.3 生成状态与验证状态分离

建议使用两个正交状态，而不是一个模糊的“成功／失败”：

| 维度 | 状态 | 含义 |
| --- | --- | --- |
| 生成状态 | `COMPLETE` | 所有必需 L3 权威数据已经形成 |
| 生成状态 | `PARTIAL` | 只有允许延后的代理或证据缺失，P0 数据仍完整 |
| 生成状态 | `FAILED` | 无法形成合法 L3 权威状态 |
| 验证状态 | `NOT_RUN` | 尚未执行完整验证 |
| 验证状态 | `PASSED` | 适用硬约束和测试全部通过 |
| 验证状态 | `CONDITIONAL` | P0 通过，但存在明确允许的近似、缺失或低置信结果 |
| 验证状态 | `FAILED` | 至少一项适用硬约束或阻断测试失败 |

`PARTIAL` 不能用于掩盖覆盖、重叠、连通、拓扑或身份错误。只有结构继承等可选代理未计算、且契约明确允许时，才可能形成 `PARTIAL + CONDITIONAL` 快照。L4 默认只接受 `COMPLETE + PASSED`；是否接受条件快照必须由运行计划明确授权并记录。

### 10.4 三层验收方法

L3 验收分为三层：

1. **单世界硬约束**：每个世界都必须满足完整覆盖、无重叠、连通、合法边界、有限数值、稳定身份等不变量。
2. **固定构造测试世界**：K01–K04 用受控输入检查特定空间、壳体和运动关系。
3. **固定种子组统计**：检查面积、数量、形状、微板块比例、偏好方向和球面无偏性，避免把统计先验误写成单世界配额。

三层不能互相替代。硬约束通过不表示分布自然；统计分布合理也不能容忍某个世界存在覆盖空洞；固定测试通过也不能证明随机组合没有系统偏差。

### 10.5 K01–K04 在 L3 的验收职责

既有 K01–K04 会继续被 L4、L5 扩展，但在 L3 只检查本层有权回答的内容：

| 测试世界 | L3 固定输入 | L3 必须验证 | 暂不由 L3 验证 |
| --- | --- | --- | --- |
| K01 壳体与板块解耦 | 受控主板块、一个大陆性域及周围海洋性背景 | 完整覆盖、壳体域连续、同板块可含多种壳体、大陆边缘不强贴板块边界 | 最终海岸、陆地面积和地形高度 |
| K02 相向运动 | 两块共享边界的板块及受控欧拉旋转代理 | 边界采样速度有限，法向相对分量稳定为相向资格，参考系变换后结果不变 | 汇聚分类门槛、造山、海沟和火山 |
| K03 相离运动 | 两块共享边界的板块及受控相离代理 | 法向相对分量稳定为分离资格，切向混入按预期变化 | 裂谷、洋中脊、热沉降和新生洋壳 |
| K04 走滑与三重点 | 三板块、三条合法边界及受控运动 | 邻接和三重点拓扑稳定，指定边界切向分量占主导，无悬空边界 | 走滑地形、断层盆地和地震表现 |

测试输入仍遵循 L2-D07：`TestInput` 与 `TestOracle` 分离，并调用与随机世界相同的正式 L3 模型。测试答案不能进入生成器充当隐藏提示。

### 10.6 单因素与变形关系测试

除固定世界外，L3 还应执行不依赖具体地图形状的关系测试：

- 将整个输入绕球心旋转，板块面积、邻接、拓扑和局部关系应等价。
- 改变立方球面面编号或遍历顺序，权威结果不变。
- 增减线程、批次和缓存，离散身份与规范摘要不变。
- 提高空间细化层级，已有对象身份和同点连续属性不变。
- 给所有板块角速度加同一参考系旋转，边界相对速度不变。
- 改变海平面或全球水量，板块和壳体域身份不变。
- 只提高构造活动度，角速度尺度按统计方向变化，板块分区不重画。
- 只提高微板块倾向，合法候选统计改变，但拓扑门槛不放宽。

这些测试检查模型关系，比保存一张肉眼比较的参考图片更稳定。

### 10.7 确定性分级

跨平台浮点实现可能存在极小差异，因此确定性应分层判断：

| 层级 | 要求 |
| --- | --- |
| 身份与拓扑 | plateId、boundaryId、邻接、三重点、主／微类型必须完全一致 |
| 离散归属 | 规范测试层级的板块归属与壳体域身份必须一致 |
| 连续数值 | 在版本化绝对／相对容差内一致，不能跨过分类门槛 |
| 规范摘要 | 对排序和量化后的权威数据计算，用于跨平台回归 |
| 原始二进制浮点 | 不默认要求逐位一致，除非实现明确承诺 |

量化只用于规范摘要和比较，不能反过来替代权威精度。若数值差异导致拓扑、身份或分类变化，即使仍在一般浮点容差附近，也应视为确定性失败。

### 10.8 单世界指标与种子组统计

每个快照至少输出：

```text
主板块／微板块数量与面积分布
覆盖空洞和重叠面积
每块连通分量数
边界总长、边界段和三重点数量
最小宽度、紧凑度和狭颈指标
壳体域面积、碎片数和过渡带宽度统计
角速度、代表线速度和相对速度统计
稳定核心数量与面积
修复、重试、降级和拒绝候选数量
```

固定种子组再汇总：

- 板块数量和面积的分布范围；
- 最大板块是否长期占据某个立方球面面或极区；
- 边界长度和三重点密度是否出现接缝偏差；
- 微板块数量和面积占比是否符合复杂度预算；
- 大陆性壳体、过渡壳和稳定核心是否出现椒盐化或单一化；
- 高级偏好是否呈现规定统计方向；
- 有界重试率和失败率是否超过允许范围。

具体阈值、样本数和置信区间由 L3 原型基准冻结到模型版本。单个随机世界不需要接近统计均值，但必须满足所有硬门槛。

### 10.9 失败代码与证据保存

失败应使用稳定代码，而不是只留自然语言日志。首批建议包括：

```text
L3_COVERAGE_GAP
L3_AREA_OVERLAP
L3_DISCONNECTED_PLATE
L3_INVALID_BOUNDARY_TOPOLOGY
L3_DEGENERATE_TRIPLE_JUNCTION
L3_UNRESOLVED_FRAGMENT
L3_MICROPLATE_BUDGET_EXCEEDED
L3_INVALID_MOTION_VECTOR
L3_REFERENCE_FRAME_FAILURE
L3_NONDETERMINISTIC_RESULT
L3_PROXY_SEMANTIC_VIOLATION
L3_RETRY_LIMIT_REACHED
```

每条失败记录至少包含：

```text
失败代码与严重级别
涉及对象和球面位置
违反的规则／门槛版本
实际值、期望范围和容差
上游快照与随机来源
已执行的修复／重试
最小复现输入
是否阻断 L4
```

可恢复候选被拒绝属于生成证据，不必使整个世界失败；但若达到重试上限仍无法满足 P0 不变量，则必须输出 `FAILED`，不能发布一个视觉上看似正常的快照。

### 10.10 验证执行顺序

建议固定为：

```text
1. 数据契约和有限数值检查
2. 覆盖、重叠、连通与拓扑 P0 检查
3. 面积、宽度、形态和复杂度检查
4. 壳体、运动和代理语义检查
5. K01–K04 适用测试
6. 确定性与关系变形测试
7. 固定种子组统计回归
8. L4 输入契约检查
9. 生成验证报告并原子提交快照
```

前序 P0 失败后可以继续运行只读诊断，但不得把后续测试通过解释为整体通过。每项测试要记录适用、不适用、通过、条件通过或失败，禁止把“未运行”统计为通过。

### 10.11 面向查询的证据

L3 快照应支持以下查询：

- 某球面点属于哪块板块，依据哪个分区版本？
- 它属于何种壳体倾向域，与板块身份是否一致或交叉？
- 相邻板块有哪些，共享边界和三重点在哪里？
- 该板块的运动代理和参考系是什么？
- 为什么某个候选被认定为微板块或被降为壳体碎片？
- 某个稳定核心为何只是候选，缺少哪些年代证据？
- 当前快照通过了哪些测试，哪些状态仍是代理或未验证？

查询结果来自权威状态和 EvidenceBundle，不从地图颜色、显示几何或自然语言模板反推。

### 10.12 L3 对 L4 的发布门槛

正式进入 L4 前至少需要：

```text
生成状态为 COMPLETE
验证状态为 PASSED
P01–P55 中所有适用硬约束通过
K01–K04 的 L3 职责通过
确定性检查通过
固定种子组统计没有阻断回归
不存在未解释的 P0 修复或语义违规
L4 输入契约版本匹配
```

开发调试时可以显式加载失败或条件快照，但必须带诊断模式标记，且输出不能混入正式世界缓存或被误认为验收通过。

### 10.13 D07 建议规则

```text
L3 输出不可变、可寻址且原子提交的 PlateStateSnapshot
权威板块、壳体、运动和代理状态与可重建缓存分开
生成状态和验证状态正交记录，未运行不等于通过
验收分为单世界硬约束、K01–K04 固定世界和固定种子组统计
K01–K04 在 L3 只验证本层输入关系，不提前验收 L4/L5 地形结果
身份拓扑要求完全一致，连续数值使用版本化容差和规范摘要
旋转、参考系、细化、线程、海平面和单因素偏好均有关系测试
失败使用稳定代码并保存对象、位置、门槛、重试和最小复现输入
P0 失败不能发布正式快照，候选拒绝与世界失败明确区分
L4 默认只接收 COMPLETE + PASSED 且契约匹配的 L3 快照
```

## 十一、L3 初步验收方向

| 编号 | 测试 | 通过条件 |
| --- | --- | --- |
| P01 球面覆盖 | 任意采样点有唯一板块归属，所有板块并集覆盖完整球面 |
| P02 无面积重叠 | 板块内部没有面积重叠，共享部分仅为合法边界 |
| P03 连通性 | 每个主板块和微板块的区域连通，断裂区域被正确拆分或拒绝 |
| P04 边界拓扑 | 普通边界连接两个板块，三重点和边界端点关系完整，无悬空边界 |
| P05 跨面连续 | 板块和边界穿过立方球面接缝时身份、方向和邻接不变 |
| P06 标识稳定 | 细化、并行、缓存删除和不同遍历顺序不改变 plateId、boundaryId 与邻接图 |
| P07 面积形状 | 主板块和微板块满足版本化面积、紧凑度和碎片限制 |
| P08 海陆解耦 | 改变海平面或水量不改变板块身份，板块内部可同时包含不同壳体倾向和海陆状态 |
| P09 初始分区 | 加权初始分区完整覆盖球面，并为每块板块提供连通生长起点 |
| P10 面积方向 | 提高某板块目标权重时，其候选面积总体按预期变化，不破坏全局覆盖 |
| P11 形态范围 | 最终板块不退化为规则等面积多边形，也不产生超出门槛的狭颈和碎片 |
| P12 松弛停止 | 松弛按固定容差或迭代上限停止，未满足条件时明确重试或失败 |
| P13 并行确定性 | 不同线程数、批次和单元遍历顺序得到相同 plateId、归属和邻接图 |
| P14 接缝无偏 | 板块核密度、面积和边界形态不在立方球面接缝及角点形成统计异常 |
| P15 偏好方向 | 在固定种子组中，板块数量与相关因果偏好呈规定统计方向且不违反面积门槛 |
| P16 壳体覆盖 | 每个球面位置都有唯一或明确混合的壳体状态，连续属性无空洞 |
| P17 板块解耦 | 同一板块可包含大陆、过渡和海洋壳倾向；壳体边缘不被强制贴合板块边界 |
| P18 海陆独立 | 改变海平面只改变海陆和海岸，不改变壳体域身份与连续属性 |
| P19 过渡连续 | 大陆—海洋过渡带跨 L1 面接缝和细化层保持连续，宽度符合表达门槛 |
| P20 基底方向 | 提高大陆性／浮力代理时基底高程资格按模型方向变化，但不直接强制最终陆地 |
| P21 碎片控制 | 大陆性主域和碎片满足面积、连通、间距与数量限制，无椒盐噪声 |
| P22 跨尺度壳体 | 父子单元的壳体比例和连续属性按面积聚合一致，细化不改变域身份 |
| P23 切平面速度 | 任意采样点满足 `v(r) · r` 在数值容差内为零 |
| P24 刚体一致 | 同一板块所有局部速度均可由同一个权威欧拉旋转向量重建 |
| P25 参考系约定 | 零净旋转检查通过；统一改变参考系不改变任一边界的相对速度 |
| P26 边界分解 | 法向与切向分量可重建原相对速度，A／B 顺序反转时符号按约定一致反转 |
| P27 近轴退化 | 欧拉轴附近低速点不产生无效数值或虚假高速方向，并带有正确不确定状态 |
| P28 活动度方向 | 固定种子组中提高构造活动度会提高速度尺度统计，不改变板块分区和欧拉轴身份 |
| P29 运动确定性 | 线程数、边界采样密度、投影、网格细化和遍历顺序不改变权威角速度及同点派生速度 |
| P30 类型资格 | 每个微板块均满足连通、拓扑、尺度、形状和独立运动资格，不以面积单项决定类型 |
| P31 主骨架独立 | 关闭微板块生成后，主板块仍完整无重叠覆盖球面并具有合法邻接拓扑 |
