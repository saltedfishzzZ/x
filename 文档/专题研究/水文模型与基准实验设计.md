## 1. 本轮目标与边界

建立最小闭环：指定地形与降水 → 土壤入渗／蒸散 → 地表径流 → 河流汇集 → 湖泊蓄水和出流，以及地下水与地表水交换。

首轮使用人工地形、人工河网与外部气候强迫，属于 C0 开放气候模式。验证水文计算域的水量，不声称全球大气水量或能量已经闭合。

本轮不求解大气、洪水漫溢、潮汐回水、河道动量、非饱和带 Richards 方程、冰雪、泥沙、岩溶湍流管道和承压含水层。对应规范测试标为 NOT_IMPLEMENTED，不以简单模型替代后宣称通过。

模型成熟度初始均为 candidate。实现选择确定不等于科学有效性已经确定。

## 2. 选型结果及理由

| ID | 原型选型 | 选择理由 | 明确限制／未来比较项 |
| --- | --- | --- | --- |
| H0 | 统一体积账本 | 每笔水量可以核对 | 不代替动量和能量方程 |
| H1 | 定容量土壤桶、限速入渗和重力排水 | 参数少，可手算；先验证分配与状态更新 | 项目概念模型，不是完整 HEC-HMS SMA；后续比较 Green–Ampt／多层模型 |
| H2 | 无环单向地形路由，河段采用线性储水 | 保留河段储量与出流时延，可用解析解 | 不给出真实流速／洪水水面；未来再比较 Muskingum 或水动力模型 |
| H3 | 单调水位容量曲线、线性门槛出口 | 可验证湖位、出流与出口事件 | 线性出口为概念近似，不是天然溢流口的通用水力公式 |
| H4 | 两个有限储水体的线性水头差交换 | 双向且有解析基准，容易检查不造水 | 只用于指定的饱和连通区间；地下复杂网络及河床脱水另行扩展 |
| H5 | 外部指定蒸散／水面蒸发需求，实际量受水量限制 | 隔离气候误差，先检查水文账本 | 不是气象蒸散模型，暂不调用 FAO-56 或计算潜热 |

模型思想参考 [HEC-HMS Soil Moisture Accounting](https://www.hec.usace.army.mil/confluence/hmsdocs/hmstrm/canopy-surface-infiltration-and-runoff-volume/infiltration/soil-moisture-accounting-loss-model) 与 [Linear Reservoir Model](https://www.hec.usace.army.mil/confluence/hmsdocs/hmstrm/baseflow/linear-reservoir-model)。HEC-HMS 的线性储水参考用于基流；本文将同类储量关系用于概念河段，是项目选型，不能说成官方已验证了我们的河道路由。

地下交换的水头与导水系数背景参考 [USGS MODFLOW RIV](https://water.usgs.gov/nrp/gwsoftware/ModelMuse/Help/riv_object_pane.html)。该资料还说明地下水头低于河床底时需要分段关系；H4 不覆盖该状态。

## 3. 数据、单位与边界

所有储水量统一保存为体积 m³；液态水采用常密度近似。长度 m、面积 m²、时间 s、流量 m³/s。输入雨量与蒸发深度先转换为时间段累计体积。

| 符号 | 含义 | 单位 |
| --- | --- | --- |
| A | 某表面实际受雨／蒸发面积 | m² |
| p、e | 本时间段累计雨深／蒸发需求深度 | m |
| S、Smax、Sfc | 土壤水、最大容量、排水阈值 | m³ |
| G、Gmax | 地下可动储水、该桶容量 | m³ |
| V | 河段／湖泊储水 | m³ |
| fmax、dmax | 入渗／土壤排水的面积归一化速率上限 | m/s |
| τ | 线性储水响应时间，必须正值 | s |
| h、z | 水头／水位与高程 | m，同一基准 |
| B | 水头每升高一米对应的储水增量 | m² |
| Cg | 连接导水系数 | m²/s |

同一块地表只能被一个受雨面积单元计账，湖面与河面不得又计入陆地受雨面积。首轮湖面和河面蒸发使用固定面积；变化面积在通过基线后再扩展。

外部端点分别命名为 rainfall、evaporation、prescribed_inflow、outlet。封闭盆地不设置 outlet。固定水头边界是有账本的外部水库，不能暗中补水。

## 4. H0：交换账本与守恒

一笔交换记录包含时间区间、来源、去向、体积、模型 ID 和唯一事件 ID。内部交换由同一个体积同时扣减来源、增加去向，禁止两端分别计算或裁剪。

```text
残差 r = 最终总储量 − 初始总储量 − 外部输入 + 外部输出
```

临时待路由水包、河段水、湖水、地下水都属于域内储量。若遗漏等待转移的水包，会错误地报告水量消失。

入流只提交一次；幂等恢复通过事件 ID 和阶段提交完成。不能以事后补水或缩放所有水量的方式消除残差。

## 5. H1：土壤桶的离散算子

这是选定计算顺序的离散概念模型。以下各体积均为当前步数量；要求 `0 ≤ Sfc ≤ Smax`、储量和速率合法。面积 A 只包含该陆地单元。

1. 外部雨量形成地表水包 `W = pA`。本轮不保留坡面洼蓄，上一时段径流不重新入渗。
2. 入渗量 `F = min(W, fmax·A·Δt, Smax−S)`；更新 `S ← S+F`。
3. 待路由径流 `R = W−F`，保存为域内水包，不立即算外部出流。
4. 土壤实际蒸散 `ET = min(e_soil·A, S)`；更新 `S ← S−ET`，ET 记到外部蒸发。
5. 地下补给 `D = min(max(S−Sfc,0), dmax·A·Δt, Gmax−G)`；更新 `S ← S−D, G ← G+D`。

这一步序意味着本步排水释放的孔隙不在同一步回用于先前的雨水入渗。减小时间步会改变结果，应进行步长收敛检查。不能将一步离散答案当作真实连续入渗的解析解。

地下桶满时排水受限；余水留在土壤，本模型不会凭空产生额外容量。若以后加入毛管上升、植被胁迫或地表洼蓄，须改变模型版本并新增实验。

Sfc 在此为概念排水阈值，未经土壤资料标定不能直接声称等于实测田间持水量。fmax、dmax 等演示系数不由“石灰岩”名称自动决定。

## 6. H2：地形路由与河段储水

### 6.1 路由拓扑

对有严格低邻居的陆地单元，按 `(本单元高程−邻居高程)/中心距离` 选择最大正坡降接收者。相等时按稳定 ID 决定，不依赖遍历顺序。只进入已声明邻接边。

平坦连通区若有出口，以距出口的图距离建立下降次序，平距离按稳定 ID 决定；这是排水排序，不修改权威高程。无出口区交给显式湖盆节点。首轮不自动填平全部洼地；人工样例需要明确盆地归属与出口。

将湖泊收缩为节点后，地表路由必须为有向无环图；显式分汊暂拒绝。地下交换图与地表图分开，不能用地表无环约束禁止地下双向交换。

### 6.2 线性河段

单河段定义：`dV/dt = I − Q`，`Q = V/τ`。I 为本子步内常值入流率。

解析更新：

```text
a = exp(−Δt/τ)
V1 = V0·a + I·τ·(1−a)
O  = V0 + I·Δt − V1
```

O 是整步输出体积，不能用 `Q_end·Δt` 替代。τ 不是流速，也不能无标定就解释为真实河道传播时间。

按稳定拓扑次序路由。陆地径流包在当前路由子步开始作为初始储量注入受纳河段；上游河段输出 O 作为下游本子步均匀入流 `O/Δt`。此做法守恒，但近似了上游出流的时间形状，必须通过串联河段步长收敛实验。

最终出口的 O 才计为离域水；内部河段输出只属于交换。τ=0 非法；需要瞬时传递时使用明确的 junction 类型，不能令储水方程除以零。

## 7. H3：湖泊容量和门槛出口

### 7.1 容量曲线

基准采用固定面积 A、平底 z0：`V=A·max(h−z0,0)`。一般湖盆使用严格递增的分段线性容量表；反查水位必须单值。湖底不能产生负储量，曲线范围外输入需要拒绝或进入已声明扩展段，不能静默外推。

雨量、实际蒸发分别进入账本。蒸发算子 `E=min(e_lake·A,V)`，按已声明次序更新储量。第一版不将库容曲线用于真实河口回水。

### 7.2 选定出口近似

```text
Vspill = 容量曲线在出口高程 hspill 对应的体积
Qout = max(V−Vspill,0)/τlake
```

τlake 为概念参数。该关系便于建立可测的蓄水原型，不代替堰流、孔口或天然河道的定量水力关系。

路由阶段 I≥0，本阶段无蒸发和渗漏（它们在其他算子执行）：

- 若 V0≥Vspill，令 x0=V0−Vspill，对 x 使用第 6 节线性解析更新，再令 V1=Vspill+x1。
- 若 V0<Vspill 且 I=0，不变。
- 若 V0<Vspill 且 I>0，计算 `tc=(Vspill−V0)/I`。Δt≤tc 时仅蓄水；否则在 tc 处分段，剩余时间以 x0=0 进入出口分支。
- 全步出流 `O=V0+IΔt−V1`，门槛以下出流严格为零。

闭口湖使用独立的 no_outlet 类型，所有 IΔt 加入储量，避免把极大 τ 当作永久封闭。

## 8. H4：有限储水体的水头差交换

### 8.1 关系及适用域

在指定水位区间内取 `h1=z1+V1/B1`、`h2=z2+V2/B2`，正向流量 `Q12=Cg(h1−h2)`。常数 B、Cg 是本基准的线性化假设；含水层可用 `B=Sy·A`，Sy 为可排水比例，不能直接等同总孔隙率。

仅在两端保持所声明饱和连通、线性储水关系有效时使用。地表水有水才允许向地下失水；河床脱水、承压或容量耗尽需事件处理，不能继续套公式得到负水量。

定义 `λ=Cg(1/B1+1/B2)`、`δ0=h1−h2`。无其他源汇的单连接解析交换：

```text
δ(t) = δ0 exp(−λt)
T12 = δ0/(1/B1+1/B2) · (1−exp(−λΔt))
V1_new = V1−T12
V2_new = V2+T12
```

Cg=0 时交换为零。T12 的符号决定流向。实现应使用数值稳定的 `expm1` 等价形式，并验证对应数学库的跨平台行为。

### 8.2 边界与多连接

若解析解会越过任一端储量、容量或饱和适用边界，在首次触及边界的时刻截断，提交合法交换，并报告需要更换边界模型。不能简单对最终负值取零。首次原型不自动求解脱水后的继续交换。

首轮完整耦合场景限定每个储水体最多参加一条 H4 边，互不相交的边可独立执行。重叠多连接输入明确拒绝。任意地下网络需后续联合求解或经验证的子步方案，不能因稳定 ID 排序就声称消除了算子顺序误差。

河段若参与 H4，须提供受支持区间的体积—水位关系，不能把 H2 的 τ 当作水位参数。此交换阶段和路由阶段分步，需检查步长依赖。

## 9. 完整一步的冻结顺序

1. 校验输入、状态和模型适用区间，加载本步外部雨量／蒸发需求。
2. 执行 H1：降水、入渗、径流包、土壤蒸散和地下补给。
3. 对地表水体加入直接降水，执行有限水量蒸发。
4. 执行 H4 单连接交换；越适用边界即报告事件，未有后续模型时停止该实验。
5. 将陆地径流包注入河段；以稳定拓扑顺序执行 H2／H3，内部输出传下游，末端输出入外部账本。
6. 检查各储量、阶段与全域收支，原子提交状态及账本。

供比较的步长：3600、1800、900 s；若未达收敛门槛继续减半，并报告成本。外部雨量随步长按同一连续强迫重积分，不能每个子步都重复整段雨量。

为揭示不同步算法误差，解析组件独立测试、固定一步集成测试和连续极限测试分别执行。整步顺序改变即需模型版本变化。

## 10. 基准实验与独立预期值

以下数字均为合成实验参数，不是自然环境的推荐参数。所有未明确启用的通量为零；储量单位 m³、时间 s。当前引擎执行状态全部 NOT_RUN。

### B01：封闭容器（H0；HYD-04、GW-02）

输入：V0=100，无任何通量，运行任意合法步数。

预期：V=100，外部输入输出均为 0，累计残差 0。账本可以为空，但不得生成补水记录。

### B02：两支流瞬时汇流（H0；HYD-02）

输入：两个 junction 分别传入 10、20 m³，没有储水／损失，流向一个出口。

预期：出口 30 m³。另把 5 m³ 放入已声明储水体，预期出口 25、储量增加 5，不能仍报告出口 30。

### B03：土壤、蒸散与补给（H1；LND-02）

输入：A=1000；Δt=3600；p=0.1；S0=20；Smax=50；Sfc=20；G0=0；Gmax=100；fmax=0.025/3600；dmax=0.015/3600；e_soil=0.01。

预期：降水 100，入渗 25，径流包 75，实际蒸散 10，补给 15，土壤最终 20，地下最终 15。平衡：初始 20+降水 100−蒸散 10=最终域内 110。

### B04：干土与地下容量上限（H1；LND-01、03）

子例 a：S0=0，无雨，蒸散需求 10；结果 ET=0、S=0。

子例 b：沿用 B03，但 G0=98、Gmax=100；结果 D=2、S_final=33、G_final=100，R=75、ET=10。限制补给的 13 m³ 留在土壤，不能消失。

### B05：河段脉冲退水（H2；HYD-02）

输入：V0=100，I=0，τ=3600，Δt=3600。

预期：V1=100/e=36.78794411714423；O=63.21205588285577。期末流量约 0.0102188733658734 m³/s，但不能用它乘 Δt 作为累计输出。

### B06：河段恒定入流（H2；HYD-02）

输入：V0=0，I=1 m³/s，τ=3600，Δt=3600。

预期：V1=3600(1−1/e)=2275.634011782808；O=3600/e=1324.365988217192。初期部分来水储存在河段中。

### B07：闭口湖净蓄水（H3；HYD-04）

输入：固定面积 1000，湖底 0，V0=100，I=0.5 m³/s，Δt=600，无出口。

预期：V1=400，h1=0.4 m，出流 0。

### B08：湖泊跨越出口（H3；HYD-05）

输入：A=1000，湖底 0，Vspill=100，V0=0，I=2 m³/s，τlake=100，Δt=150。

预期：50 s 达出口，后续 100 s 的超门槛储量为 200(1−1/e)；V1=226.4241117657115，h1=0.2264241117657115 m；O=73.57588823428846。

注意：这里并不是 V0=300 的退水问题，不能复用另一个实验答案。

### B09：湖泊门槛以上退水（H3；HYD-05）

输入：V0=300，Vspill=100，I=0，τlake=100，Δt=100。

预期：V1=100+200/e=173.5758882342885；O=126.4241117657115。模型只排门槛以上的水。

### B10：蒸发耗尽湖水（H5；HYD-06、LND-05）

输入：A=1000，V0=30，累计蒸发需求深度 0.05，无其他过程。

预期：实际蒸发 30、剩余 0、未满足需求 20。未满足需求不是水量损失，不能写入蒸发账本。

### B11：固定水头差通量（H4 关系层；GW-01）

输入：两个外部恒水头边界 h1=10、h2=8；Cg=0.01 m²/s；Δt=100。

预期：Q=0.02 m³/s、累计交换 2；两端边界账本符号相反。该题验证通量关系，不应用有限储水体的衰减公式。

### B12：两个有限储水体均衡（H4；GW-02）

输入：z1=z2=0，B1=B2=1000，V1=2000、V2=1000，Cg=0.5，Δt=1000；合法储量范围包含整个解。

预期：λ=0.001 s⁻¹，T12=500(1−1/e)=316.0602794142788；最终 V1=1683.939720585721、V2=1316.060279414279，总量 3000。

交换初值后体积相反；等初始水头时 T12=0。这三个子例检查方向与对称性。

### B13：提前触及适用边界（H4；GW-03）

输入：B1=B2=1，z1=10、z2=0，V1=1、V2=0，Cg=1，Δt=1。假定连接的最低有效 V1 为 0。

无限制解析解会给出超出 1 m³ 的交换。预期：在 `t*=−0.5 ln(9/11)≈0.1003353477310756 s` 首次到边界，交换正好 1，V1=0、V2=1；报告 EVENT_REQUIRES_MODEL 并停止，不报告整个 1 s 已成功模拟。

### B14：完整一步闭环（H0～H3；CPL 水量基础）

输入：B03 陆地输出的 75 m³ 径流在路由步开始注入空河段；τ=3600、Δt=3600；河段全部输出进入空闭口湖，湖泊无直接降水／蒸发，H4 关闭。

预期：土壤 20、地下 15、河段 75/e=27.59095808785817、湖泊 75(1−1/e)=47.40904191214183。外部雨量 100、ET 10、出口 0，最终总量 110。

该答案是第 9 节所定义的一步离散实验，不声称 75 m³ 真实暴雨径流在自然界瞬时注入河段。

### B15：两个串联河段的连续解（H2；收敛测试）

输入：两段 τ 相同，第一段初始 100，第二段初始 0，无后续外部入流；t=τ=3600。

连续方程解析答案：V1=100/e；V2=100/e；出口=100(1−2/e)=26.42411176571154。

H2 的逐段平均入流离散计算不必一步命中答案；Δt=3600、1800、900 s 及继续减半时，应向该答案收敛。若用“一步算法自己算出的输出”当参考，就测不出时间形状误差。

### B16：坡面与封闭洼地（H2；HYD-01、03）

子例 a：三单元直线相邻，中心距 1、面积均 1、高程 [3,2,1]，末端指定出口，雨深均 0.001，无入渗，全部为 junction。预期两内部边按顺坡连接，总出口 0.003 m³。

子例 b：高程 [3,1,3]，无出口，中间指定闭口湖；仅两侧陆地各降雨 0.001 m，预期湖获得 0.002 m³，外部出流 0。

子例 c：对无出口平坦区只提供地形、不提供湖盆定义，预期返回 NEEDS_BASIN_DEFINITION；不静默随机开沟。

### B17：可复现和守恒回归（SYS-01～03）

输入：B14 重复运行、打乱互不相交单元顺序、在提交点恢复、跨目标平台运行。

预期：标准化权威输出完全一致；科学误差检查通过但摘要不同，仍算复现性失败。数学库 exp 的末位差异需在实现确定性方案时解决，不能通过放松该门槛隐藏。

### B18：拒绝不支持场景（HYD-08～09、H4 边界）

输入：负面积、τ=0、累计雨量含 NaN、潮汐反向河流、同一桶有多条 H4 边、非单调容量曲线、缺失水位关系。

预期：各自返回稳定的错误码与原因；不输出看似合法的最终世界。分汊、回水和多边交换在本版是能力限制，并非自然界不允许。

## 11. 数值容差与检查顺序

基准参考用高精度计算；未来原型拟使用 binary64。以下为合成小型实验的预注册工程目标，不是对现实模型精度的声明：

| 对象 | 通过标准 |
| --- | --- |
| ID、路由拓扑、错误类型 | 精确一致 |
| B01～B14 的直接解析／离散参考体积 | `abs(error) ≤ 1e−9 m³ + 1e−12·abs(reference)` |
| 直接参考水位 | `abs(error) ≤ 1e−10 m + 1e−12·abs(reference)` |
| B13 边界时刻 | 绝对误差 ≤ 1e−10 s |
| 小型实验累计水量残差 | `abs(r) ≤ 1e−9 m³ + 1e−12·max(初始储量,累计外部输入,累计外部输出,1 m³)` |
| B15 时间离散误差 | 报告每档误差；细化直到两段储量与累计出口各自相对误差 ≤ 0.1%，总守恒仍须满足上行标准 |
| 跨平台标准化权威数据 | 完全一致，不能用上述浮点容差替代 |

先检查非法值和适用域，再看非负性、局部收支、整体收支，最后比较参考结果。即使全域误差抵消，局部错误仍失败。

不允许因测试未通过自动提高容差。若目标不适合正式全球尺度，须另立尺度化误差预算并记录依据，不能直接把本表套到全星球。

这里冻结的是解析实现验证目标。真实流量、湖位或蒸散误差门槛仍待真实数据与用途评估，不把机器精度误差当成现实预测误差。

## 13. 当前决定与未决事项

已明确：原型模型关系、单位、计算顺序、范围限制、18 组基准场景及理想数值容差。
