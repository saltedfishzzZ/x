## 1. 目的、范围与阅读方式

目标是把“符合自然规律”转化为可追溯、可计算、可检查的工程要求。覆盖当前设计中从行星条件、地质、气候、水系、地貌、生态到分类、区域细化、存档与解释的完整链路，以及用户列出的全部景观词汇。未来新增机制必须先扩展本规范，不宣称穷尽所有地球科学现象。

本文中的“必须”是用于实现和验收的项目约束；“候选”尚需比较和批准为具体模型；“待标定”不能视为通过。本文是场景定义，不是执行报告；已实现的水文子集见[实现验证记录](../历史记录/独立水文原型验证记录.md)。子集基准通过不表示其关联的全部整引擎场景均已验证。

科学来源支持过程认识，不自动认可本文提出的算法、阈值或软件。文中的测试布置与发布门槛为本项目的工程设计。引用的入门资料只支持机制说明，不足以充当未列出公式的技术依据。

### 1.1 四种证据必须分别报告

| 证据 | 回答的问题 | 不能代替什么 |
| --- | --- | --- |
| 实现正确性 | 代码是否正确求解所选模型 | 不能证明模型适用于所有环境 |
| 物理一致性 | 单位、收支、边界、交换是否一致 | 守恒的错误模型仍可能不真实 |
| 现实有效性 | 独立观测是否支持模型表现 | 单一地点拟合不能保证跨环境适用 |
| 复现性 | 相同配置是否得到相同权威数据 | 稳定复现错误不等于科学正确 |

软件正确性与模型适用性需要分别验证，参见 [HEC-HMS Validation Guide](https://www.hec.usace.army.mil/confluence/hmsdocs/hmsvg/4.5/validation-guide)。

### 1.2 模型状态

- `candidate`：有候选依据，公式或参数尚未冻结。
- `implemented`：已有实现，尚未通过全部适用测试。
- `verified`：实现与基础约束通过，未必具有现实验证。
- `validated_in_domain`：在明确环境、尺度与指标范围内通过独立验证。
- `heuristic`：受约束的生成或识别规则，不能称为物理求解。
- `deferred`：仅预留；不得生成声称已模拟其成因的事实。

上述状态是分类，不应混成一个“真实性分数”。每个模型单独保存证据与适用域。

## 2. 模型登记与科学来源规则

每个模型登记以下字段，缺失项须明确标为未决：

```yaml
model_id: HYD-LAKE
model_version: candidate-1
status: candidate
process: 湖泊储水与出口
references: [稳定文献标识、链接、章节、访问日期]
equations: [公式编号、离散形式、求解顺序]
inputs: [变量、单位、空间含义、时间含义、合法范围]
outputs: [变量、单位、输出层级]
parameters: [数值或范围、来源、标定方式、不确定性]
initial_conditions: 待具体场景指定
boundary_conditions: 待具体场景指定
validity_domain: [尺度、气候、岩性、水力状态等]
omitted_processes: []
conserved_quantities: []
external_sources_and_sinks: []
test_ids: [HYD-04, HYD-05]
tolerance_profile: 待冻结
validation_datasets: []
known_failures: []
```

来源优先级：基础守恒与量纲关系、同行评议原始论文、科学机构技术手册、实测数据、项目生成规则。后两类不能包装成普适物理定律。

采用第三方模型时冻结具体版本、方程变体、参数和依赖，不将“latest”文档地址当作可复现实验版本。每个外部数据集保存版本、许可、下载日期、校验值和预处理脚本。

随机系数若无观测支持，应标记为设计参数；不得把随机采样区间写成已知自然常数。修改模型、参数、阈值或数据集均需重新确定受影响的验证范围。

## 3. 全局物理契约

### 3.1 单位与时间

内部优先使用 SI：长度 m、面积 m²、体积 m³、质量 kg、时间 s、能量 J、通量 W/m²。温度场明确 K 或 °C，绝对温度公式必须用 K。

降水深度、单位面积质量通量和总水量不得混用。`降水体积 = 降水深度 × 实际球面面积`。雪冰以水当量或质量进入水量账本，不能将等厚雪与水视为等质量。

地质时间、气候统计时间和水文积分时间分开。若采用无真实时长的构造事件，其阶段只能标为相对阶段，不得伪造百万年级年龄。长期平均侵蚀率不能无依据地等同于“用年均流量代入瞬时非线性公式”。

固定地图记录代表时刻、季节或统计周期；不要求所有储量变化为零。只有声明稳态或周期稳态的模型才检查相应平衡。

### 3.2 统一交换账本

对储量 M，任一时间段满足：

```text
r = (M_end − M_start) − (Σ输入 − Σ输出 + 显式源 − 显式汇)
```

每笔内部交换由同一条记录产生两端相反的增减，含来源、去向、时间区间、数量与模型 ID。先限流以满足可用储量，再向两端提交相同交换；不能两端各自裁剪。

分别追踪水、固体沉积物及已模拟的溶解物质。相变时检查质量与所模拟的潜热，不把水蒸发当作行星水量销毁。外部强迫中的降水和热量作为边界输入显式登记。

### 3.3 开放与闭合模型

- 外部气候驱动水文时，只要求所模拟水文域对外部通量记账；不能宣称全球大气水量闭合。
- 启用大气水汽反馈时，降水与蒸发必须进入大气账本；不能一边固定降水、一边宣称水汽全闭合。
- 地质事件抬升若未追踪完整地幔物质，声明外部构造强迫；不能声称整个行星固体质量与能量已闭合。
- 如果不求解动量，声明风场或水力关系为参数化输入，不能声称完整动力学一致。

### 3.4 能量与求解合法性

辐射、感热、潜热、地中热及储热使用统一正负方向。潜热项由实际相变质量确定，不能重复计算。任何近似散热或外部热源需登记。

NaN、无穷值、非法负储量、负面积、无效索引为结构错误。不能通过静默截断负水量修复；微小舍入修正应有计量记录并计入误差预算。

## 4. 科学模型目录与场景测试

各表中的通过条件使用第 7 节的阈值机制。没有数值阈值的现实或近似模型只能停留在候选状态。测试 ID 是未来测试和报告的稳定关联标识。

### 4.1 行星条件与球面空间（PLN、GEO）

候选表示为固定半径球体加高程。自转、轴倾角与恒星输入参与气候参数；不模拟扁率和空间重力变化时明确近似。恒星光谱、大气成分、压强及轨道条件暂限于已验证类地范围，超范围配置拒绝或标为实验世界。

球面总面积应为 `4πR²`；刚体板块速度可用 `v = ω × r` 表示。网格类型尚未选定。空间离散为工程设计，不因采用球面就自动消除数值偏差。

| 测试 ID | 场景与输入 | 预期／指标 |
| --- | --- | --- |
| PLN-01 | 非正半径、重力，非有限参数，超适用域输入 | 非法输入拒绝；超域不静默钳制为合法世界 |
| GEO-01 | 全球各层网格，含极区和跨面边界 | 面积总和误差、无空洞重叠、邻接互惠 |
| GEO-02 | 常数标量场与已知刚体旋转 | 重采样保持常数；速度切向；长度面积正确 |
| GEO-03 | 已知总质量场粗细往返转换 | 总质量保持在预算内；类别不算术平均 |
| GEO-04 | 将同一人工地形刚体旋转后重复计算 | 几何和无外部方向强迫的过程结果等变；不把真实纬度气候差异误判为错误 |

### 4.2 板块、地壳、岩性与地质历史（TEC）

板块归属、地壳属性、海陆状态独立。边界根据相对速度在局部法向／切向上的分量分类。首版采用构造事件及地势响应规则；完整地幔对流、板块重组和岩石力学暂不求解。

板块相互作用与构造形态参考 [USGS Understanding plate motions](https://pubs.usgs.gov/gip/dynamic/understanding.html)。该资料支持过程类型，不提供本项目事件核的定量参数。地壳均衡或冷却沉降模型在选定具体技术来源前只能登记为候选。

| 测试 ID | 场景与输入 | 预期／指标 |
| --- | --- | --- |
| TEC-01 | 相邻板块具有相同角速度 | 相对速度为零，不凭边界存在制造碰撞山系 |
| TEC-02 | 指定纯汇聚、纯张裂、纯侧滑与斜向运动 | 速度分解正确；滑动不无条件生成山脉；形态规则可追溯 |
| TEC-03 | 一个板块内同时有两类地壳；大陆跨板块 | 不强制海岸与板块边界重合 |
| TEC-04 | 当前无活动边界，但有历史抬升事件 | 允许古老山系保留；年龄／阶段顺序一致 |
| TEC-05 | 多事件重复作用于同一区域 | 厚度合法、参数有限；外部增减有记录，不重复累积同一事件 |
| TEC-06 | 岩层及断裂穿越分块 | 同一地层和断裂身份连续；岩性物性来源与版本一致 |

### 4.3 地势、海洋、海平面与岛屿（SEA）

候选地势由构造贡献、基底、沉积层和地表过程组成。海洋采用静态等势面近似，未模拟潮汐／海流引起的水位差。海平面求解可用离散容量函数 `V(H)=Σ A_i max(H−z_i,0)`，但仅对当前与海洋连通的单元求和；跨越门槛引起连通集合变化时重新求解。

此式为项目离散几何模型；细网格未分辨的岸坡误差需要收敛测试。总水量与海洋分配量不同：湖泊、地下水、雪冰的初始分配及后续交换必须入账。

| 测试 ID | 场景与输入 | 预期／指标 |
| --- | --- | --- |
| SEA-01 | 固定面积平底容器，水量 V | 水深等于 V/A，达到数值容差 |
| SEA-02 | 两盆地被高程已知的门槛隔开 | 未越门槛不连通；越门槛后重算水位与体积 |
| SEA-03 | 内陆低于海平面的封闭盆地 | 不自动填入海水；作为独立水文对象 |
| SEA-04 | 固定地势逐步增加海洋水量 | 静态模型水位不下降、淹没集合不缩小；不外推到动态地壳情况 |
| SEA-05 | 冰雪融化与海洋交换 | 水质量闭合；漂浮与陆上冰分别处理，未实现的海冰机制禁用 |
| SEA-06 | 岛屿位于接缝或细化边界 | 身份、岸线连接与水位基准保持一致 |

### 4.4 辐射、气温、环流近似与水汽（CLI）

依据：气候模型区分直接模拟和参数化过程，见 [NOAA GFDL](https://www.gfdl.noaa.gov/climate-modeling/)；能量收支的物理含义见 [NASA Radiation Budget](https://science.nasa.gov/ems/13_radiationbudget/)。

候选温度方案：带热容量与区域热输送的简化能量平衡模型。形式可写为 `C·dT/dt = 吸收短波 − 出射长波 + 水平净热输入 + 显式外部热源`，所有右侧项为 W/m²，C 为 J/(m²·K)。大气层与地表若分开，各自建立账本，不能把地表辐射直接等同于大气顶出射辐射。

风场初期可以参数化，但其依据和适用自转范围需补齐；水汽使用非负、守恒的输送与凝结近似。地形抬升降水只是候选参数化，不等于“迎风坡必定湿润”。洋流初期若以有效热输送代替，应登记来源和边界，不能伪称已求解真实洋流。

| 测试 ID | 场景与输入 | 预期／指标 |
| --- | --- | --- |
| CLI-01 | 均匀单箱，无水平输送，固定反照率、无温室黑体基准 | 平衡温度符合 `T=[S(1−α)/(4σ)]^(1/4)`；此式只用于该理想测试 |
| CLI-02 | 无外源、两箱仅交换热量 | 总能量守恒，温差按所选传热模型变化 |
| CLI-03 | 对称边界、圆轨道、零轴倾角的理想球体 | 没有由网格引入的非物理南北偏差；不要求复杂真实行星处处对称 |
| CLI-04 | 封闭输送域中的已知水汽团，无源汇 | 总水汽保持、非负、接缝不漏水；报告数值扩散 |
| CLI-05 | 给定湿气流越山，与无山／反向风对照 | 检查模型预期的降水位置变化和水汽预算；无水汽输入时不凭山造雨 |
| CLI-06 | 固定其他参数增加反照率，或增加热容量 | 单箱平衡温度响应与季节响应符合方程；不把单箱方向性推广成所有局地气候定律 |
| CLI-07 | 极昼、极夜及季节过渡 | 辐射非负、积分正确，无极区奇点 |
| CLI-08 | 年循环反复积分 | 记录储热与储水漂移、周期差和迭代残差；未达标不标为平衡 |

### 4.5 蒸发、蒸散、土壤入渗与积雪（LND、ICE）

蒸散候选参考 [FAO-56 Penman–Monteith](https://www.fao.org/4/x0490e/x0490e06.htm)，必须区分参考作物蒸散与实际地表蒸散；湖面蒸发不能直接套用草地参考值。输入不足时选择另一个已登记模型，不能虚构湿度、辐射和风速观测。

入渗／土壤可先选储水桶模型，再比较更细模型；截留、入渗、储存、蒸散和径流的分配参考 [HEC-HMS 技术说明](https://www.hec.usace.army.mil/confluence/hmsdocs/hmstrm/canopy-surface-infiltration-and-runoff-volume)。这里的“损失”只是离开径流分量，并非离开整个水循环。

雪先使用质量守恒的积累与融化模块；温度指数法若被采用，应明确为经验近似而非完整能量解。冰川动力、冰蚀与冰期遗迹须另选模型，不能由积雪贴图推断。积累与消融的基本关系参考 [NSIDC 冰川质量平衡](https://nsidc.org/learn/parts-cryosphere/glaciers/why-glaciers-matter)。

| 测试 ID | 场景与输入 | 预期／指标 |
| --- | --- | --- |
| LND-01 | 干土、无水输入，蒸发需求为正 | 实际蒸散受可用水限制，储量不负 |
| LND-02 | 固定土壤容量、已知初始储量和降水 | 入渗、径流、排水、储水和蒸散闭合 |
| LND-03 | 隔绝底部的饱和土柱持续入水 | 有明确积水或径流出口，不无限吞水 |
| LND-04 | 同一 FAO 参考算例输入与单位转换 | 与独立参考结果一致；mm/day 与 m/s 换算正确 |
| LND-05 | 关闭土壤补给，逐步提高蒸发需求 | 不持续产生无限蒸散；能量模式中潜热与实际质量交换一致 |
| ICE-01 | 给定雪水当量，关闭降雪、升华与融化 | 雪质量不变 |
| ICE-02 | 只开放融雪过程 | 雪减少量等于液态水增加量；不直接新增下游水而漏减雪 |
| ICE-03 | 冷而干与冷而湿两个理想区域 | 缺少积累不能仅凭低温生成大量雪；持续性标签符合季节记录 |
| ICE-04 | 启用冰流或冰蚀候选 | 必须另有通量、质量与地形验证；未实现时禁止“已模拟冰川地貌”声明 |

### 4.6 地形排水、河网、湖泊与湿地（HYD）

区分地形路由与水力求解：单向坡降路由可作为首版近似，但不适合承压流、潮汐、回水和复杂分汊的全部情况。平坦区、数字噪声坑和真实内流盆地分开处理。多流向权重之和必须为一或有明确储存／出口项。

湖泊使用水位—面积—容量关系和出流条件。任一时间段 `ΔV = P_lake + Q_in + G_in − E_lake − Q_out − G_out`，各项均为该时间段积分体积。固定水位边界意味着与外部水库交换，不能隐藏成自动补水。

湿地识别使用水位、饱和与淹水持续性，不能单凭低坡度。更完整水文过程参考 [USGS 地表地下水过程](https://pubs.usgs.gov/circ/circ1139/htdocs/natural_processes_of_ground.htm)。

| 测试 ID | 场景与输入 | 预期／指标 |
| --- | --- | --- |
| HYD-01 | 已知坡面和分水岭，均匀产流 | 流域归属、出口总量与人工答案一致 |
| HYD-02 | 两支流汇合，无损失、计入河段储量 | 输入等于输出加储量变化；不能忽略输送时延强求瞬时相等 |
| HYD-03 | 平坦区、微小噪声坑、真实封闭盆地并列 | 不产生无处理的路由循环；修坑记录与真实盆地保留可检查 |
| HYD-04 | 固定面积湖，恒定净入流 F，未到出口 | `V(t)=V0+Ft`、水位变化符合容量关系 |
| HYD-05 | 湖位跨越出口、再降低；两个连通湖 | 越门槛启动合法出流，低于门槛不产生无来源排水；水量闭合 |
| HYD-06 | 无地表出口的干旱湖盆，允许蒸发与地下交换 | 储水变化有解释；不强制开沟入海；盐度未模拟时不确定标盐湖 |
| HYD-07 | 季节河流及间歇湿地 | 标签与淹水历时一致，不将一季干涸误报结构错误 |
| HYD-08 | 分汊河、岛洲周边多路径 | 权重与交换闭合；模型不支持时明确限制，不复制两份完整流量 |
| HYD-09 | 回水、逆坡河床和潮汐口边界 | 简化路由报告不适用；水力扩展按能量／水面条件检验，不用“河床处处下降”作为普适物理定律 |

### 4.7 地下水、泉与岩溶通道（GW、KAR）

多孔介质候选采用 Darcy 型通量 `q = −K∇h`，q 与 K 单位 m/s，h 为水头 m；总流量还需乘截面积。K 可为张量，Darcy 通量不同于孔隙内速度。适用边界和地下水方程参考 [USGS MODFLOW 数学说明](https://water.usgs.gov/software/code/ground_water/modflow/doc/ofr9459.pdf)。

简化河流交换可以使用经过适用域审查的水头差—导水系数关系，参考 [MODFLOW 水头依赖边界](https://water.usgs.gov/nrp/gwsoftware/modflow2000/MFDOC/head-dependent_flux_boundary_p.html)。河道干涸、隔水层与可用储量必须处理。

岩溶由可溶岩及水岩作用支持，参考 [NPS Caves and Aquifers](https://www.nps.gov/articles/caves-and-aquifers.htm)。首版可使用受岩层与裂隙约束的通道网络，属于规则近似；湍流洞穴管道不能无条件套用多孔介质 Darcy 模型。完整溶解动力学与塌陷力学仍待选型。

| 测试 ID | 场景与输入 | 预期／指标 |
| --- | --- | --- |
| GW-01 | 均匀 K、一维长度 L、截面 A、固定两端水头 | `Q=KA(h1−h2)/L`；反向水头使流向反转 |
| GW-02 | 两储水区无外部源汇，仅交换 | 总水量守恒；等水头无交换 |
| GW-03 | 河水位高／低于邻近地下水头两个场景 | 允许河流失水与获水，方向和限流正确 |
| GW-04 | 有压补给、泉口高于附近地面；另设无补给枯竭场景 | 用水头判定，不只比较地面高程；泉水不能无限维持 |
| KAR-01 | 相同裂隙分别放入可溶与不可溶岩层 | 岩溶规则不在缺少必要岩性时触发；其他成因洞穴独立处理 |
| KAR-02 | 落水洞—暗河—泉口跨分块连接 | 入口损失与出口／储量配平，通道身份不随探索变化 |
| KAR-03 | 溶蚀扩大空洞；随后规则塌陷 | 移除的岩石计入溶解／碎屑账本或显式外部汇；几何不穿透禁入层 |
| KAR-04 | 同一地下节点网络多次细化 | 水文连接不变，局部三维无非法重叠；未解力学不声称洞顶稳定性经过证明 |

### 4.8 河流侵蚀、坡面、泥沙与河曲（ER、MOR）

河流下切候选 `E=K_e A^m S^n` 为经验化长期模型：E 为 m/s，A 为 m²，S 无量纲，则 K_e 单位随 m 变化，不能与地下水 K 混淆。适用前提与阈值变体参考 [Landlab Stream Power](https://landlab.readthedocs.io/en/latest/tutorials/landscape_evolution/smooth_threshold_eroder/stream_power_smooth_threshold_eroder.html)。面积代流量关系在气候不均匀或有地下交换时需要重新审查。

坡面候选线性输运 `q_s=−D∇z`，q_s 为单位宽度固体体积通量 m²/s，D 为 m²/s；仅作为缓坡近似候选，不用于所有崖壁。泥沙方程需区分固体体积与含孔隙沉积厚度，任何下切模型若不模拟去向须登记输出汇。基岩与覆盖层联合输运可比较 [Landlab SPACE](https://landlab.readthedocs.io/en/latest/tutorials/landscape_evolution/space/SPACE_user_guide_and_examples.html)。

河曲不能只用正弦线覆盖河道；首版可作受谷地约束的形态生成，迁移与岸蚀须另有模型。机理参考 [NPS Meandering Stream](https://home.nps.gov/articles/meandering-stream.htm)。

| 测试 ID | 场景与输入 | 预期／指标 |
| --- | --- | --- |
| ER-01 | 下切模型 A=0、S=0 或 K_e=0 | 此过程贡献为零，不强制其他过程也为零 |
| ER-02 | 一维周期正弦坡面，仅线性扩散 | 振幅按 `a(t)=a0 exp(−Dk²t)` 衰减，平均高度保持；网格细化收敛 |
| ER-03 | 上游侵蚀—搬运—下游沉积，闭合边界 | 岩石／沉积固体收支闭合，孔隙与密度换算明确 |
| ER-04 | 硬软岩层接触、抬升及差异侵蚀 | 地貌与输入变化相符，不能预设每处接触都形成瀑布 |
| ER-05 | 崖壁、大坡度、过大时间步 | 拒绝不适用的缓坡模型或切换已验证方案，不发生无限削平／负厚度 |
| MOR-01 | 弯曲河道与受限谷地，指定河岸条件 | 河道不穿山，不无故逆接；若声称迁移，提供岸蚀沉积证据 |
| MOR-02 | 河道改道或裁弯场景 | 上下游连通、水体转移、旧河道状态同时更新 |
| MOR-03 | 河段落差和有效流量形成瀑布候选 | 落差、上下游高程与水源均可查询；无水时标干瀑地貌或不显示流水 |

### 4.9 风成、海岸、潮间带与暗礁（WND、CST）

风成景观需要风、可移动沉积物和地表条件，参考 [NPS Aeolian Landforms](https://www.nps.gov/subjects/geology/aeolian-landforms.htm)。首版可做有物源约束的沙地识别；完整起沙、输沙及沙丘迁移方程需另选技术模型。干旱不意味着处处有沙。

海岸分开表达水位范围、波浪／潮流强迫、底质与泥沙来源。相关专业模型入口为 [USACE Coastal Engineering Manual 官方目录](https://www.publications.usace.army.mil/USACE-Publications/Engineer-Manuals/u43544q/73686F72652070726F74656374696F6E/udt_43544_param_orderby/Title/udt_43544_param_direction/ascending/)，该目录不等于已选输沙公式。潮汐影响水位的背景见 [NOAA Estuary Change](https://oceanservice.noaa.gov/facts/estuarychange.html)。首版若仅输入潮差统计，不声称求解天体潮汐或风暴潮。

暗礁先定义为参考水位下的浅水障碍物，不等同于珊瑚礁。珊瑚生长与水化学不在首版模型内。

| 测试 ID | 场景与输入 | 预期／指标 |
| --- | --- | --- |
| WND-01 | 干旱区无可用沙源，对照有沙源区 | 不凭干旱生成大体积沙丘；沙量有来源 |
| WND-02 | 单向风输沙与封闭物质边界 | 输沙启用时保持固体收支；无风不发生该模型的风输运 |
| CST-01 | 平面岸坡、指定周期水位范围 | 淹没集合与高程相符，零潮差不伪造周期潮滩 |
| CST-02 | 相同岸形不同底质／输沙条件 | 海滩、石滩不只由距离海岸决定；未解输运时仅标形态近似 |
| CST-03 | 河流输出泥沙进入海岸域 | 接收量等于河流输出量，无重复沉积或物质丢失 |
| CST-04 | 礁顶跨越低／高参考水位，细化海底 | 出露与淹没状态随基准变化一致，浅水障碍位置稳定 |

### 4.10 土壤、植被、生态与动态景观（ECO、ATM）

首版生态采用功能类型／适生规则，不宣称完整演替、物种扩散或碳循环。植物功能类型如何影响反射、根系取水和交换可参考 [CTSM/CLM 地表表征](https://escomp.github.io/CTSM/tech_note/Ecosystem/CLM50_Tech_Note_Ecosystem.html)。本项目的分类阈值仍需独立标定。

土壤形成若只使用母质与水分的规则映射，应标记为近似；养分、风化、火灾、动物与人类土地利用未实现时不编造影响。竹林需明确所指类型、适生数据与生物地理假设，不能以通用林地规则证明其真实存在。

烟岚、云岫是景观词；首版映射为云雾表现候选，不默认等于烟尘污染。凝结机制背景见 [NOAA How Clouds Form](https://prod-01-alb-www-noaa.woc.noaa.gov/jetstream/clouds/how-clouds-form)。只有气候均值时可标“云雾潜势”，不能声称某时刻必有云。

| 测试 ID | 场景与输入 | 预期／指标 |
| --- | --- | --- |
| ECO-01 | 人工设定适生／不适生条件和边界样本 | 规则结果匹配独立标注，记录不确定区而非硬凑全覆盖 |
| ECO-02 | 同单元多覆盖类型与水体占比 | 同一互斥覆盖层比例和为一；景观标签允许叠加，不混为重复面积 |
| ECO-03 | 根系取水／蒸散反馈启用 | 土壤减水与大气增水一致；无可用水不得无限取水 |
| ECO-04 | 无竹类专属数据，或缺失物种存在假设 | 竹林保持候选／预留，不以精确概率声称已验证 |
| ATM-01 | 仅有年均湿度，对照完整温湿度瞬时场 | 前者只产生潜势；后者才按所选凝结模型生成瞬时云雾 |
| ATM-02 | 关闭动态景观或改变渲染随机种子 | 不改变地质、水文等权威事实；若云参与辐射则属物理模型变更，必须重算 |

## 5. 用户景观词汇的逐项覆盖

本表是项目语义与验收映射，不是已获地学界认可的统一分类标准。相对位置、植被、水体、地貌与天气分层保存。所有阈值均需声明空间尺度，命名差异不能伪装成不同物理机制。

首版计划标记：`识别`=从已有事实识别；`近似`=需明确规则和限制；`预留`=专项资料或过程未就绪。计划不代表已实现。每一行均必须执行 CLS-01 至 CLS-04，并执行其关联过程测试；每类至少包含正例、缺少必要条件的反例和边界例。

## 6. 跨模块、尺度与工程场景

### 6.1 耦合等级

- `C0 外部强迫`：气候驱动水文，不含陆面反馈；只检查相应开放域收支。
- `C1 有限反馈`：蒸发、水面覆盖、雪反照率等声明过的量回传；检查两端一致及迭代稳定。
- `C2 扩展动力学`：仅在各扩展模型通过验证后使用；不因模块数量多自动升级。

每个世界保存实际耦合等级、外部通量与省略过程。耦合状态变更需改变模型配置版本。

## 7. 误差、阈值与通过判定

### 7.1 不采用一个通用百分比

每个指标定义：变量、单位、计算域、时间窗口、归一化尺度、绝对容差、相对容差、通过依据、版本。不能把水量误差阈值直接复用于温度、河道位置或标签准确率。

统一数值比较形式：`|误差| ≤ atol + rtol × scale`。atol 与被比较量同单位；scale 不能只用可能接近零的净流量。

收支误差的 scale 建议取初末储量绝对值、累计绝对交换量与有单位的最小特征量的最大值，同时报告原始残差和归一化残差。对大储库中的小径流，再独立报告以累计通量为尺度的残差，防止海洋巨量储水掩盖河流误差。

局部、区域、全球分别统计；正负局部误差互相抵消不能视为正确。全过程累计漂移和单步最大误差都需通过。

### 7.2 现阶段可冻结与待标定的门槛

| 项目 | 门槛 | 状态与说明 |
| --- | --- | --- |
| 非法索引、NaN、无穷值、无来源对象 | 零个 | 结构性硬门槛 |
| 共享边界、连接 ID、标准化权威摘要 | 精确一致 | 工程硬门槛，不以视觉接近代替 |
| 未登记的内部水量交换／外源汇 | 零笔 | 账本硬门槛；舍入修正也要登记 |
| 已确定必要条件的标签违例 | 零个 | 语义硬门槛；不确定标签单列 |
| 理想解析单元基准 | 每题预先冻结 atol/rtol | 当前未选数值类型和网格，不能杜撰统一精度 |
| 守恒、积分与迭代误差 | 每个模型／尺度独立预算 | 经解析基准、收敛实验后冻结，生产运行不得自动放宽 |
| 现实数据偏差 | 每变量／气候区／尺度预注册指标与阈值 | 基于观测误差和用途制定，当前待标定 |
| 岱崮、竹林等专项类别 | 资料、定义和独立样本齐备后设阈值 | 未完成前不能升级为 validated_in_domain |

`待标定`意味着文档已覆盖验收方法，但对应能力还未获验证。没有阈值或必需数据的用例报告 `BLOCKED`，不报告 `PASS`；首版未包含的扩展报告 `NOT_IMPLEMENTED`。

### 7.3 数值收敛协议

对选定的连续过程使用至少三档网格或时间步长，固定物理输入，不因网格变化重抽一个世界。分别细化空间和时间，再检查组合细化。

比较湖位、出流、温度、累计侵蚀等可积分指标；不强求岸线每个像素都相同。光滑解析题检查误差下降与预期阶；有门槛、拓扑变化或非光滑地貌时，检查指标稳定性与变化原因，不武断要求单调误差。

收敛失败、解算器残差小但物理收支不闭合、或换分块后宏观水系改变，均需定位。求解器自身残差不能替代物理残差。

## 8. 现实数据与独立验证

### 8.1 外部数据模式

引擎须允许跳过随机地质生成，输入真实地形、气象、岩性或水文边界，单独检验过程。将真实地形输入模型不等于要求随机行星复制地球。

候选数据来源如下；尚未下载、选取具体样本或完成许可核对，不宣称已有基准数据集：

| 数据 | 入口与性质 | 用途及限制 |
| --- | --- | --- |
| 地形 | [USGS 3DEP](https://www.usgs.gov/3d-elevation-program/about-3dep-products-services) | 区域地形与排水基准；检查垂直基准、分辨率、裸地／表面差异 |
| 河流与水位 | [USGS Water Data APIs](https://api.waterdata.usgs.gov/) | 流量、水位过程对照；检查测站质量、流域和人为调控 |
| 气候背景 | [Copernicus ERA5](https://cds.climate.copernicus.eu/datasets/reanalysis-era5-complete?tab=overview) | 再分析结合模型与观测，不是无误差真值；使用站点等独立资料补充 |
| 辐射 | [NASA CERES](https://ceres.larc.nasa.gov/science/) | 大尺度辐射诊断；匹配时空尺度与产品误差 |
| 地表覆盖 | [ESA WorldCover 产品说明](https://worldcover2020.esa.int/data/docs/WorldCover_PUM_V1.1.pdf) | 覆盖分类对照；遥感类别不等于本项目所有景观标签 |
| 地下水与岩溶 | MODFLOW 基准题、公开泉流量及岩溶案例待选 | 缺观测时只声称数值验证，不声称真实洞穴网络可预测 |
| 岩性与专项地貌 | 区域地质图、地貌调查与物种适生资料待选 | 需核对许可和语义，不使用图片外观作唯一成因证据 |

### 8.2 校准与验证拆分

1. 先冻结模型结构、指标与分割方案，再调参数。
2. 校准和验证按流域／区域及时间分开，避免相邻格子随机拆分造成信息泄漏。
3. 保留最终未参与调参的检验集。验证失败后若修改模型，该数据不再作为未见检验集。
4. 覆盖湿润、干旱、雪主导、岩溶、海岸等适用环境；某一类型缺样本就缩小有效性声明。
5. 统一单位、时区、统计周期、投影和高程基准；缺测不填零。
6. 记录水库、灌溉、采水、采矿及人工植被影响，不能把未模拟的人类活动全归因于自然模型错误。

### 8.3 指标组合

- 气温：偏差、RMSE、季节振幅与相位，分气候区报告。
- 降水：水量偏差、季节分配、干湿区位置；只模拟月均时不验收逐日暴雨预测。
- 水文：累计水量、流量季节性、低流量、湖位；洪峰指标只用于具有相应时间分辨率的模型。
- 地形：高程和坡度分布、起伏、流域面积及河网统计；地貌观测形态不能唯一证明历史成因。
- 生态与分类：各类 precision／recall、混淆矩阵与空间分布；不以多数类掩盖稀有类别失败。
- 地下水：水头、泉出流及动态响应；未观测的通道几何仅报告可行性。

不同模型对比属于交叉检查，不等于观测验证；共享同一公式的两个软件可能共享同一结构误差。

## 9. 参数、不确定性与随机世界覆盖

参数分为物理常量、观测／文献估计、校准参数及生成偏好。记录单位、范围、相关性和来源；物理相关参数不能全部独立随机。

首先进行单参数受控实验，再对关键不确定参数做组合采样，报告输出范围与敏感性。生成种子变化和模型参数不确定性分别统计，避免将地图多样性当成可信区间。

随机回归集分为固定开发集、保留种子集与每次发布的新增压力集。种子数量由运行成本和缺陷发现率确定，发布前冻结，不为通过检查删除失败种子。失败案例缩减为小型反例，永久进入回归集。

至少覆盖：海洋较多／陆地较多、大陆集中／分散、平缓／强起伏、偏冷／偏暖、弱／强季节性，以及这些偏好的合法组合。极端全海、全陆、无降水等可作受控测试；是否向用户开放由适用域决定，不必强行生成所有组合。

区分两种不确定性：对现实知识不足的参数／模型不确定性，以及种子代表的初始世界差异。多稳态、历史依赖和地貌滞后可以是模型性质，不自动判为软件错误。

report_id: 唯一标识

## 11. 对现有核心设计的补充与修正

1. 将“所有河流不得逆坡”限定为适用的地形路由近似；水力模型按水头／能量与边界判断。
2. 固定地图不等于所有过程稳态；保存时间语义与初始化／旋转预热过程。
3. 岩溶空洞、风沙、海岸、冰川等分别有物质或适用性要求，不能仅靠局部噪声获得“已模拟”标签。
4. 气候反馈按 C0/C1/C2 记录，不把阶段迭代自动等同完整耦合。
5. 构造事件是近似外部强迫；其地质年代和地幔收支声明必须与实际能力一致。
6. 为不同物理域设置独立量纲和误差预算，科学有效性与跨平台复现分开报告。
7. 世界成因查询返回模型状态与证据，文学标签不自动产生科学成因。

| S6 | 双平台与世界级发布检查 | G0～G5，版本化报告与已知限制 |

仍需确定：每个候选方程的最终版本、具体参数及适用域、网格和时间尺度、数值类型、误差阈值、校准／检验数据样本、岱崮／石林／天坑／竹林的专项定义与数据，以及 Windows/macOS 的硬件支持矩阵。

这些未决事项是后续研究和原型工作的清单，不妨碍规范记录完成，但阻止相关能力被提前宣布为已验证。
