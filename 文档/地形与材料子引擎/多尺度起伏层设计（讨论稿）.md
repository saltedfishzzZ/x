# 多尺度起伏层设计

> **文档状态**
>
> - 文档类型：分层设计
> - 决策状态：已确认
> - 实现状态：未实现

本文讨论地形与材料子引擎的 M4“多尺度起伏层”。M4 在 M3 长波基础表面上，使用正式 `ReliefAuthorization`、材料约束、方向结构和命名随机流，生成区域至地貌尺度的原生起伏。它负责形成可供 M5 分析的权威固体表面，但不提前把几何结果命名为河谷、峡谷、海岸或其他依赖后续过程的地貌。

关联：[地形与材料子引擎前置条件清单](地形与材料子引擎前置条件清单（讨论稿）.md) · [输入契约与垂直基底层设计](输入契约与垂直基底层设计（讨论稿）.md) · [材料背景层设计](材料背景层设计（讨论稿）.md) · [基础高程层设计](基础高程层设计（讨论稿）.md)。

## 一、M4 的职责与边界

### M4 负责

- 只读取 `PASS + RELEASED` 的 M3 正式发布和 `M4ReliefInputView`。
- 在 M3 授权空间、波长、方向、正负幅度和材料条件内生成 P2—P3 起伏。
- 在具备正式能力与局部细化授权时生成受限 P4 原生几何，并为局部三维保留连接。
- 用构造成因、材料结构和空间相关控制形态，不用一张通用无方向噪声代替全部地形。
- 为每项形态发生器保存稳定身份、物理谱系、尺度带、随机流和预算消耗。
- 输出 `reliefContributionField` 以及 `baseElevation + relief` 形成的原生固体高程。
- 使用 M3 的材料几何映射，在新的原生固体表面重新查询材料柱和出露候选。
- 向 M5 提供权威高程、支持尺度、误差、来源和形态发生器证据。

### M4 不负责

- 修改 M3 基础高程、授权预算或材料放置变换。
- 重新计算板块、构造边界、区域均衡或 P0—P1 长波骨架。
- 生成流水侵蚀、冰蚀、风蚀、海蚀、溶蚀或沉积形成的成熟地貌。
- 将低势线直接称为河谷，将陡坡直接称为山崖，或将负高程判定为海洋。
- 建立最终峰顶、山脊、谷线、鞍部和盆地拓扑对象；这些由 M5 从完整表面识别。
- 使用显示细分、纹理或镜头距离生成权威自然细节。
- 为了使用完授权预算而强制添加随机起伏。

## 二、正式输入与输出

### 2.1 正式输入

```text
BaseElevationRelease          # M3 PASS + RELEASED
M4ReliefInputView
TerrainRandomStreamManifest
MultiScaleReliefModelManifest
MultiScaleReliefParameterProfile
TerrainMaterialRunPlan
```

M4 不直接读取 M3 内部数组或未发布 M2 状态。材料、方向、来源和预算均通过 M3 受限视图及其引用获得。

### 2.2 拟议输出

```text
MultiScaleReliefSnapshot
├─ reliefContributionField
├─ primarySolidElevationField
├─ causalShapeGeneratorLedger
├─ directionAndScaleFields
├─ ReliefConsumptionLedger
├─ primaryMaterialColumnView
├─ surfaceExposureCandidates
├─ refinementPatchLineage
├─ conflictUncertaintyAndErrorFields
└─ sourceEvidenceGraph
```

`primarySolidElevationField` 是对 M3 基础高程的不可变派生结果，不覆盖 M3。`primaryMaterialColumnView` 使用相同 `MaterialPlacementTransform` 与新的固体表面求交；它仍只是原生背景材料出露候选，不包含后续风化、沉积或覆盖状态。

## 四、M4-D01：状态所有权与上下游边界

### 4.1 M4 拥有的权威状态

M4 拥有的是从 M3 授权派生的**原生起伏贡献**，以及加入该贡献后的**原生固体高程**：

```text
primarySolidElevation(x) =
    baseElevation_M3(x)
  + authorizedRelief_M4(x)
```

其中 `authorizedRelief_M4` 必须能够展开到一个或多个稳定形态发生器、授权标识和预算消耗。最终合成高程方便 M5 计算几何，但不能覆盖或伪装 M3 基础项。

每个形态发生器至少保存：

```text
generatorId
generatorKind
physicalLineageId
authorizationId / budgetAccountId
spatialEnvelope
allowedAndUsedWavelengthBands
directionStructure
amplitudeAndSignBudget
materialConstraintRefs
randomStreamKey
parentChildLineage
confidence / error / knowledgeState
```

发生器表示“哪一种受约束规则产生了这部分起伏”，不是 M5 已识别出的山峰、山脊或盆地对象。

### 4.2 M3 与 M4 的边界

| 内容 | M3 | M4 |
| --- | --- | --- |
| P0 行星长波骨架 | 拥有 | 不修改 |
| P1 大陆—洋盆和大型区域包络 | 拥有 | 不修改 |
| P2 构造广域包络、方向和预算 | 提供授权 | 在授权内解析区域形态 |
| P3 地貌尺度起伏 | 只提供剩余预算与约束 | 标准生成范围 |
| P4 局部原生细节 | 预留能力与材料几何 | 仅在正式细化能力和预算下生成 |
| P5 场景／可漫游细节 | 不拥有 | 首版不承诺；留给局部三维扩展 |

M4 不得移动 M3 的低频骨架。若 M4 需要一个非零 P0—P1 平均分量，它必须已经包含在 M3 广域响应或 `ReliefAuthorization` 明确授权的父级矩中。

### 4.3 M4 与 M5 的边界

M4 生成连续或分片连续的权威高程场和发生器证据；M5 从完整表面计算坡度、曲率、峰顶、洼地、鞍部、山脊、谷线和盆地拓扑。

因此：

- M4 可以使用“山系型发生器”“裂谷型发生器”等成因规则组织形态；
- M4 不宣告某个采样点已经是最终山峰、山巅、山岭、山谷或盆地对象；
- 发生器中心线不等于 M5 山脊线，负形中心线也不等于谷线；
- M5 的识别结果不能反向修改 M4 已发布起伏，只能作为回归证据或新版本输入。

这样可以避免算法设计时指定了一条中心线，系统便无条件把它当作真实山脊或河谷。

### 4.4 M4 与后续自然过程的边界

M4 只生成原生固体形态。以下结果需要后续过程证据：

- 河谷、峡谷、河曲、河滩、江洲和三角洲；
- 冲积平原、滩涂、海滩和海蚀崖；
- 风蚀石林、沙丘、戈壁铺面和成熟荒漠形态；
- 冰斗、冰蚀谷、冰碛和雪原；
- 溶洞、暗河、天坑及岩溶地下连通；
- 土壤、风化层、现代沉积物和植被覆盖。

M4 可以生成这些过程未来可利用的坡面、低势、材料接触和裂隙条件，但不能把资格升级成事实。

### 4.5 原生形态允许包含什么

不依赖后续气候与水文过程即可合理形成的原生形态可以进入 M4，例如：

- 受汇聚方向约束的区域山系起伏和峰群基础；
- 张裂轴、肩部、断块和地堑式原生高低组合；
- 压扭或张扭控制的斜列起伏；
- 材料与结构控制的丘陵、残余高地和局部洼地基础；
- 火山或撞击形态只有在未来上游提供正式成因能力与预算时才可启用，首版不凭随机圆形生成。

这里的名称描述发生器类型，不是最终地图地貌标签。是否形成可识别山峰、盆地或崖壁仍由 M5 几何分析决定。

### 4.6 原生固体表面与材料重新求交

M4 起伏会改变表面与地下材料界面的交点，因此不能直接复制 M3 的基础出露候选。M4 应：

1. 保持 M3 `MaterialPlacementTransform` 不变；
2. 使用 `primarySolidElevationField` 重新执行材料反向查询；
3. 输出新的 `primaryMaterialColumnView` 和出露候选；
4. 若表面超出材料有效包络，则限制发生器、保留未解析或阻断，不能填入默认材料；
5. 不根据新的出露结果反向迭代重算本轮 M4 起伏。

材料对形态的前置调节只能读取授权包中已经冻结的材料约束和允许查询，最终出露用于结果解释及 M5／后续过程消费。首版因此保持单向数据流，避免“形态改变出露—出露再改变形态”的隐式循环。

### 4.7 不允许的快捷方式

M4 不允许：

- 在整颗行星叠加同一套分形噪声后按高度着色；
- 沿板块边界复制等宽、等高的山墙或沟槽；
- 将 M3 包络中心线直接挤成一条山脊；
- 用随机圆锥代表山峰、随机凹坑代表盆地而无来源资格；
- 用材料类别标签直接设定固定粗糙度和固定高度；
- 在局部加载时重新抽样，导致退出再进入后地形改变；
- 把渲染法线、位移贴图或视觉细分写回权威高程。

| M4-R05 P2—P4 守界 | P2—P3 按授权生成，P4 仅在正式细化能力下生成，P5 不伪装实现 |

## 五、M4-D01 确认结论

M4-D01 已确认：M4 拥有从 M3 授权派生的 P2—P3 原生起伏、具备能力时的受限 P4 细节、发生器账本、预算消耗和组合后的原生固体高程；它不修改 M3 的 P0—P1 骨架。M4 的发生器是成因与生成证据，不是 M5 的峰、脊、谷、鞍或盆地对象，也不提前命名需要气候、水文和侵蚀证据的成熟地貌。M4 使用新表面重新查询材料出露，但不建立出露与本轮起伏之间的隐式反馈。

## 六、M4-D02：真实波长、尺度带与频谱预算

### 6.1 为什么不能用 LOD 代表自然尺度

网格 LOD 表示采样密度，地形尺度表示自然形态在真实空间中的波长或支持范围。两者有关，但不相等：

- 同一山系跨越多个 LOD，不能因放大而重新生成另一座山系；
- 相同 LOD 在不同纬度、面内位置和网格畸变下具有不同真实边长；
- 一个高 LOD 网格可以只承载平滑长波场，也可以在授权后承载短波细节；
- 显示细分可以远高于权威计算 LOD，但不会增加自然信息。

M4 因此以米为单位的球面弧长定义波长，以支持尺度和误差决定需要的 LOD。

### 6.2 P2—P4 的语义范围

首版先冻结尺度职责，不立即冻结数值边界：

| 尺度带 | 主要语义 | 典型输出 | 不能承担 |
| --- | --- | --- | --- |
| P2 区域尺度 | 将 M3 广域包络解析成区域级起伏组织 | 长山系分段、裂谷带段、断块群、区域高低组合 | 改写大陆—洋盆骨架 |
| P3 地貌尺度 | 形成可被 M5 识别的地貌级几何变化 | 峰群基础、支岭基础、丘陵群、局部洼地和斜列起伏 | 直接命名峰、谷、峡谷或河道 |
| P4 局部尺度 | 在正式细化区域补充受材料和结构约束的局部原生几何 | 坡面粗糙层级、局部岩体起伏、窄断块和崖壁几何候选 | 场景级碎石、纹理、植被或完整可漫游结构 |

具体 `λ_min`、`λ_max`、过渡宽度和最小采样数必须通过空间原型、固定夹具和目标机器性能共同标定，并进入版本化 `ScaleBandProfile`。不能把尚未验证的公里数写成永久架构事实。

### 6.3 尺度带描述符

每个尺度带至少声明：

```text
ScaleBandDescriptor
├─ bandId / semanticLevel
├─ minWavelengthMeters
├─ maxWavelengthMeters
├─ lowerAndUpperTransitionWidth
├─ minimumSamplesPerWavelength
├─ supportRadiusMeters
├─ allowedGeneratorKinds
├─ meanAndMomentPolicy
├─ amplitudeVarianceSlopeCurvatureBudgets
├─ aggregationRule
├─ randomNamespace
└─ calibrationAndErrorRefs
```

波长使用球面真实弧长；具有方向性的形态还分别保存沿主方向和横向的相关长度。`supportRadiusMeters` 用于计算补丁边缘所需的邻域，不等同于波长本身。

### 6.4 M3—M4 的尺度交接

M3 与 M4 在 P2 附近存在职责交接，但不能使用一道硬切频率。M3 的低频响应与 M4 的较高频解析通过一对版本化平滑窗连接：

```text
W_M3(λ) + W_M4(λ) = 1     # 交接区内，在约定容差下
```

- M3 仍拥有交接区的广域均值、方向和总预算；
- M4 只使用 `ReliefAuthorization` 分配的互补份额；
- 两个窗共享同一物理谱系和预算账户；
- 交接区不能出现能量缺口、重复增强或环状波纹；
- 改变交接窗属于模型版本变化，不是显示设置。

这里的“频谱”是尺度分解语义，不强制实现必须使用全球球谐变换。球面小波、局部带限基、方向核或其他通过验证的方法都可以实现同一契约。

### 6.5 平滑重叠窗与尺度闭合

P2、P3、P4 相邻尺度带采用平滑重叠窗，而不是互不相交的硬区间。对于一个多尺度发生器：

```text
Σ W_band(λ) = 1
```

在其授权波长范围内应近似成立。这样做可以避免：

- 硬切波长造成的振铃和周期条纹；
- 同一形态在两个尺度带各生成一次；
- 局部细化启用 P4 时突然改变 P3 外观；
- 聚合后出现缺失频段或异常能量峰。

同一发生器跨带时保留一个 `generatorId` 和父子尺度谱系，各带只是它的带限分量，不能被当作三个独立成因来源。

### 6.6 预算不是单一“最大高度”

每个授权尺度带分别管理：

```text
meanBudget                 父级允许的平均偏移
positiveAmplitudeEnvelope 正向幅度范围
negativeAmplitudeEnvelope 负向幅度范围
reliefVarianceBudget       起伏离散程度
slopeBudget                坡度贡献范围
curvatureBudget            曲率与尖锐度范围
spectralPowerEnvelope      各波长允许的相对强度
```

这些预算是数值授权和验收约束，不宣称等同于真实机械能。只限制峰值高度是不够的：高频小振幅仍可能制造不合理陡坡或锯齿，因此坡度、曲率和尺度功率必须共同受控。

预算之间不是简单互换。未使用的 P2 幅度不能自动转移到 P4，未使用的正向预算也不能直接变成负向凹坑。跨尺度或正负转移只有授权包明确给出规则时才允许。

### 6.7 父级均值与低频泄漏

默认规则为：

- P2 可以使用 M3 明确授权的非零父级均值和低阶矩；
- P3、P4 在各自父支持域内默认满足零均值或指定矩约束；
- 任何非零低频分量都必须来自 M3 授权，不能由随机场偶然积累；
- 局部补丁启用更短波长后，聚合回父级不得移动原有均值与主要梯度；
- 低频泄漏按物理波长和面积加权矩检测，不以视觉上“看不出来”为通过依据。

零均值约束不要求每个小单元正负完全对称，而要求在声明的支持域和误差范围内闭合。成对构造形态仍按其授权的正负比例执行。

### 6.8 采样资格与抗混叠

每个尺度带只有在当前网格满足 `minimumSamplesPerWavelength`、方向采样和误差要求时才能生成。最低条件不是简单的理论两点采样，因为方向性山系、尖锐界面和后续坡度计算需要更高裕度。

如果分辨率不足：

- 保存该带的预算和未解析状态；
- 可以输出满足聚合契约的低阶摘要；
- 不把短波内容折叠成伪长波起伏；
- 不通过增加显示顶点伪装已经解析；
- 可向 L1 协调器请求细化，但资源不足时仍保持未解析。

从细尺度向粗尺度聚合前必须使用与尺度描述符匹配的带限过滤，避免高频混叠改变父级均值、方向和坡度统计。

### 6.9 跨尺度相关性

真实山地的不同尺度通常相关：大山系决定支岭大致方向，支岭又限制更小起伏的位置。M4 不应为每个尺度带抽取完全独立的噪声。

建议使用层级发生器：

```text
P2 parent generator
├─ P3 child generators conditioned on parent direction/envelope
│  └─ optional P4 detail conditioned on P3 material and structure
└─ shared physicalLineageId and hierarchical random keys
```

子级使用独立但可追溯的命名随机流，在父级包络、方向、预算和边界条件内采样。增加 P4 不得移动既有 P2/P3 发生器；调整一个子发生器也不得改变无关区域。

### 6.10 各向异性尺度

山系、裂谷和断块常具有长轴与短轴，因此不能只保存一个各向同性波长。每项方向性发生器至少声明：

```text
parallelCorrelationLength
normalCorrelationLength
verticalAmplitudeScale
orientationDispersion
endpointTransitionLength
```

这些量使用球面切向方向和真实距离。长轴、横向宽度和端部衰减分别受预算控制，避免沿来源中心线生成无限长、等宽、等高条带。

### 6.11 局部 P4 的启用条件

P4 不是放大到某一级就自动开启。必须同时满足：

- M3 授权包含 P4 波长和预算；
- 当前计算网格达到采样要求；
- 材料与结构覆盖足以约束局部形态；
- 补丁具有完整支持边缘和父级摘要；
- 相邻补丁使用兼容尺度描述符和随机流；
- 运行计划允许该区域生成，但运行计划不改变自然结果。

缺少任一条件时，P4 保持 `UNRESOLVED` 或 `NOT_GENERATED`，界面可继续平滑显示 P3 表面，但不能声称局部自然细节已经存在。

## 九、M4-D03：构造成因与形态发生器

### 9.1 发生器的含义

形态发生器是一个有来源、有方向、有尺度和有预算的高程贡献规则：

```text
ShapeGenerator
├─ generatorId / generatorKind
├─ authorizationId / physicalLineageId
├─ controlGeometry
├─ signedResponseComponents
├─ scaleBandAllocation
├─ directionAndAsymmetry
├─ segmentationAndEndpointRules
├─ materialConstraintSlots
├─ randomParameterRefs
├─ budgetConsumption
└─ confidenceAndError
```

它不是一枚固定模板，也不是一个已经识别完成的地貌对象。发生器的控制线不等于山脊或谷线，控制面不等于盆地边界，形态中心不等于峰顶。M5 必须从所有发生器组合后的完整高程场中独立识别几何对象。

### 9.2 发生器的基本几何族

M4 首版使用少量可组合、可验证的几何族，而不是为每个景观名称写一个生成器：

| 几何族 | 控制几何 | 适用形态 |
| --- | --- | --- |
| `BELT` 带状发生器 | 球面曲线、沿线坐标和有符号横向距离 | 山系型起伏、裂谷轴肩、压扭斜列结构 |
| `BLOCK` 块状发生器 | 球面区域、边界侧别和块体局部基 | 断块、阶梯式高低组合、局部倾斜块体 |
| `PATCH` 区域发生器 | 有限球面区域和内部方向场 | 丘陵群、峰群基础、局部高低起伏 |
| `PAIRED` 成对发生器 | 共享来源的正负控制几何 | 裂谷轴部—肩部、压扭／张扭成对响应 |
| `JUNCTION` 联合发生器 | 多分支端部和联合邻域 | 三重点及复杂边界交会区 |
| `DOMAIN` 背景发生器 | 连续材料／结构域 | 稳定区低幅起伏和继承性方向变化 |

每个构造成因可以组合多个几何族。例如大陆张裂由 `BELT + PAIRED + BLOCK` 共同表达，而不是只压出一条负槽。

### 9.3 带状发生器的球面表达

对球面控制曲线定义沿线弧长 `s` 和有符号横向距离 `d`：

```text
Δh(s,d) = A(s) × P(d / W(s), asymmetry(s)) × E(s)
```

- `A(s)` 是沿线有界振幅；
- `W(s)` 是随位置变化的横向宽度；
- `P` 是可非对称、多峰或成对的横向剖面；
- `E(s)` 处理端部、分段衔接和真实缺口。

曲线、距离和方向都使用球面几何。相邻兼容分段在端部连续衔接；真实转换、低活动缺口、三重点和未解析区可以形成有证据的中断。禁止让每个数据库分段两端机械归零，从而在长山带中制造周期缺口。

### 9.4 大陆碰撞与缩短带

碰撞／缩短授权优先生成多层级 `BELT` 与受限 `PATCH`：

- P2 组织一条或多条宽缓、可弯曲且可分段的区域起伏带；
- P3 在父带内生成相互关联的次级高地、峰群基础和支状起伏；
- 横向剖面可以近对称，也可以根据壳体、方向和授权表现不对称；
- 沿线振幅、宽度和方向缓慢变化，避免等宽等高山墙；
- 允许相邻带错列、并合或分叉，但必须保持统一来源预算和稳定谱系；
- 带间低处只是几何低势，不自动成为山谷或河道。

M4 不模拟完整褶皱冲断历史，也不直接声明某个起伏是褶皱山、山峰或高原；它生成与缩短、增厚和方向约束一致的原生形态基础。

### 9.5 俯冲型边缘

俯冲授权继承 M3 的极性、上覆侧、下沉侧和弧侧包络。M4 可以生成：

- 下沉侧负起伏的分段、宽度变化和局部连续性；
- 上覆侧受压缩控制的正起伏带；
- 前侧、弧侧或后侧的相对位置约束与有界高低组合；
- 斜向俯冲下沿边界与横向方向不同的相关结构。

如果极性未知，不能随机决定哪一侧出现非对称结构。若没有正式火山过程能力，弧侧资格只能约束位置和预算，不能自动生成规则火山锥、火山链或岛弧标签。负起伏也不能直接命名为海沟，海水覆盖仍需后续求解。

### 9.6 大陆张裂与过渡张裂

大陆张裂采用共享预算的 `PAIRED` 结构：

- 轴部负起伏；
- 两侧宽度和高度可不同的正肩部；
- 受方向和材料约束的 `BLOCK` 断块群；
- 沿轴分段、错列、转接和局部消失；
- P3 子发生器沿父级张裂方向相关，而不是在轴内铺一层各向同性噪声。

轴部与肩部不能分别按完整预算生成。块体倾斜与错移必须具有上游断层／结构资格，不能用随机棋盘高低块代替伸展构造。轴部低势由 M5 判断是否形成连续洼地或盆地，不能在 M4 直接命名为裂谷湖盆。

过渡张裂在大陆张裂和洋壳扩张形态之间连续变化，不因壳体分类阈值突然更换模板。

### 9.7 洋壳扩张轴

洋壳扩张发生器只消费 M3 已排除远场热成熟重复后的轴部授权：

- 形成宽度有限、沿轴分段的正负组合和方向结构；
- 与 M3 远场成熟基底连续衔接；
- 转换段和错列扩张段保持拓扑来源，不生成贯穿转换段的连续山墙；
- 无更新源或扩张资格时不使用随机线条制造洋中脊。

该发生器生成原生扩张轴形态，不宣告最终洋中脊、裂谷谷地或热液地貌对象。

### 9.8 走滑、压扭与张扭

近纯走滑主要提供排列方向和局部化条件，垂向预算应很低或为零。只有存在正式压扭、张扭、弯折或阶区资格时，才启用有符号发生器：

- 压扭可形成与主剪切带斜交或雁列的正起伏；
- 张扭可形成斜列负起伏和受限边缘正响应；
- 发生器共享原汇聚或离散预算，不创建新的垂向能量账户；
- 单一走滑线不得被压成连续山脊或沟槽；
- 阶区几何不足时保持方向资格和未解析状态，不随机猜测拉分或挤压区。

M4 只表达原生高低组合。是否形成拉分盆地、断层山或具体陡崖由 M5 几何和后续证据判断。

### 9.9 三重点与多边界交会

三重点使用 `JUNCTION` 发生器协调各分支端部：

- 每个分支先保留自身发生器和预算；
- 联合区调整端部方向、宽度和衔接，但不增加第四份来源预算；
- 多方向结构可以共存，不能强迫产生单一放射主轴；
- 不把三条带的峰值叠加成点状高峰或深坑；
- 闭合失败、极性未知或分支过短时扩大未解析区和误差。

相邻但不属于同一三重点的独立来源不强行并入 `JUNCTION`，其重叠留给 M4-D06 组合。

### 9.10 断块与继承结构

`BLOCK` 发生器必须由 M3 授权和 M2/M3 已发布的断层接触、损伤带或结构方向支持。它可以表达：

- 块体的有界平移、倾斜和宽缓内部起伏；
- 相邻块体的相对高低与阶梯关系；
- 断层附近的局部化宽度和不确定带；
- 父块到子块的细化谱系。

缺少可靠错移量时，使用范围和未知状态，不能为视觉效果任意赋予精确断距。块体边界是发生器边界，不自动等于最终陡崖线；材料映射仍由 M3 `MaterialPlacementTransform` 提供，M4 不另造地下断层几何。

### 9.11 稳定区与弱构造区

稳定区并非完全平坦，但其起伏必须来自 M3 明确授权的剩余预算、继承结构和材料非均质性。建议使用低振幅 `DOMAIN + PATCH`：

- 相关长度大于无结构白噪声，方向可弱或继承背景组构；
- P2/P3 平均和方差严格受控，不因“稳定核心”身份自动抬高；
- 可以形成丘陵群、低高地和局部洼地的几何基础；
- 不直接生成成熟侵蚀残丘、岱崮、石林或风蚀地貌；
- 没有剩余预算时允许保持平缓，不为丰富度强行造景。

### 9.12 暂不具备来源的发生器

火山锥、熔岩台地、撞击坑、盐构造、冰川形态和大型滑坡需要各自的正式来源能力、参数和验收。首版如果上游没有对应能力，它们保持 `NOT_APPLICABLE`，不能通过随机圆形、放射线或纹理伪装实现。

未来新增这些发生器时，应作为新的 `generatorKind`、授权能力和模型版本接入，不改变旧世界结果。

### 9.13 候选建立流程

每类发生器遵循：

```text
1. 读取 ReliefAuthorization 与适用能力
2. 建立可用空间包络和方向基
3. 生成稳定候选身份与父子谱系
4. 在授权范围内选择分段、宽度、非对称和子结构参数
5. 求值各尺度带的有符号贡献
6. 记录预算请求、误差和未解析部分
7. 交给 M4-D06 统一组合与预算结算
```

候选数量不是景观配额。某个世界可以没有强碰撞山系、活动张裂或明显走滑垂向形态。

## 十一、M4-D03 确认结论

M4-D03 已确认：以 `BELT`、`BLOCK`、`PATCH`、`PAIRED`、`JUNCTION` 和 `DOMAIN` 六类基础几何族组合构造成因形态。碰撞、俯冲、张裂、扩张、走滑混合、三重点、断块和稳定区分别使用符合其方向、侧别、成对关系和预算来源的发生器；控制几何不等于最终地貌对象。火山、撞击、冰川等缺少正式上游能力的形态不生成。所有候选保留授权、谱系、尺度和预算，具体随机参数留给 M4-D04，统一组合留给 M4-D06。

## 十二、M4-D04：随机流、空间相关与确定性形态变化

### 12.1 随机性的职责

随机性只在已经满足自然资格、已经获得 M3 授权的发生器内部选择具体实现，例如：

- 一条山系带沿线宽度和振幅如何缓慢变化；
- 次级起伏在父包络中的位置、间距和相对强弱；
- 张裂段如何错列、哪些合格子段解析为断块；
- 稳定区允许的低幅起伏采用哪一种空间 realization；
- 相同因果条件下，世界种子如何产生不同但仍合理的几何。

随机性不能：

- 创造不存在的汇聚、张裂、断层、火山或材料条件；
- 把缺失、未知和未生成状态补成看似完整的地形；
- 决定海陆、水体、气候或成熟过程地貌；
- 绕过发生器预算、尺度、方向和材料约束；
- 因线程、瓦片、浏览顺序或重试而改变世界。

### 12.2 随机用途分层

每个发生器把随机用途分开：

| 随机用途 | 示例 | 稳定性要求 |
| --- | --- | --- |
| `TOPOLOGY_CHOICE` | 合格分支是否出现、父子发生器数量 | 发生器身份确定后不因采样 LOD 改变 |
| `PARAMETER_CHOICE` | 宽度、非对称、间距、端部长度 | 参数增加时不移动既有样本序列 |
| `PHASE_CHOICE` | 带限基函数相位和局部空间排列 | 跨补丁、跨面和重算一致 |
| `RESIDUAL_FIELD` | 预算内相关残差 | 保持零均值／父级矩和频谱包络 |
| `REFINEMENT_SPLIT` | 父发生器细化为哪些子发生器 | 只依赖稳定父标识、尺度带和子索引 |

各用途具有独立随机流。增加一种坡面属性不能移动山系分段的随机序列，增加 P4 也不能重新抽取 P2/P3 参数。

### 12.3 命名随机键

所有随机样本继承 M1 的无状态命名随机流：

```text
RandomKey = hash(
    worldSeed,
    randomModelVersion,
    "M4",
    generatorId,
    physicalLineageId,
    scaleBandId,
    samplePurpose,
    stableSampleIndex,
    relevantParameterFingerprint
)
```

运行计划、线程、瓦片编号、内存地址、缓存键、相机、显示 LOD 和请求时间不得进入随机键。空间采样需要稳定的球面位置或发生器局部坐标标识，不能使用临时数组下标。

`relevantParameterFingerprint` 只包含真正改变该随机分布的自然参数。无关设置变化不应导致整条随机序列雪崩式改变。

### 12.4 参数随机与空间随机场分离

“发生器有多宽”与“宽度沿线如何变化”是两类状态：

- 参数随机从有界、版本化分布中选择全局或分段参数；
- 空间随机场生成连续、相关的局部变化；
- 参数值进入发生器快照，空间场由稳定键和模型重建；
- 两者分别记录来源、范围、实现值和截断状态。

禁止在每个网格单元独立抽取高度。那会产生白噪声、网格印迹，并在提高 LOD 时改变形态。

### 12.5 球面相关场

空间变化定义在权威球面几何或发生器自身坐标中：

- `DOMAIN/PATCH` 使用球面距离、三维单位向量或通过验证的球面带限基；
- `BELT/PAIRED` 优先在沿线弧长 `s` 与横向距离 `d` 中生成相关场；
- `BLOCK` 在块体局部基和边界距离中生成内部变化；
- `JUNCTION` 在联合邻域中协调各分支相关场。

不得直接在经纬度平面生成后包回球体，也不得让六个立方体面分别生成独立噪声。跨面和极区必须保持值、相关长度及方向统计连续。

### 12.6 各向异性与非平稳性

形态变化通常随方向和位置改变。每个相关场可以声明：

```text
parallelCorrelationLength
normalCorrelationLength
orientationFieldRef
localVarianceEnvelope
localSpectralSlope
nonstationarityDrivers
```

- 山系沿主轴的相关距离通常可大于横向距离；
- 裂谷断块可沿轴分段、横向快速变化；
- 稳定区可使用弱各向异性或近各向同性场；
- 端部、三重点、材料边界和方向转折可以缓慢改变方差与相关长度；
- 非平稳调制来自正式包络和参数，不能用任意手绘遮罩。

随机场仍必须受发生器空间包络限制；相关核不能越过无授权区域传播完整振幅。

### 12.7 带限频谱与分布形状

每个随机场绑定 M4-D02 的尺度带和频谱功率包络，只在授权波长内含有显著功率。实现可以采用球面小波、稀疏带限基、方向核卷积或其他验证方法，但必须记录：

```text
basisOrKernelVersion
frequencyWindowRef
coefficientDistribution
phaseRule
normalizationRule
tailAndExtremePolicy
```

高斯分布不是强制要求。偏态、重尾或截断分布可以表达不对称形态，但极值策略必须版本化并满足幅度、坡度和曲率预算。禁止生成后按当前世界极值整体归一化，因为远处新增一个极值会改变已有区域。

### 12.8 跨尺度相位与父子继承

P2、P3、P4 既不能完全相同，也不能完全独立。建议：

- P2 决定父发生器的大致走向、分段和方差包络；
- P3 使用独立子流，但其候选概率、方向和强度受 P2 条件约束；
- P4 使用 P3 的局部材料、方向和未使用预算，并保持独立子流；
- 子尺度启用后不改变父尺度系数；
- 父发生器删除或失效时，其子流通过谱系一起失效；
- 跨尺度窗重叠区使用共享相位约束或正交残差，防止重复波峰和破坏性抵消。

这种关系产生相关的层级形态，同时保证局部细化不会重绘整个区域。

### 12.9 父级矩与预算归一

随机场生成后只能在预先声明的支持域和尺度带内执行预算匹配：

- 移除未授权的均值和低阶趋势；
- 调整到授权方差或功率包络，但不能按世界极值缩放；
- 同时检查正负幅度、坡度和曲率；
- 超出预算时优先通过有界参数求解或拒绝 realization；
- 若必须裁剪，保留裁剪位置、幅度和对频谱的影响。

不能先生成任意噪声，再用一次全局最小—最大归一化把它“塞进”预算。预算匹配算法本身必须是确定且版本化的。

### 12.10 局部补丁与边界一致

局部区域生成不能以补丁左上角作为随机原点。建议随机场由全局可寻址基函数、稳定球面格址或发生器局部坐标重建：

- 相邻补丁在重叠区查询同一系数；
- 补丁范围改变不改变已有核心结果；
- 核函数支持范围决定必要 halo；
- 范围外未生成系数可按稳定键按需求值，不要求先生成全球高分辨率场；
- 补丁拼接不使用任意淡入淡出掩盖随机场不一致。

如果边界支持不完整，缩小可发布核心或保持未解析，而不是用新随机值填边。

### 12.11 自然变异与知识不确定性分离

同一个 `WorldId` 对应一份固定自然 realization。模型不知道某处断块落差，并不意味着每次查询都重新随机一个落差。

- **自然变异**由世界种子和命名随机流确定，属于世界状态；
- **输入不确定性**来自上游误差和知识缺口；
- **模型不确定性**来自近似公式和未校准范围；
- **数值误差**来自采样、截断和归约。

不确定性通过范围、分布摘要或候选状态表达，不用运行时随机抖动权威高程。若未来需要不确定性集合模拟，每个 ensemble 成员必须具有单独身份，不能覆盖标准世界。

### 12.12 防止伪周期与模板重复

发生器需要检测：

- 沿线等间距重复峰谷；
- 固定方向条纹和经纬网格印迹；
- 立方体面大小对应的周期；
- 相同模板在不同发生器上仅旋转或缩放复用；
- 补丁尺寸对应的环带与方块边界；
- 多个尺度带在固定倍频上异常同步。

避免重复不意味着取消确定性。应通过多尺度稳定基、参数分布和来源条件增加形态空间，并用自相关、功率谱、方向统计和变形测试识别伪模式。

### 12.13 数值确定性与跨平台

同一规范输入必须在声明的 Windows/macOS 数值策略下产生稳定结果。实现阶段需在以下方案中选择并基准验证：

- 计数器式整数哈希后进行规定的浮点映射；
- 固定系数顺序和稳定归约；
- 对关键分支使用量化判定或容差迟滞；
- 保存规范摘要，对允许的浮点差异规定不会改变的分类和预算边界。

具体算法尚未冻结，但随机核心、分布映射、基函数、归一和数值策略都必须进入模型版本。

### 12.14 建议输出

```text
ReliefRandomFieldView
├─ randomStreamManifestRefs
├─ generatorParameterRealizations
├─ bandLimitedSpatialFieldDescriptors
├─ crossScalePhaseAndLineage
├─ correlationAndAnisotropyFields
├─ momentAndBudgetAdjustmentLedger
├─ clippingAndRejectedRealizations
├─ periodicityAndArtifactDiagnostics
└─ determinismEvidenceRefs
```

## 十四、M4-D04 确认结论

M4-D04 已确认：随机性只在已授权发生器内部选择具体形态，按拓扑、参数、相位、残差和细化用途隔离无状态命名流。空间变化使用球面、带限、可各向异性且可非平稳的相关场；P2—P4 通过父子条件和独立子流保持相关但不互相重抽。预算匹配不依赖世界极值，补丁从全局可寻址系数重建。自然变异与知识、模型和数值不确定性分别表达，并通过周期诊断、跨平台摘要和缓存重建验证确定性。

## 十五、M4-D05：材料与结构对起伏的有界调节

### 15.1 材料不是地貌标签

M4 使用材料连续物性、层序、接触和结构方向调节已经获得授权的形态发生器，但不采用“某种岩石对应某种固定地貌”的规则。

以下推断不成立：

```text
硬岩 → 必然高山
软岩 → 必然低谷
石灰岩 → 必然天坑或溶洞
水平层理 → 必然岱崮或台地
裂隙密集 → 必然峡谷或暗河
```

这些地貌通常还需要暴露时间、风化、流水、地下水、侵蚀、搬运和沉积等过程。M4 只形成原生几何条件和材料控制的响应差异。

### 15.2 正式材料输入

M4 只能读取 M3 `M4ReliefInputView` 中冻结的材料约束：

```text
ReliefMaterialConstraint
├─ materialDomainRefs
├─ effectiveStrengthAndStiffness
├─ densitySupportRef
├─ beddingFoliationAndLineation
├─ fractureAndDamageZoneSummaries
├─ contactAndContrastSummaries
├─ heterogeneityAndMixtureState
├─ validDepthAndScaleRange
├─ confidenceAndError
└─ allowedModifierTargets
```

其中密度对长波浮力的主要贡献已经由 M3-D02 处理。M4 只读取 M3 明确授权的剩余支撑或局部响应修饰，不能再次把整柱密度异常加入高程。

M4 不直接读取未放置的 M2 内部数组，也不以本轮最终出露结果反向修改发生器。正式材料约束必须在 M3 授权时冻结，从而保持单向依赖。

### 15.3 材料可以调节的量

材料修饰器只能作用于指定发生器和尺度带：

```text
MaterialReliefModifier
├─ targetGeneratorId / targetComponent
├─ amplitudeFactorRange
├─ parallelAndNormalScaleFactors
├─ localizationFactor
├─ orientationTensorContribution
├─ slopeAndCurvatureLimits
├─ blockOrSegmentEligibility
├─ unresolvedFraction
└─ sourceConfidenceAndError
```

允许调节：

- 起伏响应在空间上更集中还是更分散；
- 沿结构方向和横向的相关长度；
- 授权范围内的振幅分配和局部方差；
- 断块、分段或子发生器更适合在哪里解析；
- 坡度和曲率预算的局部分配；
- P3/P4 中哪些材料控制细节能够被当前尺度解析。

默认不允许材料修饰反转构造贡献符号，也不允许材料单独创建新发生器或增加来源总预算。

### 15.4 强度与刚度的解释边界

强度和刚度影响材料如何承受或集中形变，但与最终高低没有简单单调关系：

- 较强材料可能允许较集中的原生坡度，也可能把形变转移到邻近弱带；
- 较弱材料可能产生较宽缓分布，也可能在断层资格下集中变形；
- 相同材料在碰撞、张裂和稳定区中的修饰方向可以不同；
- 缺少完整流变和时间模型时，只使用版本化、有界响应代理；
- “更坚硬”不能直接转换为固定正高程，“更软弱”不能直接转换为固定负高程。

每个修饰关系必须绑定发生器种类和响应分量，不能使用一个全局 `hardnessToHeight` 函数。

### 15.5 层理、片理与线理方向

M2/M3 提供的结构方向以球面三维向量和张量表达。M4 将构造方向与材料结构方向组合为目标发生器的方向约束：

- 两者一致时可以提高方向相干性或局部化程度；
- 斜交时保留双方向或形成有界偏转，不强制平均成一条轴；
- 近正交且强度相当时提高方向冲突和未解析程度；
- 强构造授权不能被低置信材料方向任意旋转；
- 多组层理、片理和裂隙不能压成单一平均角度；
- 方向组合使用张量或等价轴向统计，并保持 `n` 与 `-n` 的平面等价性。

层理方向可以影响原生坡面与局部起伏的取向，但不直接生成单面山、台地、岱崮或层状崖壁名称。

### 15.6 裂隙、断层损伤带和接触

裂隙与损伤带可以：

- 提高授权发生器的局部化资格；
- 调整 P4 可解析方向和相关长度；
- 为 `BLOCK` 边界和分段提供证据；
- 扩大几何误差或多解范围。

它们不能单独证明存在活动断层、河道、地下水通道、溶洞或崖壁。

材料接触按语义处理：

| 接触类型 | M4 处理原则 |
| --- | --- |
| 渐变接触 | 修饰器连续过渡，不产生高程台阶 |
| 清晰接触 | 允许响应参数变化，但不自动形成断崖 |
| 断层接触 | 只有授权错移／断块能力时允许几何不连续 |
| 侵入接触 | 保留独立材料和方向影响，不自动生成环形山体 |
| 混杂带 | 使用混合属性和未解析份额，不强制单一结构方向 |
| 不整合代理 | 保留层序截切影响，不推断具体侵蚀历史 |

### 15.7 材料对不同发生器的作用

| 发生器 | 合理调节 | 不允许的快捷规则 |
| --- | --- | --- |
| 碰撞 `BELT/PATCH` | 横向宽度、局部化、支状方向、坡度上限 | 强岩直接抬高为峰 |
| 俯冲边缘 | 上覆侧起伏宽度、结构偏转、分段相干性 | 岩性标签决定火山链 |
| 张裂 `PAIRED/BLOCK` | 断块资格、轴肩宽度、块体倾斜范围 | 软材料自动成为裂谷轴 |
| 走滑混合 | 阶区局部化、雁列方向、误差范围 | 裂隙密集自动生成槽谷 |
| 稳定区 `DOMAIN/PATCH` | 低幅方差、相关长度、弱方向性 | 材料随机纹理直接变高程 |

修饰必须保持发生器原有物理谱系和预算账户。

### 15.8 多材料混合和尺度有效化

一个网格或发生器支持域可能包含多种材料、薄层和未解析比例。M4 不能只取“占比最大岩性”。应根据目标属性和尺度使用 M2 已确认的有效化结果：

- 强度和刚度使用适合结构与混合方式的有效响应范围；
- 方向性保留多峰张量和离散度；
- 断块资格读取接触与损伤带拓扑，而不是面积平均；
- 坡度／曲率修饰同时考虑材料异质性与支持尺度；
- 未解析薄层保留其比例和影响范围，不能静默删除。

P4 只有在材料支持尺度足够时才能使用细材料差异。粗材料摘要不能被放大成精确局部岩性边界。

### 15.9 多修饰器组合

多个材料属性可能来自同一材料证据链。组合时：

1. 先按 `materialDomainId`、属性谱系和目标发生器归组；
2. 在物性联合分布中计算一个目标修饰结果；
3. 再与独立材料域或独立结构证据有界组合；
4. 检查振幅、尺度、坡度、曲率和方向预算；
5. 保留冲突、未解析份额和各项来源。

禁止把强度、刚度、密度和岩性资格作为独立倍率连续相乘，导致指数式放大或衰减。相关属性必须保留联合不确定性。

### 15.10 修饰函数的边界

材料修饰函数应围绕中性值有界，例如概念上：

```text
amplitude' = amplitude × boundedModifier
scale'     = scale × boundedScaleModifier
direction' = combineTensors(tectonicDirection, materialDirections)
```

具体函数和数值留待标定，但必须满足：

- 输入连续变化产生连续响应，明确断层除外；
- 低置信不自动等于中性值，而是扩大结果范围或保持未解析；
- 合法中性值、未知、不适用和缺失分别表达；
- 修饰后仍满足 M3 授权和 M4-D02 各类预算；
- 不按当前世界材料极值重新归一化；
- 不以输出高程反推材料参数。

### 15.11 最终表面材料查询

发生器组合完成后，M4 使用 `primarySolidElevationField` 对 M3 `MaterialPlacementTransform` 执行反向查询，生成：

```text

surfaceExposureCandidates
multipleIntersectionState
materialCoverageError
```

这一结果用于 M5 几何解释和后续自然过程。若某处超出材料有效包络、出现无法解析多交点或与授权约束冲突：

- 标记失败、未知或请求合法细化；
- 不使用默认岩石填充；
- 不回到本轮 D05 重新改变发生器；
- 新模型需要耦合迭代时必须创建新版本和显式收敛契约。

## 十七、M4-D05 确认结论

M4-D05 已确认：材料连续物性、层序、接触和结构方向只对已授权发生器作目标明确的有界修饰，调节局部化、相关长度、方向、幅度分配、坡度和曲率，但不创造来源、增加总预算或默认反转符号。密度浮力不重复 M3；多材料按尺度和属性有效化，相关物性不作为倍率链连乘。最终原生表面重新查询材料出露，但不反馈到同一快照。坚硬、软弱、可溶、层状或裂隙材料均不能直接等同于某种成熟地貌。

## 十八、M4-D06：发生器组合、预算结算与局部细化

### 18.1 组合目标

M4-D03 至 D05 会产生多个具有不同来源、尺度、符号、方向和材料修饰的发生器。D06 负责把它们组合成唯一的 `reliefContributionField`，完成 M3 授权预算结算，并生成可供 M5 使用的 `primarySolidElevationField`。

组合必须同时避免：

- 同一物理来源经多个发生器重复消耗预算；
- 先运行的线程或补丁抢走共享额度；
- 多个合法发生器线性叠加出异常尖峰、陡坡或高频锯齿；
- 正负贡献抵消后丢失强过程竞争证据；
- 细化重新生成父级形态或改变相邻区域；
- 用逐点裁剪制造平顶、断边和新的伪频率。

### 18.2 发生器关系类型

每对存在交互的发生器必须具有明确关系：

| 关系 | 含义 | 处理方式 |
| --- | --- | --- |
| `SAME_LINEAGE` | 同一物理来源的不同几何／尺度表达 | 共享预算并按谱系联合求解 |
| `PARENT_CHILD` | 父发生器与细尺度子发生器 | 子级只用父级保留的尺度和预算 |
| `PAIRED` | 同一来源的正负或轴肩成对结构 | 保持联合参数和共同预算 |
| `EXCLUSIVE` | 互斥的形态解释候选 | 确定性选择或保留未决，不同时提交满额结果 |
| `COMPATIBLE_INDEPENDENT` | 不同物理来源且可以共存 | 在共享局部约束下有界组合 |
| `COMPETING` | 可共存但方向、空间或预算强冲突 | 保留分项、冲突和有界净结果 |
| `MODIFIES` | 一个状态只修饰目标发生器 | 不作为独立高程相加 |
| `DISJOINT` | 空间或尺度无交互 | 独立求值和结算 |

关系图必须引用闭合且无非法循环。相邻不等于同源，标识不同也不等于独立。

### 18.3 确定性预算事务

预算结算采用“登记—联合分配—提交”三阶段：

```text
1. REGISTER
   收集全部候选请求，不消耗正式预算

2. ALLOCATE
   按 authorizationId、budgetAccountId、尺度带和关系图
   使用版本化规则联合分配

3. COMMIT
   生成不可变消耗账本、拒绝／未解析份额和结果摘要
```

不能采用“哪个发生器先执行，哪个先扣预算”的方式。并行实现可以不同，但规范分配结果必须等价于对完整候选集合执行一次确定性求解。

每个预算账户至少记录：

```text
authorized
requested
allocated
consumed
releasedUnused
unresolved
rejected
clipped
remaining
```

所有量按尺度带、正负符号和需要的均值／方差／坡度／曲率维度分别保存。预算不是单一米值。

### 18.4 预算分配原则

候选总请求超过授权时，不按生成顺序裁掉后来的候选。建议使用版本化权重和约束求解：

- P0/P1 守界和父级矩属于硬约束；
- 成对响应和同源谱系先满足内部一致性；
- 高置信、高适用性不等于无上限优先，只影响声明权重和误差；
- 互斥候选按证据和稳定随机选择规则处理；
- 独立来源各自保留最小可表达份额后再分配剩余量；
- 无法满足几何、材料或采样条件的请求进入未解析或拒绝，不转给无关发生器；
- 未用预算可以释放为 `remaining`，不要求消耗完毕。

具体优化算法留待原型比较，但输入排序、平局处理、约束优先级和数值容差必须版本化。

### 18.5 带内组合

同一尺度带内先按物理谱系和发生器关系组合：

1. 合并同一发生器的分段和跨面表示；
2. 联合求解 `PAIRED` 正负结构；
3. 处理 `EXCLUSIVE` 候选；
4. 对同源父子和同源多几何分配预算；
5. 分别组合独立正贡献和独立负贡献；
6. 计算方向、坡度、曲率和空间冲突；
7. 生成带内净贡献及未解析部分。

独立发生器可以增强局部起伏，但使用连续饱和和共享几何约束。不能只取最大值，也不能无限线性相加。原始分项、组合前后振幅及饱和量全部进入账本。

### 18.6 跨尺度组合

跨 P2—P4 按 M4-D02 平滑窗和发生器谱系重建：

- 同一发生器各带分量在重叠区满足窗函数闭合；
- P3/P4 移除未授权父级均值和趋势；
- 子发生器只消费父级或授权包明确保留的预算；
- 不同尺度的方向可逐级变化，但不能无证据翻转；
- 新启用 P4 不重算 P2/P3 系数；
- 跨带总坡度和曲率仍受共享预算约束。

细尺度振幅虽小，也可能导致过大坡度。跨尺度检查必须在合成表面上执行，不能只验证每个尺度带单独合格。

### 18.7 正负贡献和冲突

M4 分别保存：

```text
positiveReliefContribution
negativeReliefContribution
netReliefContribution
processConflict
directionConflict
scaleConflict
budgetConflict
geometryConflict
```

两个强相反发生器抵消后，净值接近零不代表“没有地形作用”。方向相斥也不能通过平均角度生成一条虚假中间方向。

冲突严重但仍有合法数值解时，保留净场、分项和较大误差；没有合法解时保持未解析或阻断，不能用平滑抹去来源竞争。

### 18.8 超限处理

当合成表面超过幅度、坡度、曲率或频谱预算时，处理顺序为：

1. 检查重复来源和错误预算分配；
2. 在相关发生器组内执行连续、有界的整体调整；
3. 重新验证父级矩、成对关系和方向结构；
4. 仍无法满足时拒绝部分 realization 或保持未解析；
5. 只有数值安全需要时才逐点硬裁剪，并记录伪影风险。

禁止逐点削峰后把结果当作正常地形，因为这会产生平顶、尖锐裁剪边和额外高频。调整不能按当前世界极值重新缩放无关区域。

### 18.9 原生固体表面形成顺序

权威顺序为：

```text
M3 baseElevation
  + 已结算 M4 各带正负贡献
  = primarySolidElevation
  → 材料反向查询与覆盖检查
  → M5 几何与拓扑分析
```

材料反向查询若发现包络越界或多值不可解析，该 M4 候选失败、降级或请求合法细化；不能回写已提交的发生器组合。需要调整时创建新的候选／快照版本。

### 18.10 局部细化补丁

M4 局部细化使用不可变派生补丁：

```text
ReliefRefinementPatch
├─ parentReliefSnapshotId
├─ patchId / core / halo / supportMargin
├─ parentGeneratorRefs
├─ resolvedScaleBands
├─ childGeneratorRegistry
├─ parentBudgetAllocationRefs
├─ bandLimitedContributions
├─ aggregationAndBoundaryEvidence
├─ materialQueryRefinement
├─ errorsAndUnresolvedLedger
└─ dependencyRefs
```

补丁只能：

- 重新采样相同发生器；
- 解析父级已登记但未解析的尺度带和子发生器；
- 降低离散误差；
- 在父预算内改善材料界面和局部形态。

补丁不能新增无父级授权的来源、改变父发生器身份、移动 P2/P3 骨架或修改范围外状态。

### 18.11 补丁重叠与边界

相邻和重叠补丁必须：

- 引用相同父快照、模型、尺度描述符和发生器版本；
- 在交叠核心区得到相同规范值和发生器身份；
- 共享全局可寻址随机系数；
- 使用足以覆盖最大核支持的 halo；
- 在父级约束下连续衔接，而不是用任意透明度混合两套不同地形；
- 对显式断层不连续保持两侧语义，不用边界平滑抹除。

谱系不同或依赖版本不同的补丁不能拼接成同一权威表面，应报告版本冲突。

### 18.12 父子聚合

子级向父级聚合至少检查：

| 内容 | 聚合要求 |
| --- | --- |
| 高程贡献 | 面积均值、范围、方差和低阶矩闭合 |
| 频谱 | 各带功率和重叠窗重建误差闭合 |
| 坡度／曲率 | 分布、极值范围和超限覆盖率符合父预算 |
| 方向 | 张量、多峰、一致性和冲突摘要闭合 |
| 发生器 | 父子身份、覆盖份额和状态可追溯 |
| 预算 | 请求、分配、消耗、剩余、未解析、拒绝和裁剪闭合 |
| 材料 | 表面柱、接触、多交点和越界摘要按尺度一致 |
| 误差 | 可降低误差有证据下降，模型误差不因细化自动消失 |

M5 尚未生成，因此 M4 细化不以“山脊数量一致”作为父子约束；它保持的是高程、发生器和尺度统计。M5 将另行定义对象谱系。

### 18.13 依赖失效

补丁和发生器依赖至少包括：

- M3 快照与授权标识；
- 尺度带和交接窗版本；
- 发生器模型与随机流版本；
- 材料约束和方向字段；
- 预算分配与父级发生器；
- 数值策略和误差容差。

依赖变化只使受影响的空间、尺度、发生器及其子谱系过期。缓存删除不造成过期；相机和显示变化不进入依赖图。

### 21.8 验收证据组合

M4 需要组合：

1. **结构不变量**：引用闭合、单位、有限值、关系无环、预算守恒、资产摘要和原子性。
2. **因果关系**：改变汇聚、张裂、极性、材料强度或方向时，只有相关发生器按预期变化。
3. **解析／简化基准**：直线带、常宽剖面、单一倾斜块、已知带限场和简单预算账户。
4. **变形关系**：球面旋转、立方体面重映射和存储重排不改变物理结果。
5. **属性测试**：随机合法输入始终满足尺度、预算、状态、连续和确定性规则。
6. **跨尺度测试**：父子聚合、频谱重建、低频泄漏、补丁边缘及局部／全球一致。
7. **统计校准**：预注册种子组的振幅、坡度、曲率、相关长度、方向和频谱位于版本化类地包络。
8. **伪影检测**：条纹、网格印迹、重复模板、面周期、补丁方块、平顶和裁剪边。
9. **跨平台确定性**：Windows/macOS 允许误差不改变发生器、预算、状态和验收结论。
10. **消费者契约**：M5 只能读取公开视图，并能识别尺度不足、断点和边缘不完整。

视觉检查可辅助识别山墙、噪声海、重复纹理和接缝，但不能单独证明物理合理性或正式通过。

## 二十四、M4 内部一致性复核

M4-D01 至 M4-D07 的职责、数据流、尺度和预算关系复核通过。权威运行依赖为：

```text
M3 正式发布与 ReliefAuthorization
  → M4-D02 冻结尺度带和预算维度
  → M4-D03 建立发生器候选与关系
  → M4-D04 生成稳定参数和带限空间变化
  → M4-D05-A 应用冻结的前置材料修饰
  → M4-D06 联合分配预算、组合并形成原生固体表面
  → M4-D05-B 对最终表面执行材料反向查询
  → M4-D07 验收和发布
```

D05 的章节编号不代表它在运行中只有一个步骤。D05-A 只读取 M3 授权中冻结、与最终出露无关的材料约束；D05-B 只在表面完成后查询材料柱和出露候选。D05-B 不反馈 D03—D06。若最终表面超出材料包络，当前候选失败、降级或进入新快照，不在原快照内迭代修补。

复核确认以下边界：

1. **无 M3—M4 重复计权**：所有发生器引用 M3 授权、物理谱系和预算账户。
2. **无材料—起伏隐式循环**：前置修饰与最终出露查询分成 D05-A/D05-B 两个单向阶段。
3. **无尺度漂移**：真实波长决定 P2—P4 内容，LOD 只决定采样资格；P3/P4 不改变未授权低频矩。
4. **无随机越权**：随机流只实例化合格发生器，不创造因果来源或填补未知。
5. **无执行顺序偏差**：候选完整登记后联合分配预算，不采用并行先到先得。
6. **无拓扑提前注入**：M4 向 M5 交付完整表面和发生器证据，不预制峰、脊、谷、鞍或盆地对象。
7. **无过程地貌提前命名**：M4 原生低势和陡坡不直接成为河谷、峡谷、海沟、海岸或侵蚀崖。
8. **无发布旁路**：M5 标准输入只能来自 `PASS + RELEASED` 的原子 M4 发布。

需要留待原型标定的事项包括尺度带具体波长、交接窗、发生器剖面、参数分布、相关核、预算权重、坡度／曲率上限、补丁 halo、伪周期阈值和跨平台数值策略。这些不改变已确认的架构语义。
