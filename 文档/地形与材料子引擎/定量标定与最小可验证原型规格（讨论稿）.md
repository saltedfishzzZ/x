## 一、原型阶段的核心问题

首个原型需要回答：

1. 同一种子和版本化输入能否在球面上稳定重建同一世界？
2. 构造与材料约束能否形成方向、尺度和幅度受控的基础地形？
3. 中尺度起伏能否增加自然变化而不破坏长波骨架和预算？
4. 能否从完整固体表面稳定识别坡度、关键区域、脊谷和盆地？
5. 能否建立不填洼的容器曲线、门槛和多路潜在连接？
6. 各层误差、来源、身份和能力能否汇总成可复现发布？
7. 固定测试能否发现错误，而不是只生成一幅视觉上可接受的图？

首个原型不需要证明所有自然系统已经实现，而需要证明已确认架构中最关键、风险最高的链路可以落地。

## 三、P-D01：首个原型的目标与边界

### 3.1 原型目标

建议首个原型定义为：

> 输入一个种子和固定的 `earthlike-prototype-v1` 档案，在分层等角立方球面上生成一颗具有构造方向、材料背景、长波高程和受控中尺度起伏的原生固体行星；随后计算基础几何拓扑与固体容器接口，并输出可复现、可验收的无界面总发布。

它必须贯通：

```text
固定世界规格与种子
  → L1 球面空间
  → 最小构造约束
  → M1 输入契约
  → M2 简化材料背景
  → M3 长波基础高程
  → M4 受控中尺度起伏与固体表面
  → M5 基础几何与盆地拓扑
  → M6 容器曲线、门槛与潜在连接
  → M7 无界面总发布与验收报告
```

### 3.2 为什么选择垂直切片

逐层把所有能力实现完整后再集成，会把最危险的问题推迟到最后，例如：

- 相邻层单位、尺度和身份无法真实连接；
- M3/M4 预算规则无法产生 M5 可识别的稳定形态；
- M5 盆地对象无法支持 M6 容量积分；
- 补丁和对象身份在总发布时才暴露冲突；
- 各层单测都通过，但端到端结果不可重现。

垂直切片让每层只实现足以支持下一层的最小能力，并尽早验证跨层契约。未进入切片的能力保留明确的 `NOT_AVAILABLE`，不以临时默认值伪装完成。

### 3.3 首个原型的正式输入

原型默认只接受：

```text
seed
prototypeProfileId = earthlike-prototype-v1
```

测试和研究模式可显式覆盖少量因果参数，但这些覆盖进入世界身份。正式输入至少展开为：

```text
PrototypeWorldInput
├─ seed
├─ fixedPlanetRadiusAndGravityProfile
├─ fixedVerticalDatum
├─ fixedCubedSphereBaseLevel
├─ fixedTectonicPriorProfile
├─ fixedMaterialPriorProfile
├─ fixedTerrainScaleProfile
├─ fixedAcceptanceProfile
└─ modelAndParameterVersions
```

用户不直接输入“生成一座雪山”“增加峡谷”或“海洋占比 70%”。高级参数仍调整成因先验和预算，而不命令某处出现最终景观。

### 3.4 L1 与构造侧最小能力

原型保留：

- 六面等角立方球面和球面向量权威几何；
- 固定全球骨架层级及至少一级可验证局部细化；
- 全球稳定单元身份、跨面邻接和真实面积／距离；
- 少量板块或壳体区域及连续边界；
- 汇聚、张裂和稳定内部三类构造资格；
- 边界方向、侧别、宽度、衰减和来源预算；
- 固定版本的构造输出契约和证据。

原型暂不要求：

- 完整板块运动历史反演；
- 所有俯冲、扩张、转换、三重点和微板块组合；
- 火山、热点、撞击与地质年代演化；
- 真实地球板块数量和分布统计的最终标定。

汇聚和张裂被选中，是因为它们同时提供正、负地形贡献、方向结构和边界成对关系，能够检验 M3—M6 的关键路径。

### 3.5 M1 最小能力

M1 在原型中必须提供：

- 世界身份、种子和命名随机流；
- 球面空间、单位、参考半径和垂直基准；
- 固定有效重力／等势高程近似；
- 构造发布准入与能力协商；
- 原型运行清单、模型和参数版本；
- 明确的可用、缺失、未解析和失败状态。

原型不允许把路径、机器、线程或界面状态写入世界身份。

### 3.6 M2 最小能力

M2 建议只实现足以影响地形并供下游验证的连续材料背景：

```text
bulkDensity
effectiveStrengthOrErodibilityProxy
porosity
permeabilityEvidence
dominantStructureDirection
materialFamilyPrior
uncertainty
```

至少支持大陆倾向、洋壳倾向和过渡区域的连续混合，而不是把板块标签直接翻译成岩性。材料柱可以先采用有限层数和简化层序，但必须保持单位、垂向顺序、空间连续性、来源和误差。

原型不生成详细岩石年代、矿物组分、完整沉积层序、风化层或洞穴网络。

### 3.7 M3 最小能力

M3 必须输出：

- 版本化类地参考基准；
- 材料密度／壳体倾向形成的长波区域高程代理；
- 汇聚正响应、张裂负响应和稳定区低幅背景；
- 米制贡献账本、正负分量、限幅和冲突；
- 简化材料放置到世界几何的映射；
- 对 M4 的来源、尺度、方向和幅度授权。

至少使用 P0—P1 长波和有限 P2 广域响应。不得按单颗世界极值归一化，也不得把当前板块速度乘任意时间直接得到高程。

### 3.8 M4 最小能力

M4 建议实现三类原生发生器：

```text
COLLISION_BELT
RIFT_SHOULDER_AND_FLOOR
STABLE_BACKGROUND_RELIEF
```

并支持：

- P2—P3 两个真实波长尺度带；
- 方向相关、球面带限的确定性随机场；
- 父子尺度预算和重叠窗；
- 材料强度与结构方向的有界调节；
- 联合预算结算和正负贡献保留；
- 一个局部细化补丁的可重建性；
- 完整原生固体表面、误差、断点能力状态和发生器账本。

原型暂不实现 P4 场景细节、成熟侵蚀形态、火山锥、撞击坑、沙丘、冰川或完整海底地貌。

### 3.9 M5 最小能力

M5 首个原型至少计算：

- 一个粗尺度和一个中尺度的坡度、坡向及地形相对曲率；
- 局部高差、有效覆盖和误差；
- 最大、最小、鞍部和平坦关键区域；
- 山脊与谷线走廊的基础候选；
- 连续坡面区域；
- 盆地—控制鞍部嵌套关系；
- 跨面一致、补丁暂定状态和基础跨尺度谱系。

陡崖显式断点和局部三维锚点至少保留数据接口与 `NOT_AVAILABLE` 状态，但首个原型可以不生成真实断层崖、洞穴或悬挑结构。

### 3.10 M6 最小能力

M6 首个原型至少实现：

- 统一等势高程坐标；
- 解析容器和选定地形盆地的自由液面面积—势位曲线；
- 容积—势位曲线及面积积分一致性；
- 控制门槛、同高事件集和容器合并层级；
- 严格下降连接、平坦转移区和门槛条件连接；
- 多出口候选与等势分量压缩；
- 水体边界求解器输入视图，但不运行实际水量分配；
- 容量、门槛、路径和误差的结构化查询。

地下通道、实际海平面、湖泊水位、河流流量、渗漏和季节状态全部标记为未实现或由下游拥有。

### 3.11 M7 最小能力

M7 首个原型必须：

- 引用 M1—M6 不可变输出并验证真实依赖闭包；
- 生成一个 `CORE_PROTOTYPE_V1` 发布档案；
- 提供最小探索、诊断和水体边界输入视图；
- 输出能力矩阵和所有缺失能力；
- 建立基础来源、要求、断言和失败证据图；
- 生成结构化总验收报告与最小复现包；
- 验证同种子重跑、分块顺序和至少两种线程配置；
- 通过单一不可变根提交总发布。

首个原型只要求无界面生成与查询。桌面应用、交互地图和三维球体不属于 M7 原型通过条件。

### 3.12 首个综合原型世界

建议使用一个人工构造但通过正式路径生成的综合世界 `PV01`：

```text
PV01 构造—材料—地形综合世界
├─ 一个分段汇聚带
├─ 一个分段大陆裂谷
├─ 一个稳定内部区域
├─ 连续大陆／过渡／洋性材料背景
├─ 一处汇聚与裂谷影响相邻但不重合的区域
├─ 至少一个封闭盆地
├─ 至少一个平坦或近同高门槛案例
├─ 至少一个跨立方球面面缝的长结构
└─ 一个局部细化补丁
```

PV01 用于验证端到端组合，不代替解析微夹具。它不要求包含海洋、湖泊、河流、雪山、沙漠或所有目标地貌。

### 3.13 配套解析微夹具

原型至少配套：

```text
PF01 常量球面
PF02 单解析山丘
PF03 单解析洼地
PF04 标准鞍面
PF05 平顶与宽平谷
PF06 嵌套双盆与同高双门槛
PF07 跨面方向场
PF08 局部补丁聚合
```

解析夹具允许绕过部分自然发生器，专门验证球面度量、导数、拓扑、容量和拼接；PV01 必须走正式 L/M 层路径。两类测试的用途和证据不能混淆。

### 3.14 首个原型明确排除

以下内容不进入首个原型验收：

- 气候环流、降水、温度和季节状态；
- 全球水量分配、实际海平面和最终海陆图；
- 河网、湖泊、湿地、瀑布、三角洲和地下水；
- 侵蚀、搬运、沉积、风化和长期地貌演化；
- 目标清单中所有地貌类别的最终语义识别；
- 完整洞穴、暗河、天坑和悬挑三维几何；
- P4/P5 近景细节和可漫游场景；
- Windows/macOS 桌面界面、渲染和交互；
- GPU 加速、分布式计算和生产级性能优化；
- 与真实地球数据的一次性最终标定。

排除项必须显示为未提供能力，不能由噪声、规则标签或展示效果假装存在。

### 3.15 原型交付物

首个原型完成时应交付：

```text
prototype source and build definition
versioned parameter profile
PV01 and PF01—PF08 inputs
M1—M7 immutable prototype snapshots
structured capability matrix
machine-readable acceptance report
human-readable result summary
minimal reproduction packages
determinism and cross-platform comparison
known limitations and next-slice proposal
```

本阶段只定义这些交付物，不在尚未确认技术栈时规定具体文件扩展名或目录实现。

### 3.16 原型通过的最低条件

P-D01 层面建议最低成功条件为：

1. 固定种子与版本输入可重现相同离散对象、拓扑和发布结论；
2. PV01 同时形成受控汇聚高地、裂谷低地和稳定背景，不依赖后处理绘制；
3. M3/M4 尺度与幅度预算闭合，无世界极值归一化；
4. M5 可从 M4 表面独立识别关键区域、脊谷和盆地；
5. M6 曲线非负单调、积分一致，且不填洼建立门槛与多路连接；
6. 跨立方球面面缝无重复对象、断线和方向翻转；
7. 局部补丁不改变已解析粗尺度结果超出容差；
8. 所有未实现能力明确可见，不以默认值或显示数据补齐；
9. 失败注入能被验证器拒绝并生成最小复现包；
10. M7 能原子发布或明确拒绝整个垂直切片。

### 3.17 不允许的快捷方式

P-D01 不允许：

- 为尽快出图跳过 M2、M5、M6 或 M7；
- 用一张分形噪声高度图代表完整构造和材料链；
- 直接绘制 PV01 预期山脉与裂谷形状；
- 用地貌标签反向生成高程；
- 为得到连通路径而填洼或烧入河槽；
- 用最终图像相似度作为唯一验收；
- 在尚未标定时宣称参数代表真实地球定值；
- 为未实现能力返回零、空数组或默认材料而不标状态；
- 先构建桌面界面再补核心科学契约；
- 为单个平台或单个测试世界写特例。

## 五、P-D02：固定输入与专门测试世界

### 5.1 三类固定测试资产

首个原型不以任意随机种子生成的世界充当唯一基准，而使用三类用途分离的固定资产：

```text
原型测试资产
├─ PV01 综合世界：验证正式 L/M 层能否端到端组合
├─ PF01—PF08 解析夹具：用已知函数和拓扑关系验证数值算法
└─ PI01—PI06 故障注入夹具：验证错误能否被检测、定位和拒绝
```

三者的证据不能互相替代：PV01 生成得自然，不证明导数或容量数值正确；解析夹具通过，不证明正式生成链能够组合；故障注入通过，只证明验证器能识别指定错误。

### 5.2 固定输入包与身份规则

每个测试资产必须由版本化输入包定义，至少包含：

```text
PrototypeFixtureInput
├─ fixtureId
├─ fixtureVersion
├─ fixtureKind
├─ worldSeed
├─ profileId
├─ geometryFrameId
├─ gridPlan
├─ analyticOrConstructiveInputs
├─ requiredCapabilities
├─ expectedRelations
├─ toleranceProfileId
└─ oracleVersion
```

规则如下：

1. `fixtureId + fixtureVersion` 唯一确定输入内容；修改任何权威输入必须升版本。
2. 随机资产使用明确的 64 位无符号种子；解析夹具无须随机，接口若强制要求种子则固定为零且不得消费随机流。
3. 输入包、Oracle、容差和待测实现分别版本化；更新容差不得静默改写旧结果。
4. 夹具坐标优先用单位球面向量、角距离和局部正交标架定义，避免经纬度极点与投影伪影。
5. 预期结果保存关系、区间、离散拓扑和规范摘要；不把某次运行的原始浮点数组直接当作科学真值。
6. 测试显示图只用于人工诊断，不参与通过判定。

### 5.3 原型共同计算规格

P-D02 先冻结足以使测试可执行的计算规模；这些值是原型测试常量，不是最终类地标定结论：

| 项目 | `prototype-grid-v1` 固定值 | 用途 |
| --- | --- | --- |
| 参考半径 | 6,371,000 m | 统一球面距离与面积量纲 |
| 有效重力 | 9.80665 m/s²，首版视为空间常量 | 建立等势高程近似 |
| 垂直基准 | 零位等势参考面 | 只作为固体高程参照，不代表海平面 |
| 全球骨架 | 六面等角立方球面，每面 `256 × 256`，对应 L8 | 支持全球端到端运行 |
| 局部细化 | 一个 L10 核心补丁，带足够 halo；覆盖 PV01 的跨面或盆地区域 | 验证父子聚合与重建 |
| M5 分析尺度 | 320 km 与 80 km | 分开粗尺度骨架和中尺度对象 |
| M4 原型波段 | P2：800—3,200 km；P3：160—800 km | 为首批发生器提供真实波长边界 |
| 浮点策略 | 权威计算至少二进制 64 位；离散决定使用规范化比较规则 | 减少跨平台分歧 |

L8 全球格约含 393,216 个叶单元，规模足以暴露跨面、并行和拓扑问题，同时仍适合普通桌面 CPU 验证。L10 只用于一个局部补丁，不把首个原型变成全球高分辨率生成器。

M4 波段和 M5 分析尺度在此只是测试边界。P-D03 仍需决定物理参数范围、预算和标定目标；后续证据若表明当前分辨率不足，应通过新版本档案调整，而不是在同一测试版本中自适应改变。

### 5.4 PV01 综合世界的固定规格

`PV01-v1` 使用固定种子 `0x5056303154455354` 和 `earthlike-prototype-v1`。它必须通过正式构造、M1—M7 接口生成，禁止向最终高程直接写入预期山脉、裂谷或盆地。

PV01 的输入不是现实板块复刻，而是一组最小构造与材料约束：

| 区域 | 固定输入条件 | 预期关系，不预先规定逐点答案 |
| --- | --- | --- |
| 汇聚带 C1 | 一条分段球面边界，具有连续汇聚资格、方向与两侧壳体倾向 | 边界附近形成方向一致的正高程响应；离带衰减 |
| 裂谷带 R1 | 一条分段球面边界，具有连续离散资格和成对肩部／轴部授权 | 轴部相对降低、两肩相对抬升，三者共享预算 |
| 稳定域 S1 | 远离 C1/R1 的连续区域 | 只出现低幅、长相关背景起伏 |
| 过渡域 T1 | 大陆倾向到洋性倾向的连续材料混合带 | 材料属性连续，不产生板块标签式台阶 |
| 相邻影响区 X1 | C1 与 R1 的影响尾部接近但控制线不相交 | 贡献可叠加但来源、正负分量和冲突分别保留 |
| 封闭盆地 B1 | 由正式低地响应与周缘正响应共同形成 | M5 能识别闭合盆地，M6 建立容量与控制门槛 |
| 同高门槛区 E1 | 两个在容差内等势的候选门槛 | 保留事件集与多出口，不按遍历顺序强选唯一出口 |
| 跨面结构 Q1 | C1 或 R1 的一段穿越至少一条立方球面面缝 | 字段、方向、对象身份和走廊跨缝连续 |
| 细化区 H1 | 覆盖 B1、E1 或 Q1 之一的 L10 补丁 | 细化提高局部解析度，父级聚合与既有粗拓扑保持在容差内 |

固定几何不依赖地图投影绘制。边界和区域以三维球面控制点、大圆／球面样条段、测地宽度及衰减核引用表达；输入包必须证明 Q1 实际穿越当前 `geometryFrameId` 的面缝。

PV01 的成功不要求某个峰值恰好等于指定米数。它要求以下顺序和关系成立：

- C1 正响应的带内中位数高于其外侧匹配背景；
- R1 轴部中位数低于两侧肩部，肩部与轴部来源同属成对预算；
- S1 的起伏功率和坡度统计低于 C1/R1 活跃区；
- T1 连续物性及其有界修饰不出现无来源跳变；
- B1 的面积—势位和容积—势位曲线非负、单调且积分一致；
- E1 输出同高事件集或明确的不确定关系；
- Q1 和 H1 不产生重复、断裂、方向反转或身份漂移；
- M7 只能在完整依赖、能力和证据闭合后发布。

### 5.5 PF01—PF08 解析夹具

解析夹具默认在单位球面上定义，再用共同参考半径转换距离。`p` 表示单位球面位置，`d(p,c)` 表示到中心 `c` 的球面角距离，局部夹具使用由中心法向自动构造的正交切平面坐标 `(x,y)`。所有函数必须在有效域、过渡域和无定义点分别给出预期状态。

| 编号 | 权威输入 | 主要验证 | 必须成立的结果 |
| --- | --- | --- | --- |
| PF01 常量球面 | `h(p)=0 m` | 面积、邻接、跨面拼接、导数零场 | 地形相对坡度与曲率在容差内为零；无虚假极值、脊谷和盆地 |
| PF02 单解析山丘 | `h(p)=1000·exp[-d(p,c)²/(2σ²)] m`，`σ=5°` | 梯度、坡向、曲率、最大区与尺度响应 | 唯一最大区位于 `c` 的定位误差内；坡向和解析梯度关系一致 |
| PF03 单解析洼地 | PF02 取负，幅值 `800 m` | 最小区、盆地边界、面积与容积曲线 | 唯一主盆地；曲线单调且数值积分与解析／高精度 Oracle 一致 |
| PF04 标准鞍面 | 局部 `h=Axy`，外圈以光滑窗过渡到常量背景 | 鞍部分类、四象限连接、方向不依赖遍历顺序 | 中心为一个鞍部区域；高低分支连接关系正确 |
| PF05 平顶与宽平谷 | 分段光滑平台加宽谷，两处内部梯度低于误差阈值 | 平坦关键区域、未定义坡向、区域而非单点表达 | 平顶和宽平谷各保留为区域；不得用噪声制造唯一代表点 |
| PF06 嵌套双盆与同高双门槛 | 两个内盆、一个外盆及两个等势门槛的光滑组合面 | 盆地嵌套、事件集合并、多出口和容量去重 | 层级与合并顺序正确；双门槛保留；父子容量不重复计量 |
| PF07 跨面方向场 | 固定三维向量 `a` 在各点切平面的投影场，避开投影零点 | 向量基变换、跨面方向连续、走廊拼接 | 跨缝后物理方向连续，无分量符号误判和重复对象 |
| PF08 局部补丁聚合 | 带限父场加只存在于授权波段且父单元均值为零的细节场 | L8/L10 聚合、halo、预算和重建确定性 | 细化核心解析细节；回聚合保持父值、低阶矩和离散拓扑结论 |

PF04—PF06 的分段函数必须采用至少一阶连续的显式过渡窗，并由独立 Oracle 以更高分辨率或解析关系求预期结果。夹具生成函数不复用待测 M3/M4 发生器，以免实现错误同时污染输入与答案。

### 5.6 PI01—PI06 故障注入夹具

故障注入建立在一份本可通过的最小资产上，每次只注入一类错误：

| 编号 | 注入错误 | 预期拒绝位置 |
| --- | --- | --- |
| PI01 面缝邻接破坏 | 删除或反转一条跨面邻接／方向变换 | L1、M5 或 M7 的接缝与闭包验证 |
| PI02 混合快照 | 将一个 M4 补丁指向不同 M3/M2 依赖 | M7 依赖闭包验证 |
| PI03 预算超支 | 使 M4 某尺度或来源消耗超过 M3 授权 | M4 预算结算或 M7 证据验证 |
| PI04 非单调容积 | 篡改一段 M6 容积曲线使其随势位下降 | M6 曲线不变量验证 |
| PI05 重复对象身份 | 令跨面或补丁两侧对象共享非法身份／出现重复实体 | M5 身份与拼接验证 |
| PI06 顺序依赖 | 让相同输入在不同分块或线程顺序下得到不同离散关系 | M7 确定性验证 |

每个故障必须产生稳定的失败分类、最小影响范围和复现包。测试只在目标验证器发现目标错误时通过；崩溃、超时或被无关前置错误拦截不算有效命中。

### 5.7 基准答案与容差的管理

基准结果分为四类：

1. **解析真值**：能从函数直接得到的高程、梯度、面积或关系。
2. **高精度 Oracle**：解析积分困难时，使用独立、更高分辨率实现生成参考区间。
3. **关系真值**：例如“轴部低于肩部”“容积单调”“双门槛并列”，不要求逐点相同。
4. **离散规范结果**：对象数量、嵌套关系、事件集合、能力状态和失败分类，可使用规范序列化摘要固定。

连续值采用绝对误差、相对误差、空间定位误差和拓扑稳定裕度的组合容差；离散结论要求完全一致，除非夹具明确把结果定义为不确定集合。具体容差数值在 P-D03/P-D06 冻结，P-D02 只冻结证据类型和比较方法。

不允许在看过当前实现结果后逐项放宽容差。调整夹具、Oracle 或容差时必须说明原因、建立新版本并重跑全部受影响资产。

## 七、P-D03：参数范围、占位值与标定目标

### 7.1 参数不是同一种事实

所有量都进入统一参数登记表，但必须先区分其性质：

| 类型 | 含义 | 能否通过调参改变 |
| --- | --- | --- |
| `CONVENTION` | 单位、参考系、符号、坐标架和测试分辨率等版本约定 | 只能通过新规格版本改变 |
| `OBSERVATION_BOUNDED` | 受现实观测或实验约束，但存在地区差异和不确定性的量 | 可在来源支持的区间内标定 |
| `PROTOTYPE_PRIOR` | 为打通原型暂设的范围和名义值 | 可以替换，不能宣称为现实定值 |
| `DERIVED` | 由上游状态和公式计算出的量 | 不允许独立调参 |
| `ENGINEERING` | 采样、迭代、缓存和数值求解参数 | 只能影响误差与性能，不得改变模型语义 |

每个参数至少记录：

```text
ParameterRecord
├─ parameterId / version
├─ ownerLayer
├─ semanticType
├─ unitAndDimension
├─ validDomain
├─ prototypeRange
├─ nominalValue
├─ distributionOrTransform
├─ dependenciesAndJointConstraints
├─ sourceRefs
├─ maturity
├─ sensitivityClass
├─ calibrationDataset
└─ replacementAndInvalidationRules
```

禁止只保存一个裸数值。没有单位、来源、适用尺度或成熟度的值，不得进入正式原型档案。

### 7.2 参数成熟度

参数成熟度采用五级状态：

```text
M0 UNSET          尚未给值，能力不得假装可用
M1 PLACEHOLDER    工程占位，只用于跑通链路
M2 PLAUSIBLE      有量纲和合理区间支持，但尚未系统标定
M3 CALIBRATED     已在校准集上完成预注册目标的标定
M4 VALIDATED      在独立保留集与跨平台验收中保持成立
```

`earthlike-prototype-v1` 允许使用 M2 参数运行标准原型，但发布必须公开成熟度；M1 参数只能进入实验发布；M0 参数对应能力必须为 `NOT_AVAILABLE`。首个原型不把任何地形响应参数直接标成 M4。

### 7.3 首版参数档案分层

建议把原型参数拆成五个可独立升级但相互引用的档案：

```text
earthlike-prototype-v1
├─ planet-conventions-v1
├─ tectonic-response-priors-v1
├─ material-priors-v1
├─ terrain-budget-priors-v1
└─ analysis-and-container-priors-v1
```

世界身份保存所有档案的内容摘要，不能只保存总档案名称。研究覆盖创建新的参数实例和世界身份，不得原地修改 `earthlike-prototype-v1`。

### 7.4 已冻结的定义与测试约定

以下内容继承 P-D02，属于 `CONVENTION`，不参与拟合：

| 参数 | 原型值 | 状态 |
| --- | --- | --- |
| 参考半径 | 6,371,000 m | 原型约定 |
| 有效重力 | 9.80665 m/s²，空间常量 | 原型近似 |

有效重力的空间变化、旋转势、椭球体和真实大地水准面属于后续模型能力。首版的常量重力是显式近似，不作为类地行星普遍定律。

### 7.5 构造响应的原型先验

以下数值用于约束 PV01 的量级，成熟度初始为 M2；它们是待验证区间，不是自然常数：

| 参数族 | 原型范围 | 名义起点 | 约束关系 |
| --- | --- | --- | --- |
| 汇聚影响有效全宽 | 300—1,200 km | 700 km | 沿边界可平滑变化，不能窄于可解析尺度 |
| 汇聚正响应幅度 | 1,000—5,000 m | 3,000 m | 带内统计高于匹配背景，远场连续衰减 |
| 裂谷影响有效全宽 | 200—900 km | 500 km | 轴部与双肩使用同一成对发生器 |
| 裂谷轴部负响应 | 300—2,000 m | 900 m | 轴部低于两肩，负号单独保存 |
| 裂谷单侧肩部正响应 | 100—1,200 m | 450 m | 两肩共享预算，不要求严格对称 |

响应振幅不能由当前板块速度直接乘一个任意时间得到。速度、壳体倾向、边界类型和材料只能通过已声明的响应模型共同决定参数条件；模型尚未实现时使用 PV01 固定先验，不制造伪地质年龄。

### 7.6 材料背景的原型先验

M2 首版只需要支持地形链的连续有效属性。建议范围如下：

| 参数 | 原型范围 | 名义起点 | 说明 |
| --- | --- | --- | --- |
| 大陆倾向有效体密度 | 2,600—2,900 kg/m³ | 2,750 kg/m³ | 尺度有效量，不等同于单一岩石样品 |
| 洋性倾向有效体密度 | 2,850—3,100 kg/m³ | 2,950 kg/m³ | 用于相对区域基底代理 |
| 有效孔隙率 | 0.01—0.30 | 按材料族给先验 | 只提供连续证据，不求地下水状态 |
| 地形抗蚀／强度代理 | 0—1 | 0.5 | 无量纲排序代理，不能解释为真实岩体强度 |
| 渗透性证据 | 0—1 加未知状态 | 0.5 或未知 | 不能解释为实际渗透率，M6 不据此生成地下通道 |
| 结构方向置信度 | 0—1 | 由构造与材料来源派生 | 低置信度时减弱各向异性，不随机补方向 |
| 材料对起伏幅度修饰 | 0.70—1.30 倍 | 1.00 | 有界修饰，不能创造构造来源或额外预算 |

密度、孔隙率、强度和渗透性之间存在相关性，但首版不允许把多个相关代理直接连乘。M2 必须使用具名联合材料先验或明确只选一个主修饰量，避免重复放大同一证据。

### 7.7 M3/M4 高程与起伏预算先验

首版按来源和尺度管理幅度，建议使用以下成熟度为 M2 的合理区间：

| 参数族 | 原型范围 | 名义起点 | 预算规则 |
| --- | --- | --- | --- |
| 大陆—洋性区域基底对比 | 2,000—6,000 m | 4,000 m | 只表达相对长波对比，不决定海陆 |
| P2 起伏 RMS／授权幅度 | 0.15—0.55 | 0.35 | 只消费所属来源 P2 预算 |
| P3 起伏 RMS／授权幅度 | 0.08—0.35 | 0.18 | 不改变 P0—P1 均值和长波矩 |
| 方向相关长度比 | 1.0—4.0 | 活动带 2.0，稳定区 1.0 | 由来源方向和置信度共同限制 |
| 相邻尺度重叠宽度 | 各波段对数宽度的 10%—25% | 15% | 使用互补平滑窗，避免功率缺口或重复 |
| 独立来源合成增益上限 | 相对线性和的 0.6—1.0 | 0.8 | 通过连续饱和抑制无界叠加 |
| 原型诊断高程包络 | −12,000—10,000 m | 只作报警边界 | 超界触发诊断，不按包络重新归一化 |

“RMS／授权幅度”是发生器实际起伏强度相对授权上限的比例，不是将每个区域强制缩放到同一 RMS。世界局部没有足够授权时允许低于名义值，也不强制用完预算。

### 7.8 M5/M6 分析参数先验

几何与拓扑判断优先相对于误差和尺度定义，避免使用跨尺度固定坡度或固定高差阈值：

| 参数族 | 原型范围／形式 | 名义起点 | 含义 |
| --- | --- | --- | --- |
| 有效特征最小信噪比 | `featureMagnitude / propagatedError` 为 2—5 | 3 | 低于门槛保留暂定或未解析 |
| 平坦区判定 | 梯度置信区间包含零，且连通支持面积达标 | 误差驱动 | 不用随机扰动打破平台 |
| 极值／鞍部最小支持 | 至少跨越 2—4 个该尺度有效分辨单元 | 3 个 | 防止单格噪声成为对象 |
| 跨尺度生存要求 | 在相邻两个分析尺度上有可追踪谱系 | 默认要求 | 单尺度对象可保留为低置信候选 |
| 门槛等高判定 | 势位差不大于联合垂直不确定度的 1—2 倍 | 1 倍 | 满足时保留同高事件集 |
| 曲线自适应误差预算 | 不超过输入垂直不确定度对应容积影响的 10%—50% | 25% | 不能用更精细采样伪造高于输入的信息 |
| 容量积分闭合 | 曲线积分、空间积分和层级去重三者使用同一误差账本 | 强制关系 | 具体数值容差在 P-D06 冻结 |

这些门槛控制“可解析性”，不直接定义山峰、峡谷、湖泊或河流语义。

### 7.9 联合约束与禁止独立调节

以下参数必须联合处理：

- 构造带宽度、波段边界、网格分辨率和 M5 分析尺度；
- 汇聚／裂谷振幅、材料修饰、M3/M4 总预算和诊断包络；
- 材料密度、区域基底对比和垂直参考模型；
- 平坦阈值、特征信噪比、输入误差和对象支持范围；
- 容器曲线采样密度、垂直误差和积分闭合容差；
- 各向异性比、结构方向置信度和球面方向场连续性。

单独调高其中一个量而不重验相关约束属于无效标定。参数登记表必须保存联合组和冲突检查器。

### 7.10 标定顺序

标定按不可逆优先级进行：

```text
C0 量纲与数学正确性
  → C1 解析夹具误差与收敛性
  → C2 PV01 因果关系和预算闭合
  → C3 固定种子组的分布与敏感度
  → C4 独立保留集与跨平台验证
  → C5 视觉诊断与产品体验检查
```

前一阶段未通过时不得进入后一阶段调参。视觉结果只能发现问题或提出新假设，不能覆盖量纲、守恒、拓扑、因果和确定性失败。

### 7.11 校准集、保留集与防过拟合

除 PV01 外，后续建立两个不可重叠的预注册种子集合：

- `PCAL-v1`：用于拟合参数和比较候选模型；
- `PVAL-v1`：在参数冻结后才用于验收，不参与调参。

种子列表、样本规模和抽样层在 P-D06 冻结。任何参数变更都会使相关 PVAL 结论失效；若查看保留集后据此改参，该集合随即降级为校准数据，必须建立新的保留集版本。

每次标定至少输出：目标定义、输入版本、参数前后值、联合约束、敏感度、未识别参数、失败案例和保留集状态。

### 7.12 标定目标的优先级

不把所有指标压成一个可互相补偿的总分。采用分层目标：

1. **硬约束**：单位、闭包、单调性、预算、依赖、身份、确定性和拓扑不变量；任一失败即淘汰。
2. **因果关系**：汇聚高地、裂谷轴肩、稳定区低幅、材料有界修饰等方向性关系。
3. **数值质量**：解析误差、网格收敛、补丁聚合、容量积分和跨平台差异。
4. **统计合理性**：高度、坡度、频谱、相关长度、盆地尺度和对象持久性的联合分布。
5. **表达质量**：连续缩放下是否易于观察和解释，只能在前四层通过后评估。

统计标定比较联合分布和条件分布，不只匹配全球均值。现实数据可用于约束量级与分布，但首个原型不以逐像素复刻地球为目标。

### 7.13 敏感度与不可识别参数

每个可校准参数至少进行局部扰动和区间采样：

- 检查输出对参数的方向、非线性和交互作用；
- 找出几乎不影响结果的冗余参数；
- 找出多个参数能产生相同输出的不可识别组合；
- 检查小幅变化是否导致拓扑或发布状态突然翻转；
- 区分模型结构误差、参数不确定性和数值误差。

不可识别参数不得给出虚假的精确值。首版应固定其中一部分、合并参数，或保留多个等价情景，并在发布中记录不确定性。

### 7.14 P-D03 不允许的调参方式

- 按单颗世界最高点和最低点重新缩放全部高程；
- 为让 PV01 通过而写入位置特例或种子特例；
- 同时调参和修改 Oracle，却不升版本；
- 用最终图片相似度取代关系、误差和拓扑断言；
- 将归一化代理解释为真实物性；
- 把所有误差吸收到一个“噪声强度”参数；
- 在校准集和保留集之间移动失败样本以提高通过率；
- 用一个总分让严重物理失败被其他指标抵消；
- 为不同操作系统维护不同科学参数；
- 不记录失败尝试，只保存最终看似合理的参数。

## 九、P-D04：最小算法与候选比较

### 9.1 算法选择原则

首个原型选择算法的顺序为：

1. 语义符合已确认的 L1—L7 与 M1—M7 契约；
2. 能用 PF 解析夹具或独立 Oracle 验证；
3. 在球面面缝、平坦区、并列事件和局部补丁上行为明确；
4. 同种子、不同分块顺序与线程数得到一致离散结果；
5. 误差能随分辨率或求解精度呈可解释收敛；
6. CPU 上能完成 `prototype-grid-v1`；
7. 最后才比较速度、内存和工程复杂度。

首版不追求一次选出最终生产算法。算法身份、版本、参数和数值策略必须进入快照；替换算法会产生新发布，不允许在运行中根据局部结果静默切换。

### 9.2 参考算法与候选算法双轨制

关键步骤保留两种角色：

| 角色 | 用途 | 要求 |
| --- | --- | --- |
| 参考算法 | 为解析困难的步骤提供透明、较高精度、较慢的对照 | 实现简单、路径独立、可提高精度，不要求生产性能 |
| 原型候选 | 贯通正式快照并满足原型运行规模 | 符合契约、确定性、误差和性能门槛 |

参考算法不与候选算法共享关键离散逻辑，避免同一个错误同时出现在答案与实现中。若两者不一致，先检查解析关系、收敛趋势和第三种简化实验，不以“多数实现一致”代替证明。

### 9.3 L1 球面空间最小算法

首版选择：

- 使用标准等角立方球面正向／逆向映射；权威位置始终归一化为三维单位向量；
- 通过球面大圆距离、切空间投影和球面多边形面积计算真实度量；
- 四叉层级使用父级键加 Morton 型子路径形成稳定单元身份；
- 跨面邻接通过三维边界位置和规范面选择重建，不依赖显示投影的二维坐标相接；
- 局部细化采用确定性四叉拆分，并维持已确认的邻域与 halo 契约；
- M5/M6 需要三角网时，对每个四边形使用由全局单元身份决定的规范对角线，三角化只作分析视图。

参考计算使用高精度球面公式直接验证边长、面积、方向变换和闭合面积。禁止用经纬度平面距离、各面独立法向或渲染网格替代权威几何。

### 9.4 最小构造状态算法

随机世界的首版构造状态采用以下透明流程：

```text
命名随机流
  → 球面确定性最远点／蓝噪声式板块种子
  → 球面 Voronoi 壳体域
  → 每个域的固定范围欧拉旋转向量
  → 边界两侧速度 v = ω × r
  → 相对速度的法向／切向分解
  → 汇聚、张裂、稳定或未解析资格
```

PV01 使用固定种子和固定构造输入包，但仍经过相同的域、边界、相对运动、分类和发布接口。它可以固定板块种子与欧拉向量，不能直接固定最终山脉或裂谷高程。

首版只将持续且超过不确定度的法向分量分为汇聚或张裂；接近门槛时保留混合或未解析状态。转换边界、三重点和微板块可被几何识别，但不在首个地形响应中承诺完整动力学。

候选比较包括球面 Voronoi 与其他分区方法，但首个原型不求解完整地球动力学偏微分方程，也不使用长时间板块演化来掩盖当前代理模型的范围。

### 9.5 M1/M2 最小算法

M1 主要执行规范化与契约校验：

- 按字段模式解析世界输入，执行单位与范围检查；
- 从内容生成世界身份和命名随机流键；
- 固定参考半径、重力和垂直基准；
- 通过能力表和依赖摘要拒绝不兼容输入；
- 采用规范序列化，避免映射遍历顺序进入身份。

M2 采用“区域先验加紧支撑连续混合”的最小算法：

1. 壳体倾向、边界距离、边界侧别和构造域提供材料先验特征；
2. 每类先验通过球面测地距离核形成非负权重；
3. 权重以分区单位方式归一，连续属性在物理允许域内混合；
4. 垂向材料柱使用有限层节点和保持顺序的单调插值；
5. 结构方向由权威球面向量投影到局部切空间，低置信度处衰减而非随机补向。

首版不以硬 Voronoi 标签直接产生材料台阶。参考算法可使用更密的球面采样和直接核求和；候选算法可以使用空间索引加速，但必须在误差界内保持同一连续场与来源权重。

### 9.6 M3 基础高程最小算法

M3 使用可分解的有类型响应图：

- 区域基底：材料与壳体代理通过固定单调响应曲线映射为长波相对高程；
- 汇聚响应：沿球面边界的正高程横向核乘沿程平滑幅度场；
- 裂谷响应：一个负轴部核与两个正肩部核组成不可拆分的成对发生器；
- 稳定背景：仅在剩余长波预算内加入低幅带限场；
- 多来源组合：先分开累计正负贡献，再按来源预算使用连续软饱和函数结算；
- 材料放置：在高程冻结后将材料柱与表面求交，不反馈本轮高程。

边界影响按球面测地距离和边界有向坐标计算，不在立方球面各面独立卷积。首版参考算法对边界采样点直接求和；候选算法可用分段空间索引或快速卷积近似，但必须比较远场截断误差、核积分和跨缝连续性。

软饱和只能执行已登记预算，不得按世界极值重新缩放，也不得消除正负贡献账本。

### 9.7 M4 多尺度起伏最小算法

首版按发生器选择不同但可合成的带限场：

| 场景 | 最小算法 |
| --- | --- |
| 稳定背景 | 使用种子寻址的实球谐随机系数，在 P2/P3 波段应用平滑谱窗 |
| 汇聚带 | 横向汇聚核乘沿边界弧长的一维带限随机调制 |
| 裂谷带 | 轴部与双肩共享沿程随机调制和预算，再分别应用横向符号核 |
| 材料修饰 | 以平滑、有限范围倍率调节幅度、方向相关与局部化 |
| 局部补丁 | 在更细采样点重新求值同一全局可寻址场，仅增加已授权的细尺度系数 |

球谐场作为首版参考与原型候选的共同数学基线，优点是天然跨面连续、频带明确且易于独立求值。它在局部更新和高分辨率时成本较高，因此只承诺 P2/P3 与 L8/L10 原型规模。

后续可将分层立方球面小波或紧支撑球面基函数作为性能候选，但必须证明：波段功率、父子矩、跨面连续性、补丁重建和确定性与参考场在容差内一致。普通逐面分形噪声不能作为候选，除非解决面缝、物理波长、频谱预算和局部重建问题。

### 9.8 M5 几何与拓扑最小算法

M5 分为几何场与拓扑对象两条路径：

**几何场**

- 在球面切平面内，以真实距离进行加权二次最小二乘拟合；
- 从拟合面解析得到梯度、坡向、Hessian、相对曲率和拟合残差；
- 分别在 320 km 与 80 km 支持尺度上计算，支持核由物理距离定义；
- 面缝邻域先转入同一切空间，不拼接二维面坐标；
- 平坦区或病态拟合返回未定义方向与传播误差。

**拓扑对象**

- 在规范三角分析面上，把误差范围内不可排序的相邻等高点压缩成平台分量；
- 使用 lower/upper link 连通关系识别最小、最大和鞍部候选；
- 用按高程稳定排序的并查集建立低位合并树和盆地—控制鞍部层级；
- 山脊／谷线先由尺度化 Hessian 与梯度关系形成二维走廊响应，再以拓扑关键区域约束连接；
- 走廊区域是权威对象，细化中心线只作派生索引；
- 跨尺度对象通过空间覆盖、拓扑关系和持久性建立谱系，不按格元编号继承身份。

参考算法在 PF02—PF06 上直接使用解析导数或高分辨率拓扑 Oracle。候选若使用有限差分、离散 Morse 理论或其他拟合方式，必须保留平台、多鞍部和不确定集合，不能通过任意微扰制造唯一答案。

### 9.9 M6 容器与潜在连接最小算法

首版把 M5 的盆地及其规范三角表面视为分片线性固体表面：

- 对给定等势位逐三角形裁剪，累计自由液面面积、湿润表面积和边界接触量；
- 对每个分片线性三角单元使用解析分段积分形成容积增量；
- 自适应势位节点必须包含所有控制门槛和拓扑事件；
- 用独立的直接空间积分在抽查势位验证曲线积分；
- 嵌套容器通过排他区域和合并树只计量一次；
- 相邻格元建立严格下降有向边，误差内等势节点先压缩为平坦分量；
- 控制门槛连接和普通邻接分开存储，多出口保持集合；
- 若需寻找两容器间最低几何屏障，使用最小化路径最大势位的 minimax 图搜索。

参考算法提高三角细分与势位采样精度，候选算法可以缓存分片多项式和事件区间。无论采用何种优化，面积与容积必须非负，容积随势位单调，门槛事件与曲线使用同一表面版本。

### 9.10 M7 发布与验证最小算法

M7 不再计算自然状态，只执行确定性编排：

- 用内容摘要引用不可变层资产；
- 以有向无环依赖图验证世界、参数、模型、输入和层快照闭包；
- 使用规范字段顺序、数字表示和集合排序生成摘要；
- 按依赖拓扑序执行验证器，结果以稳定要求编号归档；
- 对可交换数值归约使用固定分块树与补偿求和策略；
- 离散对象按规范键排序后分配发布索引，索引不反向成为对象身份；
- 所有门槛通过后写入候选根，再以单一不可变根提交发布。

失败复现包只保存必要输入、参数、依赖引用、失败断言和最小覆盖，不依赖原机器绝对路径或线程调度。

### 9.11 确定性规则

算法允许连续浮点值在预注册容差内存在跨平台差异，但以下内容必须完全一致：

- 世界、参数、对象和资产身份；
- 板块邻接、边界类别与能力状态；
- 平台分量、盆地嵌套、门槛事件集合和离散连接；
- 失败分类、发布通过／拒绝结论；
- 随机系数键集合与随机流消费规则。

所有会改变离散决定的浮点比较必须使用统一误差区间、稳定次级键和明确的“不确定／并列”状态。禁止依赖哈希表遍历顺序、线程完成先后、平台数学库的隐式随机行为或非确定性并行归约。

### 9.12 候选算法比较门槛

每个候选按同一顺序评估：

| 门槛 | 内容 | 失败后处理 |
| --- | --- | --- |
| A 契约 | 输入输出、单位、状态所有权和不越权 | 直接淘汰 |
| B 正确性 | PF 解析关系、PV 因果关系和 PI 拒错 | 直接淘汰 |
| C 收敛性 | 加密格网、缩小步长或提高阶数时误差合理下降 | 直接淘汰或保留为实验 |
| D 稳定性 | 面缝、旋转、补丁、分块、线程和跨平台 | 离散不一致则淘汰 |
| E 资源 | 时间、峰值内存、局部更新成本和实现复杂度 | 在 A—D 通过者之间比较 |

性能比较使用同一硬件类别、输入、编译模式和精度策略，并报告中位数与尾部耗时。不能降低分辨率、关闭证据、改变参数或省略失败检查来获得更快结果。

### 9.13 算法实验记录

每次候选实验至少保存：

```text
AlgorithmExperiment
├─ questionAndHypothesis
├─ referenceAndCandidateIds
├─ fixedInputsAndProfiles
├─ expectedRelations
├─ errorAndConvergenceResults
├─ discreteDifferenceReport
├─ determinismReport
├─ timeAndMemoryReport
├─ knownFailureCases
└─ decisionAndReason
```

未入选算法及失败原因同样保留。算法替换必须说明它改变的是误差、性能还是模型语义；若改变模型语义，需要新的模型与参数版本，而不能作为纯优化发布。

### 9.14 首版明确不采用

- 端到端机器学习直接生成高程或拓扑；
- 逐立方球面面独立生成噪声后用视觉接缝掩盖；
- 以侵蚀滤镜代替尚未实现的水文与长期地貌过程；
- 为保证排水而填平盆地或烧入河道；
- 用 GPU 非确定性归约作为唯一权威路径；
- 依赖渲染网格、纹理或图像识别生成科学对象；
- 未经解析与收敛验证的黑箱几何库作为唯一 Oracle；
- 在运行中按结果好坏自动选择不同科学算法。

## 十一、P-D05：原型输出、存储与查询接口

### 11.1 本轮冻结逻辑契约

P-D05 冻结数据的语义、身份、依赖、空间分块和查询行为，不提前冻结编程语言、数据库产品、压缩库或具体文件扩展名。实现技术只有在满足本节契约后，才能在 P-D07 选择。

首个原型采用无界面、文件可持久化的核心发布包，并提供进程内查询接口与等价的命令行操作。桌面应用未来只能作为消费者读取发布，不拥有或重算科学状态。

### 11.2 四类资产

发布中的资产必须标明类别：

| 类别 | 内容 | 是否权威 | 丢失后的处理 |
| --- | --- | --- | --- |
| `AUTHORITATIVE` | 构造、材料、高程、固体表面、拓扑、容器及正式清单 | 是 | 发布不完整，必须拒绝或恢复 |
| `INDEX` | 空间索引、对象查找表、层级目录、查询加速结构 | 否 | 可由绑定的权威资产重建 |
| `EVIDENCE` | 断言结果、误差、来源、故障复现和验收报告 | 不生成自然状态，但决定发布资格 | 缺少必需证据时不能标准发布 |
| `PRESENTATION` | 色带、缩略图、导出网格和诊断图片 | 否 | 可重建，不能供科学消费者回读 |

同一字段不得在多层以 `AUTHORITATIVE` 身份重复保存。为查询而物化的联合视图属于索引或缓存，必须引用原始权威资产与生成器版本。

### 11.3 总发布的逻辑结构

`CORE_PROTOTYPE_V1` 的逻辑资产图为：

```text
TerrainMaterialRelease
├─ WorldIdentity
├─ ParameterAndModelSet
├─ SpatialFrameworkRelease
├─ TectonicRelease
├─ M1InputContractRelease
├─ M2MaterialRelease
├─ M3BaseElevationRelease
```

总发布只保存各层不可变发布引用、依赖闭包和总验收结论。它不把所有字段复制成一个巨型文件，也不选择“各层最新版本”动态拼接。

### 11.4 统一资产头

每个持久化资产必须具有等价于以下内容的统一头：

```text
AssetHeader
├─ assetId
├─ assetClass
├─ schemaId / schemaVersion
├─ producerModelId / algorithmVersion
├─ worldIdentity
├─ layerReleaseId
├─ directDependencyIds
├─ semanticContentHash
├─ encodedByteHash
├─ spatialCoverage
├─ levelAndSupportScale
├─ unitsAndDatum
├─ uncertaintyAndErrorModel
├─ capabilityAndStatus
├─ createdByRunId

```

`semanticContentHash` 标识规范化科学内容，不能因无损压缩方式、文件分包或存储路径变化而改变；`encodedByteHash` 用于发现具体字节损坏。两者用途不同，不能互相替代。

时间戳、机器名、绝对路径和线程数可以进入运行记录，但不得进入世界身份或科学内容摘要。

### 11.5 球面字段的分块

全球字段按以下逻辑键分块：

```text
FieldChunkKey
├─ fieldId
├─ cubedSphereFace
├─ quadtreeLevel
├─ mortonRangeOrTileKey
├─ coreCoverage
├─ haloCoverage
├─ supportScale
└─ sourceReleaseId
```

规则如下：

1. 每个位置在同一层级和同一字段上只有一个核心权威所有者；halo 只是邻域计算副本。
2. 面缝两侧使用同一三维球面位置、邻接变换和规范边界身份。
3. L10 补丁单独保存并引用其 L8 父覆盖，不破坏或覆写父资产。
4. 补丁区分核心、过渡和 halo；只有核心有资格替代相同查询尺度下的父级采样。
5. 分块大小属于工程参数，不能改变随机键、离散对象、聚合结果或语义摘要。
6. 跨块对象和边使用全局稳定身份；规范所有者由身份排序规则决定，不按任务完成先后决定。

### 11.6 连续字段的表示

权威连续字段至少保存：

- 数值与物理单位；
- 垂直基准或向量参考架；
- 支持尺度、波段和有效 LOD；
- 输入误差、离散误差和模型不确定性的独立引用；
- 来源贡献或来源账本引用；
- 覆盖状态与缺失原因；
- 有效范围及是否经过限幅。

首版权威连续计算和持久化精度使用二进制 64 位浮点。未来可以增加量化的展示副本，但不得把有损副本回读为权威输入。

无数据不能只用 `NaN` 或零表示。查询至少需要区分：覆盖外、能力未提供、输入未解析、数值无定义、依赖失败和资产损坏。数值载荷与状态掩码必须共同解释。

### 11.7 离散对象、图与曲线的表示

M5/M6 对象至少分成：

```text
ObjectRecord
├─ stableObjectId
├─ objectRevisionId
├─ objectKind
├─ sourceReleaseId
├─ spatialFootprint
├─ representativeGeometry
├─ scaleAndValidity
├─ uncertainty
├─ properties
├─ lineageRefs
└─ evidenceRefs
```

对象身份不取决于数组下标、文件位置、代表点或补丁加载顺序。图边使用端点稳定身份、边类型、方向条件、势位区间和来源证据；并列门槛与多出口保存集合或事件分量，不强制编号成物理优先级。

面积—势位、容积—势位等曲线保存自变量单位、定义域、节点、分段表示、误差界、拓扑事件和插值规则。客户端不得自行猜测插值方法，也不能把曲线外推到定义域之外。

### 11.9 查询一致性与尺度协商

一次查询会话必须固定：

- 总发布 ID；
- 消费者契约版本；
- 请求的物理支持尺度和允许 LOD；
- 最大误差或允许降级规则；
- 不确定性情景；
- 空间覆盖和资源预算。

查询过程中即使出现新发布，也不能自动切换。若请求尺度无法解析，返回明确的能力不足、可用尺度和误差，不静默换用更粗字段。客户端可以重新提交降级请求，但该决定必须出现在查询记录中。

连续缩放时，桌面消费者可以预取相邻层级，但屏幕上的一次科学检查必须标明当前使用的发布、尺度和误差。视觉插值不得产生新的权威峰、盆地、门槛或材料边界。

### 11.11 无界面原型操作面

P-D05 只定义以下逻辑操作，具体命令名称和序列化格式留到 P-D07：

```text
generate   根据种子和参数档案生成候选层快照
validate   对夹具、层快照或总发布运行验收
publish    验证依赖闭包后原子提交总发布
inspect    查看身份、能力、覆盖、参数和依赖
query      执行字段、区域、对象、拓扑或容器查询
explain    返回来源与证据链
reproduce  从最小复现包重跑指定失败
export     生成明确标为非权威的诊断或交换副本
```

`generate` 完成不等于发布成功；`publish` 只能消费已经冻结并通过要求的候选资产。

### 11.12 持久化、缓存与原子性

物理存储必须满足：

- 不可变、内容寻址和逐资产完整性校验；
- 支持先写临时候选、完成校验后提交单一发布根；
- 中断运行不会让半成品成为可见正式发布；
- 权威资产、索引、缓存、证据和展示物可分别清理；
- 缓存键包含发布、字段、尺度、覆盖、算法和误差要求；
- 删除缓存不改变科学摘要，删除权威资产会使发布不可用；
- 旧发布仍可打开、验证、迁移或明确报告不兼容；
- Windows 与 macOS 对相同规范内容计算相同语义摘要。

压缩、打包和磁盘布局可以不同，但解码后的规范内容必须一致。文件系统原子重命名、嵌入式数据库事务或对象存储提交记录都可作为实现候选，P-D07 再选择。

### 11.13 最小复现包

失败复现包至少包含：

- 世界与夹具身份；
- 模型、算法和参数版本；
- 触发失败的最小空间覆盖及其依赖闭包；
- 随机流键和必要输入；
- 失败断言、期望、实际结果与容差；
- 原始资产内容摘要及读取方式；
- 可在无界面环境运行的复现入口。

复现包不依赖原机器路径，不默认携带整个世界，也不包含与失败无关的展示缓存。若最小化会改变拓扑或随机上下文，则保留能够复现该关系的最小闭合区域并说明原因。

### 11.14 导出与互操作边界

原型可以导出表格、栅格、网格或诊断图，但导出器必须声明：

- 源总发布和源资产；
- 投影、坐标、单位、尺度和重采样方式；
- 被删除或降级的误差、来源、拓扑和身份信息；
- 导出物是否有损；
- 禁止作为权威输入回灌的标志。

交换格式的限制不能反向削弱核心模型。例如普通高度栅格无法保存悬挑、谱系或多出口时，应标明信息损失，而不是修改权威对象使其适配格式。

| 编号 | 验收内容 |
| --- | --- |
| P5-G01 权威唯一 | 每项科学状态只有一个拥有层，联合视图与缓存不复制权威 |
| P5-G02 发布闭合 | 总发布引用同一世界身份下完整、兼容、不可变的依赖闭包 |

| P5-G04 分块不改结果 | 面、块、halo 和任务顺序不改变字段、对象或发布结论 |
| P5-G05 补丁不覆写父级 | L10 补丁单独引用 L8，并保持核心、过渡、halo 和聚合关系 |
| P5-G06 缺失原因明确 | 覆盖外、未提供、未解析、无定义、依赖失败和损坏可区分 |
| P5-G07 对象身份稳定 | 身份不依赖数组下标、文件路径、代表点或加载顺序 |
| P5-G08 查询固定发布 | 一次查询不因新发布、缓存或 LOD 到达而混合快照 |
| P5-G09 尺度不静默降级 | 不可解析时返回能力、可用尺度和误差，由消费者明确重试 |
| P5-G10 消费者不越权 | 气候、水体、桌面和局部三维视图只获得各自最小数据 |
| P5-G11 原子可恢复 | 中断和失败不会暴露半发布，旧发布保持可验证 |
| P5-G12 复现包自包含 | 最小闭合输入可在无界面环境重现同类失败 |
| P5-G13 导出信息损失显式 | 投影、重采样、降级和不可回灌状态均有记录 |
| P5-G14 存储技术可替换 | 逻辑契约不依赖某个数据库、容器格式或操作系统路径 |

## 十三、P-D06：验收、性能与跨平台门槛

### 13.1 验收结论与门槛等级

原型验收不使用一个可互相抵消的总分，而分为三类门槛：

| 门槛 | 内容 | 是否可豁免 |
| --- | --- | --- |
| A 科学与结构硬门槛 | 单位、依赖、预算、拓扑、单调性、解析关系、身份和拒错能力 | 不可豁免 |
| B 发布与跨平台门槛 | 确定性、内容摘要、能力、证据、原子性和 Windows/macOS 一致性 | 标准发布不可豁免 |
| C 性能与资源门槛 | 生成时间、峰值内存、包体积和查询延迟 | 研究运行可记录失败，标准原型发布必须达到 |

最终状态为：

```text
PASS         A/B/C 全部通过，可成为标准 CORE_PROTOTYPE_V1 发布
CONDITIONAL  A 通过，但 B 或 C 的非科学项未通过；只供具名研究消费者
FAIL         任一 A 门槛失败，或资产损坏、依赖不闭合、验证器无效
```

`CONDITIONAL` 不能作为下游气候、水体或桌面应用的默认输入。任何阻断项都必须产生稳定失败编号和最小复现包。

### 13.2 测试集合与样本规模

首版标准验收固定使用：

| 集合 | 数量 | 用途 |
| --- | --- | --- |
| `PF01—PF08` | 8 个解析夹具 | 数值、拓扑、球面与补丁正确性 |
| `PV01-v1` | 1 个综合世界 | 构造至 M7 的正式端到端链 |
| `PI01—PI06` | 6 个故障注入夹具 | 验证拒错、定位和复现能力 |
| `PCAL-v1` | 32 个固定种子 | 参数标定、敏感度和候选比较 |
| `PVAL-v1` | 32 个独立固定种子 | 参数冻结后的保留集验证 |

PCAL/PVAL 的种子表通过独立预注册过程生成并保存摘要。两组不得重叠；查看 PVAL 后根据其结果改参，会使该版本降级为校准数据，并要求建立新的保留集版本。

32 个种子只用于发现明显退化、极端失败和参数不稳定，不足以证明最终类地统计分布。最终产品的统计标定需要更大样本，不能引用原型样本宣称普遍真实性。

### 13.3 L1 球面几何硬门槛

`prototype-grid-v1` 至少满足：

| 指标 | 门槛 |
| --- | --- |
| 单位向量范数 | `|‖p‖−1| ≤ 5×10⁻¹⁴` |
| 全球单元面积闭合 | 全部核心单元面积和相对 `4πR²` 的误差 `≤ 1×10⁻¹⁰` |
| 邻接互反 | 100%，每条边两侧引用一致 |
| 面缝覆盖 | 无缺口、无重叠核心、无重复边 |
| 往返映射 | 面坐标→球面向量→规范面坐标回到同一规范单元 |
| 球面旋转关系 | PF 字段和离散拓扑在规定旋转后保持等价 |
| 补丁聚合 | L10 回聚合后的父级常量、面积与低阶矩误差不超过各自数值容差 |

若所选面积算法的理论舍入界无法达到上述闭合值，必须先给出误差推导和收敛证据，再通过新容差档案调整；不能仅因实现失败放宽门槛。

### 13.4 PF01—PF08 解析验收

首版解析门槛如下：

| 夹具 | 关键门槛 |
| --- | --- |
| PF01 | 相对地形坡度、曲率在数值零容差内；虚假极值、鞍部、脊谷与盆地数量均为 0 |
| PF02 | 主最大区包含解析中心；定位误差不超过当地一个 L8 单元对角线的 0.5；有效域梯度 RMS 相对误差 `≤ 5%` |
| PF03 | 主盆地数量与边界类别正确；抽查势位的容积相对 Oracle 误差 `≤ 1%`；曲线非负单调 |
| PF04 | 鞍部区域数量、四象限上下连接及旋转后的连接同构完全一致 |
| PF05 | 平顶与宽平谷均保持区域表达；内部坡向为未定义；不得产生唯一伪代表点 |
| PF06 | 内外盆地嵌套、合并顺序、同高双门槛、多出口和容量去重完全一致 |
| PF07 | 跨面切向量角误差的第 99 百分位 `≤ 1×10⁻⁸ rad`；重复或断裂走廊为 0 |
| PF08 | L10 细节存在于授权波段；回聚合父均值相对授权幅度误差 `≤ 1×10⁻¹⁰`；粗级离散拓扑不变 |

对 PF02/PF03 的连续误差还需进行至少 L7、L8、L9 三档分辨率收敛实验。在进入渐近区后，线性分辨率减半时关键误差应至少缩小 1.5 倍；若受到输入误差下限限制，报告必须显示平台期而不是继续声称收敛。

### 13.5 PV01 因果与预算门槛

PV01 不按逐点金标准比较，而按预注册区域和关系验收：

- C1 汇聚带内高程中位数高于匹配背景，差值下界大于联合不确定度；
- R1 轴部高程中位数低于两侧肩部，两侧肩部均高于匹配远场背景；
- S1 的 P2/P3 功率和坡度第 90 百分位均低于活动带对应统计；
- T1 的连续材料属性没有超过误差解释范围的无来源跳变；
- X1 保留汇聚与裂谷两个来源及正负账本，任何来源预算超支为零；
- B1 被 M5 识别为闭合盆地，M6 面积与容积曲线非负单调且积分闭合；
- E1 保留同高事件集和多出口，结果不受遍历顺序影响；
- Q1 跨面字段跳变、重复对象、断线和方向翻转均为零；
- H1 细化后粗尺度对象关系和父级预算保持在预注册容差内；
- M7 的依赖、能力、证据和资产摘要全部闭合后才允许发布。

“大于联合不确定度”首版解释为差值的保守下界仍大于零；具体传播使用 P-D03 参数与数值误差模型。若关系只能靠忽略不确定度成立，则视为失败。

### 13.6 预算、曲线和拓扑硬门槛

以下要求采用零容忍或仅允许可证明的舍入误差：

| 类别 | 门槛 |
| --- | --- |
| 来源预算 | 每个来源、区域和波段的消耗不得超过授权上限加数值舍入界 |
| 正负账本 | 正分量、负分量、限幅量和净值可重新结算一致 |
| 容量单调性 | 势位上升时面积与容积不为负，容积不得下降 |
| 积分闭合 | 曲线积分、直接空间积分和层级去重在联合误差内一致；PF03 相对误差 `≤ 1%` |
| 拓扑引用 | 不存在悬空对象、断裂谱系、非法环或跨快照引用 |
| 平坦分量 | 等势区域压缩后严格下降摘要无环，多出口不丢失 |
| 对象唯一性 | 同一发布和尺度下无重复稳定对象，跨块副本均指向规范所有者 |
| 能力诚实性 | 所有排除能力为明确不可用，不能以零值、空对象或展示数据代替 |

### 13.7 确定性与变形验收

对 PF、PV01 及 PVAL 中预选的 8 个种子执行：

```text
线程配置：1、2、4（平台可用时）
分块顺序：规范正序、规范逆序、固定种子乱序
缓存状态：冷缓存、暖缓存、删除可重建索引后重建
空间变形：立方体 24 个定向旋转用于 PF；PV01 使用 6 个预注册旋转
补丁状态：无补丁、加载补丁、卸载并重建补丁
```

同一平台、相同模型与参数下，下列内容要求完全一致：

- 语义内容摘要；
- 随机键及离散随机选择；
- 对象身份、数量、类别、谱系和图连接；
- 门槛事件、平坦分量和发布结论；
- 失败编号和能力状态。

权威连续数组在同一平台应逐位一致；若底层基础数学函数阻止逐位一致，必须改用已登记的确定性数学路径或将该字段标为不满足标准发布，不能把差异留给显示层隐藏。

旋转实验比较旋转后的物理场与对象同构，不要求面编号、存储块编号或展示坐标相同。

### 13.8 Windows/macOS 跨平台门槛

首个跨平台矩阵至少包含：

- 一个受支持的 Windows x86-64 环境；
- 一个受支持的 macOS Apple Silicon 环境；
- 相同模型、参数、夹具、种子与发布模式；
- 相同二进制浮点精度和确定性算法配置。

跨平台必须完全一致的内容：世界身份、参数摘要、随机键、能力状态、离散对象与拓扑、失败分类和发布结论。

连续值使用字段专用的统一比较式：

```text
|a-b| ≤ absoluteTolerance + relativeTolerance × max(|a|, |b|)
```

原型起始容差：

| 字段类型 | 绝对容差 | 相对容差 |
| --- | --- | --- |
| 高程／距离 | `1×10⁻⁶ m` | `1×10⁻¹²` |
| 无量纲材料代理／权重 | `1×10⁻¹²` | `1×10⁻¹²` |
| 坡度与曲率的无量纲中间量 | `1×10⁻¹⁰` | `1×10⁻¹¹` |
| 面积／容积 | 按输入尺度推导，不使用一个全球绝对值 | `1×10⁻¹¹` |

这些是跨平台复现容差，不是科学近似误差。若跨平台差异足以改变任何离散决定，即使连续值仍在表中容差内，也视为失败。

### 13.9 故障注入门槛

PI01—PI06 必须全部满足：

1. 验证器返回预期的主失败类别；
2. 失败定位包含目标资产、空间范围或依赖边；
3. 标准发布被拒绝；
4. 生成最小复现包；
5. 修复注入后同一基础资产恢复通过；
6. 不以崩溃、超时、进程异常退出或无关前置错误算作命中。

另外对验证器本身执行反向自检：删除目标断言或替换为空实现后，相关 PI 必须使自检失败，避免“测试永远通过”。

### 13.10 统计保留集门槛

PVAL-v1 不要求每颗世界拥有相同地貌，但要求：

- 32 个世界全部完成依赖闭包，或对失败给出预注册允许的明确原因；
- 非预期崩溃、非有限值、资产损坏和发布半成品数量为 0；
- 来源预算超支、容积下降、非法拓扑引用和能力伪装数量为 0；
- 至少 95% 的世界通过所有适用因果方向关系；
- 高程、坡度、频谱功率、相关长度、盆地数量与尺度没有超出 P-D03 诊断包络的未解释离群值；
- 参数小扰动的输出方向与敏感度报告一致，不出现大量无解释拓扑翻转；
- 失败世界不得从集合中删除，必须作为版本化反例保留。

“至少 95%”在 32 个样本上意味着最多允许 1 个世界只在非硬性的适用因果关系上失败；该失败仍需解释。所有硬门槛继续要求 32/32 通过。

### 13.11 原型性能与资源门槛

定义 `reference-cpu-profile-v1`：本地桌面级 8 个逻辑 CPU、16 GiB 可用内存、固态存储、无 GPU 科学计算。具体基准机器与编译配置在 P-D07 登记，但不得针对不同平台使用不同科学参数。

在该档案上，首版目标为：

| 操作 | 门槛 |
| --- | --- |
| PV01 从输入到 M7 候选生成 | 墙钟时间 `≤ 15 min` |
| PV01 完整标准验收与发布 | 墙钟时间 `≤ 25 min` |
| 峰值常驻内存 | `≤ 8 GiB` |
| 权威发布包加必需证据 | `≤ 10 GiB` |
| 单点暖查询 | 第 95 百分位 `≤ 50 ms` |
| 对象详情与一跳拓扑查询 | 第 95 百分位 `≤ 200 ms` |
| 10 万采样点区域／剖面查询 | 第 95 百分位 `≤ 2 s` |
| 失败复现包启动至同类失败 | 常规局部失败 `≤ 60 s`；全局依赖失败 `≤ 5 min` |

端到端生成与验收至少进行 5 次独立进程运行，报告各次结果、中位数和峰值内存。查询延迟在每个独立进程中对每类操作执行至少 1,000 个预注册请求，分别报告暖缓存第 50／95／99 百分位；冷缓存另行报告，不混入暖查询分布。所有结果记录后台负载和存储状态。首次原型允许性能门槛导致 `CONDITIONAL`，但不得通过降低 L8/L10 规格、跳过层、关闭证据或使用有损权威数据达标。

### 13.12 查询与存储验收

P-D05 的接口至少验证：

- 同一查询会话不会在新发布出现后改变总发布 ID；
- 删除索引或缓存后重建，权威查询和语义摘要保持一致；
- 随机截断候选写入时，正式发布根不可见；
- 篡改单个字节能由字节摘要发现，重编码无损内容不改变语义摘要；
- 请求不可用尺度会返回明确能力与可用范围，不静默降级；
- 导出再读不能以默认方式成为权威输入；
- 权威资产缺失时发布不可打开为完整状态；
- 旧发布与新发布可以同时查询，且一次会话不混用对象修订。

### 13.13 验收报告与证据完整性

标准报告至少包含：

```text
PrototypeAcceptanceReport
├─ releaseCandidateId
├─ worldAndProfileIds
├─ platformAndBuildIdentity
├─ requirementResults
├─ fixtureResults
├─ convergenceResults
├─ determinismAndMetamorphicResults
├─ crossPlatformComparison
├─ calibrationAndHoldoutStatus
├─ performanceAndResourceResults
├─ injectedFailureResults
├─ exceptionsAndNonBlockingWarnings
├─ reproductionPackages
└─ finalDecisionAndBlockingReasons
```

每个 `PASS` 必须引用实际证据资产。缺少证据等同未执行，不得写成通过。报告生成器和验证器版本也进入证据图。

### 13.14 不稳定测试与门槛变更

- 同一输入偶发通过、偶发失败时，正式结果为失败；不能重试择优。
- 基础设施故障与科学失败分开分类，但前者仍不能生成通过报告。
- 门槛修改需要理由、影响分析、新容差档案和受影响测试全量重跑。
- 查看失败结果后修改门槛，不得覆盖旧报告。
- 性能基准机器更新时保留旧档案，并通过重叠机器运行建立可比关系。
- 自动接受新的金标准输出是禁止操作；离散基准变化必须人工审阅原因和语义差异。

## 十五、P-D07：实施顺序、里程碑与技术栈冻结

### 15.1 实施原则

原型采用“垂直里程碑加阻断门”的推进方式。每个里程碑必须：

- 产生可运行、可查询、可版本化的最小资产；
- 使用已经定义的 PF/PV/PI 验收，而不是临时演示图；
- 提交算法身份、参数、误差、能力和已知限制；
- 通过本阶段退出条件后，下一阶段才能依赖其正式资产；
- 未完成能力返回明确状态，不能用空值或临时数据补齐；
- 如果发现架构语义错误，回到文档修订并升版本，不在代码中添加隐含例外。

实现仍需遵守“修改代码前先给出具体方案并取得确认”的工作规则。P-D07 确认只代表工程路线获得认可，不等于授权立即创建或修改代码；进入每个实施里程碑前仍需提交该里程碑的代码改动方案。

### 15.2 技术栈建议

首个核心原型建议采用：

| 范围 | 建议 | 理由 |
| --- | --- | --- |
| 核心语言 | Rust 稳定工具链 | 跨平台、本地性能、明确数据所有权、适合不可变资产和并行分块 |
| 工程组织 | Cargo workspace，多库加一个无界面 CLI | 层边界可测试，核心不依赖桌面应用 |
| 权威浮点 | IEEE 754 binary64 | 与 P-D02/P-D06 一致，便于误差分析 |
| 线性代数 | 小型三维／矩阵库封装在内部数学接口后 | 避免第三方类型泄漏到发布契约 |
| 并行 | 确定性任务图加数据并行工作池 | 并行只改变调度，不改变随机流、归约树和身份 |
| 元数据 | UTF-8 规范 JSON，遵循确定性规范化规则 | 人工可查、跨语言，适合清单、模式和报告 |
| 连续字段 | 版本化头加规范顺序的小端 binary64 分块 | 直接、可流式、容易验证字节与语义摘要 |
| 对象／图／曲线 | 按稳定身份排序的规范记录流 | 保留对象身份、引用和事件，不依赖数据库行号 |
| 完整性摘要 | SHA-256 | 跨平台、成熟、便于外部工具验证 |
| 压缩 | 可选 Zstandard 封装 | 压缩字节不进入语义摘要，可更换或关闭 |
| 查询索引 | 原型采用可重建的嵌入式索引候选 | 索引不是权威，具体库由存储验证决定 |
| 参考 Oracle | 独立 Python 环境，仅用于解析／高精度验证 | 与 Rust 正式实现保持路径独立，不进入运行时 |
| 自动化 | Windows 与 macOS 原生构建和无界面测试 | 直接验证目标平台，不以容器模拟替代全部证据 |

“规范 JSON”只允许有限数值；未定义、未知和失败使用显式状态，不能把 `NaN`、无穷或缺字段当作语义。连续数组以固定端序、固定字段顺序和固定掩码解释，压缩前内容用于语义摘要。

Rust 是建议的首选，不在 P-D07 方案确认时立即成为不可更改结论。它需要通过 15.4 的技术验证，才在 E0 结束时正式冻结。若失败，应基于同一验证记录比较 C++ 等备选，不得因团队偏好直接替换。

### 15.3 建议的核心工程边界

未来工程建议使用以下逻辑模块；实际目录名称在创建工程前再次确认：

```text
workspace
├─ contracts       共享身份、单位、状态、模式和错误
├─ sphere          等角立方球面、四叉层级、邻接和度量
├─ tectonics       壳体域、欧拉运动、边界资格和构造输出
├─ materials       连续材料先验与材料柱
├─ elevation       M3 基础高程和贡献图
├─ relief          M4 带限起伏、预算和补丁
├─ topology        M5 几何字段、平台与对象图
├─ containers      M6 曲线、门槛和潜在连接
├─ release         M7 资产、证据、验收和原子发布
├─ query           固定发布的字段、对象和解释查询
├─ cli             生成、验证、发布、查询和复现入口
├─ schemas         版本化数据模式与兼容性测试
├─ fixtures        PF/PV/PI/PCAL/PVAL 固定输入
└─ reference       独立 Oracle 与离线比较工具
```

依赖方向必须与自然状态一致：`contracts/sphere` 为底座，构造先于材料与地形，M1—M7 单向推进。`query` 只读发布，`cli` 负责组装，不允许低层反向依赖 CLI、展示或桌面模块。

不为每个文档概念都创建独立包。只有需要独立版本、测试边界或依赖隔离的部分才拆分；工程拆分不得改变已确认的状态所有权。

### 15.4 E0 前置技术验证

创建正式实现前，先用可丢弃的最小实验验证五项高风险假设：

| 编号 | 技术验证 | 最小成功条件 |
| --- | --- | --- |

| TS02 确定性数学 | 随机键、球谐系数、固定归约在 Windows/macOS 比较 | 离散结果一致，连续值满足统一容差 |

| TS04 容器积分 | PF03/PF06 的分片积分、事件和层级去重 | 单调、积分和嵌套门槛通过 |

### 15.5 里程碑 E0：工程与契约底座

范围：

- 冻结首版工具链、依赖锁定和跨平台构建；

### 15.6 里程碑 E1：L1 球面空间与查询底座

范围：等角立方球面、L8 全球格、L10 补丁、稳定身份、邻接、距离、面积、切空间和基础分块查询。

主要夹具：PF01、PF07、PF08 的几何部分，以及 PI01。

退出条件：

- L1 几何硬门槛全部通过；

### 15.7 里程碑 E2：最小构造与 M1

范围：球面种子域、Voronoi 壳体域、欧拉运动、边界相对速度、汇聚／张裂／稳定资格，以及 M1 世界身份、参数档案、随机流和运行清单。

- PV01 的 C1/R1/S1 构造资格和方向关系成立；

### 15.8 里程碑 E3：M2 材料与 M3 基础高程

范围：连续材料背景、有限材料柱、区域基底、汇聚／裂谷核响应、贡献图、预算组合和材料放置。

退出条件：

- 活动带与稳定域的因果方向关系带不确定度通过；
- 材料过渡无无来源台阶，修饰保持有界；

- 材料放置不反馈同轮高程。

### 15.9 里程碑 E4：M4 多尺度起伏与补丁

主要夹具：PF08、PV01 的 Q1/H1、PI03，以及球谐跨平台实验。

退出条件：

- 频带、功率、父子矩和预算闭合；
- 面缝连续，无逐面噪声接缝；
- 补丁加载、卸载、重建不改变粗尺度结论；
- 线程、分块和平台不改变随机键及离散状态；
- M4 固体表面可由 M5 受限视图读取。

### 15.10 里程碑 E5：M5 几何与拓扑

范围：两种尺度的切平面拟合、梯度／曲率、关键区域、脊谷走廊、坡面、平台、盆地合并树、对象身份与谱系。

主要夹具：PF01—PF08，重点为 PF02—PF06；PI05。

退出条件：

- 解析导数、定位与收敛门槛通过；

- 对象身份不随块、补丁、线程或代表点改变；
- M5 不修改表面、不填洼、不生成水文语义；

### 15.11 里程碑 E6：M6 容器与潜在连接

范围：面积／容积／接触曲线、控制门槛、同高事件、嵌套去重、严格下降、平坦分量和 minimax 屏障查询。

### 15.12 里程碑 E7：M7 总发布与完整查询

范围：M1—M6 依赖闭包、能力矩阵、证据图、消费者视图、完整查询接口、原子总发布和最小复现。

主要夹具：PV01、PI01—PI06、查询与存储验收。

退出条件：

- PI01—PI06 全部准确命中并可复现；
- 冷暖缓存和索引重建不改变权威结果；
- 查询固定发布、尺度、误差和情景；
- 资产损坏、依赖缺失和中断提交全部被拒绝；
- 可产生一个 `CORE_PROTOTYPE_V1` 候选，但尚不宣告最终通过。

### 15.13 里程碑 E8：标定、保留集与跨平台发布

范围：PCAL 标定、敏感度、参数冻结、PVAL 验收、Windows/macOS 比较、性能优化和最终报告。

顺序固定为：

```text
PCAL 标定
  → 参数候选冻结
  → PVAL 首次运行
  → 跨平台比较
  → 不改变科学参数的性能优化
  → 全量回归
  → 标准发布决定
```

退出条件：

- P-D06 的 A/B/C 门槛全部通过；
- PVAL 未被用于回调本版参数；
- Windows/macOS 离散结论一致、连续值在容差内；
- 性能优化未改变语义摘要或科学结论；
- 验收报告、复现包、已知限制和下一切片建议完整；
- M7 原子提交首个正式 `CORE_PROTOTYPE_V1`。

### 15.14 每个里程碑的工作循环

每个里程碑内部执行：

```text
确认本里程碑代码方案
  → 冻结输入与退出断言
  → 实现最小纵向能力
  → 先跑解析／结构夹具
  → 再跑综合与故障夹具
  → 记录性能与限制
  → 审阅证据并决定通过、返工或修订规格
```

不得同时大规模实现多个未通过的相邻层。可以并行研究独立算法，但正式资产只能依赖已经通过退出门的上游里程碑。

### 15.15 依赖与版本管理

- 工具链和第三方库使用锁文件固定精确版本；
- 数学、序列化、压缩和摘要库升级必须重跑相应 PF、跨平台和摘要兼容测试；
- 权威模式遵循显式版本与迁移，不使用隐式结构反射作为永久格式；
- 第三方库类型不能出现在稳定消费者契约中；
- 可重建索引可以升级重建，权威资产迁移必须保留旧内容与来源；
- 构建应能在无网络环境使用已经锁定的依赖完成；
- 依赖许可证与 Windows/macOS 分发条件在 E0 登记。

### 15.16 桌面应用与局部三维的冻结时点

桌面应用不进入 E0—E8 的标准原型通过条件。核心在 E7 必须提供稳定的只读查询契约和 `Local3DAnchorView`，但桌面框架、渲染引擎和打包方式在核心正式发布后单独决策。

当前可保留的候选方向是：

- Rust 核心直接复用；
- 跨平台桌面壳负责窗口、任务管理和文件选择；
- GPU 渲染只消费 `ExplorationView`，不参与科学计算；
- 三维球体和局部地形从同一固定发布查询；
- 局部三维组件以后通过锚区接口扩展，不改变全球单值表面语义。

在选择桌面技术前，需要用 E7 查询接口完成独立的连续缩放、分块流送和内存预算验证。避免为某个 UI 框架反向修改核心存储或对象身份。

### 15.17 首个原型之后的顺序

`CORE_PROTOTYPE_V1` 通过后，建议按以下顺序扩展：

1. 扩大构造类型、材料表达和 P4 局部细节；
2. 建立气候子引擎前置条件和最小垂直切片；
3. 建立实际水量、海平面、湖泊和河网的水体／水文切片；
4. 生成地貌语义与覆盖层；
5. 构建连续缩放桌面观察器；
6. 再扩展完整局部三维、洞穴和地下水结构。

每一步仍使用独立快照与显式反馈，不把下游结果直接写回当前权威发布。

### 15.18 P-D07 不允许的实施方式

- 先搭建桌面界面，再用临时高度图等待核心补齐；
- 一次实现所有 L/M 层后才运行端到端测试；
- 未通过 TS 技术验证就冻结难以替换的存储或数学库；
- 为赶里程碑绕过正式接口、证据或发布门；
- 在同一个提交中同时改变模型语义、参数和优化而不分开验证；
- 让 Python Oracle 成为正式运行时依赖或复用 Rust 核心逻辑；
- 为不同操作系统维护不同科学模型或参数；
- 将缓存、数据库索引或渲染资源升级为权威状态；
- 因性能不足降低已冻结的科学测试规模；
- 未经方案确认直接开始代码修改。

## 十七、P-D01—P-D07 总体一致性复核

### 17.1 范围与实施一致

- P-D01 的最小垂直切片与 P-D07 的 E0—E8 顺序一致；每个必需层都有实施里程碑。
- 气候、水文、实际海陆、完整地貌语义、局部三维内部和桌面应用始终保持排除状态。
- P-D07 没有通过工程模块新增 P-D01 未授权的自然能力。

### 17.2 输入、参数与测试一致

- P-D02 的 PV/PF/PI 资产分别对应综合、解析和拒错，不互相替代。

- 任何研究覆盖、参数档案和夹具版本都进入 P-D05 的世界与资产身份。

### 17.3 算法、数据与验收一致

- P-D04 每项最小算法都有 P-D02/P-D06 对应夹具、收敛关系或故障注入。
- P-D05 的权威资产、索引、证据和展示分类与 M7 已确认所有权一致。
- P-D04 的参考／候选双轨制不会让 Oracle 成为正式运行时依赖。
- P-D05 的语义摘要、固定发布查询和原子提交支持 P-D06 的确定性及跨平台验收。

### 17.4 单向依赖与反馈边界一致

完整原型链保持：

```text
空间与构造
  → M1 输入契约
  → M2 材料背景
  → M3 基础高程
  → M4 原生固体表面
  → M5 几何拓扑
  → M6 固体容器接口
  → M7 总发布
```

材料最终出露不反馈同轮高程，M5/M6 不修改表面，M6 不拥有水量，M7 不复制权威自然状态，查询与桌面不回写科学发布。未发现同快照循环依赖。

### 17.5 身份、尺度与确定性一致

- 球面单元、对象修订、跨尺度谱系、层发布与总发布身份彼此分开。
- LOD 是采样资格，P2/P3 和 320 km／80 km 是物理尺度；两者没有互相替代。
- 随机键、分块、线程、缓存和显示状态不进入自然语义。
- 同平台逐位确定性、跨平台连续容差和离散完全一致的要求边界明确。

### 17.6 尚未解决但不构成规格冲突的事项

以下内容必须由 T0/E0 或后续标定给出证据，当前不宣称已经成立：

- Rust 与候选数学库能否达到跨平台确定性目标；
- 球谐场在 L8/L10 原型规模上的时间和内存成本；
- 平台感知拓扑与容器积分的实际收敛和稳定性；
- 规范记录、语义摘要与索引重建的工程复杂度；
- P-D03 名义参数是否能通过 PCAL/PVAL；
- P-D06 性能目标是否需要在不改变科学规模的前提下优化；
- 桌面应用、三维渲染和局部三维组件的最终技术栈。

这些事项均有对应技术验证、里程碑或后续子引擎入口，不需要修改当前状态所有权。

### 17.7 复核结论

P-D01 至 P-D07 在范围、依赖、参数、算法、数据、查询、验收和实施顺序上保持一致，未发现阻止进入 T0 技术验证的架构矛盾。本文版本提升为 1.0，表示规格决定完成，不表示任何代码、夹具、参数标定或跨平台验证已经完成。
