> **文档状态**
>

> - 决策状态：已确认

本文讨论地形与材料子引擎的 M6“固体容器与水体边界接口层”。M6 把 M5 已发布的固体表面、盆地—鞍部拓扑和几何对象整理为可供水体边界求解器、水文系统及地图语义层使用的容器接口。它计算“如果某个等势液面达到某一门槛，固体几何能够容纳多少空间、在哪里越界以及可能与哪些容器连通”，但不决定实际有多少水，也不生成海洋、湖泊、河流或湿地状态。

## 一、M6 的职责与边界

### M6 负责

- 只读取兼容且 `PASS + RELEASED` 的 M5 正式发布。
- 读取版本化垂直基准、有效重力方向和允许的等势面代理。
- 将 M5 几何盆地转换为可查询的固体容器接口。
- 生成面积—势位、容积—势位和边界接触关系等反事实几何曲线。
- 建立控制鞍部、几何溢出门槛、容器邻接与合并事件。
- 提供只依赖固体形状的潜在下坡连通、几何屏障和低位通道。
- 提供全球水体边界求解所需的固体表面分布和连通事件输入。
- 传播尺度、覆盖、材料、断点、补丁和几何误差。
- 保持容器、门槛、屏障和路径对象的稳定引用及来源证据。

### M6 不负责

- 创建或修改 M4 权威固体高程、M5 几何对象及其拓扑。
- 决定全球总水量、海平面、海洋覆盖或最终海陆状态。
- 计算降水、蒸发、径流、入渗、地下水位、季节蓄水或洪水过程。
- 将几何溢出门槛直接认定为正在出流的水文出口。
- 将潜在下坡路径直接认定为河道、溪流或暗河。
- 根据低于某个高度直接生成海洋、湖泊、沼泽或湿地。
- 根据材料渗透性单独判定容器会蓄水或漏水。
- 为获得连通水系而填洼、切开鞍部或烧入河道。

### 2.1 正式输入


`VerticalAndGravityReference` 必须来自与 M1/M5 相同世界身份的版本化基准。它描述当地“上”方向、用于液面比较的有效重力势或经验证近似，以及适用范围和误差。M6 不从气候、水量或目标海平面反推该基准。

## 四、M6-D01：状态所有权与系统边界

### 4.1 M6 是固体接口层

M5 回答“固体表面有哪些几何区域和拓扑关系”，M6 回答“这些几何关系可为假设液面和潜在重力运动提供什么容器接口”：

```text
M5 已发布固体几何
  → M6 固体容器、门槛、屏障和潜在连通接口
  → 独立水体边界求解器使用全球水量或指定势位求水体覆盖
  → 水文系统结合气候、材料与时间状态求流动和蓄水
  → 地貌语义层综合证据命名海洋、湖泊、河流、湿地等
```

M6 的曲线与图都是反事实查询结构。例如“势位达到 `φ` 时容器几何体积为 `V`”并不表示世界当前拥有这部分水，也不保证固体边界不渗漏。

### 4.2 四类状态必须分离

以下状态不得混成一个“水面高度”字段：

1. **固体边界状态**：M4/M5 拥有的地形表面、盆地、鞍部和断点。
2. **容器接口状态**：M6 拥有的面积／容积曲线、几何门槛、邻接和潜在路径。
3. **水体边界状态**：独立求解器拥有的实际液面势位、水体覆盖、海洋连通和岸线。
4. **水文过程状态**：水文系统拥有的水量收支、流量、季节变化、入渗、地下交换与洪泛。

它们可以引用同一个盆地对象，但必须属于不同快照和所有者。下游变化不能反向改写已经发布的 M6 容器接口；若侵蚀、沉积或坍塌改变固体表面，则从新的演化地表快照重新生成相应 M5/M6 快照。

### 4.3 从 M5 盆地到 M6 容器

M5 的 `basinObject` 是固体低位连通与控制鞍部关系。M6 在以下条件满足时，才为其建立正式容器：

- M5 对象为正式规范对象，而非未解决的补丁候选；
- 边界、最低区域和控制门槛具有足够覆盖；
- 垂直与重力基准兼容；
- 固体表面采样支持目标势位和精度；
- 误差足以给出有效的面积、容积与接触区间；
- 所需局部三维边界若未提供，能力清单明确说明缺失。

未满足条件时返回 `PROVISIONAL_CONTAINER`、`PARTIAL_CONTAINER` 或 `UNRESOLVED_CONTAINER`，不能用插值、默认封闭或假想边界补齐。

并非每个 M5 低地候选都需要成为标准容器。低显著性微洼地可保留诊断接口；是否参与某个水文尺度的求解由消费者根据能力与尺度选择，M6 不删除它们。

### 4.4 等势液面而非等球心半径

静止液面趋向有效重力等势面。对于旋转、自转扁率或重力异常存在的行星，简单使用相同球心半径或相同原始高程，可能产生错误的全球连通顺序。因此 M6 的容器门槛和曲线使用统一势位参数：

```text
φ = effectiveGravityPotential(position)
```

或使用与它单调等价、经过版本化定义的“等势高程”。首版允许类地近似，但必须声明：

- 重力／旋转模型版本；
- 近似适用的空间尺度和高度范围；
- 从 M1 垂直基准到势位坐标的转换；
- 转换和模型误差；
- 在误差可能改变连通顺序时返回不确定事件。

显示使用的海拔、高程夸张或地图投影不能充当液面势位。M6 也不能通过预设目标海岸线反向扭曲重力基准。

### 4.5 M6 拥有的权威对象

M6 可以拥有以下绑定 M5 快照的派生对象：

```text
solidContainer
containerThresholdEvent
equalControlThresholdSet
containerMergeRelation
geometricBarrierInterface
potentialPassageInterface
potentialDownhillConnection
globalLevelSetConnectivityEvent
```

这些对象的身份和修订遵守 M5-D06 的谱系原则，但属于 M6 命名空间。M5 盆地身份不能直接复用为 M6 容器身份，因为一个 M5 几何对象可能：

- 因覆盖不足尚不能形成正式容器；
- 在不同势位区间对应多个容器阶段；
- 与并列控制门槛形成一个复合接口；
- 在局部三维边界加入后产生新的容纳或连通分支。

M6 对象必须反向引用 M5 来源，不得反向修改 M5 对象或身份。

### 4.6 几何门槛不等于正在溢流

M6 的 `containerThresholdEvent` 表示假设液面势位达到某值时，固体边界首次允许与相邻低位区域接触。它不证明：

- 容器中已有足够水量；
- 当前水位已经达到门槛；
- 门槛处存在持续流量；
- 材料不会渗漏或破坏；
- 下游路径可输送该流量；
- 门槛已经因侵蚀形成河道。

因此接口应使用 `geometricThreshold`、`potentialPassage` 等中性名称。只有水体边界和水文求解完成后，才可以派生实际溢流、出口、河道或洪泛状态。

### 4.7 潜在路径不等于河网

M6 可以根据有效重力势、M5 谷线／坡面和容器门槛建立潜在下坡连接。该图表达“若有可移动介质并满足过程条件，几何上可能朝哪些方向移动”。它必须允许：

- 平坦区中的多个同等方向；
- 分流、汇合和并列通道资格；
- 误差导致的多候选连接；
- 断点和屏障两侧的未知关系；
- 无可信下坡方向的封闭或未解析状态。

M6 不在此图上分配水量，不选择唯一河道，也不为了获得无环单流向树而填洼。实际河网可以与潜在路径不同，因为降水、材料、侵蚀、植被、沉积和历史过程尚未加入。

### 4.8 固体屏障与材料边界

M6 可以声明：某一固体表面或局部三维结构在几何上隔开两个空间，某个鞍部或开口在特定势位下提供通道。材料信息只能作为下游接口证据：

```text
geometricBarrierState
materialPermeabilityEvidence
fractureAndOpeningEvidence
validityScale
uncertainty
```

M6 不把低渗材料直接判为绝对隔水层，也不把高渗材料直接判为泄漏通道。水力传导、饱和状态、压力和地下交换属于水文或地下水系统。

### 4.9 与水体边界求解器的边界

独立水体边界求解器至少同时读取：

- M6 的全球固体容器和连通接口；
- L2 或世界环境提供的全球水量、指定液面势位或边界条件；
- 必要的冰、水汽或地下储量分配假设；
- 求解模型、时间状态和误差策略。

它输出实际水体覆盖、连通分量、液面、岸线和剩余水量账本。M6 不缓存这些结果为自己的权威状态。相同 M6 快照可以被不同水量情景重复使用，并得到不同海洋或内陆水体分布。

这保证低于全球海平面的封闭陆地盆地不会仅因高程较低就自动成为海洋；只有水体求解证明液面覆盖并具有相应连通关系时，才能获得水体状态。

### 4.10 与水文系统的边界

水文系统在 M6 接口上继续计算：

- 降水、融雪、蒸发和植被截留；
- 地表径流、入渗、地下水和泉流；
- 河流流量、分流、河中岛、漫流和三角洲；
- 湖泊季节涨落、溢流时序和干涸；
- 侵蚀、搬运与沉积造成的后续表面变化。

M6 只提供固体几何约束和潜在连接。水文系统不能把自己的数值填洼面伪装成 M6 原始容器；如需算法辅助面，应作为水文派生状态并保留与 M6 原始几何的差异。

### 4.11 快照与反馈边界

M6 输出为不可变派生快照：

- M5 快照变化会使相关 M6 快照过期；
- 重力或垂直基准变化创建新 M6 快照；
- 水量、气候或季节变化不使 M6 固体接口失效；
- 侵蚀、沉积、坍塌或构造变化只有形成新的权威固体表面后，才触发新一轮 M5/M6；
- 下游不得把实际岸线、河道或湖面写回旧 M6 快照；
- 显示抽稀和查询缓存不改变容器身份。

这形成跨时间的显式迭代：

```text
原生／演化固体快照 t
  → M5 几何拓扑 t
  → M6 固体容器接口 t
  → 水体与水文状态 t
  → 经过程模型形成新的演化固体快照 t+1
```

不存在同一快照内部的隐藏反馈。

### 4.12 不允许的快捷方式

M6-D01 不允许：

- 把高程小于零直接解释为海洋；
- 在 M6 内输入一个水量后把结果保存为固体容器事实；
- 把控制鞍部直接标为实际水文出口；
- 把潜在下坡连接直接发布为河网；
- 用单流向填洼结果替代 M5 原始盆地拓扑；
- 用相同球心半径无条件替代有效重力等势面；
- 根据材料标签直接决定蓄水或漏水；
- 用补丁边界封闭容器或把它当作流出世界的出口；
- 将下游岸线、水位或季节状态回写 M6；
- 为匹配期望海陆比例修改固体表面或重力基准。

## 五、M6-D01 确认结论

M6-D01 已确认：将 M6 定义为只读固体接口层；它从 M5 几何和版本化重力／垂直基准派生容器、门槛、屏障及潜在下坡连接，但不拥有水量、水位、海陆、水文过程或成熟地貌。面积和容积等查询使用有效重力等势坐标或声明误差的等价近似，而非无条件使用球心半径。几何门槛不等于实际溢流，潜在路径不等于河网，材料和表面封闭也不直接证明水力封闭。下游过程若改变地形，必须通过新的固体表面、M5 和 M6 快照形成显式下一时刻。

## 六、M6-D02：面积—势位、容积—势位与边界接触曲线

### 6.1 统一液面坐标

M6 为每个容器建立以等势液面为自变量的几何曲线。为了让曲线具有直观长度单位，建议定义版本化的等势高程坐标：

```text
ζ = (φ - φref) / gref
```

其中 `φ` 是有效重力势，`φref` 是参考等势面，`gref` 是声明的参考重力。`ζ` 与 `φ` 单调等价，单位为米，但不等于任意位置的球心半径差。每条曲线必须携带：

- 势模型、旋转模型、参考等势面和 `gref`；
- `ζ ↔ φ` 的转换与适用范围；
- 当前容器允许查询的最小、最大势位；
- 势模型和转换误差；
- 若使用类地简化高程，简化的有效尺度和失败条件。

同一曲线中的所有几何量使用同一个 `ζ` 定义。禁止把局部海拔、球心半径、显示高度和有效重力势混用。

### 6.2 四类不同的几何量

在假设液面 `ζ` 下，至少区分：

```text
freeSurfaceArea(ζ)       # 容器内等势液面截面的面积
containedVolume(ζ)       # 固体边界与假设液面之间的三维体积
wettedSolidArea(ζ)       # 低于液面的固体接触表面积
boundaryContact(ζ)       # 液面与固体相交的线／区域及其拓扑
```

四者不能共用一个含糊的“水面面积”：

- `freeSurfaceArea` 用于体积增量、表面通量和边界求解；
- `containedVolume` 表示几何容量，不代表实际储水量；
- `wettedSolidArea` 可供蒸发、渗漏或材料接触模型参考，但不决定过程强度；
- `boundaryContact` 描述潜在岸界、接触分支和门槛事件，不是最终岸线。

如果局部三维能力未提供，曲线只覆盖已声明的全球单值表面部分，并显式排除洞腔、悬挑下空间及未解析孔洞。

### 6.3 容积和面积的基本关系

使用等势高程 `ζ` 时，在没有拓扑事件的光滑区间内应满足：

```text
d containedVolume / dζ ≈ freeSurfaceArea × metricCorrection
```

`metricCorrection` 由有效重力、等势面几何和坐标定义确定；在采用严格体积保持的等势高度坐标时可归入面积定义。若直接以重力势 `φ` 为自变量，则导数包含局部 `1 / |g|` 权重，不能简单令 `dV/dφ = A`。

数值实现必须联合验收面积曲线与体积积分：

- 容积非负且随势位单调不减；
- 自由液面面积非负；
- 区间体积增量与面积积分在误差内一致；
- 最低可容纳势位处容积趋近于零或声明的局部三维初始腔体积；
- 曲线不得因插值出现负面积、负体积或局部回退。

### 6.4 曲线定义域与容器阶段

一个 M5 盆地在不同势位可能经历多个 M6 容器阶段：

```text
独立低位容器
  → 达到第一控制门槛
  → 与相邻容器合并为复合容器
  → 达到更高门槛
  → 并入更大父容器
```

每个阶段具有半开或闭合的势位定义域、来源盆地集合和控制事件。曲线必须说明查询值属于：

- 当前子容器的局部容量；
- 合并后复合容器的总容量；
- 相对于控制门槛新增的增量容量；
- 只供诊断的未闭合部分。

消费者不得把不同阶段的局部曲线直接拼接为一条累计曲线，也不能在父、子容器间重复计算同一空间。

### 6.5 排他容量与并集容量

为避免嵌套盆地和合并容器重复计量，M6 同时提供：

```text
exclusiveVolume(ζ)    # 只归属于当前容器阶段、未计入子阶段的体积
inclusiveVolume(ζ)    # 当前容器及其有效子容器空间并集的体积
```

并集计算按三维空间支持区求并，不按各曲线数值盲目相加。应满足：

- 子容器的排他空间互不重叠；
- 父容器的包含容量等于有效排他空间的并集体积；
- 合并门槛两侧的总体积在误差内连续；
- 门槛事件可以改变面积、边界分支和导数，但不能凭空创造或删除有限体积；
- 等价控制门槛同时处理，不按遍历顺序逐个产生伪中间阶段。

### 6.6 平坦底、平台和宽鞍部

当大面积固体表面恰处于相同或误差内等势位时：

- `freeSurfaceArea` 或边界接触可以在该势位发生有限跳变；
- `containedVolume` 仍应保持连续；
- 平坦底首次被覆盖时，零深度接触面积与正体积必须分开；
- 宽鞍部使用一个门槛区域和势位区间，不展开为大量顺序不稳定的小事件；
- 误差无法确定接触顺序时，返回事件簇和上下界，不强制排序。

曲线表示必须支持单侧值和事件元数据，不能用普通光滑插值抹平真实拓扑变化。

### 6.7 陡崖、显式跳变与垂直边界

连续陡坡带和显式高度跳变会改变接触曲线：

- 容积仍按真实三维边界积分；
- 自由液面面积可在越过台阶时改变；
- 湿润固体面积可能因近垂直崖面快速增加；
- 边界接触可从一条分支变为多条分支；
- 未解析断点使用跳高区间和两侧几何给出容量包络。

不得把零宽跳变当作具有任意大但有限坡度的斜面，也不得用显示三角网格厚度制造额外容积。

### 6.8 球面和三维度量

所有面积和体积使用 L1/M5 对应的真实三维几何：

- 自由液面面积在相应等势面上测量；
- 湿润面积沿固体表面测量；
- 容积在三维空间中积分；
- 边界长度和接触区域使用真实度量；
- 经度纬度像素面积和地图投影平面面积不能直接使用；
- 显示高程夸张不进入任何容量计算。

对于覆盖很大的容器，局部平面近似必须声明分块误差和球面／等势面拼接规则，不能把整个盆地投影到一个平面后积分。

### 6.9 自适应曲线表示

曲线使用与误差和事件相适应的分段表示，而不是固定高度间隔的全局查表。每个节点或区间至少记录：

```text
levelCoordinateInterval
freeSurfaceAreaInterval
containedVolumeInterval
wettedSolidAreaInterval
boundaryContactSummary
topologyEventRefs
interpolationClass
numericalIntegrationError
geometryAndPotentialError
```

加密节点的依据包括曲率变化、面积导数变化、平坦接触、鞍部合并、断点和请求误差。普通区间可压缩，关键事件附近必须保留足够分辨率。插值方式需保证体积单调性和事件位置，不以高阶振荡换取表面光滑。

### 6.10 误差与上下界

曲线误差至少包括：

```text
solidSurfaceError
potentialReferenceError
samplingAndIntegrationError
boundaryAndHaloError
topologyEventOrderingError
local3DCompletenessError
combinedCurveEnvelope
```

面积和容积误差具有空间相关性，不能把每个采样点的独立极值简单相加。建议通过相关误差包络、保守几何界或版本化集合采样传播。输出的上下界自身也必须保持物理一致：

- 下界和上界均非负；
- 容积上下界随势位单调不减；
- 下界不超过中心估计，中心估计不超过上界；
- 门槛顺序被误差颠倒时输出事件簇，不伪造精确顺序；
- 误差大到影响容器闭合时降低能力状态。

### 6.11 尺度、LOD 与补丁

容量曲线绑定 M5 对象尺度和实际表面支持：

- LOD 只决定积分误差是否满足要求，不改变所查询的物理尺度；
- 细化后同一物理尺度的曲线应向稳定结果收敛；
- 子补丁的排他容量聚合到父范围时必须守恒；
- 补丁边界不能充当固体边界或液面封闭线；
- 未覆盖全部容器边界时只发布部分曲线或上下界；
- 局部与全球完整计算在相同输入和误差目标下应一致。

### 6.12 建议输出

```text
ContainerGeometryCurveView
├─ levelCoordinateManifest
├─ containerStageDefinitions
├─ freeSurfaceAreaCurves
├─ containedVolumeCurves
├─ exclusiveAndInclusiveVolumeCurves
├─ wettedSolidAreaCurves
├─ boundaryContactCurves
├─ topologyEventKnots
├─ uncertaintyEnvelopes
├─ validityAndCoverage
└─ sourceEvidenceRefs
```

### 6.13 不允许的快捷方式

M6-D02 不允许：

- 用二维投影像素数直接代替球面面积；
- 用最低点与最高点之间的包围盒体积代替真实容量；
- 把自由液面面积、湿润表面积和边界接触长度混成一个字段；
- 直接相加父子容器曲线而重复计算空间；
- 用固定等高步长跳过平坦区、门槛或断点事件；
- 用非单调插值产生负面积、负体积或容量回退；
- 把数值容量当作当前实际水量；
- 在局部三维缺失时默认洞腔为实心或空心而不声明；
- 通过改变表面或门槛来让曲线符合期望湖泊大小；
- 用显示高程夸张参与面积和容积积分。

## 八、M6-D02 确认结论

M6-D02 已确认：以版本化有效重力势或单调等价的等势高程为统一自变量，分别建立自由液面面积、容积、湿润固体面积和边界接触曲线。嵌套与合并容器同时提供排他和并集容量，通过三维空间并集避免父子重复计量；体积在控制门槛处保持连续，面积和接触拓扑允许事件变化。平坦区、宽鞍部和断点保留单侧值与事件簇。曲线采用单调、自适应、误差受控的分段表示，使用真实球面／三维度量，并明确局部三维、尺度、LOD、补丁和覆盖限制。

## 九、M6-D03：控制门槛、几何越界事件与容器合并

### 9.1 从 M5 控制鞍部到 M6 门槛事件

M5 的控制鞍部描述固体低位连通分量在哪里发生拓扑合并。M6 将它与统一等势坐标、容器阶段和 D02 曲线绑定，形成几何门槛事件：

```text
ContainerThresholdEvent
├─ thresholdEventId
├─ sourceContainerStageRefs
├─ controlSaddleOrRegionRefs
├─ thresholdLevelInterval
├─ contactGeometry
├─ adjacentAndReceivingCandidates
├─ capacityImmediatelyBelow
├─ mergedContainerStageRef
├─ barrierAndPassageEvidence
├─ uncertaintyAndEventOrdering
└─ sourceEvidenceRefs
```

M6 不重新寻找或移动 M5 鞍部。若重力势转换使多个高程事件的顺序发生变化，M6 可以形成不同的势位事件排序，但必须保留 M5 来源和转换证据；若差异落在误差内，则保持未排序事件簇。

### 9.2 事件类型

建议区分以下几何事件：

```text
FIRST_BOUNDARY_CONTACT       # 假设液面首次接触某一边界区域
PASSAGE_BECOMES_AVAILABLE   # 固体几何通道在该势位首次开放
CONTAINERS_MERGE            # 两个或更多低位连通容器合并
BOUNDARY_BRANCH_CHANGE      # 接触边界的分支数或连接关系变化
GLOBAL_ROOT_TRANSITION      # 闭合球面拓扑层级进入最终根阶段
UNRESOLVED_EVENT_CLUSTER    # 顺序或类型受误差影响
```

`PASSAGE_BECOMES_AVAILABLE` 只表示空间几何允许跨越，不表示水正在流过。`GLOBAL_ROOT_TRANSITION` 只服务全局拓扑闭合，不代表全球被水淹没。

### 9.3 门槛势位与容量状态

每个事件至少保存三个相关量：

```text
thresholdLevelInterval
capacityBelowThreshold
capacityAtThresholdConvention
```

由于零深度接触可具有面积而不具有有限体积，必须明确门槛采用左极限、右极限还是事件区间语义。建议：

- `capacityBelowThreshold` 使用门槛下侧极限；
- 门槛恰好处的零深度接触单独进入接触状态；
- 门槛上侧进入新的合并容器阶段；
- 宽平鞍部使用势位区间和区域接触，不虚构唯一瞬间；
- D02 曲线在事件节点引用同一个 `thresholdEventId`。

这样可避免因浮点相等判断不同而重复或遗漏容量。

### 9.4 并列和近同高门槛

若多个控制区域的势位区间重叠，或其差异不足以稳定决定顺序，M6 建立：

```text
EqualControlThresholdSet
├─ memberThresholdCandidates
├─ sharedLevelEnvelope
├─ jointlyAffectedContainers
├─ possibleMergeOutcomes
├─ orderingState
└─ resolutionRequirement
```

事件集作为一个规范单元处理。不能按格元编号、补丁到达顺序或微小随机扰动依次执行，从而产生物理上没有证据的中间容器。若提高精度后可稳定区分顺序，应在新修订中拆分事件集并保留谱系。

同高多门槛可以表达多个潜在越界位置，这对未来分流、湖泊多出口或湿地漫流很重要；M6 不预先选择一个“主出口”。

### 9.5 合并层级与邻接图分离

M6 至少维护两种不同关系：

1. **容器合并层级**：液面势位单调上升时，低位连通分量只出现、扩张和合并。压缩同高事件集后，层级必须无环，且父事件势位不低于子事件。
2. **固体边界邻接图**：记录容器隔着哪些边界、门槛或断点相邻。该图可以有环，也可以包含尚未开放的通道。

两者不能混成一张“水流图”。合并层级用于容量和全局液面连通查询；邻接图用于询问可能跨越的边界。实际水流方向和流量仍由下游状态决定。

### 9.6 潜在越界方向

几何邻接本身是对称关系，但从一个已假设填充到门槛的源容器出发，可以构造情景化有向关系：

```text
PotentialThresholdTransition
├─ sourceContainerStage
├─ thresholdEvent
├─ destinationCandidateSet
├─ downstreamPotentialEvidence
├─ directionState
└─ uncertainty
```

方向判定只使用门槛两侧的有效重力势和固体连通：

- 外侧存在明确更低连通区时，可声明潜在向外越界；
- 两侧低区对称或势差落入误差时，方向为双向资格或未解析；
- 多个外侧分支可同时保留；
- 目的区域未完整覆盖时，不能假设其最终去向；
- 方向资格不携带流量、持续时间或实际激活状态。

### 9.7 单调事件图

在固定 M5/M6 快照和固定尺度下，假设液面单调上升时：

- 已连通的固体低位空间不能在更高势位无故断开；
- 合并事件不能逆转为分裂事件；
- 容器包含空间只能保持或扩大；
- 父事件势位必须不低于所有子事件的下界，误差重叠时形成事件簇；
- 任意循环必须位于一般邻接图，不能出现在规范合并层级中。

如果数值结果违反这些规则，应判定拓扑、势位转换或事件排序失败，不能通过重新排序标识掩盖。

### 9.8 固体屏障和越顶

一个几何屏障可拥有多个门槛。M6 记录：

```text
barrierGeometryRef
crestLevelEnvelope
thresholdRegions
adjacentContainerStages
resolvedWidthAndSupport
discontinuityState
materialEvidenceRefs
```

假设液面超过最低门槛称为几何“越顶资格”，并不表示屏障发生侵蚀、决口或漫顶流。更高的次级门槛仍可保留，用于主门槛堵塞、不同场景或误差分析，但不能在标准静态连通查询中与最低门槛重复触发同一次合并。

### 9.9 显式断点和局部三维通道

- 显式断点的高侧、低侧和跳高进入门槛几何，但断点本身不自动形成开口；
- 断层材料是否导水不由 M6 判定；
- 已解析洞口、天然桥下通道或地下空腔可以形成独立的固体几何通道事件；
- 地下通道事件必须引用局部三维组件、入口和最窄控制截面；
- 地下空间存在不等于具有水力连通，填充、压力、虹吸和渗流仍属下游；
- 局部三维能力缺失时，不得用地表鞍部假装地下通道，也不得假设绝对封闭。

表面门槛与地下通道并存时分别保存，交由下游水体或地下水模型根据自身能力选择。

### 9.10 闭合球面的全局终点

闭合球面没有“流出地图”。所有容器随势位上升最终进入一个专用全局根阶段：

- 根阶段只证明低位连通层级闭合；
- 最后一个全局事件不自动成为海平面；
- 全球最高区域不称为溢洪道；
- 不为根阶段生成现实可用的无限容量；
- 海洋边界求解器只能在给定水量或势位的有限查询范围内使用事件图。

### 9.11 尺度、补丁与事件谱系

门槛事件绑定物理尺度和 M5 对象谱系：

- 细尺度可能解析粗尺度宽鞍部中的多个次级门槛；
- 粗尺度事件与细尺度事件允许一对多、多对一或等价集关系；
- 在相同物理尺度增加 LOD 时，稳定事件势位和合并关系应收敛；

## 十二、M6-D04：潜在下坡路径、固体屏障与多路连接图

### 12.1 图的用途

它不回答是否存在水、流量有多大、何时到达，也不决定最终河道。图以 M5 坡面、谷线走廊、平坦区、盆地、断点和局部三维门户，以及 M6-D03 门槛事件为证据。

```text
├─ flatTransferRegionNodes
├─ containerStageNodes
├─ thresholdEventNodes
├─ barrierAndPassageNodes
├─ local3DPortalNodes
├─ directedAndUndirectedRelations
├─ equalPotentialComponents
├─ uncertaintyAndAlternativeEdges
└─ sourceEvidenceRefs
```

### 12.2 四类基本连接

建议至少区分：

```text
STRICT_DESCENT
EQUAL_POTENTIAL_TRANSFER
THRESHOLD_TRANSITION
LOCAL_3D_PASSAGE
```

- `STRICT_DESCENT`：沿有效重力势显著下降的表面连接；
- `EQUAL_POTENTIAL_TRANSFER`：平坦区或势差落入误差带的无确定方向连接；
- `THRESHOLD_TRANSITION`：假设源容器达到 D03 门槛后才可使用的情景连接；
- `LOCAL_3D_PASSAGE`：由已解析洞口、管道或多层固体空间支持的连接。

连接类型不能互相替代。尤其不能把等势连接人为倾斜成严格下降，也不能把地表上相邻但被屏障隔开的区域直接连通。

### 12.3 严格下降连接

严格下降连接使用有效重力势差、M5 下降方向、坡面结构和谷线走廊共同建立。每条连接至少保存：

```text
sourceSupportRegion
destinationSupportRegion
potentialDropInterval
pathCorridorOrRegion
lengthAndSlopeEnvelope
minimumResolvedWidth
barrierIntersections
directionConfidence
validScaleAndCoverage
```

局部梯度只决定邻近下降资格，不能单独证明长距离路径。长路径必须由连续走廊或相邻区域序列支持；路径遇到洼地、平坦区、门槛、断点或未知边界时，必须切换到相应连接类型或终止为未解析。

### 12.4 平坦转移区域

平坦区中不存在可信唯一坡向。M6 将整个连通平坦区及其入口、出口候选表示为一个转移区域：

```text
FlatTransferRegion
├─ regionGeometry
├─ levelEnvelope
├─ incomingConnections
├─ lowerExitCandidateSet
├─ equalLevelBoundaryContacts
├─ unresolvedInternalRouting
└─ resolutionAndErrorState
```

如果有多个低侧出口，它们全部保留。M6 不在平坦区内部绘制任意蛇形线，也不根据格元遍历顺序生成排水方向。只有新的尺度、精度或过程地貌改变了势差，才能在新快照中解析方向。

### 12.5 多路、分叉与汇合

连接图原生支持：

- 一个源区域连接多个可信下降分支；
- 多个上游区域汇入同一低位区域；
- 平坦区同时连接多个等势或低势出口；
- 并列门槛提供多个情景越界分支；
- 误差重叠时保存互斥或并存的候选边；
- 不同物理尺度下出现不同层级的支路。

M6 不为这些分支分配流量比例。可以保存坡降、宽度、长度、连续性和误差等几何属性，但不能把它们归一化成实际分流权重。真实分流取决于水位、动量、糙率、流量、沉积和历史过程。

### 12.6 等势环与有向无环摘要

严格势降边不能形成势位回升的有向环。平坦区和误差范围内的等势连接可以形成环，因此：

1. 原始连接图保留等势连通分量；
2. 将每个等势连通分量压缩为单一超节点；
3. 只在超节点之间建立严格下降或门槛条件边；
4. 压缩后的严格下降摘要应无环。

检测到严格下降环时，应报告势位转换、方向或拼接失败，不能通过删除任意一条边修复。门槛连接只有在对应容器阶段的情景下启用，不混入无条件下降摘要。

### 12.7 固体屏障

固体屏障描述在给定尺度和势位范围内阻止直接几何穿越的表面或体积边界：

```text
SolidBarrierInterface
├─ barrierGeometry
├─ separatedRegionRefs
├─ crestOrThresholdEnvelope
├─ availablePassageRefs
├─ scaleAndResolution
├─ discontinuityState
├─ materialEvidenceRefs
└─ uncertainty
```

山脊、台地边缘、崖壁或局部三维实体都可能提供几何屏障证据。屏障只限制几何路径：

- 不自动成为分水岭；
- 不证明完全隔水；
- 不排除渗流、裂隙、管道或未来侵蚀切穿；
- 不因材料坚硬就获得无限高度或永久性；
- 已知开口必须作为独立通道引用。

### 12.8 路径走廊而非单格链

潜在路径首先表达为具有宽度和误差的区域走廊，派生中心线只用于索引或显示：

- 宽谷底允许多个中心线候选或无唯一中心线；
- 坡面漫流可用二维转移区域表达，不强制压成线；
- 狭窄谷槽可在证据充分时形成线状走廊；
- 接近分水区的方向不确定带保持区域状态；
- 路径几何不得吸附到显示折线或网格边。

该表达为未来湿地漫流、冲积扇分流和三角洲多路水系保留空间，但这些过程地貌仍需后续模型生成。

### 12.9 容器内部与容器之间

连接分成两层：

1. **容器内部潜在连接**：坡面、谷地和平坦区怎样将几何路径导向低位区域。
2. **容器间条件连接**：只有假设液面达到门槛后，才通过 D03 事件连接到相邻容器。

内部路径终止于封闭最低区域并不构成算法失败。M6 不填洼以强迫它继续流向全球根。后续水文可以让水在此蓄积、蒸发、入渗，或在达到门槛后使用条件连接。

### 12.10 局部三维路径

`LOCAL_3D_PASSAGE` 必须引用明确的三维固体空腔或门户，并至少声明：

```text
entryAndExitPortalRefs
centerlineOrVolumeSupport
minimumCrossSectionEnvelope
potentialProfile
surfaceConnectionRefs
geometryCompleteness
```

若通道中存在局部势位升高，纯重力自由表面流未必能通过；M6 保存势位剖面和控制截面，不推断压力流、虹吸或饱和渗流。只有入口而没有已解析出口时，连接保持悬而未决，不能猜测暗河去向。

### 12.11 路径代价与资格指标

为便于下游搜索，M6 可以提供纯几何指标：

```text
pathLength
potentialDrop
slopeEnvelope
resolvedWidth
constrictionGeometry
turningAndBranchComplexity
roughnessEvidenceRef
uncertaintyCost
```

这些指标不是流阻、流速或通量。`roughnessEvidenceRef` 只引用材料与表面粗糙度证据；水力糙率、侵蚀阈值和输沙能力由过程模型决定。路径排序若提供，只能说明某项几何查询偏好，不能发布为自然选择的唯一河道。

### 12.12 尺度、补丁与跨面拼接

- 图节点和边绑定明确物理尺度；
- 粗尺度路径可在细尺度细分、分叉、合并或变为漫流区域；
- LOD 提升只降低误差，不自动改变分析尺度；
- 补丁边界上的路径端点保持 `PROVISIONAL_BOUNDARY`；
- 相邻补丁按共享支持区、势位、方向和对象谱系确定性拼接；
- 立方球面面缝不成为屏障、通道或分水边界；
- 局部与全球完整分析在相同尺度下应产生一致的压缩连接图。

## 十五、M6-D05：水体边界求解器输入契约

### 15.1 求解器是 M6 的消费者

水体边界求解器是 M6 的独立下游。M6 只提供固体容器和等势连通接口，求解器再结合外部水状态输入计算实际水体边界：

```text
M6 OceanBoundarySolverInputView
  + SurfaceLiquidAllocation / SpecifiedLevel / BoundaryConditions
  + WaterBoundaryModelManifest
  → WaterBoundarySnapshot
```

`WaterBoundarySnapshot` 可以包含实际液面、覆盖、连通水体、潜在岸界和剩余账本，但不属于 M6 快照。相同 M6 发布可以被多个水量、季节或假设情景重复消费。

### 15.2 三种问题必须分开

求解器至少区分三种查询模式：

1. **给定等势液面求覆盖**：输入指定 `ζ` 或 `φ`，查询固体表面以下的空间、连通分量和边界接触。
2. **给定单个连通水体的液态体积求液面**：输入水体所属容器／种子区域及分配体积，反演 D02 单调容量曲线得到液面。
3. **给定全球水库存求所有水体分布**：仅有总水量和地形通常不足以唯一确定多个封闭盆地间的水量分配，必须另有初始分配、长期交换、降水—蒸发平衡、地下交换或其他边界条件。

M6 必须显式报告第三类问题的自由度，不能暗中假设“所有水从全球最低点开始填充”或“每个低地都填到同一液面”。这些假设若被某个实验模型采用，应属于求解器配置并进入结果来源。

```text
└─ limitationsAndEvidenceRefs
```

该视图不包含预选海洋种子、目标海岸线、期望海陆比例、实际水量或已经分类的岛屿。求解器若需要这些内容，必须从独立、版本化的世界环境或求解请求读取。

### 15.4 指定液面覆盖查询

给定 `ζ` 时，M6 接口应支持求解器得到：

- 固体表面低于该势位的候选覆盖区域；
- 在该势位已开放的门槛和通道；
- 按固体连通关系形成的空间分量；
- 液面与固体的接触线、接触区域和误差带；
- 未解析断点、局部三维缺失和补丁覆盖限制；
- 从指定种子分量可达的范围。

“低于液面”只是几何覆盖资格。只有求解请求声明某个连通分量实际拥有水，该分量才能进入水体结果。与水源分量不连通的内陆低地不能仅因势位更低就自动成为同一海洋。

### 15.5 给定体积反演液面

对指定容器阶段或连通水体，求解器可使用 D02 曲线反演：

```text
find ζ such that containedVolume(ζ) = allocatedLiquidVolume
```

反演必须：

- 使用单调区间和 D03 事件节点；
- 在越过门槛时切换到正确的合并容器阶段；
- 对并列门槛整体处理，不产生遍历顺序差异；
- 返回液面区间、覆盖范围和剩余体积误差；
- 对超出已验证容量范围的输入明确失败或请求更大覆盖；
- 不把冰、水汽、土壤水或地下水自动计入表面液态体积。

若门槛事件改变连通分量，求解器必须按自己的水量分配与连通规则继续求解，不能把子容器曲线无限外推。

### 15.6 全球水量账本

世界环境可以拥有总水库存，但水体边界求解需要明确分配到表面液态水的份额：

```text
totalWaterInventory
├─ atmosphericWater
├─ surfaceLiquidWater
├─ snowAndIceStorage
├─ soilAndVadoseWater
├─ groundwaterStorage
├─ chemicallyBoundOrOtherStorage
└─ allocationUncertainty
```

M6 不拥有该账本，也不决定各份额。求解器只能消费与目标时间状态一致的 `surfaceLiquidWater` 或具名情景输入。若其他储库未建模，必须作为假设和误差说明，不能把总水库存全部倒入地表容器。

### 15.7 海洋身份与连通性

“海洋”不是最低高程的同义词。求解器需要根据实际水体状态和产品语义判断：

- 水体是否连接到指定全球主水体种子或满足全球尺度条件；
- 是否与其他大水体通过已激活门槛连通；
- 连通是否只存在于表面、局部三维通道或尚未验证的地下路径；
- 水体尺度、持续性和时间状态是否满足海洋分类要求；
- 多个互不连通的大型水体是否分别保存。

M6 只提供连通证据。它不预设只有一个海洋，也不把全球最低容器自动命名为主海洋。

### 15.8 低于海平面的封闭陆地盆地

若一个封闭盆地的固体底部低于某个海洋液面，但其边界高于该液面且不存在已激活通道：

- 它不属于该海洋连通分量；
- 它可以保持干燥；
- 也可以由独立水量分配形成湖泊、盐湖、湿地或季节水体；
- 地下渗入、降水与蒸发需由水文系统计算；
- 海洋液面不能隔空填充该盆地。

这项规则必须在求解器契约中作为结构断言，而不是地图后处理修正。

### 15.9 水体边界、岸界和地貌语义

求解器可以从实际液面与固体表面相交得到：

```text
waterBoundaryContact
waterCoverageComponent
waterSurfaceRegion
shorelineUncertaintyBand
```

这些仍是水体边界状态：

- 接触线不自动成为地貌学海岸；
- 被水包围的固体区域可成为岛屿几何候选，但“岛屿”语义仍需尺度、持续性和产品规则；
- 潮滩、滩涂、海滩、江岸和湖岸需要潮汐、波浪、沉积、材料或水文证据；
- 岸线随情景或季节变化不修改 M6 固体边界；
- 显示用平滑岸线不能回写求解器权威覆盖。

### 15.10 静水近似与动态边界

M6 提供的是等势静态容器接口，适合求解代表性静水边界。下列现象需要独立动态模型：

- 潮汐与风暴增水；
- 波浪爬高和破碎；
- 河口回水与洪水漫滩；
- 水面坡度、流动惯性和旋转流体动态；
- 季节冰盖、冰坝湖和溃决；
- 水库调度或人工工程。

求解器可以在 M6 静态基线上叠加动态边界，但必须另存时间、模型和偏差，不得把瞬时高水位写成新的固体容器曲线。

### 15.11 不确定性与多解

若门槛排序、容量曲线、局部三维通道或水量分配存在不确定性，求解器输入应支持：

- 连接关系候选集；
- 势位与容量上下界；
- 不同门槛事件排序情景；
- 未知地下交换标记；
- 水量分配自由度；
- 可比较的结果集合而非伪精确单解。

M6 可以提供几何不确定性包络，但不能替求解器选择最“好看”的海陆方案。若输入不足以唯一确定结果，必须返回多解或 `UNDERDETERMINED`。

### 15.12 全球与局部查询

- 全球指定水量求解需要完整的相关容器、门槛和全局连通索引；
- 区域指定液面查询可以在完整边界条件下局部执行；
- 接触查询边缘的水体分量标记为暂定，不宣称闭合；
- 区域补丁不能假设窗口外是陆地、海洋或无限蓄水池；
- 相同 M6 快照、情景和完整覆盖下，局部与全球重叠核心应一致；
- 跨立方球面面缝的水体分量和边界不能断裂或复制。

### 15.13 求解结果的来源绑定

下游 `WaterBoundarySnapshot` 至少绑定：

```text
sourceM6SnapshotId
waterInventoryOrSpecifiedLevelInputId
allocationAndBoundaryConditionId
solverModelAndParameterVersion
timeOrScenarioId
resultCoverageAndUncertainty
containerThresholdAndCurveRefs
```

缺少这些来源时，结果不能与世界种子一起作为可重现自然状态发布。改变水量、分配条件、时间或求解模型会产生新的水体快照，不修改 M6。

### 15.14 不允许的快捷方式

M6-D05 不允许：

- 仅按高程正负生成海陆二值图；
- 用全球总水量自动填满所有低地而忽略储库分配；
- 默认所有封闭盆地共享同一液面；
- 将全球最低盆地自动指定为唯一主海洋；
- 把低于海洋液面的不连通内陆盆地隔空填水；
- 以目标海陆比例或目标海岸形状反推修改 M6 容器；
- 把水体接触线直接命名为海滩、滩涂或江岸；
- 把潮汐、风暴增水和河口回水写入静态容器接口；
- 在输入不足时强制输出唯一水体分布；
- 让局部查询窗口边缘充当水体边界或无限外海。

## 十七、M6-D05 确认结论

M6-D05 已确认：向独立水体边界求解器提供固体表面、容器曲线、门槛事件、连通索引、屏障、三维能力和误差，而不预置海洋、水量或目标海陆比例。指定液面求覆盖、指定单个水体体积反演液面、全球水库存分配是三类不同问题；仅有全球总水量通常不能唯一决定多个封闭盆地的分配，输入不足时必须返回多解或欠定。低于海洋液面但不连通的内陆盆地不能隔空进水。实际覆盖、岸界和岛屿几何候选属于独立水体快照，动态潮汐、洪水和水文过程继续后置。

## 十八、M6-D06：尺度、补丁、材料、地下接口与不确定性传播

### 18.1 M6 结果的空间作用域

M6 结果按其对外部边界的依赖分为三类：

```text
LOCAL_METRIC_RESULT       # 局部面积、局部体积增量、局部坡降等
BOUNDARY_DEPENDENT_RESULT # 容器闭合、门槛、路径去向等依赖更大邻域
GLOBAL_TOPOLOGY_RESULT    # 全球连通索引、最终根层级等依赖全球覆盖
```

局部可计算不等于局部可正式发布。一个补丁可以可靠给出某段固体表面积或局部排他体积，却未必能证明盆地闭合、最低门槛或最终去向。每个结果必须声明作用域、所需支持区和完整性状态。

### 18.2 物理尺度与采样分辨率

M6 沿用 M5 的物理分析尺度，不把网格 LOD 当作自然尺度：

- 容器、门槛、路径和屏障绑定来源 M5 对象尺度；
- LOD 只影响积分、边界定位和通道解析误差；
- 同一物理尺度增加采样时，已解析曲线和拓扑应收敛；
- 细尺度对象不能无条件替换粗尺度对象；
- 粗尺度宽通道可在细尺度解析为多个狭窄通道；
- 低于当前采样能力的结构保持未解析，不通过插值补造。

### 18.3 容器与门槛的跨尺度谱系

M6 对象继承 M5 来源谱系，并建立自己的跨尺度关系：

```text
PERSISTS_AS
REFINES_INTO
AGGREGATES_FROM
SPLITS_INTO
MERGES_INTO
CHANGES_INTERFACE_REPRESENTATION
UNRESOLVED_RELATION
```

一个粗尺度容器可以包含多个细尺度微容器；一个粗尺度宽鞍可细分为多个门槛；一条漫流区域可细分为多条通道。谱系允许多对多，不能按父格与子格强制匹配。

跨尺度比较必须区分：

- 自然对象在不同尺度上的合法表达差异；
- 提高 LOD 后对同一尺度结果的数值收敛；
- 输入误差或新三维证据造成的真实修订。

### 18.4 父子容量守恒

局部细化只允许重新分配父范围内的几何容量，不得无来源创造或删除体积。对同一势位和同一物理尺度，应满足：

```text
parentExclusiveVolume
  ≈ union(childExclusiveVolumes)
    + unresolvedResidualVolume
```

其中使用三维空间并集，而非简单数值求和。还需保持：

- 子容器排他空间不重叠；
- 边界误差和未解析体积单独记账；
- 细化后的包含容量与父级包络相容；
- 门槛附近的体积连续性不因补丁切分破坏；
- 新解析空腔或悬挑空间通过来源修订改变账本，不伪装为数值误差。

### 18.5 补丁核心、支持区与暂定边界

每个补丁计算范围分为：

```text
requestedCore
  + geometryAndIntegrationHalo
  + topologySearchSupport
  = M6ComputationFootprint
```

- 只有核心中且所需外部关系完整的结果可正式发布；
- halo 可供积分、曲线和邻接计算，但不自动成为正式覆盖；
- 容器边界或路径进入未知区域时保持 `PROVISIONAL_BOUNDARY`；
- 未排除补丁外更低门槛时，当前最低门槛只是候选；
- 相邻补丁使用同一 M5/M6 身份、尺度与势位基准才能拼接；
- 拼接冲突必须扩大支持范围或降低能力，不能选择先到的一方。

### 18.6 可局部更新与必须全局重算的内容

M6 通过依赖图确定失效范围：

- 局部表面细化可重算受影响的局部面积、体积增量、接触和路径段；
- 若细化改变控制门槛顺序，必须使所有依赖的父容器阶段和连通索引失效；
- 若细化只收窄数值误差且未改变事件关系，可增量更新曲线和证据；
- 全球重力基准、等势坐标或根连通结构变化会使全局接口失效；
- 局部三维门户新增可能改变其连接到的容器与路径，但不应使无关大陆全部失效；
- 缓存失效范围和权威快照变化范围分别记录。

任何增量更新都产生新的不可变修订，不原地修改已发布 M6 快照。

### 18.7 材料证据接口

M6 可从 M5/M2 来源读取与容器边界有关的材料证据：

```text
materialFamilyDistribution
porosityAndPermeabilityEvidence
fractureAndLayerOrientation
erodibilityAndStrengthEvidence
contactAndExposureUncertainty
supportScale
```

材料字段只作为下游水力、渗漏、侵蚀和地下水模型的输入证据。M6 不生成：

- `watertight = true/false` 的绝对结论；
- 实际入渗率或渗漏流量；
- 饱和区、地下水位或承压状态；
- 材料侵蚀后的新门槛；
- 根据岩性标签预设的湖泊或河道。

粗尺度材料混合按目标属性和空间支持保留分布或区间，不能用多数岩性标签替代连续物性。

### 18.8 地下空间的计量边界

局部三维组件加入 M6 时，必须先声明其与全球主表面容器的空间关系：

```text
DISJOINT_CAVITY
CONNECTED_VOID
OVERLAPPING_REPRESENTATION
SOLID_OCCUPIED
UNRESOLVED_RELATION
```

容量计量遵循：

- 独立洞腔只有在三维边界闭合且能力允许时才提供容积曲线；
- 与地表开口连接的空腔通过门户事件加入容器图；
- 与主表面网格重叠表示的空间只计量一次；
- 固体占据区从可容纳空间中排除；
- 未解析关系进入上下界，不能默认全空或全实；
- 洞腔容积不自动计入表面水体，也不证明具备水力连接。

局部三维组件使用自身有效坐标和精度，但所有门槛势位必须转换到同一 M6 等势基准。

### 18.9 不确定性的类型

M6 至少分离：

```text
METRIC_UNCERTAINTY       # 面积、容积、长度、势位等数值范围
TOPOLOGY_UNCERTAINTY     # 是否连通、门槛顺序、对象对应等离散候选
MODEL_UNCERTAINTY        # 重力近似、积分模型、简化假设
COVERAGE_UNCERTAINTY     # 补丁、地下空间或边界未完整覆盖
MATERIAL_UNCERTAINTY     # 物性与结构证据范围
KNOWLEDGE_STATE          # 未知、未生成、不适用、失败
```

拓扑不确定性不能只压成一个数值误差条。例如两个门槛顺序未知时，应保留两个事件排序候选，而不是输出平均门槛。知识未知也不能编码为零容量、零渗透或无通道。

### 18.10 相关误差与情景包

同一表面误差会同时影响面积、容量、门槛和路径，因此这些误差不是相互独立。建议发布：

```text
correlatedMetricEnvelope
topologyAlternativeSet
modelVariantId
coverageScenario
jointConfidenceState
```

同一情景内的曲线、事件和路径引用同一误差实现或保守包络，避免下游把各字段最有利或最不利的独立端点任意组合成不可能世界。需要统计集合时，使用版本化联合样本或有界情景，而不是每个字段独立抽样。

### 18.11 能力状态与降级

每个区域和查询类型返回：

```text
AVAILABLE
AVAILABLE_WITH_BOUNDS
PARTIAL
PROVISIONAL
NOT_AVAILABLE
FAILED
```

合法降级示例：

- 有二维地表容器曲线，但局部三维容量为 `NOT_AVAILABLE`；
- 有局部面积和体积增量，但闭合容器为 `PROVISIONAL`；
- 门槛集合已知，但顺序仅 `AVAILABLE_WITH_BOUNDS`；
- 材料证据缺失，不影响纯几何容量，却使水力材料接口为 `PARTIAL`。

### 18.14 不允许的快捷方式

M6-D06 不允许：

- 简单相加重叠父子体积；
- 在门槛顺序变化后只更新局部曲线而保留旧全局连通索引；
- 用补丁边缘封闭容量或截断路径；

## 二十、M6-D06 确认结论

M6-D06 已确认：按局部度量、边界依赖和全球拓扑区分结果作用域，并沿用物理尺度而非 LOD 定义对象。局部细化通过三维空间并集和未解析残差保持父子容量守恒；补丁边缘不能证明闭合、最低门槛或最终去向。材料只作为连续物性与结构证据，不直接产生水力结论；地下空间必须与全球主表面进行不重不漏的空间计量。数值误差、拓扑多解、模型、覆盖、材料和知识状态分别传播，并使用相关情景包保持曲线、事件和路径联合一致。

### 21.7 验收证据组合

M6 需要组合：

1. **结构不变量**：引用闭合、单位、非负、单调、容量守恒、层级无环、摘要一致和原子性。
2. **解析基准**：球冠、圆锥、抛物盆、嵌套盆、平门槛、台阶和简单三维空腔。
3. **变形关系**：球面旋转、立方球面重映射、等价采样和存储重排不改变物理语义。
4. **属性测试**：随机合法容器始终满足曲线、事件、连接、身份和状态约束。
5. **跨尺度测试**：父子容量、门槛谱系、路径表示、LOD 收敛和未解析残差。
6. **补丁测试**：核心、halo、暂定边界、冲突、拼接、跨面和局部／全球一致。
7. **不确定性测试**：数值包络、拓扑候选、相关场景、能力降级和欠定状态。
8. **消费者契约**：水体、水文、语义、桌面和局部三维消费者只能读取授权视图。
9. **跨平台确定性**：Windows/macOS 的允许数值误差不改变事件顺序结论、拓扑候选、身份和验收状态。
10. **可解释性测试**：每条曲线、事件、边和屏障可追溯到 M5、势位基准、尺度和算法版本。

视觉检查可辅助发现接缝、断线和异常边界，但不能单独证明容量或连通正确。

### 21.8 发布阻断条件

沿用 `PASS`、`CONDITIONAL_PASS`、`FAIL` 和 `UNVERIFIED`。以下任一情况阻断标准发布：

- M5 依赖不是兼容的 `PASS + RELEASED`；
- 垂直基准、有效重力势、单位或等势转换不一致；
- 面积／容量出现负值、非单调、积分不闭合或父子重复计量；

- 等势连接被伪造成严格下降，补丁边缘被当成屏障或出口；
- 关联不确定性被拆成不可能组合，拓扑多解被平均；
- 材料证据被升级为未经验证的水力结论；
- 局部三维空间重复计量或未声明缺失；
- M6 修改 M5 表面、填洼，或注入实际水量、海洋、流量和河网语义；
- CI01—CI14 必需夹具或消费者契约未验证；

- 快照、能力、验收包和发布清单摘要不一致。

`CONDITIONAL_PASS` 仅供能力清单中具名实验消费者读取，默认不能作为标准水体边界求解输入。视觉质量和平均通过率不能抵消必需失败。

```text

                    ↘ REJECTED
```

## 二十四、M6 内部一致性复核

M6-D01 至 M6-D07 的已确认决定形成以下单向依赖：

```text
M5 PASS + RELEASED 与版本化垂直／重力基准
  → M6-D02 构建容器阶段及面积、体积和接触曲线
  → M6-D03 将控制区域绑定为门槛事件和合并层级
  → M6-D04 建立严格下降、平坦转移、条件门槛和三维连接
  → M6-D05 发布水体边界求解器输入视图
  → M6-D06 规范尺度、补丁、材料、三维、误差和对象修订
  → M6-D07 验收并原子发布
```

复核确认：

1. **无固体表面反馈**：D02—D06 只读 M5，不填洼、不切割，也不为修复容量或连通修改几何。
2. **无重力基准循环**：等势坐标来自版本化世界输入，不由目标海岸、海陆比例或水量反推。
3. **无容量重复计量**：父子、补丁和三维空间使用排他支持与三维并集统一记账。
4. **无门槛—曲线循环**：D02 从固体几何计算曲线；D03 把已知控制区域绑定为事件，事件只分段和索引曲线，不修改几何容量。
5. **无路径强制排水**：D04 允许封闭终点、等势区域和多路候选，不为制造河网改变 D02/D03。
6. **无水状态反向注入**：D05 只发布输入接口，水量、液面、海洋、岸界和流量保存在独立下游快照。
7. **无材料越权**：材料只作为水力和过程模型的证据，不在 M6 生成隔水、渗漏或侵蚀结论。
8. **无不确定性拼接矛盾**：D06 使用相关情景保持曲线、事件和路径联合一致，拓扑多解不平均。
9. **无执行顺序身份**：对象规范化与拼接不依赖补丁、线程、缓存和遍历顺序。
10. **无发布旁路**：标准水体与水文消费者只能读取 `PASS + RELEASED` 的受限视图。

需要留待原型标定的事项包括等势高程近似、曲线节点误差、积分方法、事件容差、平坦区压缩、路径支持尺度、三维计量结构、材料证据聚合、相关情景数量、补丁 halo、失效范围和跨平台数值策略。这些不改变上述所有权与状态语义。
