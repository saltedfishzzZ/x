本文讨论地形与材料子引擎的 M3“基础高程层”。M3 将 L5 构造高程约束与 M2 材料背景转换为版本化的长波固体基础表面和材料几何映射，为 M4 多尺度起伏提供稳定骨架。它不生成完整山峰、河谷、海岸或最终演化地表。

关联：[地形与材料子引擎前置条件清单](地形与材料子引擎前置条件清单（讨论稿）.md) · [输入契约与垂直基底层设计](输入契约与垂直基底层设计（讨论稿）.md) · [材料背景层设计](材料背景层设计（讨论稿）.md) · [构造地形约束层设计](../构造子引擎/构造地形约束层设计（讨论稿）.md)。

## 一、M3 的职责与边界

### M3 负责

- 将构造基底、长波抬升／沉降资格和材料背景转为米制基础高程贡献。
- 建立行星尺度与大陆尺度的连续基础表面。
- 生成汇聚、张裂、走滑和三重点的广域高程包络，不生成最终局部形态。
- 根据材料密度、强度和层序生成受限的材料浮力／保存能力修饰。
- 生成 `MaterialPlacementTransform`，把 M2 材料坐标映射到世界几何。
- 保存每项高程贡献、预算、冲突、误差和来源。
- 向 M4 提供基础高程、方向包络、剩余起伏预算和材料柱视图。
- 输出不可变 `BaseElevationSnapshot`。

### M3 不负责

- 使用高频随机噪声生成山峰、支岭、局部丘陵或细碎坡面。
- 生成河流切割、峡谷、河曲、冲积平原、三角洲或海蚀地貌。
- 根据海平面把高程直接分类为陆地或海洋。
- 为追求世界内部高差而按每颗行星极值重新归一化。
- 修改 L5 构造快照或 M2 材料背景。
- 让 M4 细节反向改变已发布的 M3 基础表面。

## 四、M3-D01：基础高程所有权与尺度边界

M3 输出的是 `baseElevation`，表示在加入 M4 显式山岭、峰群和局部起伏前的固体长波骨架。它不是最终地表，也不是简单平滑后的最终高程。

建议尺度职责为：

| 尺度／贡献 | M3 | M4 |
| --- | --- | --- |
| P0 行星尺度 | 大陆—洋盆基底、全球长波趋势 | 不修改 |
| P1 大陆尺度 | 高原／盆地区域包络、长山系广域抬升 | 在包络内组织山系细节 |
| P2 区域尺度 | 只提供构造响应包络、方向和预算 | 生成山岭、裂谷段、断块与区域起伏 |
| P3 地貌尺度 | 不生成具体对象 | 生成峰群、支岭和局部洼地 |
| P4/P5 局部与场景 | 不拥有 | M4 或未来局部三维扩展 |

M3 的 P2 输出是“允许在哪里、沿什么方向、还能使用多少高程预算”的包络，不是已经完成的山岭形态。同一物理来源在 M3 和 M4 之间共用预算标识，防止广域抬升与局部山岭重复消耗完整构造强度。

概念上：

```text
primaryElevation = baseElevation(M3) + authorizedRelief(M4)
```

两项都进入统一贡献账本。M4 可以在授权范围内改变局部极值和表面形态，但不能移动 M3 的大陆、洋盆、大型高原和盆地骨架，也不能反向覆盖 M3 快照。

M3 同时生成 M2 层序到世界空间的材料几何映射，使基础高程上的每个位置都能得到可追溯材料柱。映射与高程共享来源和误差，但不修改 M2 原始材料状态。

### 4.1 明确排除的结果

M3 不因负高程生成海洋，不因高程大生成雪山，不因低势线生成河谷，也不因坡度高生成山崖名称。这些分别需要水体边界、气候、水文、M4/M5 几何及地貌识别证据。

## 六、M3-D01 确认结论

M3-D01 已确认：M3 拥有 P0—P1 长波基础高程，并在 P2 提供广域构造响应包络、方向和剩余预算；M4 才生成具体山岭、峰群、裂谷段和局部起伏。M3 与 M4 通过同源预算标识防止重复计权，M4 不回写 M3 骨架。M3 同时生成 M2 材料层序到世界几何的显式映射和基础材料柱视图，但不修改 M2。高程正负与海陆分离，基础高程不直接产生过程地貌或地貌名称。

## 七、M3-D02：地壳、材料密度与区域基准高程

### 7.1 要解决的问题

M3-D02 要生成的是大陆—洋盆和大型区域起伏的低频基底。它需要回答“为什么这里整体较高或较低”，但不能把板块名称、壳体类别或岩性名称直接翻译成固定海拔。

区域基底至少受以下因素共同约束：

- 上游连续壳体倾向、厚度代理、浮力代理及其置信度；
- M2 材料柱在声明深度范围内的密度结构；
- L5 板块内部基底倾向和长波构造资格；
- 类地预设中的重力、参考半径、参考密度和补偿深度；
- 尚未解析的长波残差、输入误差和模型近似误差。

这些量只形成长波支撑关系。汇聚边界、张裂带和走滑复合区的具体米制响应留给 M3-D03；山岭、峰群和局部盆地留给 M4。

### 7.2 建议的组成结构

概念上，区域基底写成：

```text
regionalBaseElevation =
    referenceCrustContribution
  + crustalBuoyancyContribution
  + materialColumnContribution
  + inheritedLongWaveContribution
  + boundedUnresolvedResidual
```

这是一份贡献账本结构，不意味着所有项都使用简单线性相加。每项必须声明来源、单位、支持尺度、参考状态、适用范围、误差、预算和组合组。属于同一物理来源的壳体浮力与材料密度证据必须融合或共享预算，不能重复相加。

`regionalBaseElevation` 使用 M1 确认的米制球面垂直基准，保留绝对数值含义。允许陆内区域低于参考零面，也允许洋性背景存在海岭或高地候选；最终是否被海水覆盖仍由后续水体边界求解决定。

### 7.3 壳体贡献：使用连续状态，不使用标签高度表

“大陆壳”“过渡壳”“洋壳”只可作为解释或先验索引，不能采用类似“大陆一律 +800 米、洋壳一律 -4000 米”的规则。权威计算读取连续字段，例如壳体倾向、有效厚度代理和上游浮力资格，并在球面上平滑过渡。

这意味着：

- 大陆性倾向较强不保证当地一定高；稳定核心也不自动成为高原。
- 洋性倾向较强不保证当地一定深；其他长波或构造贡献可以抬高它。
- 壳体过渡区必须随连续输入渐变，不在板块边界、立方体面缝或分类阈值处产生台阶。
- 上游只有无量纲资格时，M3 必须使用版本化标定关系并显式增加模型误差，不能伪装成直接物理测量。

### 7.4 材料贡献：积分材料柱，而不是只看表层岩石

材料对长波高程的影响采用声明深度范围内的柱积分密度异常代理：

```text
columnDensityAnomaly = integral(ρ_material(z) - ρ_reference(z), dz)
```

M3 再结合重力、参考地幔密度、补偿深度和适用的支撑模型，把这一异常转换为有界高程贡献。这里关注的是具有区域支撑意义的整根材料柱；薄表层、局部覆盖物或单个岩性名称不能直接抬高或压低整个区域。

材料柱存在混合、尖灭、断层错移或未解析份额时，积分必须读取 M2 的组成比例、体积预算和误差。不同材料排列若具有相同平均密度，但结构支撑含义不同，应保留层序及结构差异，不能只留下一个平均密度数值。

### 7.5 首版采用“标定的均衡／浮力代理”

完整岩石圈均衡需要可靠的壳厚、地幔密度、热结构、弹性厚度和演化历史，而当前上游并不保证全部提供。因此首版不宣称执行完整地球动力学模拟，而采用版本化的类 Airy 均衡／浮力代理：

1. 当壳厚、密度柱及参考状态可用时，使用具有单位和方向意义的简化均衡关系。
2. 当只有连续资格或相对代理时，使用经固定测试世界和现实统计范围标定的单调映射。
3. 代理模式、标定参数和适用范围进入模型清单，结果携带模型误差。
4. 缺失必需输入时，按 M1 能力协商决定降级、保持未知或阻断；不得用随机值补齐。

补偿深度和参考密度由版本化类地参数给出，不根据每颗行星的输出极值反推。未来若加入挠曲均衡、热沉降或完整岩石圈模型，应作为新模型版本和新贡献项接入，而不是静默改变旧世界。

### 7.6 未解析长波残差

首版可以保留低振幅、受限带宽的 `boundedUnresolvedResidual`，表达当前模型未显式解析的长波差异，但它必须：

- 只占预先声明的剩余高程预算；
- 使用独立、稳定且可寻址的随机流；
- 受壳体、材料、支持尺度和球面连续性约束；
- 聚合后不得改变父级长波均值和已确认的主要趋势；
- 标记为未解析贡献，不能解释成具体地质过程。

残差不能用来强行制造大陆、洋盆、高原或指定景观，也不能掩盖输入冲突。

### 7.7 冲突与不确定性

当壳体代理指向抬升、材料密度代理指向沉降时，M3 保存两个有符号分量、净结果和冲突指标。低置信输入降低结论置信度并扩大误差范围，不自动把贡献缩成零；知识不足与物理作用很弱仍是两种不同状态。

误差至少包括：

- 上游输入误差；
- 材料柱未解析份额和属性相关误差；
- 从资格映射到米值的标定误差；
- 均衡／浮力代理的模型误差；
- 空间离散、跨尺度聚合和边界截断误差。

### 7.8 建议输出字段

```text
RegionalBaseElevationView
├─ regionalBaseElevation
├─ referenceCrustContribution
├─ crustalBuoyancyContribution
├─ materialColumnContribution
├─ inheritedLongWaveContribution
├─ boundedUnresolvedResidual
├─ effectiveSupportScale
├─ compensationModelRef
├─ contributionLedgerRefs
├─ conflictIndex
├─ confidence
└─ errorEnvelope
```

所有字段绑定同一 `BaseElevationSnapshotId`、垂直基准、模型版本和空间覆盖。下游可以查询净高程，也能追溯每项来源和近似层级。

## 九、M3-D02 确认结论

M3-D02 已确认：采用连续壳体状态、整根材料柱密度异常和版本化类地参考参数，共同生成米制长波区域基底。首版使用诚实标记误差的类 Airy 均衡／浮力代理，而不宣称完整模拟岩石圈；分类标签不直接决定高度，稳定核心不自动成为高原，权威高程不按单颗行星极值重新归一化。少量未解析长波残差可以存在，但必须独立记账、受剩余预算和带宽约束，并且不能覆盖已知因果趋势。

## 十、M3-D03：构造资格到米制长波响应

### 10.1 输入语义与转换边界

L4 负责相对运动和边界作用资格，L5 已将线性边界展开为球面连续响应核，并提供抬升／沉降资格、方向、来源、置信度和组合预算。M3 不重复分类边界，也不重新生成一套空间核；它在 L5 的支持范围内完成以下转换：

```text
无量纲作用资格
    ↓ 版本化响应曲线、来源预算和材料修饰
米制广域正／负高程贡献
    ↓ 保留方向、误差、冲突和剩余预算
供 M4 解析具体形态的构造响应包络
```

若 L5 提供与当前 `earthlike-v1` 和 M3 模型清单兼容的米制参考贡献，M3 可以将其作为标定输入；它仍不是最终高程。若只有无量纲资格，M3 使用版本化响应曲线转换。两条路径不得同时把同一来源完整计入两次。

### 10.2 米制响应模型

每个构造来源 `s` 的概念响应为：

```text
rawMeterResponse(s, x) =
    sourceBudget(s)
  × calibratedResponse(responseKind, qualification)
  × spatialKernelWeight(s, x)
  × boundedMaterialModifier(s, x)
  × maturityModifier(s, x)
```

其中：

- `sourceBudget` 是该运动来源可用于 M3 与 M4 的总响应预算，而不是能量的严格物理量。
- `calibratedResponse` 把有界资格映射到 `earthlike-v1` 下的米制参考幅度，采用版本化、单调且有饱和上限的曲线。
- `spatialKernelWeight` 直接继承 L5 的球面弧长、有符号横向距离和端部衔接，不基于地图投影重算。
- `boundedMaterialModifier` 只在材料证据允许的范围内调整幅度、宽度和正负分配。
- `maturityModifier` 只读取上游已有的相对成熟度或继承状态；没有可靠时间信息时保持中性或未知。

响应完成后仍要通过组合组限幅和 M3／M4 预算分配。置信度不直接乘入上述公式：低置信表示结果误差更大或不能发布，不等于物理作用一定更弱。`UNKNOWN` 也不能当成零。

### 10.3 不能用速度乘任意时间得到高程

板块相对速度是当前运动代理，地形高度则是构造增厚、热过程、材料支撑、侵蚀和重力调整长期共同作用的结果。缺少可靠历史时，以下计算不成立：

```text
高程 = 当前板块速度 × 随意指定的百万年数
```

首版因此采用经现实范围和固定测试世界约束的状态响应模型，而不伪造绝对构造年龄。未来如果引入可验证的时间演化、岩石圈流变和侵蚀反馈，应建立新的时变模型版本；不能把新模型静默塞进当前静态响应曲线。

### 10.4 汇聚响应

汇聚来源至少分开保存以下米制广域分量：

- **碰撞／缩短增厚**：以宽缓正贡献形成大陆尺度或区域尺度抬升包络。
- **俯冲上覆侧**：在极性可靠时形成非对称的上覆侧正贡献和方向包络。
- **俯冲下沉侧**：形成独立负贡献资格，可为后续海沟侧低势提供骨架，但此处不生成海沟对象。
- **弧侧资格**：只保留偏移位置、方向和剩余预算，不在 M3 直接生成火山弧或岛弧。

碰撞资格与俯冲资格可以在复杂过渡段并存，但必须共享相应的汇聚来源预算。极性未知时，M3 不能猜测哪一侧抬升或下沉；可保留较对称的缩短响应、扩大误差，并把非对称分量标记为未解析。

### 10.5 张裂与扩张响应

离散来源根据 L5 已确认的资格产生：

- **大陆张裂**：轴部广域负贡献与两侧受限正肩部贡献，共享同一张裂预算。
- **过渡张裂**：在大陆张裂与洋壳扩张响应之间连续过渡，不按标签跳变。
- **洋壳扩张轴**：形成轴部热隆升／浅化包络和方向约束。
- **远场热成熟**：属于 M3-D02 区域基底；D03 只处理扩张轴邻近额外响应。

扩张轴响应与 D02 的洋壳成熟基底共享更新源谱系。组合时必须检查覆盖尺度和来源预算，避免同一热状态被解释为两次完整隆升。M3 只产生宽尺度轴部和肩部包络，具体裂谷谷地、断块、洋中脊分段由 M4 生成。

### 10.6 走滑、压扭与张扭

近纯走滑默认不产生显著净垂向高程。它在 M3 主要输出方向、局部化倾向和交给 M4 的形态预算。

- 压扭可以收窄、偏移或增强已有汇聚正响应，但继承汇聚预算，不创建第二份抬升来源。
- 张扭可以调整已有张裂负响应、肩部响应及方向，但继承离散预算，不创建第二份沉降来源。
- 只有上游具有可靠弯折、阶区、压扭或张扭证据时，才允许有界垂向修饰。
- 单凭高走滑资格不能制造山带、裂谷或交替高低噪声。

### 10.7 三重点与相邻多来源

三重点附近先保留三个分支各自的响应，再按 L5 的联合关系和闭合证据执行联合限幅。三条最大响应不能在一个点简单相加，也不能只保留最强分支而丢失方向冲突。

三重点输出应具有有限面积的联合区，而不是单格尖峰。若速度闭合、分支极性或端部几何不可解析，相关分量降低知识状态或扩大误差；不得靠平滑把问题隐藏。

彼此靠近但不属于同一三重点的独立边界仍可共同作用，其贡献分别记账，并在 M3-D05 中按来源关系组合。

### 10.8 材料对构造响应的作用边界

M2 材料强度、密度、层序和结构方向可以调节：

- 响应是宽缓分布还是更易局部化；
- 正负分量在两侧的相对分配；
- M3 保留多少广域响应、向 M4 交付多少具体起伏预算；
- 响应误差和未解析尺度。

材料不能单独创造不存在的汇聚、张裂或走滑来源，也不能仅凭“硬岩”“软岩”标签任意反转构造响应符号。材料修饰必须有界、可追溯，并保持 M2 连续物性优先于岩性名称。

D03 发生在 D04 完整几何放置之前，因此这里只能读取与最终表面截取无关的 M2 背景物性摘要、材料坐标包络和预先声明的响应参数。D03 不得读取 D04 派生的最终出露材料再反向修改自身高程，否则会形成隐式循环。完整材料放置若与已生成基础表面不相容，应在 D04 报告失败、越界或未解析状态，不回写 D02/D03 迭代求解。

### 10.9 M3 与 M4 的预算拆分

每个来源建立统一预算：

```text
totalSourceBudget
├─ consumedByM3BroadResponse
├─ reservedForM4Relief
├─ unresolvedBudget
└─ clippedBudget
```

M3 消耗广域长波部分，并向 M4 交付剩余幅度、允许尺度带、方向、空间包络和来源标识。M4 可以在保持父级聚合和预算守恒的前提下把剩余预算组织为具体山岭、断块或裂谷段，但不能再次使用完整的 `totalSourceBudget`。

预算不是要求 M4 必须把剩余额度全部用完。材料、尺度、相邻来源冲突或模型限制可以让部分预算保持未使用或未解析。

### 10.10 建议输出

```text
BroadTectonicElevationView
├─ positiveResponseField
├─ negativeResponseField
├─ netBroadResponseField
├─ responseEnvelopeField
├─ preferredDirectionField
├─ sourceResponseLedger
├─ sourceBudgetLedger
├─ remainingReliefBudget
├─ conflictIndex
├─ confidenceAndKnowledgeState
└─ errorEnvelope
```

正贡献、负贡献和净结果分别保存。`netBroadResponseField` 便于计算基础高程，但不能替代来源账本；正负抵消后仍需知道这里存在强过程竞争。

## 十三、M3-D04：材料层序到世界几何的显式映射

### 13.1 映射对象

M2 保存的是参考壳层中的材料坐标、材料单元、界面、接触和相对顺序。M3 通过版本化的 `MaterialPlacementTransform` 将材料点映射到行星固连世界坐标：

```text
F : MaterialCoordinate(domainId, u, v, ζ)
    → WorldPosition(x, y, z)
```

其中 `u、v` 表示材料域内的球面切向位置，`ζ` 表示相对参考壳层的材料深度坐标。世界位置最终使用 L1 权威球面方向、M1 垂直基准和米制径向位置表达。经纬度、地图投影坐标和显示夸张均不进入权威变换。

该映射既不是简单增加一个高程偏移，也不是把每根材料柱独立拉伸到地表。它是定义在材料体上的分片三维变换，需要同时处理位置、层厚、接触、结构方向、体积变化和误差。

### 13.2 变换组成与固定顺序

首版变换按版本化顺序组合：

```text
MaterialPlacementTransform
├─ sphericalAnchorTransform       球面锚定与局部基
├─ broadDisplacementTransform     长波抬升／沉降位移
├─ orientationTransform           倾斜、剪切与宽缓弯曲
├─ boundedStrainTransform         有界厚度／体积应变
├─ discontinuityTransform         有证据的断层分片错移
└─ solidSurfaceIntersection       与 M3 固体表面求交和截取
```

组合顺序属于模型语义并进入版本清单。改变顺序可能改变界面位置、表层出露和结构方向，因此必须形成新结果版本，不能当成实现细节任意交换。

### 13.3 连续区域的几何约束

在没有显式断层或混杂接触的材料域内部，变换必须分片连续，并尽量保持一一对应。至少满足：

- 材料单元内部不发生无来源的翻转、自交或负层厚；
- 上下界面和相对顺序在连续变形后保持一致；
- 相邻材料域在声明为连续或渐变接触时保持位置相容；
- 变换 Jacobian 为有限值，方向保持条件不被破坏；
- 体积变化符合声明的应变范围，不能凭高程差机械增加地下材料体积；
- 球面面缝、补丁边缘和 LOD 边界不产生几何裂缝。

若目标基础高程无法由允许位移和应变支持，M3 必须报告材料覆盖不足、变换不可逆或预算冲突，不能偷偷拉伸材料柱填满空间。

### 13.4 抬升、沉降、倾斜与宽缓弯曲

长波抬升和沉降首先表现为材料体的连续位移场。倾斜与宽缓弯曲由 L5 方向、M2 层序方向和 M3 构造包络共同约束：

- 纯径向平移保持层厚时，只改变整体位置；
- 厚度变化必须进入 `boundedStrainTransform`，并记录应变、体积和密度解释；
- 倾斜同步改变界面法向、层理、片理、线理和有效物性张量；
- 宽缓弯曲允许同一层在区域内改变倾向，但不能在当前尺度下折叠成不可逆映射；
- 没有构造方向证据时，不生成固定朝向或随机强倾斜。

首版不要求模拟连续介质力学的完整应力—应变历史。它生成满足几何、预算和方向约束的状态映射，并把近似误差显式写入结果。

### 13.5 断层错移与分片不连续

只有 M2 已存在 `FAULTED` 接触，且上游具有可用方向、影响范围和错移资格时，`discontinuityTransform` 才能在接触两侧使用不同变换。每个断层分片至少保存：

```text
faultContactId
hangingOrSideRefs
displacementVectorOrRange
displacementKnowledgeState
damageZoneWidth
transformOnEachSide
contactTopologyBeforeAfter
confidenceAndError
```

缺少可靠错移量时，可以保持断层接触与相对错移资格，但不得编造精确落差。断层接触也不等于当前活动断层。M3 只表达继承几何和广域错移；具体断层崖、地堑块体和局部断块形态由 M4 解析。

断层两侧允许位置不连续，但不能产生无语义重叠或材料空洞。若当前尺度无法解析重叠、间隙或多分支关系，应保留 `UNRESOLVED` 体积和拓扑关系，交给局部细化处理。

### 13.6 尖灭、夹层、侵入与混杂

- **尖灭**：保持 M2 的零厚边界和单元谱系，不能将其插值成负厚度或突然消失的无来源缺口。
- **夹层**：粗尺度保留厚度比例和未解析份额；只有细化能力足够时才解析具体薄层。
- **侵入体**：随宿主材料几何共同映射，同时保留 `INTRUSIVE` 接触和独立材料身份；M3 不新造岩浆活动。
- **混杂带**：按 M2 的混合和重叠语义映射，不强行排列成单一整齐层序。
- **不整合代理**：保留相对先后和截切关系，不由 M3 推断绝对年代或具体侵蚀历史。

上述结构的变换结果必须能反向追溯到原始材料单元与接触。显示层为了简化而合并薄层时，不得覆盖权威映射。

### 13.7 固体表面截取与出露材料

完成材料体放置后，M3 用自身基础固体表面执行几何求交：

```text
PlacedMaterialVolume ∩ BaseSolidSurface
    → BaseMaterialColumnView
    → exposedMaterialCandidate
```

截取结果回答“基础表面当前位置接触哪种背景材料”，不表示后续风化、侵蚀、沉积、土壤、积雪或水体覆盖已经发生。被基础表面截断的材料单元仍保留其 M2 身份；截断只记录在 M3 派生视图中。

查询结果至少区分：

```text
EXPOSED              与基础表面相交
COVERED              位于其他背景材料之下
TRUNCATED            被基础表面截切
OUTSIDE_ENVELOPE      超出 M2 声明覆盖
UNRESOLVED_CONTACT    当前尺度无法判定接触
MULTIPLE_INTERSECTION 同一径向查询存在多个合法交点
```

`OUTSIDE_ENVELOPE` 在标准生成所需范围内是阻断问题，不能用默认岩石填充。

### 13.8 非单值与局部三维结构

全球基础固体表面仍是相对球面方向的单值高度场，但地下材料界面不必永远是单值径向函数。倒转层、强褶皱、复杂断层叠瓦或侵入关系可能让同一径向线多次穿过同一材料单元。

首版采用两级表达：

1. 全球层保存多交点、顺序、接触和局部三维结构引用，不强行压扁为单层柱。
2. 需要精确几何时，由局部三维补丁解析体网格、界面网格或等价结构，并通过全球锚点连接。

如果当前能力只能确认“存在复杂多值结构”而不能解析具体形状，结果保持 `MULTIPLE_INTERSECTION + UNRESOLVED`。洞穴、天坑和暗河等后生空腔仍不由该映射生成。

### 13.9 结构方向与物性张量的协变

层理、片理、线理、裂隙方向及有效物性张量必须使用同一变换的局部导数更新。概念上：

```text
direction_world = transformDirection(J, direction_material)
tensor_world    = transformTensor(J, tensor_material)
```

其中 `J` 是局部变换 Jacobian。轴向平面的 `n` 与 `-n` 等价关系在变换后仍成立。不能只移动材料界面而保留旧方向，也不能直接平均欧拉角。断层不连续两侧分别计算方向变换。

### 13.10 正向、反向查询与证据

`MaterialPlacementTransform` 至少支持：

- 材料坐标到世界坐标的正向查询；
- 世界位置到材料候选及交点集合的反向查询；
- 基础表面处材料柱、出露候选和接触查询；
- 原始／变换后界面、结构方向和误差对照；
- 变换来源、组合顺序、Jacobian、断点和截取证据查询。

反向查询不存在唯一解时返回候选集合及知识状态，不能任意挑选第一层。查询结果绑定 M2 与 M3 快照标识、LOD、支持尺度和误差。

```text
│  ├─ transformVersion
│  ├─ continuousDomainTransforms
│  ├─ discontinuityTransforms
│  ├─ localJacobians
│  └─ inverseQueryCapability
├─ placedInterfaceGeometry
├─ transformedFabricAndTensors
├─ BaseMaterialColumnView

```

| M3-H38 映射不回写 | M2 材料单元、组成、层序、接触和预算保持不可变 |

| M3-H41 接触保持 | 渐变、清晰、断层、侵入、夹层、混杂和不整合语义在映射后可追溯 |
| M3-H42 断层有据 | 只有具备接触和上游证据时允许分片错移，未知错移不被补成精确落差 |

## 十五、M3-D04 确认结论

M3-D04 已确认：采用版本化、分片三维 `MaterialPlacementTransform`，把 M2 材料坐标显式映射到球面世界几何。连续区域保持层序、接触、体积和方向协变；断层仅在有证据处允许分片不连续，未知错移不编造精确落差。材料放置完成后再与 M3 基础固体表面求交，生成材料柱与出露候选，但不修改 M2，也不冒充后续风化和沉积。复杂多值结构保留多交点和局部三维引用，无法解析时保持未知，不能强行压成单值材料柱。

## 十六、M3-D05：多来源组合、限幅与冲突保留

### 16.1 组合目标

M3-D02 至 D04 会产生区域基底、构造正负响应、材料修饰、几何约束和未解析残差。D05 需要将它们组合成唯一可查询的 `baseElevationField`，同时保留来源关系和不确定性。

以下两种极端都不可接受：

- 把所有数值直接相加，导致同源重复、异常尖峰和无限增长；
- 只保留最终净值或最强来源，导致相反过程、次要控制和冲突证据消失。

因此 M3 采用**有类型的贡献图**。每项贡献先声明自己与其他贡献的关系，再由对应组合器处理。

### 16.2 贡献类型与组合算子

| 贡献类型 | 语义 | 组合方式 |
| --- | --- | --- |
| `REFERENCE` | 唯一垂直参考与零点 | 每个结果只能有一个兼容参考 |
| `BASE` | D02 区域长波基底 | 与参考组合，不能重复出现同一基底来源 |
| `INDEPENDENT_RESPONSE` | 不同物理来源的广域正负响应 | 在响应类型内有界、顺序无关地组合 |
| `PAIRED_RESPONSE` | 同一来源的成对结构，如裂谷轴部与肩部 | 联合求解并共享预算，不拆成独立满额贡献 |
| `EXCLUSIVE_HYPOTHESIS` | 极性或模型解释互斥的候选 | 权重总和受限；未决时保留候选，不同时满额实现 |
| `MODIFIER` | 材料、成熟度或结构对指定响应的修饰 | 只作用于声明目标，不能独立生成高程 |
| `CONSTRAINT` | 几何、材料覆盖或模型适用范围 | 限制合法解域，不能冒充新的物理来源 |
| `RESIDUAL` | 未解析但允许的低频剩余 | 最后使用剩余预算，不能覆盖已知趋势 |

组合关系是数据契约的一部分。未声明类型的贡献不得进入标准生成；不能因为两个字段都有“米”单位就默认相加。

### 16.3 统一来源身份与预算账户

每项贡献至少携带：

```text
contributionId
physicalLineageId
sourceObjectId
budgetAccountId
combinationGroupId
responseKind
operatorKind
targetContributionRefs
signedMeterRange
supportScale
spatialSupport
confidenceAndKnowledgeState
errorEnvelope
```

`physicalLineageId` 用于识别来自同一上游运动或材料证据的派生项。即使两个贡献拥有不同 `contributionId`，只要共享同一物理谱系和预算账户，就不能各自消耗完整预算。组合前必须完成引用闭合、单位兼容、垂直基准兼容和预算账户检查。

### 16.4 固定组合顺序

建议按以下阶段执行：

```text
1. 验证参考、单位、尺度、来源、目标和知识状态
2. 建立贡献依赖图并拒绝非法循环
3. 组合 REFERENCE 与 BASE，形成区域起始面
4. 在各预算账户内处理成对响应和互斥假设
5. 分别组合独立正响应与独立负响应
6. 将 MODIFIER 施加到其指定目标
7. 应用 CONSTRAINT，记录限幅、拒绝和未解析份额
8. 从剩余预算生成受限 RESIDUAL
9. 计算正、负、净高程、冲突指标与误差
10. 生成 M4 剩余预算和完整来源账本
```

这一顺序进入组合模型版本。修饰器不能早于目标存在，残差不能先占用预算，最终限幅也不能反向抹去原始贡献。

### 16.5 同源、独立与互斥来源

不同关系采用不同规则：

- **同源派生**：先在共同预算内分配。例如碰撞、俯冲和压扭来自同一汇聚运动时，不得各取一份完整抬升预算。
- **独立且相容**：可以共同增强结果，但使用有饱和上限的组合器，来源数量增加不能无限增高。
- **成对响应**：共同求解空间形状和预算，例如裂谷轴部沉降与肩部抬升。
- **互斥解释**：候选权重总和不得超过 1；证据不足时保留多候选与误差，不用平均结果伪装成确定解释。
- **相反但可共存**：正负两侧分别组合，随后求净值并保留冲突。
- **修饰关系**：修饰器只能改变指定贡献的幅度、宽度、方向或预算分配，不能脱离目标单独相加。

不同 `sourceObjectId` 不自动意味着物理独立；同一上游运动经多个层次派生后仍由 `physicalLineageId` 识别。

### 16.6 有界组合与限幅

同类独立来源采用版本化、交换且顺序无关的饱和组合。具体函数留待原型标定，但必须满足：

- 单个弱来源保持近似线性响应；
- 多个中等独立来源可以增强结果；
- 接近模型上限时逐渐饱和，而不是无限线性增长；
- 增加极弱来源不会显著削弱已有强来源；
- 输入连续变化时结果连续，不因跨过阈值产生高程台阶。

优先使用平滑饱和函数。硬裁剪只作为超出模型安全域的最后保护，并产生 `CLAMPED` 状态、裁剪前数值、裁剪量及规则版本。不能在裁剪边缘制造新的山脊或盆地。

上限和下限来自 `earthlike-v1` 的响应适用范围及来源预算，不根据每颗行星的最高点、最低点或平均值重新缩放。

### 16.7 正负贡献与冲突指标

M3 分别保存：

```text
combinedPositiveContribution
combinedNegativeContribution
netElevationContribution
processConflictIndex
directionConflictIndex
hypothesisConflictState
budgetConflictState
```

净贡献可用于形成基础高程，但不能替代正负分量。例如强抬升与强沉降相互抵消后，净值可能接近零，`processConflictIndex` 仍应较高。

冲突至少区分：

- **过程竞争**：可共存的正负作用同时较强；
- **方向冲突**：多个结构方向缺少稳定主方向；
- **解释冲突**：互斥模型候选均有证据但无法裁决；
- **预算冲突**：请求消耗超过来源账户或 M3/M4 总预算；
- **几何冲突**：组合高程与材料覆盖、合法应变或接触关系不相容。

冲突不能统一转换成降低置信度。作用强度、知识状态、模型冲突和数值误差分别保留。

### 16.8 材料修饰的组合边界

材料密度对区域浮力的贡献已在 D02 处理；D05 不能再次把同一密度异常作为独立高程加入。材料在此主要作为指定构造响应的修饰器：

- 强度和结构可改变响应宽度与局部化程度；
- 密度及支撑能力可在声明范围内调整米制幅度；
- 层序和断层关系可限制几何映射的合法解；
- 未解析材料状态扩大误差或保留未决预算。

多个材料修饰器若来自同一属性链，应先合成为一个目标修饰，不能连乘到无限放大或衰减。修饰后符号反转只有在模型明确允许且有对应物理语义时才合法；默认禁止。

### 16.9 残差与全局漂移

`boundedUnresolvedResidual` 最后生成，并满足：

- 只使用每个尺度带和区域的剩余预算；
- 在声明支持域内满足零均值或已声明均值约束，避免偷偷移动区域基准；
- 与已知主要趋势正交或受相关上限约束，不能复制一份模糊的构造响应；
- 不用于修补材料映射失败、来源缺失或预算冲突；
- 不触发全世界重新居中或按极值重标。

高程贡献本身不是严格质量守恒量，因此 M3 不强制全行星正负积分为零。只有明确成对的物理响应需要遵守其局部联合预算。

### 16.10 缺失、未知和部分覆盖

组合器不能把未知值当零，也不能在缺少一个候选时自动重新归一化其他候选以填满预算。对于部分覆盖：

- 已知区域继续生成，并保留实际覆盖边界；
- 过渡带根据模型声明扩展，防止截断台阶；
- 必需来源缺失时相应结果保持未知或阻断发布；
- 允许降级时记录 fallback、损失能力和新增误差；
- `NOT_APPLICABLE` 不占预算，`ZERO` 表示已计算且近零，两者不可互换。

### 16.11 空间连续与确定性归约

来源优先作为球面可查询场组合，再采样到网格。组合器不能依赖瓦片遍历顺序、线程数、加载顺序或观察范围。实现应：

- 在组合组内按稳定身份执行规范归约；
- 对浮点累积采用版本化数值顺序或等价稳定算法；
- 使同一来源跨立方球面接缝和补丁边界连续；
- 对合法物理不连续只保留显式断点，不用平滑抹除；
- 让局部计算和全球计算在重叠区域得到同一组合结果。

## 十九、M3-D06：跨尺度、区域细化与 M4 预算交付

### 19.1 连续缩放的权威语义

M3 的权威对象不是某一张固定分辨率栅格，而是版本化来源、组合规则和可查询的带限球面场。各 LOD 栅格是同一权威场在不同支持尺度上的采样、重建或摘要：

```text
AuthoritativeSources + ModelVersion + CombinationGraph
    → canonicalBaseElevationField
    → samples / summaries / refinement patches
```

因此连续缩放只改变可见和可计算的空间带宽、采样密度与误差，不改变已经确定的 P0—P1 骨架。相机距离、浏览顺序和显示细分不得进入自然结果。

### 19.2 真实波长与网格 LOD 分离

每项贡献继续使用 M-D05 确认的真实空间波长和支持尺度，例如 P0—P2 尺度带；L1 的四叉 LOD 只是承载这些场的离散分辨率。

- 同一尺度带可以根据纬度、畸变和误差要求在不同 LOD 上采样；
- 提高 LOD 不自动授权更短波长的自然内容；
- 一个贡献只有在当前网格满足其最小采样要求时才可解析；
- 无法解析时保留聚合摘要、误差和未解析比例，不能混叠成伪长波地形；
- 显示网格可以更细，但新增顶点只能插值或渲染，不能成为权威自然细节。

### 19.3 父快照与区域细化补丁

区域细化采用不可变派生补丁：

```text
BaseElevationRefinementPatch
├─ parentSnapshotId
├─ patchId / spatialFootprint
├─ requestedAndActualLOD
├─ resolvedWavelengthBands
├─ sourceAndModelRefs
├─ coreRegion / transitionHalo
├─ sampledFieldsAndSummaries
├─ materialPlacementRefinement
├─ reducedAndRemainingErrors
├─ unresolvedLedger
└─ validationAndDependencyRefs
```

补丁不覆盖父快照。查询时按快照谱系选择覆盖当前位置和所需尺度的最高有效补丁，并返回实际支持尺度和误差。重叠补丁若引用相同父级、来源和模型，交叠核心区必须一致；否则视为版本冲突，不能按生成时间选择一个结果。

### 19.4 细化允许改变什么

细化可以：

- 更准确地采样同一连续来源场；
- 降低空间离散、界面定位和数值积分误差；
- 在父级预算内解析此前聚合的正负贡献分布；
- 解析材料尖灭、薄层、断层错移或多交点结构；
- 将父级未解析预算分配给具有稳定身份的子贡献；
- 改善极值范围、覆盖率、方向分布和冲突位置的估计。

细化不能：

- 移动大陆—洋盆、区域高原或大型盆地骨架；
- 为同一来源重新抽取一组不相关随机数；
- 改变父级面积均值、低阶矩和预算超过约定容差；
- 将父级未知状态无证据改成确定结果；
- 因用户先浏览某地而让该地获得不同自然结果；
- 回写父快照或改变相邻未请求区域的规范状态。

若细化发现父级约束确实错误，应触发回归失败或创建新的上游／M3 快照，而不是静默修补父级。

### 19.5 聚合契约

不同字段使用各自的父子聚合规则：

| 字段 | 子级向父级聚合要求 |
| --- | --- |
| 基础高程 | 真实面积加权均值、范围、方差与低阶矩在容差内闭合 |
| 正负贡献 | 分别聚合均值、极值、覆盖率和来源份额 |
| 方向结构 | 聚合方向张量、多峰和一致性，不直接平均角度 |
| 来源预算 | 按 `budgetAccountId` 汇总消耗、剩余、未解析和裁剪量 |
| 冲突 | 保存平均、最大、高冲突覆盖率和冲突类型份额 |
| 材料几何 | 保持体积、层厚、接触、顺序、多交点和谱系摘要 |
| 置信与误差 | 分离模型误差、输入误差和可由细化降低的离散误差 |

局部极值可以随着细化而变得更准确，但不能仅用极值反向调整整个父级。高程不是严格守恒量，面积均值和低阶矩是跨尺度稳定约束；材料体积与已声明预算则按对应语义守恒。

### 19.6 核心区、过渡区与计算边缘

区域请求必须包含足以覆盖最大来源支持半径的计算边缘：

```text
requestedCore
  + transitionHalo
  + sourceSupportMargin
  = computationFootprint
```

- 核心区可以正式发布；
- 过渡区用于与父级和相邻补丁满足值、梯度及预算衔接；
- 计算边缘只提供边界条件，默认不作为正式结果暴露；
- 支持半径不足时扩大请求、降低可发布核心，或标记边界误差；
- 不能在补丁边缘机械淡入淡出，从而修改来源场或制造环状坡面。

相邻补丁共享稳定来源、随机流和父级边界摘要，跨立方球面面缝使用球面几何计算。

### 19.7 细化请求与优先级

M3 只向 L1 空间细化协调器提交请求，不自行拆分网格。请求理由包括：

- 来源核或材料界面接近当前采样极限；
- 高程梯度、曲率估计或插值误差超限；
- 正负过程竞争集中；
- 三重点、过渡壳或断层多值几何无法解析；
- M4 所需预算包络在当前尺度不可安全下发；
- 用户观察请求对应 P2 优先级，但不得绕过 P0/P1 正确性。

计算资源不足时保留实际完成度、未解析范围和误差，不通过降低自然约束来伪装完成。

### 19.8 向 M4 交付的授权包

M3 不只向 M4 交付一张“剩余高度图”，而是为每个来源、区域和尺度带生成 `ReliefAuthorization`：

```text
ReliefAuthorization
├─ authorizationId
├─ parentBaseElevationSnapshotId
├─ physicalLineageId / sourceObjectRefs
├─ budgetAccountId
├─ spatialEnvelope
├─ allowedWavelengthBands
├─ preferredDirectionAndCoherence
├─ allowedPositiveAndNegativeRanges
├─ consumedByM3
├─ availableToM4
├─ unresolvedAndClippedAmounts
├─ materialAndGeometryConstraints
├─ parentAggregationConstraints
├─ confidenceAndError
└─ modelAndExpiryRefs
```

授权包表达“可以在哪里、以哪些尺度和方向、在多大预算内继续组织起伏”。它不要求 M4 把额度用完，也不预先决定山峰数量、山岭位置或裂谷具体形状。

### 19.9 M4 的低频守界

M4 生成具体起伏时必须满足：

- 只消费授权的波长带和预算账户；
- P0—P1 分量为零或低于规定泄漏容差，不移动 M3 全球／大陆骨架；
- 子级起伏聚合后满足授权包给出的均值、低阶矩和正负范围；
- 具体形态引用同一 `physicalLineageId`，不创建第二份构造来源；
- 材料修饰和方向约束来自授权引用，不绕过 M3 重新读取内部状态；
- 未使用预算保持未使用，不用无意义噪声填满。

若某种具体山系需要非零低频平均抬升，该部分必须已经由 M3 广域响应消费，或由 M3 在授权包中明确提供非零父级矩；M4 不能自行改变这一事实。

### 19.10 消耗账本与不可回写

M4 输出自身的 `ReliefConsumptionLedger`，记录每项授权实际使用的预算和生成对象。它引用 M3 授权包，但不回写 `BaseElevationSnapshot`。完整地形组合时审计：

```text
consumedByM3
+ consumedByM4
+ stillAvailable
+ unresolved
+ clipped
= totalAuthorizedBudget
```

若超过预算、使用错误尺度带或授权已因上游快照变化而失效，M4 结果不可发布。新的 M3 快照会生成新的授权；旧 M4 结果保持绑定旧谱系，而不是自动迁移。

### 19.11 误差如何随细化变化

误差至少拆分为：

```text
inputError
modelError
calibrationError
spatialDiscretizationError
materialGeometryError
combinationReductionError
```

提高 LOD 通常只能降低空间离散和部分材料几何误差，不能自动降低输入、模型或标定误差。误差下降必须有实际新增采样或解析证据；单纯插值更多顶点不能提高置信度。

### 19.12 缓存、失效与确定性

采样栅格、重建系数和查询加速结构是可重建缓存，不构成世界身份。依赖图至少追踪来源、模型、参数、材料映射、组合图、尺度带和父补丁：

- 来源或模型变化创建新派生快照并使相关补丁过期；
- 只重算受影响空间与尺度范围，不清空无关区域；
- 缓存删除、暂停恢复、线程数和请求顺序不改变结果；
- 区域运行与全球运行的重叠核心使用同一规范求值规则；
- 显示缩放不触发新的自然随机采样。

## 二十一、M3-D06 确认结论

M3-D06 已确认：将权威基础高程定义为版本化来源与组合图生成的带限球面场，各 LOD 只是同一场的采样和摘要。局部细化使用不可变派生补丁，只降低离散误差或在父预算内解析细节，不能重新随机生成或移动 P0—P1 骨架。M3 通过 `ReliefAuthorization` 向 M4 交付按来源、空间、波长、方向和材料约束划分的剩余预算；M4 记录独立消耗账本，不回写 M3，且不得泄漏低频分量或为了用完额度生成噪声。

## 二十二、M3-D07：输出契约、验收与原子发布

### 22.1 原子发布资产

M3 使用四类资产组成不可拆分的正式发布：

```text
BaseElevationRelease
├─ BaseElevationSnapshot
├─ BaseElevationCapabilityManifest
├─ BaseElevationValidationPackage
└─ BaseElevationReleaseManifest
```

- `BaseElevationSnapshot` 保存权威基础高程、贡献图、材料放置、尺度谱系、预算和误差。
- `BaseElevationCapabilityManifest` 声明空间、尺度、深度、字段、查询、细化和消费者能力。
- `BaseElevationValidationPackage` 保存要求、夹具、断言、结果、证据、失败和最小复现。
- `BaseElevationReleaseManifest` 绑定 M1、M2、构造发布、模型参数、随机流及上述资产摘要。

四项必须全部可见或全部不可见。缺少任一项、摘要不一致或依赖已撤销时，不得形成标准发布。

能力清单对每项能力声明：


### 22.4 职责受限的消费者视图

### 22.7 多类验证证据

M3 没有唯一正确的随机世界图像，因此需要组合以下证据：

1. **结构不变量**：引用闭合、单位一致、有限值、合法层厚、预算守恒、依赖无环和发布原子性。
2. **因果关系测试**：只改变壳厚、密度、极性、张裂资格或材料强度时，相关结果按预期方向变化，无关结果保持稳定。
3. **解析与简化基准**：对常密度柱、对称核、单一倾斜层和简单断层等可计算案例比较结果。
4. **变形关系测试**：球面旋转、立方体面重映射、存储重排不改变物理语义。
5. **属性测试**：随机合法输入满足连续、有界、顺序无关、预算闭合和状态传播规则。
6. **跨尺度测试**：子级聚合回到父级，补丁与全球运行重叠一致，短波不泄漏到 P0—P1。
7. **统计校准**：预注册种子组的高程范围、坡度前置统计、基底分布和响应宽度位于版本化类地包络；不要求逐点复制地球。
8. **跨平台确定性**：Windows 与 macOS 在声明数值策略下获得相同规范摘要，允许的浮点差异不得改变分类、预算和发布结论。
9. **消费者契约测试**：M4 只能读取公开视图，越权、过期授权和预算超用可以被拒绝。

视觉检查可以发现山墙、接缝、尖刺和重复纹理等问题，但只作为补充证据，不能单独判定科学合理或正式通过。

### 22.8 验收结论与阻断规则

沿用 L7 已确认的四种结论：

```text
PASS
CONDITIONAL_PASS
FAIL
UNVERIFIED
```

执行状态、适用性、断言严重级与最终结论分开。以下任一情况阻断标准发布：

- 上游 M1、M2 或构造依赖并非正式 `PASS + RELEASED`；
- 基础高程包含非有限值、垂直基准不一致或必需范围存在空洞；
- 材料映射出现非法负层厚、自交、无语义重叠或表面覆盖不足；
- 同源重复计权、预算不闭合或 M3/M4 授权不可审计；
- 球面接缝、补丁边缘或局部／全球结果超出必需容差；
- `UNKNOWN`、缺失或未生成被静默当作零；
- 测试 Oracle 泄漏进正式生成路径；
- 必需夹具、消费者契约或复现证据未运行／未验证；
- 资产摘要、依赖身份或模型版本不一致。

`CONDITIONAL_PASS` 只可供清单中具名实验消费者使用，默认不能作为 M4 标准输入。阻断失败不能被其他测试的高通过率抵消。


- 只有验收结论 `PASS` 且必需能力完整时，标准资产可进入 `RELEASED`。
- `SUPERSEDED` 表示由新版本替代，但旧世界仍可按原依赖重现。
- `REVOKED` 表示发现严重契约或科学正确性问题，禁止新的标准消费，但保留历史证据。
- 发布过程使用临时候选和原子提交，崩溃后不能留下半发布状态。
- 发布清单记录生成环境和数值策略，但机器路径、线程数和缓存位置不进入世界身份。

### 22.11 M3 自验收

验证器自身需要一组故障注入夹具，确保它能发现：

- 重复来源和伪造预算闭合；
- 单位或垂直基准错配；
- 非有限值、非法层厚和材料空洞；
- 接缝、补丁环带和低频泄漏；
- 将未知值编码为零；
- 测试 Oracle 泄漏；
- 摘要哈希或依赖身份错配；
- M4 使用过期授权或超额消费；
- 线程／分块变化造成不确定结果。

故障夹具与正式 BE01—BE12 分离，避免“验证器只会验证自己生成的正确样例”。

## 二十四、M3-D07 确认结论

M3-D07 已确认：将基础高程快照、能力清单、验收包和发布清单作为原子发布资产。M4 只通过绑定明确快照的职责受限视图读取基础高程、材料几何和 `ReliefAuthorization`。BE01—BE12 固定夹具组合结构不变量、因果、解析、变形、属性、跨尺度、统计、跨平台和消费者契约证据；视觉效果只作补充。标准发布要求全部上游正式通过、M3 结论为 `PASS`、必需能力有证据且资产摘要一致；失败可定位和自包含复现，验证器另用故障注入完成自验收。

## 二十五、M3 内部一致性复核

M3-D01 至 M3-D07 的职责、数据流和预算关系复核通过，未发现阻断进入 M4 的架构矛盾。复核后的权威顺序为：

```text
M1 正式输入
  → M2 背景材料与材料坐标
  → M3-D02 区域基底
  → M3-D03 米制广域构造响应
  → M3-D05 贡献组合与冲突
  → M3-D04 材料几何放置与基础表面截取
  → M3-D06 跨尺度摘要与 M4 授权
  → M3-D07 验收和发布
```

章节编号表示讨论顺序，不表示强制执行顺序。D02/D03 先产生逐来源贡献，D05 将它们组合成基础高程，D04 再执行完整材料放置、表面截取和几何相容性检查。D05 只能读取 M2 预先声明的材料包络与放置无关约束，不能读取 D04 的截取结果。若 D04 发现不相容，结果失败或保持未解析，不回到 D05 重算。实现可以为性能融合计算步骤，但不能改变这一依赖语义或建立隐式反馈。

复核确认以下边界：

1. **无材料—高程隐式循环**：D02 只用参考材料坐标中的柱密度代理；D03 只用放置无关的背景物性摘要。D04 出露结果不反向修改 D02/D03。
2. **无 M3—M4 双重计权**：M3 广域响应和 M4 具体起伏共享 `physicalLineageId` 与 `budgetAccountId`。
3. **无海陆越权**：M3 高程正负、基础材料出露及盆地候选均不直接决定海洋或陆地。
4. **无尺度身份混淆**：真实波长决定自然内容，LOD 只决定采样能力；局部细化不改变 P0—P1 骨架。
5. **无语义提前命名**：M3 不生成最终山峰、河谷、海沟、裂谷、岛屿或海岸对象。
6. **无发布旁路**：M4 标准输入只能来自 `PASS + RELEASED` 的原子 M3 发布及其受限视图。

需要留待原型标定的事项包括均衡代理参数、各响应曲线、饱和上限、尺度带数值边界、误差容差、补丁支持半径和跨平台数值策略。这些属于定量与工程问题，不改变已确认的架构语义。
