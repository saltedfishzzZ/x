# 材料背景层设计

> **文档状态**
>
> - 文档类型：分层设计
> - 决策状态：已确认
> - 实现状态：未实现
> - 版本：0.1
> - 说明：M2-D01 至 M2-D07 架构决定已全部确认；物性范围、统计门槛与工程格式待验证。

本文讨论地形与材料子引擎的 M2“材料背景层”。M2 从正式 M1 输入发布、壳体状态、构造环境和版本化类地材料先验中生成可供 M3 高程与后续自然过程读取的固体背景。它描述材料可能由什么组成、具有哪些物性、结构和不确定性，不提前生成河流沉积、土壤、成熟岩溶洞穴或当前暴露地貌。

关联：[地形与材料子引擎前置条件清单](地形与材料子引擎前置条件清单（讨论稿）.md) · [输入契约与垂直基底层设计](输入契约与垂直基底层设计（讨论稿）.md) · [板块状态层设计](../构造子引擎/板块状态层设计（讨论稿）.md) · [边界动力学代理层设计](../构造子引擎/边界动力学代理层设计（讨论稿）.md) · [构造地形约束层设计](../构造子引擎/构造地形约束层设计（讨论稿）.md)。

## 一、M2 的职责与边界

### M2 负责

- 将壳体连续属性、构造环境和结构方向转换为材料生成资格。
- 生成材料族组成、连续物性及其联合不确定性。
- 建立相对参考壳层或深度带的背景材料域和初始垂向层序。
- 保存层理、片理、裂隙和破碎带等结构方向代理。
- 区分权威物性、材料组成、岩性族资格和派生岩性解释。
- 为 M3 提供密度、强度、材料浮力代理和起伏修饰条件。
- 为后续入渗、侵蚀、岩溶和地貌识别提供资格，不直接生成结果地貌。
- 输出不可变 `MaterialBackgroundSnapshot`、来源账本和能力声明。

### M2 不负责

- 把大陆壳标签直接翻译成唯一花岗岩，把洋壳标签直接翻译成唯一玄武岩。
- 在没有上游证据时发明精确岩层年代、化学成分或火山活动史。
- 根据尚未生成的最终高程、降水、河流或生态反向修改材料背景。
- 生成河流冲积物、三角洲沉积、海滩砂、土壤、现代风化壳或当前积雪。
- 仅凭可溶性生成溶洞、天坑或暗河。
- 直接决定最终裸露在地表的材料；M3 高程与后续演化会决定切割、覆盖和暴露。

## 二、M2 输入与输出

### 2.1 输入

```text
TerrainMaterialInputRelease  # M1 ADMITTED + PASS + RELEASED
MaterialPriorProfile         # 版本化类地材料先验
MaterialModelManifest
MaterialRunScope
```

通过 M1 输入束读取的上游信息至少包括：

- 连续壳体倾向与置信度；
- 板块和稳定区域对象；
- 汇聚、离散、走滑、压扭与张扭资格；
- 构造方向和破碎带资格；
- 更新或相对年龄代理（仅在上游正式提供时）；
- 构造来源和不确定性；
- 球面空间、垂直基准、LOD 与随机流清单。

### 2.2 输出

```text
MaterialBackgroundSnapshot
├─ MaterialDomainField
├─ MaterialCompositionField
├─ MaterialPropertyField
├─ StructuralFabricField
├─ BackgroundStratigraphy
├─ MaterialEvidenceLedger
├─ MaterialCapabilityManifest
└─ MaterialUncertaintySummary
```

M2 的垂向状态先相对版本化参考壳层和深度带表达。M3 生成固体表面后，再将其与背景层序相交，形成该表面位置的实际截取材料柱和初始暴露候选，避免 M2 依赖尚未生成的最终高程。

## 四、M2-D01：材料背景的因果来源与状态边界

### 4.1 因果链

M2 使用以下因果顺序：

```text
壳体连续状态与构造环境
    ↓
材料成因资格与版本化先验
    ↓
材料组成概率与混合预算
    ↓
连续物性及结构方向
    ↓
背景材料域与相对层序
```

随机流只在上游资格和先验允许的范围内选择材料组合，不能覆盖构造和壳体约束。

### 4.2 可使用的因果来源

| 来源 | 可约束的材料信息 |
| --- | --- |
| 连续壳体倾向 | 大陆性、过渡性、洋性背景资格及密度先验 |
| 稳定核心资格 | 较稳定、较老背景的资格，不等于唯一岩性 |
| 汇聚与缩短 | 变质、混杂、破碎和方向结构资格 |
| 离散与张裂 | 新生成基底、伸展破碎和火成活动资格（上游具备时） |
| 走滑与转换 | 狭长破碎带、剪切方向和混合资格 |
| 盆地与沉降资格 | 继承性背景充填资格，不等于现代河流沉积 |
| 相对年龄或更新代理 | 物性演化先验，仅在上游能力明确时使用 |

任何来源都只能改变带条件的概率、范围和结构，不能单独决定唯一材料。

### 4.3 三类材料状态

M2 区分：

1. **背景基岩与固体母质**：属于 M2 权威输出。
2. **继承性背景覆盖或盆地充填先验**：只有构造和类地先验足以支持时生成，并标记来源与置信。
3. **过程形成的当前覆盖物**：河流沉积、海滩砂、三角洲、土壤、现代风化壳等由后续演化快照产生，不属于 M2。

### 4.4 M2 与 M3 的非循环关系

M2 在最终地表出现前生成相对参考壳层和深度带的背景材料。M3 读取材料密度、强度和结构修饰生成基础高程，再用该固体表面截取 M2 层序。截取只决定哪些背景层位于表面附近，不回写 M2 材料成因。

如果未来模型需要材料—高程迭代，必须通过显式派生快照和收敛规则扩展，首版不建立隐式双向循环。

### 4.5 不允许的快捷映射

```text
大陆壳 → 必定花岗岩
洋壳 → 必定玄武岩
汇聚带 → 必定变质岩
盆地 → 必定沉积岩
可溶材料 → 已存在溶洞
高渗透率 → 已存在地下河
```

合法表达应是带来源和置信的资格、组成范围与物性分布。

## 六、M2-D02：材料族、组成比例与岩性解释

M2 分开保存三个概念：

```text
familyEligibility      # 在当前因果环境中允许哪些材料族
resolvedComposition    # 当前快照已解析的组成比例
interpretedLithology   # 面向查询和地图的派生岩性解释
```

材料族采用版本化分层分类，首版至少区分深成／喷出／火山碎屑火成材料、碎屑／碳酸盐／蒸发岩等沉积材料、片理／块状变质材料、松散材料和未解析材料。具体岩石名称只有在组成、结构、成因与物性共同支持时才可派生。

组成以比例向量表达，并允许保留未解析部分：

```text
sum(resolvedFractions) + unresolvedFraction = 1
```

每个比例同时携带误差或区间。M2 还要区分空间镶嵌、垂向分层、细粒混合、夹层和包体等 `mixtureMode`；相同的 60%/40% 比例在不同混合方式下具有不同水文和力学意义。

粗尺度格元保存面积或体积预算、亚格网非均质性和连续材料域引用，不把占比最大的材料强制当作整格唯一材料。局部细化可以解析更具体的分布，但子级聚合必须保持父级组成预算和未解析比例。

派生岩性解释包含候选列表、置信度、适用尺度、证据和解释规则版本。改变显示名称或解释规则不能回写组成与物性；证据不足时使用 `MIXED`、`UNKNOWN` 或材料族级描述。

## 八、M2-D03：连续物性的联合生成

M2 将属性分为三类：

1. **基础物性**：体积密度、孔隙率、固有渗透率、粒径组成、强度等。
2. **结构有效物性**：考虑裂隙、层理、混合方式和支持尺度后的有效渗透率、强度与各向异性。
3. **过程响应系数**：风化敏感性、侵蚀响应、溶蚀反应等，必须绑定使用它的过程模型和参考条件。

首版权威属性至少包括：

```text
bulkDensityKgM3
porosityFraction
intrinsicPermeabilityM2
cohesionPa
frictionAngle
compressiveStrengthPa
tensileStrengthPa
grainSizeDistribution
solubilityDescriptor
weatheringSusceptibility
erosionResponseDescriptor
fractureStorageProxy
```

每个属性同时声明单位、支持尺度、参考温压／含水条件、有效性、误差、来源和生成方法版本。过程响应系数不是跨模型通用常数，不能脱离其过程契约比较。

物性必须从材料组成、混合方式、构造环境和结构条件联合生成，保留相关关系。例如孔隙率与密度通常相关，但裂隙可能造成高有效渗透而低基质孔隙；强度与裂隙、胶结和层理共同变化。M2 不允许为每个属性分别独立抽样后再简单裁剪。

混合材料同时保存组分物性和有效物性。有效值使用带版本的混合规则：密度可按体积分数聚合，渗透率依赖连通与方向，强度需要弱层和结构控制，不能统一算术平均。结果保存 `effectivePropertyMethodId` 和适用尺度。

不确定性采用联合描述，至少保留区间、相关组或协方差／等价依赖摘要，防止下游把彼此相关的极端误差任意组合。越界样本不能静默截断；拒绝、重采样或有界变换都必须属于版本化生成规则并进入证据。

## 十、M2-D04：背景垂向层序与材料接触

M2 在最终地表生成前，以参考壳层锚定的**材料坐标**描述背景层序，并同时声明可映射到世界几何的垂向有效包络：

```text
BackgroundStratigraphy
├─ verticalCoverageEnvelope
├─ materialCoordinateDescriptor
├─ materialUnits
├─ interfaceSurfaces
├─ contactRelations
├─ relativeOrderGraph
└─ unresolvedBasement
```

每个 `MaterialUnit` 至少包含稳定标识、球面范围、材料坐标中的顶部／底部界面、厚度范围、组成与物性引用、连续性、来源、置信和误差。层厚由上下界面关系派生，不作为脱离层序和变形映射的唯一事实。M2 保存材料单元的相对位置与结构；M3 通过版本化 `MaterialPlacementTransform` 将其抬升、沉降、倾斜或错移到世界径向高程。

接触类型至少区分：

```text
GRADATIONAL       连续渐变
SHARP             清晰接触
FAULTED           断层错接
INTRUSIVE         侵入接触
UNCONFORMITY_PROXY 继承性不整合代理
INTERBEDDED       反复夹层
MIXED_ZONE        混杂过渡带
UNRESOLVED        当前尺度未解析
```

层序允许尖灭、分叉、合并、断层错移和未解析薄层，但必须通过显式对象和关系表达。相互排斥的实体层不能无说明重叠，材料包络内也不能出现无状态空洞；合法混合区、侵入体和断层带需要声明重叠语义。

M2 根据 M1 锁定的地形模型能力和 L5 约束范围提供足够的材料坐标覆盖，使 M3 所有允许的抬升、沉降与固体表面都能映射到有效材料。深于正式需求的区域可以进入 `unresolvedBasement`，但潜在近地表范围不能以未知基底代替。M3 生成 `MaterialPlacementTransform` 与 `MaterialColumnView`：前者把背景层序显式映射到世界几何，后者截取实际表面附近材料；两者都不回写 M2 的材料成因、组成预算或原始层序。

粗尺度保存层厚预算、接触面积／长度摘要、薄层未解析比例和相对顺序。细化可以解析尖灭、夹层或错移，但聚合后保持父级体积预算、顺序约束和接触语义。绝对地质年龄只有上游提供正式能力时才可使用，首版默认保存相对先后与来源代理。

| M2-M36 接触可追溯 | 每个界面可追溯到成因、材料单元、误差和规则版本 |

| M2-M40 年龄守界 | 缺少正式年龄能力时只表达相对先后，不伪造绝对年代 |

## 十二、M2-D05：结构组与材料各向异性

M2 将结构信息分为：

```text
FabricSet          层理、片理和线理等连续组构
FractureSet        节理、裂隙等离散方向组
FaultDamageZone    有上游证据的断层／剪切损伤带代理
EffectiveTensor    在给定尺度下的有效方向性物性
```

方向以行星固连三维向量、局部切平面基和方向张量为权威表达。走向、倾向、倾角只作为可读派生值；平面法向的 `n` 与 `-n` 等价，聚合时不能把等价方向误判为相反结构。

每个结构组至少保存稳定标识、类型、球面与垂向范围、平面法向／线理方向、方向离散度、间距或密度范围、连通代理、强度、来源、尺度、置信和误差。一个材料域可以具有多组结构，例如主层理、交叉节理和构造剪切方向，不能强制压缩成单一角度。

结构方向优先继承正式构造方向、材料接触和层序几何，再由 M1 命名随机流在允许范围内生成细节。缺少方向证据时降低各向异性或保持未知，不默认朝向地图北方。M2 只表达背景结构和有效物性条件，不宣告存在地下水通道、洞穴、滑坡或正在活动的断层。

粗尺度使用方向张量、多个方向峰、密度范围和亚格网连通摘要聚合，避免直接平均角度。局部细化可以解析具体裂隙面和损伤带，但必须保持父级方向分布、密度预算和连通范围。M3 映射材料层序时同步变换结构向量和张量，并保留从原始 M2 结构到世界几何结构的证据。

## 十四、M2-D06：跨尺度表达与局部细化

每个材料查询必须返回 `supportScale`、LOD、覆盖范围和未解析摘要。粗尺度材料状态不是细尺度类别的单值放大，而是一个可守恒的统计与拓扑摘要：

```text
MaterialScaleSummary
├─ compositionBudget
├─ unresolvedFraction
├─ propertyDistribution
├─ effectivePropertyTensors
├─ heterogeneitySummary
├─ structuralOrientationDistribution
├─ stratigraphySummary
├─ contactSummary
└─ domainLineage
```

局部细化读取父级组成、体积、层厚、结构密度、接触和误差预算，通过稳定随机流与因果约束解析新的子材料域。它可以减少未解析比例、细化边界、分解混合域和识别薄层，但不能无来源改变父级预算或范围外状态。

字段按语义聚合：组成与密度使用面积／体积权重；属性分布保留范围和相关结构；渗透率与强度按方向和连通规则有效化；结构保留方向张量和多峰；层序保留相对顺序、厚度预算与接触；岩性解释从聚合后的权威状态重新派生，不直接投票。

材料域具有稳定身份和谱系，可处于 `STABLE`、`REFINED`、`SPLIT`、`MERGED`、`SUPPRESSED` 或 `UNCERTAIN`。细化后边界可在父级误差范围内移动；超出范围需要新来源或判定回归。相邻补丁共享父材料域、边界条件和随机流，避免接缝。

岩性解释遵守分类层级：细尺度具体候选向上聚合为父材料族，粗尺度 `MIXED` 可在细化后分解为多个具体子域，这属于信息增加；同一权威状态在同一尺度与规则版本下必须给出稳定解释。显示语言和名称变化不进入自然状态。

## 十八、确认结论

M2-D01 已确认：M2 从正式 M1 输入发布、连续壳体状态、构造环境、结构方向和版本化材料先验生成背景材料资格、组成与物性；任何单一构造标签都不决定唯一岩性。M2 拥有背景基岩、母质和有证据的继承性层序，不生成依赖气候、水文或地表演化的当前覆盖物。背景层序相对参考壳层表达，M3 生成表面后只执行截取，不回写 M2；首版不建立材料与高程的隐式迭代。

M2-D02 已确认：材料成因资格、权威组成与派生岩性解释分开保存；组成使用带误差的比例向量并保留未解析份额，混合方式显式区分。粗尺度保存组成预算和非均质性，细化保持父级预算；具体岩性名称只有在多类证据共同支持时派生，解释变化不回写权威状态。

M2-D03 已确认：基础物性、结构有效物性和过程响应系数分层表达，全部携带单位、尺度、参考条件、误差、来源和版本。物性按组成、混合方式、构造环境和结构条件联合生成；不同属性使用适配的有效化规则，联合不确定性保留相关结构；过程响应系数绑定对应模型，只表示倾向，不表示过程已经发生。

M2-D04 已确认：背景层序以参考壳层锚定的材料坐标、材料单元、界面和接触关系表达，并覆盖 M3 所有允许形变、固体表面及所需地下深度。层序允许尖灭、夹层、侵入、混杂与断层错移，但重叠、空洞和相对顺序具有明确语义。M3 通过版本化几何映射定位背景层序并截取材料柱，不回写 M2；细化保持父级体积预算、顺序和接触摘要，缺少年龄证据时只表达相对先后。

M2-D05 已确认：层理、片理、线理、裂隙组和有证据的断层损伤带分别建模，方向以球面三维向量和张量为权威；多个结构组、方向离散度、密度和连通代理同时保留。结构来源受构造与层序约束，缺少证据时保持低各向异性或未知；跨尺度用方向分布和张量聚合，M3 几何映射同步变换结构；结构资格不冒充后续过程事实。

M2-D06 已确认：粗尺度材料保存组成和体积预算、联合物性分布、有效张量、非均质性、结构方向分布、层序与接触摘要及域谱系；局部细化只在父级约束和稳定随机流内解析子域，并保持聚合守恒。字段按自身语义聚合，材料域边界变化受误差约束；岩性解释从当前尺度权威状态重新派生，并保持分类层级一致。

M2-D07 已确认：M2 原子发布材料背景快照、能力清单、验收包和发布清单；M3 通过职责受限的公开视图读取材料坐标、组成、物性、结构与误差。MB01—MB08 作为专用固定夹具，并组合因果、属性、统计、变形、跨尺度、跨平台和消费者契约证据。标准发布只接受上游 M1 正式通过、M2 自身 `PASS` 且全部必需能力有证据的资产；失败可复现，M2 具有独立自验收。

至此 M2-D01 至 M2-D07 全部确认。下一阶段进入 [M3 基础高程层设计](基础高程层设计（讨论稿）.md)。
