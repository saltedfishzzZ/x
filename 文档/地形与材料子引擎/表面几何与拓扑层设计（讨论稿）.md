本文讨论地形与材料子引擎的 M5“表面几何与拓扑层”。M5 从 M4 已发布的完整原生固体表面推导尺度相关的坡度、坡向、曲率和局部高差，并识别具有稳定谱系的峰顶、洼地、鞍部、平坦临界区、山脊、谷线、坡面、盆地和陡崖几何候选。它分析已有表面，不重新生成或修整地形。

关联：[地形与材料子引擎前置条件清单](地形与材料子引擎前置条件清单（讨论稿）.md) · [基础高程层设计](基础高程层设计（讨论稿）.md) · [多尺度起伏层设计](多尺度起伏层设计（讨论稿）.md)。

## 一、M5 的职责与边界

### M5 负责

- 只读取 `PASS + RELEASED` 的 M4 发布及 `M5SurfaceGeometryInputView`。
- 在球面度量和明确分析尺度下计算微分几何字段。
- 在平滑区域、显式断点和误差范围内给出合法的坡度、方向和曲率状态。
- 识别峰顶、洼地、鞍部和平坦临界区候选。
- 构建山脊、谷线、坡面、盆地和陡崖几何候选及关系图。
- 为对象保存显著性、支持尺度、置信、误差、来源证据和跨尺度谱系。
- 区分几何对象、固体容器、潜在流路和需要过程证据的地貌名称。
- 向 M6 提供盆地—鞍部关系、固体屏障和潜在排水几何。

### M5 不负责

- 修改、填洼、平滑或重新随机生成 M4 权威高程。
- 为了得到连通河网而强制开槽、烧入河道或消除封闭盆地。
- 根据谷线直接生成河流，根据洼地直接生成湖泊。
- 根据陡坡直接命名山崖、峡谷、海蚀崖或断层崖。
- 根据高程正负决定海洋、岛屿、海岸或湿地。
- 生成气候、水文、侵蚀、风化、搬运、沉积或植被状态。
- 将 M4 发生器控制线复制为山脊或谷线。

## 四、M5-D01：状态所有权与分析边界

### 4.1 M5 是分析层，不是地形生成层

M5 的权威输入是 M4 已完成的 `primarySolidElevationField`。M5 所有字段和对象都必须能够追溯到该表面、分析尺度和算法版本：

```text
M4 原生固体表面
  → M5 尺度化几何字段
  → M5 临界点／线／区域与拓扑候选
  → M6 固体容器和潜在连通接口
```

M5 不允许为了让分析结果“更漂亮”而改变输入高程。若出现噪声尖峰、接缝或不合理形态，应作为 M4 回归证据或新快照问题处理，不能在 M5 静默修面。

### 4.2 两类权威结果

M5 将结果分成两类：

1. **尺度相关几何字段**：坡度、坡向、各类曲率、局部高差、粗糙度和方向一致性。它们必须携带分析尺度，不能脱离尺度讨论“真实坡度”或“真实曲率”。
2. **具有谱系的几何／拓扑对象**：临界区域、山脊候选、谷线候选、坡面区域、盆地、鞍部和陡崖候选。它们具有稳定标识、显著性和跨尺度关系，但仍是几何对象而非成熟地貌名称。

字段与对象分开保存。对象不能只靠一个分类栅格表达，字段也不能被对象边界覆盖。

### 4.3 M4 发生器与 M5 对象的关系

M4 发生器证据可以解释某个 M5 对象可能由什么原生过程形成，但不能决定对象几何：

- M5 从完整合成表面独立提取峰、脊、谷和盆地；
- M4 控制线与 M5 山脊／谷线可以偏离、分叉、合并或没有对应对象；
- 一个 M5 对象可以由多个 M4 发生器共同形成；
- 一个 M4 发生器也可能没有形成达到显著性门槛的 M5 对象；
- M5 对象引用相关发生器作为证据，不反向修改发生器或高程。

这样可防止“模型画了一条山系轴，所以那里必然有一条山脊”的循环定义。

### 4.4 M5 对象与地貌名称的关系

M5 可以输出中性的几何候选：

```text
peakCandidate
depressionCandidate
saddleCandidate
flatCriticalRegion
ridgeCandidate
valleyLineCandidate
slopeRegion
basinObject
cliffGeometryCandidate
```

它们不能直接升级为需要更多证据的地图类别：

- `valleyLineCandidate` 不等于河流、河谷或峡谷；
- `basinObject` 不等于湖泊、沼泽或海盆；
- `cliffGeometryCandidate` 不等于海蚀崖、断层崖或具体山崖地貌；
- `peakCandidate` 不自动成为命名山峰或雪山；
- `ridgeCandidate` 不自动成为山岭、分水岭或板块边界。

后续语义层需要结合材料、位置、气候、水文和过程证据分类。

### 4.5 M5 与 M6 的边界

M5 提供固体几何和拓扑关系，M6 将其整理为下游容器接口：

| 内容 | M5 | M6 |
| --- | --- | --- |
| 固体表面微分几何 | 计算并拥有 | 只读 |
| 洼地、盆地与鞍部几何 | 识别并建立基础关系 | 形成容量、溢出与屏障接口 |
| 潜在下坡方向 | 可作为几何关系 | 形成潜在流路接口 |
| 水量、水位与水体覆盖 | 不拥有 | 仍不求解；交给独立水体／水文系统 |
| 海洋连通和海岸 | 不判断 | 向水体边界求解器提供固体条件 |
| 河网与湖泊 | 不生成 | 不生成最终状态，只提供容器输入 |

M5 不为了水文方便预先填洼。真实封闭盆地必须保留，数值微坑和误差范围内的伪洼地则通过置信、显著性和尺度证据表达，而不是直接修改表面。

### 4.6 权威高程与派生数据

`primarySolidElevationField` 始终由 M4 拥有。M5 的几何字段和对象是绑定该快照的权威派生资产：

- 删除缓存后可由 M4 快照和 M5 模型重建；
- M4 快照变化会使相关 M5 资产过期；
- M5 参数变化创建新 M5 快照，不改变 M4 世界；
- M5 对象不能被写回高程作为下一次分析的隐藏输入；
- 显示抽稀、线条美化和标签布局不进入 M5 权威状态。

### 4.7 平坦区、断点和未定义状态

M5 必须把下列情况作为正常几何状态处理：

- **平坦区**：坡向可能未定义，不能随机指定方向；
- **显式断点**：断层或合法几何不连续处不能跨越求普通导数，应使用单侧状态或断点对象；
- **补丁边界不完整**：halo 不足时几何保持未生成或误差超限；
- **多值材料结构**：不改变单值固体表面，但材料解释保留多交点状态；
- **尺度不足**：小对象保持未解析，不能从插值顶点推断；
- **误差覆盖临界值**：候选保持不确定，不用随机微扰打破平局。

### 4.8 不允许的快捷方式

M5 不允许：

- 把每个局部最大格元都当作独立山峰；
- 用固定像素卷积核在全球所有 LOD 上计算坡度；
- 把等高线弯曲处直接当山脊或谷线；
- 为消除平坦区而加入随机微小高程；
- 先填平所有洼地再构建盆地拓扑；
- 跨断层直接差分并把高度跳变解释成巨大坡度；
- 将 M4 发生器轴复制为几何对象；
- 用地图投影距离代替球面真实距离；
- 用显示平滑后的网格作为分析输入。

### 4.9 M5-D01 验收方向

| 编号 | 验收内容 |
| --- | --- |
| M5-G01 上游准入 | 标准 M5 只接受 `PASS + RELEASED` 且契约兼容的 M4 发布 |
| M5-G02 只读分析 | M5 不修改、填洼、平滑或重新采样成另一份权威高程 |
| M5-G03 字段对象分离 | 几何字段与拓扑对象分别保存并共享来源 |
| M5-G04 发生器非对象 | M4 控制几何不被复制成峰、脊、谷、鞍或盆地 |
| M5-G05 几何非地貌语义 | 候选对象不越权成为河流、湖泊、峡谷、海岸或雪山 |
| M5-G06 盆地非水体 | 固体盆地和洼地不自动拥有水量、水位或覆盖状态 |

| M5-G12 确定性 | 相同 M4 快照、M5 模型和尺度请求产生相同几何状态摘要 |

## 五、M5-D01 确认结论

M5-D01 已确认：M5 是只读表面分析层，拥有尺度化微分几何字段和具有谱系的几何／拓扑候选，但不修改 M4 高程。M4 发生器只作为解释证据，不能直接成为 M5 对象；M5 峰、脊、谷、盆地和陡崖候选也不能越权成为河流、湖泊、峡谷、海岸等过程地貌。M5 保留真实封闭盆地、平坦区、显式断点和未定义状态，向 M6 提供固体容器基础而不求解水量或水体覆盖。

## 六、M5-D02：球面多尺度微分几何

### 6.1 权威表面与球面度量

M5 读取 M4 的球面方向 `n`、参考半径 `R` 和权威高程 `h(n)`，固体表面位置概念上为：

```text
X(n) = (R + h(n)) × n
```

坡度、方向和曲率从三维表面或等价球面切平面度量中计算。经纬度和地图投影只可用于显示或查询输入，不能作为导数空间；显示高程夸张也不能进入计算。

所有距离、面积、邻域和权重使用 L1 真实球面几何。立方球面面编号和局部网格轴不具有自然方向语义。

### 6.2 分析尺度先于导数

地形导数对尺度敏感。M5 不提供一个脱离尺度的唯一坡度或曲率，而是计算：

```text
GeometryField(scaleId, supportRadius, estimatorVersion)
```

每个分析尺度至少声明：

- 目标物理波长或邻域半径；
- 所需最小采样密度和 halo；
- 平滑／拟合核及边界规则；
- 导数阶数与误差模型；
- 可比较的尺度归一方式；
- 允许跨越或必须避开的断点类型。

网格 LOD 只决定某个分析尺度是否可计算。提高 LOD 不自动改变已经请求的物理分析尺度。

### 6.3 尺度化表面不回写 M4

为了计算特定尺度的几何，M5 可以构建只读分析表面：

```text
analysisSurface(scale) = scaleOperator(primarySolidElevation)
```

它只存在于 M5 派生状态，不覆盖 M4 高程。尺度算子必须：

- 在球面真实距离和面积上定义；
- 保持常量场和允许的低阶趋势；
- 对带限输入具有已知响应；
- 在显式断点两侧分别工作，不跨断层普通平滑；
- 不填平盆地、不烧入河道、不为了美观削峰；
- 记录边界截断、核支持不足和滤波误差。

可以使用局部多项式拟合、有限体积、球面小波或其他经验证方法，但语义与误差契约必须一致。

### 6.4 坡度与表面法向

坡度定义为固体表面法向与当地权威“上”方向之间的夹角，或与之等价的球面梯度量：

```text
slopeAngle ∈ [0, π/2]
surfaceNormal
terrainGradientMagnitude
```

M5 同时保留表面法向和梯度误差。坡度是连续表面状态；在显式断点处不计算跨断点坡度，而分别返回两侧单边坡度及独立跳变量。

坡度查询必须携带分析尺度。一个局部细碎表面在 P4 尺度可能很陡，在 P2 尺度仍可能属于缓坡，两者并不矛盾。

### 6.5 坡向与方向状态

坡向是最大下降方向在当地球面切平面中的三维单位向量，经纬方位角只是派生显示值：

```text
descentDirection3D
aspectAzimuthDerived
directionConfidence
```

当梯度幅度不显著高于高程和导数误差时，坡向状态为 `UNDEFINED_FLAT` 或 `UNRESOLVED`，不能随机指定朝北或继承邻格方向。跨位置比较坡向时使用平行移动或等价球面方法，不能直接比较不同切平面的二维角度。

### 6.6 曲率字段

建议至少区分：

- 沿最大坡降方向的剖面曲率；
- 沿等高方向的平面／切向曲率；
- 平均曲率与高斯曲率；
- 主曲率及对应主方向；
- 地形相对曲率与绝对表面曲率。

类地行星球面本身具有约 `1/R` 的背景曲率。若不区分，整颗行星都会被判为凸面。因此：

```text
absoluteSurfaceCurvature  包含参考球面的整体弯曲
reliefCurvature           相对版本化参考球面／尺度化基面的地形曲率
```

峰脊谷盆等地形分析默认使用 `reliefCurvature`；三维几何和精密表面计算可以读取绝对曲率。两者不能共用未注明含义的 `curvature` 字段。

### 6.7 局部高差与粗糙度

局部高差不是固定像素窗口中的最大值减最小值，而是在球面真实邻域和明确尺度中计算。建议保存：

```text
elevationRange
robustReliefRange
elevationVariance
roughnessIndex
directionalRelief
validCoverageFraction
```

极值范围对单点误差敏感，因此同时提供稳健分位范围或等价指标。方向性局部高差沿主方向和横向分别统计。邻域包含显式断点时，连续面内粗糙度和断点跳变贡献分别保存。

### 6.8 显式断点

M4 提供 `explicitDiscontinuityMask` 和相关几何证据。M5 在断点处保存：

```text
discontinuityId
leftAndRightSurfaceState
jumpMagnitudeAndError
oneSidedSlopesAndCurvatures
tangentAndNormalDirections
continuityClass
sourceEvidenceRefs
```

高度跳变不作为一个跨零宽边界的巨大连续坡度。断点附近的普通导数核不能跨越另一侧取样，除非查询明确请求包含跳变的综合指标。

若断点宽度在当前尺度下未解析，返回 `UNRESOLVED_DISCONTINUITY` 及影响范围，而不是在单个格元上制造极端坡度。

### 6.9 数值估计与网格无关性

具体导数算法留待原型比较，但必须满足：

- 使用三维位置、真实边长、面积和邻接；
- 支持不规则球面采样和立方体面边缘；
- 对常量、球面线性趋势、解析曲面和旋转变换给出预期结果；
- 不依赖单元局部 i/j 轴作为全球方向；
- 估计器声明条件数、有效样本数和支持覆盖；
- 邻域病态或样本不足时返回未知，不输出不稳定大值；
- 实现重排和线程数不改变规范摘要。

理论最小采样点数不足以保证高阶导数稳定，实际准入由分析尺度、核形状、方向覆盖和误差共同决定。

### 6.10 误差传播

微分会放大高程误差，曲率通常比坡度更敏感。每个结果至少传播：

```text
inputElevationError
samplingAndFitError
scaleOperatorError
boundaryAndHaloError
discontinuityProximityError
combinedFieldError
```

若信号不显著高于误差：

- 坡度可以给出范围而非精确值；
- 坡向保持未定义或低置信；
- 曲率符号保持未解析；
- 局部极值和临界对象留给 D03 按不确定候选处理。

低置信不能通过把数值压向零来伪装平坦。误差相关性在相邻样本和多尺度间应保留摘要。

### 6.11 跨尺度比较

同一位置可以同时存在多尺度几何状态。跨尺度比较时：

- 使用物理尺度和尺度归一导数，不直接比较不同 LOD 原始差分值；
- 记录特征随尺度出现、增强、合并或消失的过程；
- 粗尺度字段由细尺度合法聚合或同一权威表面重新分析；
- 局部细化不能改变已解析粗尺度结果超出容差；
- 不把 P4 极端坡度直接推广到整个 P2 父区。

D02 只提供字段及尺度关系，具体对象持久性和谱系在 D03—D06 决定。

### 6.12 补丁和邻域边界

区域分析需要：

```text
requestedCore
  + derivativeHalo
  + scaleOperatorSupport
  = geometryComputationFootprint
```

只有核心区可正式发布完整导数。halo 不足时缩小核心或标记边界误差，不能使用单边补零、复制边缘或显示插值凑齐邻域。相邻同谱系补丁在交叠核心应产生一致字段。

## 九、M5-D03：关键点与平坦关键区域

### 9.1 从“单格极值”改为“关键区域”

离散网格中的一个格元比邻格略高，并不意味着它是有意义的峰顶。M5-D03 从指定尺度的 `analysisSurface` 和 D02 几何字段识别关键区域，而不是直接比较原始格元高低。基础状态为：

```text
MAXIMUM_CANDIDATE       # 局部最大关键区域
MINIMUM_CANDIDATE       # 局部最小关键区域
SADDLE_CANDIDATE        # 鞍部关键区域
FLAT_CRITICAL_REGION    # 平坦且拓扑关键的连通区域
REGULAR                 # 非关键区域
UNRESOLVED              # 证据或邻域不足
```

候选首先是具有范围和误差的区域。为了显示、标注或查询，可以从区域内派生代表点，但代表点不是对象身份，也不能取代完整区域。

### 9.2 识别依据

每个分析尺度分别构造等高连通关系、上邻域和下邻域。实现可以采用等价的轮廓树、合并树或离散 Morse 类方法，但必须满足统一语义：

- 最大候选的显著邻域主要向低处连通，不存在可信的更高出口；
- 最小候选的显著邻域主要向高处连通，不存在可信的更低出口；
- 鞍部候选连接两个或更多原本分离的高侧或低侧分支；
- 平坦关键区域由整个等价高程连通区及其边界连接关系共同分类；
- 普通缓坡和平坦但拓扑无关的区域不强制生成关键对象；
- 高程差、梯度或拓扑关系落入误差带时保持候选分布或 `UNRESOLVED`。

拓扑判断使用球面真实邻接，不依赖立方球面的面内四邻域，也不把立方体面角当特殊地理位置。

### 9.3 平台、平底和近似等高区

对高度差与梯度都未显著超过误差阈值的相连样本，先形成平坦等价区：

```text
FlatRegion
├─ memberSupport
├─ elevationInterval
├─ boundaryUpperComponents
├─ boundaryLowerComponents
├─ exitsAndEntries
├─ flatnessConfidence
└─ boundaryCompleteness
```

平台是最大、最小、鞍部还是普通平地，由整个边界的高低连接决定。禁止加入随机微小高程来选出唯一“最高格”或“最低格”。完全常量的全球表面应形成一个全局平坦区域，不得产生数百万个峰或洼地。

### 9.4 显著性与持久性

一个候选成为可发布关键对象，至少综合以下证据：

- 与控制鞍部或包围等高关系之间的垂直持久性；
- 在球面真实面积或长度上的水平支持范围；
- D02 曲率、坡度和方向变化证据；
- 在相邻物理尺度上是否持续存在；
- 信号相对输入、拟合和离散误差的裕度；
- 邻域与补丁边界是否完整；
- 是否受到显式断点影响。

`topologicalPersistence` 表示对象在等高拓扑中的生存范围；面向地图命名的地貌突出度属于后续语义规则，两者不得混用。低于发布门槛的对象仍可作为诊断候选保存，不能为了达到数量目标而提升。

### 9.5 峰、洼地和鞍部的语义边界

- 最大候选只是固体表面的几何高点，不自动成为山峰、山巅或雪山；
- 最小候选只是几何洼地，不自动成为湖泊、天坑、沼泽或内流盆地；
- 鞍部候选只是固体表面的拓扑连接点，不自动成为山口、交通通道或分水岭；
- 一个宽阔高原可以有平坦最大区域而没有单一峰点；
- 一个噪声粗糙面可以有很多局部极值，但只有少数达到目标尺度的显著性要求。

盆地的完整边界、控制鞍部和嵌套关系在 D05 建立。D03 可以保存初步配对关系，但不能提前求水位、汇水量或水体覆盖。

### 9.6 显式断点附近的关键对象

断层、陡坎或其他显式高度跳变两侧分别分析。不能把断点沿线的每个高侧格元判为峰、每个低侧格元判为洼地：

- 连续侧内部按普通关键区域规则识别；
- 跳变的上缘和下缘作为 D04 陡崖候选的输入证据；
- 断点端点、交会点或封闭边界可形成单独拓扑事件，但必须保留断点来源；
- 当前尺度无法解析断点宽度或侧别时返回 `UNRESOLVED_DISCONTINUITY`；
- 任何跨断点配对都必须由显式拓扑规则授权，不能依靠普通邻接自动连接。

### 9.7 补丁边界与全球闭合

球面整体没有人为地图边界，但局部计算补丁有边界。关键区域接触计算边缘时：

- halo 足够且能完成全部上下邻域连接，才可正式发布；
- 邻域不完整时标记 `PROVISIONAL_BOUNDARY`，不得宣称为峰、洼地或鞍部；
- 相邻补丁使用相同快照、尺度和算法时，重叠候选必须可确定性合并；
- 跨立方球面面缝的对象不得复制、截断或改变类型；
- 全球最高与最低区域可作为特殊全局对象存在，其闭合证明必须来自全局覆盖或等价证据。

### 9.8 多尺度关系

D03 在每个物理尺度上独立识别关键区域，并记录候选之间的初步关系：

```text
APPEARS
PERSISTS
MERGES_INTO
SPLITS_FROM
DISAPPEARS_BELOW_SCALE
UNCERTAIN_RELATION
```

细尺度上的多个峰候选可以归入一个粗尺度高地区域；粗尺度一个峰也可以在细尺度解析为多个峰。该关系不是简单父格—子格包含。D03 生成关系证据，稳定跨尺度身份和正式谱系由 D06 决定。

### 9.9 不确定性与分类结果

每个候选保存类型置信或允许类型集合，而不是只给一个强制标签。建议最少记录：

```text
CriticalFeatureCandidateView
├─ candidateRegionGeometry
├─ candidateTypeAndAlternatives
├─ representativeSamplesDerived
├─ elevationAndGradientIntervals
├─ topologicalPersistence
├─ horizontalSupport
├─ curvatureEvidence
├─ analysisScaleAndScaleRelations
├─ provisionalPairingRelations
├─ discontinuityAndBoundaryState
├─ uncertaintyAndErrorBudget
└─ sourceEvidenceRefs
```

若误差区间跨越显著性门槛，结果必须保持不确定。提高采样分辨率可以收窄离散误差，但不能自动消除输入模型误差或知识不确定性。

### 9.10 不允许的快捷方式

M5-D03 不允许：

- 在原始格网上用八邻域比较直接统计峰和洼地；
- 用随机抖动拆分平台区或决定唯一代表点；
- 以峰数量、洼地数量或平均间距为目标反向修改高程；
- 把所有闭合低地直接标为盆地或湖泊；
- 把鞍部直接解释为水文出口或山口；
- 把断点两侧的跳变当作连续极值结构；
- 在 halo 不完整时用边缘复制补全关键关系；
- 把不同物理分析尺度的对象按格元坐标直接视为同一对象。

## 十一、M5-D03 确认结论

M5-D03 已确认：以指定物理尺度的分析表面和 D02 字段识别最大、最小、鞍部与平坦关键区域。对象首先是带误差的区域，代表点只用于派生显示；平台由整体边界连接分类，不使用随机抖动。正式候选需通过拓扑持久性、水平支持、曲率、跨尺度生存、误差裕度和边界完整性联合判断。断点两侧独立分析，补丁边界候选保持暂定；这些对象始终是中性固体几何，不自动成为山峰、湖泊、山口或水文出口。

## 十二、M5-D04：山脊、谷线、坡面与陡崖候选

### 12.1 对象不是一像素线

M5-D04 从 D02 的尺度化几何字段和 D03 的关键区域提取四类对象：

```text
RIDGE_CORRIDOR_CANDIDATE
VALLEY_CORRIDOR_CANDIDATE
SLOPE_REGION_CANDIDATE
CLIFF_GEOMETRY_CANDIDATE
```

山脊和谷线首先表示具有宽度、边界和定位误差的球面走廊。中心线只是为图结构、显示或查询派生的骨架，不是比走廊更权威的自然事实。坡面是具有相对一致下降结构的二维区域；陡崖候选可以是有限宽度的连续陡坡带，也可以是显式高度断点。

所有对象必须绑定 M4 表面快照、物理分析尺度和 D02/D03 证据。原始网格折线、等高线像素和 M4 发生器控制线不能直接成为正式对象。

### 12.2 山脊走廊

山脊候选表示横向离开其中心附近通常下降、沿纵向延伸的高地结构。识别时联合使用：

- 地形相对曲率和主曲率方向；
- 横向高差、两侧下降证据和方向连续性；
- 最大关键区域、鞍部及平台边缘的连接关系；
- 对象长度、宽度、持久性和误差裕度；
- 在相邻尺度上的存在与合并关系。

单个凸曲率样本不足以建立山脊。宽阔山脊、高原边缘和尖锐刃脊允许具有不同横截面；只有证据支持时才派生中心线。山脊候选也不自动成为分水岭，因为分水岭还取决于完整盆地拓扑和后续流向接口。

### 12.3 谷线走廊

谷线候选表示横向离开中心附近通常上升、沿纵向延伸的低地结构。其证据包括：

- 地形相对凹曲率和横向汇聚形态；
- 最大下降方向在走廊附近的会聚，但不得把方向会聚直接当作水流量；
- 最小关键区域、鞍部和平坦低地区域之间的连接；
- 连续纵坡、横截面、长度、宽度和持久性；
- 边界、断点与误差状态。

谷线候选可以位于干谷、冰川遗留谷、构造低地或尚无水文状态的普通低槽中。它不是河流、溪流、地下河、河谷或峡谷。水文系统以后可以读取谷线走廊作为潜在路径证据，但不能把它视为既成河道。

### 12.4 线网连接、分叉与终止

山脊和谷线分别形成图结构：

```text
CorridorGraph
├─ criticalRegionNodes
├─ junctionNodes
├─ endpointNodes
├─ corridorEdges
├─ branchRelations
├─ scaleRelations
└─ unresolvedConnections
```

连接必须根据连续几何与拓扑证据建立：

- 线可在关键区域、平台边界、合法交会区或显式断点处开始、终止、合并或分叉；
- 不允许仅因派生中心线靠近就吸附连接；
- 同尺度的脊线与谷线通常不能在普通连续表面上横穿而不产生关键结构；
- 若投影显示出现交叉，必须检查是否属于不同尺度、局部三维多值结构、断点或数值错误；
- 弱连接和多种同样合理的分支保存为候选关系，不用随机规则选出唯一网络；
- 补丁边界的未完成线段保持暂定端点，不能当成自然终点。

具体可采用 Morse–Smale 复形、曲率脊线、尺度空间骨架或其经验证组合，但输出语义和验收结果必须保持一致。

### 12.5 坡面区域

坡面区域是两条结构边界之间下降方向、坡度范围和曲率形态相对一致的二维连通区域。分区依据至少包括：

- 坡向场的球面连续性；
- 坡度和曲率在目标尺度上的变化；
- 山脊、谷线、关键区域、平坦区和显式断点边界；
- 不确定性是否足以支持明确边界；
- 最小有效面积和形状稳定性。

坡面不是按坡度等级简单涂色。一个坡面内部可以包含小尺度起伏；同一坡度等级也可能属于多个互不相连的坡面。无法稳定划界时应保留复合坡面或未解析边界，不得为了完全覆盖而生成大量碎片。

坡面可以重叠于更粗尺度坡面，但同一尺度的正式坡面核心原则上不重叠。边界置信带可重叠，且必须与核心区域分开表达。

### 12.6 陡崖几何的两种来源

陡崖候选至少分为：

1. `CONTINUOUS_STEEP_BAND`：在当前尺度下具有可解析宽度、显著坡高、持续陡度和边缘结构的连续表面带；
2. `EXPLICIT_JUMP_BOUNDARY`：来自 M4 明确断点，保存两侧单边坡面、跳高和断点方向。

每个候选建议保存：

```text
cliffClass
crestAndToeCorridors
heightOrJumpInterval
resolvedWidth
slopeInterval
lateralContinuity
faceOrientation3D
segmentEndpointsAndJunctions
materialSupportEvidence
resolutionAndErrorState
```

局部高坡度不足以构成陡崖：它还需要坡高、宽度、连续长度、边缘和误差证据。不同尺度可把同一结构表达为连续陡坡带或未解析跳变，但二者必须通过谱系关系连接，不能重复计为两个独立地貌。

材料可帮助解释崖壁保持能力和后续地貌资格，但不能仅凭“坚硬岩石”生成陡崖。陡崖候选也不自动成为山崖、山壁、海崖、江峡壁或断层崖。

### 12.7 平坦区、断点和局部三维例外

- 宽平台边缘可形成脊状或崖状走廊，但平台内部不得伪造唯一脊线；
- 宽平谷底可以形成谷地区域而没有唯一谷线，中心线应保持未定义或多候选；
- 显式断点是陡崖证据，不自动是山脊或谷线；
- 洞穴顶底、悬挑和多值表面只在局部三维扩展中分析，不能压成单值全球表面线；
- 表面入口、天窗或洞口的位置关系可作为后续地下结构接口，不能由普通谷线算法臆造；
- 未解析狭窄结构返回范围与所需分辨率，不通过插值制造精确线位。

### 12.8 跨尺度表达

每个对象都携带支持尺度。粗尺度山脊可以在细尺度分成多条次级脊，粗尺度谷带也可以包含多个细谷；细尺度崖段可聚合为粗尺度陡坡边界。跨尺度关系至少表达：

```text
REFINES
AGGREGATES_INTO
PARALLEL_SUBFEATURE
TERMINATES_BELOW_SCALE
CHANGES_REPRESENTATION
UNCERTAIN_RELATION
```

尺度变化允许对象类型在“宽走廊—中心线”“连续陡坡—跳变边界”等表示间转换，但不得把位置偏差误当新对象。正式稳定身份和谱系仍由 D06 统一决定。

```text
├─ ridgeAndValleyGraphs

```

### 12.10 不允许的快捷方式

M5-D04 不允许：

- 将 M4 山系、裂谷或断层控制线直接复制为脊线、谷线或崖线；
- 只按曲率符号或坡度阈值逐格分类对象；
- 对宽平台、宽谷底强制求一条唯一中心线；
- 把谷线直接当河网，把山脊直接当分水岭；
- 把所有高坡度像元连成陡崖；
- 用显示抽稀、折线平滑或吸附结果作为权威几何；
- 把补丁边缘当自然终点，把立方球面面缝当结构线；
- 为获得连通网络而修改、填平或切割 M4 表面。

## 十四、M5-D04 确认结论

M5-D04 已确认：将山脊和谷线首先表达为带宽度及误差的球面走廊，中心线仅是派生骨架；坡面是由方向场和结构边界共同形成的二维区域；陡崖则区分可解析连续陡坡带与显式高度跳变。所有对象由 D02 几何字段和 D03 关键区域联合支持，不能复制 M4 控制线，也不能只按曲率或坡度阈值逐格分类。线网的起止、合并和分叉必须有连续几何或拓扑证据，补丁边缘保持暂定。谷线、山脊和陡崖仍是中性几何候选，不自动成为河流、分水岭、峡谷或海崖。

## 十五、M5-D05：盆地、控制鞍部与嵌套拓扑

### 15.1 盆地的几何定义

M5 中的盆地是指定物理分析尺度上，由固体表面低位连通关系形成的几何容纳区域。概念上可从最低处逐渐提高查询高程：

```text
低位连通分量在最小关键区域处出现
  → 随查询高程扩张
  → 在鞍部或平坦鞍区与相邻分量合并
  → 形成盆地—鞍部层级
```

这一定义只依赖 M4 固体表面及 M5-D02/D03/D04 的几何证据。它不是已经有水的湖盆，不是河流汇水区，也不是由海平面裁切出来的海盆。高程低于某个全球水准面同样不能直接证明盆地有水或与海洋连通。

### 15.2 盆地状态

建议至少保存以下状态：

```text
CLOSED_GEOMETRIC_BASIN       # 边界和最低控制鞍部均已解析
NESTED_SUB_BASIN             # 位于更大盆地层级内
MERGED_ABOVE_CONTROL_SADDLE  # 超过控制高程后并入父盆地
GLOBAL_TOPOLOGIC_ROOT        # 闭合球面层级的最终根对象
PROVISIONAL_PATCH_BASIN      # 接触补丁边界，闭合性未证明
UNRESOLVED_BASIN             # 误差、平坦区、断点或尺度不足
```

“封闭”只表示在该尺度和固体几何上存在完整边界以及最低越界高程，不表示水量足以填到该处，也不表示蒸发、渗漏、地下连通或人工开口不存在。

### 15.3 控制鞍部和几何溢出关系

控制鞍部是盆地低位连通分量首次与外部或父分量连通的最低可信边界区域。它提供的是几何门槛：

```text
controlSaddleRegion
controlElevationInterval
connectedBasinSides
crestWidthAndSupport
boundaryConfidence
alternativeEqualControls
sourceEvidenceRefs
```

控制鞍部不自动成为水文出口。后续系统仍需判断水是否存在、水位能否达到门槛、材料是否允许渗漏、地下通道是否绕过门槛，以及侵蚀或沉积是否改变边界。

若多个鞍部的高程差未显著超过误差，必须保存并列控制区域或等价出口集合，不能用格元顺序或随机数选择唯一出口。宽平鞍部以区域表达，不能压成一个伪精确点。

### 15.4 嵌套层级与合并结构

盆地可按控制高程形成嵌套层级：小洼地先在较低鞍部合并为复合盆地，复合盆地再在更高鞍部并入更大区域。建议将平坦等价区压缩为单一拓扑节点后，建立：

```text
BasinSaddleTopology
├─ basinNodes
├─ minimumRegionRefs
├─ saddleRegionNodes
├─ parentChildContainment
├─ mergeAtElevationRelations
├─ adjacentAcrossBoundaryRelations
├─ equalControlSets
├─ persistenceAndSignificance
└─ unresolvedRelations
```

对于非退化标量表面，合并层级应保持无环；等高平台、多重同高鞍和误差重叠先形成等价节点，避免伪造任意二叉合并顺序。相邻关系图可以有环，但不得与盆地父子层级混为一张图。

### 15.5 闭合球面的根对象

行星球面没有地图外部，也不存在天然“流向无穷远”的边界。随着查询高程上升，所有低位连通分量最终合并为覆盖全球的根对象。该根对象只用于封闭球面的拓扑完整性：

- 不称为全球盆地或全球海洋；
- 不提供现实水体容量；
- 不把全球最高点当作普通湖泊溢出口；
- 水体系统建立海洋时，必须另行引入水量、水位和连通求解；
- 区域补丁不能自行创建“流出地图”的永久根节点。

### 15.6 盆地边界

盆地边界可由山脊走廊、坡面分界、平台边缘、显式断点或不确定边界带共同组成。边界保存核心和误差带：

- 已解析边界核心用于证明几何闭合；
- 误差带表示边界位置可能移动的范围；
- 显式断点需保存可通行侧、跳高和当前尺度状态；
- 宽平分界区允许多个同等有效的边界位置；
- 边界有缺口或接触未知补丁边缘时，盆地只能是暂定状态。

M5 不为获得闭合边界而抬高洼地、切开鞍部、烧入沟槽或移动山脊。

### 15.7 显著性、微洼地与尺度

数值表面可能包含大量微小洼地。M5 不删除它们，但按尺度和证据分层：

- 垂直持久性：最低区域到控制鞍部的高差；
- 水平支持：真实球面面积、边界长度和形态尺度；
- 误差裕度：持久性相对高程和拓扑误差是否显著；
- 跨尺度生存：对象在相邻分析尺度是否存在或并入父对象；
- 来源状态：是否临近断点、补丁边界或未解析区域。

低于正式门槛的微洼地保留为诊断对象或未解析表面粗糙度，不能通过填洼从 M4 表面删除。后续水文算法若为数值目的采用流向修正，必须保存在自己的派生状态中，不得改写 M5 盆地事实。

### 15.8 容量接口与 M6 边界

M5 向 M6 提供计算固体容器所需的几何基础：

```text
basinRegionAndBoundary
minimumElevationInterval
controlElevationInterval
nestedContainment
surfaceSamplesOrQueryableSurfaceRef
uncertaintyEnvelope
```

M6 可以据此建立面积—高程、体积—高程和溢出连接等容器接口。M5 不拥有最终容量曲线，也不求解水位、水量、海洋覆盖或季节变化。这样可以让同一个固体盆地被海洋、湖泊、湿地、干盐盆地或完全干燥状态复用。

### 15.9 断点、地下结构与不可见连通

- 显式断点可以形成屏障、台阶或边界缺口，但其几何作用必须按两侧和跳高判断；
- 仅凭表面几何不能证明断层带隔水或导水；
- 洞穴、暗河和岩溶管道属于三维地下连通，不能从表面鞍部自动推断；
- 已有局部三维结构时，M5 可引用其入口与固体边界，但地下容器和通道由专门三维拓扑接口表达；
- 地下绕流可能使水文意义上的封闭盆地不封闭，但不会抹去其表面几何盆地身份。

### 15.10 补丁计算与拼接

局部补丁只有在完整覆盖候选盆地边界和全部可能的更低控制路径时，才可发布封闭盆地：

- 接触核心外边缘的低位分量标记为 `PROVISIONAL_PATCH_BASIN`；
- halo 只覆盖局部边界而未排除更低远程鞍部时，不得宣称控制鞍部已确定；
- 相邻补丁拼接后按共享快照、尺度、等价区和拓扑证据合并对象；
- 局部对象标识不能以补丁坐标永久命名；
- 全球与局部分析在相同尺度和完整覆盖下应得到相同嵌套关系。

```text
├─ controlElevationIntervals
├─ parentChildContainment
```

### 15.12 不允许的快捷方式

M5-D05 不允许：

- 先填洼再识别原始盆地拓扑；
- 将低于零高程或低于全球水位的区域直接标为海盆；
- 把盆地直接标成湖泊、沼泽、盐湖或湿地；
- 把控制鞍部直接标成水文出口；
- 用补丁边界充当盆地边界或外部世界；
- 对并列控制鞍部按遍历顺序强选唯一对象；
- 把盆地父子层级与一般空间邻接图混合；
- 从表面封闭性直接推断地下不连通；
- 在 M5 内计算并拥有水量、水位或季节性蓄水状态。

## 十七、M5-D05 确认结论

M5-D05 已确认：用指定尺度固体表面的低位连通分量及其在鞍部的合并过程建立盆地—鞍部拓扑。盆地保存闭合边界、最低区域、控制高程、嵌套层级和误差；并列或平坦控制鞍部以集合或区域表达，不强选唯一点。球面没有地图外部，使用专用全球拓扑根完成层级而不把它解释为海洋。M5 保留微洼地且不填洼，只向 M6 提供构建固体容器所需的几何基础；水量、水位、海洋连通、地下渗漏和水文出口继续由下游系统决定。

## 十八、M5-D06：对象身份、跨尺度谱系与局部三维扩展

### 18.1 身份与几何分离

M5 对象不能以某个格元编号、折线顶点序列或代表点坐标作为永久身份。建议分开四类标识：

```text
candidateKey     # 单次局部计算中的暂定候选键
objectId         # 一个 M5 快照内经归并的对象身份
revisionId       # 对象几何、属性或关系的不可变修订版本
lineageId        # 跨尺度或跨快照追踪同源演化的谱系身份
```

`objectId` 绑定 M4/M5 快照和分析规范；同一对象的中心线、代表点、边界或采样密度变化不应自动改变身份。新 M5 快照不原地修改旧对象，而是创建新修订或新对象，并通过谱系关系说明继承、分裂、合并或替代。

身份判断依赖拓扑角色、空间支持区、相邻对象、控制高程、尺度区间和来源证据的组合。不得仅按几何哈希相等判断，也不得因显示折线变化就产生新自然对象。

### 18.2 单尺度规范对象

在一个固定分析尺度内，对象经历：

```text
局部候选生成
  → 证据与边界完整性检查
  → 重叠候选等价归并
  → 拓扑关系复核
  → 分配快照内 objectId
```

只有覆盖与邻域足够、关系无冲突且误差合格的对象才能成为 `CANONICAL_AT_SCALE`。其余对象保存为：

```text
PROVISIONAL
AMBIGUOUS_EQUIVALENCE
UNRESOLVED_BOUNDARY
CONFLICTING_TOPOLOGY
REJECTED_LOW_SIGNIFICANCE
```

低显著性对象可以保留诊断身份，但不得混入正式查询结果。规范化过程不能修改 M4 表面，也不能为消除冲突而移动对象。

### 18.3 跨尺度关系不是简单父子树

同一自然结构在尺度变化时可能一对一延续、一分多、多合一、改变表示或失去可解析性。因此使用带证据的关系图：

```text
PERSISTS_AS
REFINES_INTO
AGGREGATES_FROM
SPLITS_INTO
MERGES_INTO
CHANGES_REPRESENTATION
APPEARS_AT_SCALE
DISAPPEARS_BELOW_SCALE
NO_CONFIDENT_MATCH
```

每条关系至少携带空间重叠、拓扑角色一致性、高程／方向兼容、邻接保持、尺度区间和匹配置信。关系允许多对多，不能强制把所有细对象塞入唯一粗对象。

`lineageId` 只有在证据超过版本化门槛时共享。证据不足时保存多个匹配候选或 `NO_CONFIDENT_MATCH`，不能依靠最近距离或编号顺序维持虚假稳定。

### 18.4 尺度支持区间与连续缩放

每个对象声明：

```text
nativeScaleInterval
resolvedScaleInterval
significanceByScale
representationByScale
lineageRelations
```

一个粗尺度山脊可在放大后分解为多条次级山脊，一条宽谷带可出现多个细谷轴，连续陡坡也可在粗尺度变成未解析跳变。引擎返回各尺度的合法对象及关系；桌面应用如何渐隐、聚合、标注或防止视觉跳变属于显示层，不写入 M5 权威状态。

LOD 变化不等于自然尺度变化。在相同物理分析尺度下，仅提高采样分辨率时，对象应保持身份和拓扑稳定，除非新证据证明旧对象处于未解析状态。

### 18.5 补丁身份与确定性拼接

局部补丁先产生只在任务范围内有效的 `candidateKey`。正式拼接使用：

- 相同的 M4/M5 快照和分析尺度；
- 重叠核心中的几何支持与误差带；
- 关键区域、线段端点、盆地边界和邻接关系；
- 断点、平台等价区及来源证据；
- 规范化排序和确定性冲突消解。

补丁坐标、任务编号、线程编号和生成先后不能进入正式对象身份。拼接结果与补丁切分方式、处理顺序和并行度无关。

若两个补丁对同一对象给出无法调和的类型或拓扑关系，应生成 `CONFLICTING_TOPOLOGY` 诊断并扩大计算范围，不能静默保留其中一个。若对象跨越尚未加载区域，则继续保持暂定身份。

### 18.6 立方球面接缝与全局规范化

六个立方球面面的边和角只属于存储结构，不是自然边界。跨面归并必须使用 L1 权威球面向量和全局邻接：

- 同一关键区域跨面时只有一个 `objectId`；
- 山脊、谷线和崖带的方向与宽度跨面连续；
- 盆地边界和父子层级不因面缝断裂；
- 面角附近的多补丁归并使用与普通位置相同的规则；
- 面编号改变或等价重映射不能改变规范对象图。

### 18.7 跨快照修订与变化谱系

当 M4 表面、M5 参数或模型版本变化时，旧快照保持不可变。新旧对象可建立：

```text
UNCHANGED_SUCCESSOR
DEFORMED_SUCCESSOR
SPLIT_SUCCESSORS
MERGED_SUCCESSOR
RECLASSIFIED_SUCCESSOR
NEWLY_RESOLVED
RETIRED
AMBIGUOUS_SUCCESSION
```

跨快照继承不能掩盖输入变化。每条继承关系记录旧、新快照、匹配证据和差异摘要。若拓扑角色改变，例如旧洼地在新表面上被打开，应建立重分类或退役关系，不能为了保持标识而继续称作原对象。

缓存失效、重新计算或线程重排不构成自然变化；在输入与模型完全相同时必须复现同一规范身份和摘要。

### 18.8 全球单值表面与局部三维结构

M4/M5 全球主表面仍是沿球面方向定义的单值固体外表面。洞穴、悬挑、石拱、地下河通道和崖下空间可能在同一球面方向上具有多个交点，不能压入这个单值字段。

局部三维扩展使用独立几何命名空间：

```text
Local3DGeometryComponent
├─ localComponentId
├─ globalAnchorRegion
├─ globalToLocalTransform
├─ surfaceOrVolumeRepresentation
├─ portalsAndOpenings
├─ contactsAndContainment
├─ resolutionAndValidityBounds
├─ materialAndSourceRefs
└─ uncertaintyState
```

全球 M5 对象可以通过锚区、入口、接触边界或包含关系引用局部三维组件，但不能把局部三维组件的顶、底和内壁投影成互相覆盖的全球高程。局部组件也不能因暂未加载而从全球对象谱系中消失。

### 18.9 局部三维的职责边界

M5 只建立固体几何组件及其拓扑连接：

- 洞口、天窗、崖壁开口等可作为几何门户候选；
- 洞腔、管道和多层表面的几何连通可以记录；
- 材料接触和误差范围随组件保存；
- 暗河、水位、渗流、坍塌演化和洞穴成因仍由后续系统判断；
- 没有三维证据时不得从地表洼地或岩性资格自动生成洞穴网络。

首版若未实现局部三维求解，仍需保留 `NOT_AVAILABLE`、所需能力和全局锚定接口，避免未来通过破坏全球对象身份来追加地下结构。

### 18.10 对象引用与删除规则

下游快照必须通过不可变 `(snapshotId, objectId, revisionId)` 引用 M5 对象。对象不能物理原地删除：

- 在同一发布中，未通过验收的候选进入诊断集；
- 在新快照中，不再存在的对象标记 `RETIRED` 并保留继承记录；
- 被合并或分裂的旧对象保留历史引用；
- 缓存清除只删除可重建表示，不删除权威谱系；
- 显示层隐藏对象不改变其发布状态。

### 18.11 建议输出

```text
SurfaceObjectIdentityAndLineageView
├─ canonicalObjectsByScale
├─ provisionalAndDiagnosticCandidates
├─ objectRevisionRecords
├─ crossScaleRelationGraph
├─ crossSnapshotSuccessionGraph
├─ patchMergeEvidence
├─ seamConsistencyEvidence
├─ local3DComponentAnchors
├─ identityConflictsAndUncertainty
└─ deterministicIdentityManifest
```

### 18.12 不允许的快捷方式

M5-D06 不允许：

- 使用格元编号、补丁坐标、数组下标或代表点作为永久对象身份；
- 用最近距离为跨尺度对象强制一对一配对；
- 因中心线抽稀或显示几何变化创建新自然对象；
- 让任务顺序、线程数或缓存命中影响对象标识；
- 在补丁冲突时静默采用先完成或高 LOD 一方；
- 把立方球面面缝写入对象边界；
- 在新快照中原地修改旧对象或复用失效身份；
- 将洞穴、多层表面压扁到全球单值高程；
- 在没有三维证据时根据地表或材料资格自动生成地下网络。

## 二十一、M5-D07：输出契约、验收与原子发布

### 21.1 原子发布资产

每个 M5 正式发布由四类不可拆分资产构成：

```text

SurfaceGeometryCapabilityManifest
SurfaceGeometryAcceptanceBundle
SurfaceGeometryReleaseManifest
```

- **几何拓扑快照**：保存字段、对象、关系、谱系、误差和来源引用；

- **验收包**：保存要求、断言、夹具、Oracle、结果、容差和证据摘要；
- **发布清单**：绑定 M4 依赖、M5 模型、参数、数值策略、资产摘要和发布状态。

四类资产必须原子可见。消费者只能看到完整旧版或完整新版，不得读取字段已更新而对象图仍属于旧版的混合状态。缓存、显示简化和空间索引是可重建资产，不参与自然状态身份。

### 21.7 验收证据组合

M5 需要组合：

1. **结构不变量**：引用闭合、单位、有限值、层级无环、图关系合法、摘要一致和发布原子性。
2. **解析基准**：常量球面、单峰、单盆、标准鞍面、平顶、宽谷、连续陡坡和显式跳变。
3. **变形关系**：球面旋转、立方球面重映射、等价采样和存储重排不改变物理语义。
4. **属性测试**：随机合法曲面始终满足状态分离、尺度、拓扑、身份和确定性约束。
5. **跨尺度测试**：字段响应、对象持久性、谱系、表示变化和 LOD 不改变物理尺度。
6. **补丁测试**：halo、暂定对象、重叠归并、冲突检测、跨面与局部／全球一致。
7. **误差测试**：输入、拟合、尺度、断点和边界误差正确传播并能阻止过度分类。
8. **契约测试**：M6、语义层、桌面查询和局部三维消费者只能读取授权视图。
9. **跨平台确定性**：Windows 与 macOS 的允许数值差异不改变对象类型、拓扑、身份和验收结论。
10. **可解释性测试**：每个正式字段和对象可追溯到 M4 表面、尺度、证据与算法版本。

视觉检查可辅助发现接缝、碎片化、锯齿和错误中心线，但不能单独证明几何或拓扑正确。

### 21.8 发布阻断条件

沿用 `PASS`、`CONDITIONAL_PASS`、`FAIL` 和 `UNVERIFIED`。以下任一情况阻断标准发布：

- M4 依赖不是兼容的 `PASS + RELEASED`；
- 垂直基准、球面几何、尺度或单位不一致；
- 必需区域存在非有限字段、覆盖空洞或未声明误差；
- 跨显式断点执行普通导数或把跳变冒充连续陡坡；
- 平坦区被随机拆分，补丁边缘被当成自然边界；
- 关键区域、线网或盆地层级存在未接受的拓扑冲突；
- 对象身份依赖任务顺序、格元、补丁或线程；
- 跨面、重叠补丁或局部／全球结果超出容差；
- M5 修改 M4 表面、填洼或向结果注入成熟地貌／水文语义；
- ST01—ST14 必需夹具或消费者契约未验证；
- Test Oracle 泄漏进入正式分析路径；
- 快照、能力、验收包和发布清单摘要不一致。

`CONDITIONAL_PASS` 只能供能力清单中明确列出的实验消费者读取，默认不能作为 M6 标准输入。高视觉质量、其他夹具通过或平均得分不能抵消阻断失败。

```text

                    ↘ REJECTED
```

## 二十四、M5 内部一致性复核

M5-D01 至 M5-D07 的已确认决定在职责和运行依赖上形成以下单向链：

```text
M4 PASS + RELEASED 与 M5SurfaceGeometryInputView
  → M5-D02 构建只读尺度分析面和微分几何字段
  → M5-D03 识别关键区域及持久性证据
  → M5-D04 构建脊谷走廊、坡面和陡崖候选
  → M5-D05 建立盆地—鞍部层级和固体容器基础
  → M5-D06 规范对象身份、跨尺度谱系、补丁和三维锚点
  → M5-D07 验收并原子发布
```

复核确认：

1. **无表面反馈**：D02—D06 只读 M4 表面，不平滑回写、不填洼，也不为修复对象图修改高程。
2. **无尺度混淆**：物理分析尺度决定字段与对象，LOD 只决定采样资格；跨尺度关系由谱系表达。
3. **无对象循环定义**：D03 关键区域来自字段；D04 读取关键区域构线和面；D05 读取关键区域及边界建立层级，结果不反向改变 D02—D04。
4. **无水文提前求解**：盆地、控制鞍部和谷线是固体几何，水量、水位、海洋连通、河流和地下水保持下游所有权。
5. **无身份依赖执行顺序**：D06 在候选与关系完成后规范化身份，补丁、线程和缓存不参与自然标识。
6. **无全局／局部三维压扁**：全球单值表面和局部多值组件使用独立表示，通过锚区与门户连接。
7. **无语义越权**：峰、脊、谷、盆地和崖保持中性候选，成熟地貌名称需要材料、气候、水文、位置与过程证据。
8. **无发布旁路**：M6 与其他标准消费者只能读取 `PASS + RELEASED` 的受限视图。

需要留待原型标定的事项包括导数估计器、尺度核、显著性与持久性门槛、走廊宽度、坡面分区容差、崖高／坡度门槛、盆地误差带、谱系匹配权重、补丁 halo、跨平台数值策略和局部三维数据结构。这些不改变上述职责与状态语义。
