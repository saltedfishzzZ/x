## 一、为什么要独立设立这个子引擎

构造子引擎只回答“哪里有抬升、沉降、缩短、张裂或方向结构资格”，它不产生最终地表。要得到可供气候、水文和地貌使用的地形容器，还必须处理：

- 构造资格如何转为有单位且有误差的高程。
- 大陆、过渡和洋壳背景如何影响基底高度，而不直接变成海陆标签。
- 岩石与未固结材料的硬度、裂隙、渗透性和抗侵蚀性如何表达。
- 山系、盆地、裂谷和平原等大尺度形态如何继承构造方向。
- 中小尺度起伏如何增加自然变化，又不破坏已确认的全球骨架。
- 坡度、曲率、山脊、谷线、鞍部、盆地和分水结构如何稳定计算。
- 低于海平面的封闭盆地如何不被误标为海洋。

因此，“地形与材料”不是在构造场上叠加一层噪声，而是将构造约束转换为具有几何、材料和拓扑语义的固体行星表面。

## 二、首要边界：原生地形与演化地表

已确认分开两类状态：

| 状态 | 含义 | 生成者 |
| --- | --- | --- |
| `PrimaryTerrainMaterialSnapshot` | 由构造、固体材料和多尺度地形规则生成的原生固体表面 | 地形与材料子引擎 |
| `SurfaceStateSnapshot` | 在原生地形上经气候、水文、风化、侵蚀、搬运和沉积后形成的可探索地表 | 后续地貌演化与耦合流程 |

这一分离有三个作用：

1. 气候和水文可以先获得稳定的固体容器。
2. 河谷、峡谷、冲积平原和三角洲不会在没有水量或沉积物证据时提前出现。
3. 后续侵蚀和沉积通过新派生快照表达，不回写构造快照或原生地形。

M-D01 已确认：两类快照均不可变、可追溯；后续过程通过派生快照记录演化，不覆盖原生结果。固体高程、海洋连通性、水面高程和水体覆盖状态分开建模。

## 三、必需上游输入

### 3.1 世界规格

从 L2 读取：

- 世界标识、种子和 `earthlike-v1` 版本。
- 行星半径、重力等级、参考形状和垂直基准背景。
- 高级偏好及其可以作用的因果参数范围。
- 命名随机流、模型清单和运行计划。

### 3.2 球面空间

从 L1 读取：

- 等角分层立方球面单元、面积、邻接、距离和球面方向。
- 单元中心、共享边、顶点和独立对象几何的权威语义。
- 四叉细化、父子聚合、邻域缓冲和跨面连续契约。

### 3.3 已发布构造快照

只接受满足以下条件的 `TectonicSnapshot`：

- L7 标准发布配置结论为 `PASS`。
- L6 发布状态为 `RELEASED`。
- `TerrainInputView` 契约版本兼容。
- 必需的板块、壳体背景、边界资格、构造约束、方向结构和来源证据完整。
- 没有未接受的缺失、过期或语义不兼容字段。

`DRAFT`、`DIAGNOSTIC_ONLY` 和 `CONDITIONAL_PASS` 构造结果可用于调试地形模型，但不能生成对外声称可信的正式地形快照。

## 四、子引擎输出边界

如果采用“原生地形”分工，输出至少包含：

### 4.1 高程与表面字段

- 垂直基准标识、单位和误差说明。
- 构造基底贡献、长波高程、中尺度起伏和局部起伏的分解账本。
- 基岩表面、初始未固结覆盖厚度与原生地表高程。
- 数值置信、细化状态、来源证据和适用尺度。

### 4.2 材料状态

- 材料族或岩性资格，而不是在证据不足时强制命名具体岩石。
- 体积密度、抗侵蚀性、风化敏感性、孔隙与渗透性、裂隙／层理方向等下游属性及其范围。
- 基岩、风化层、初始未固结覆盖与未知材料的显式状态。
- 构造来源、初始材料生成规则和不确定性证据。

### 4.3 几何与拓扑摘要

- 坡度、坡向、曲率、局部高差和起伏尺度。
- 山脊、谷线、鞍部、盆地、高地和平坦面候选。
- 盆地容积—高程关系、最低鞍部、潜在溢出口和球面连通关系。
- 不依赖已存在水量的潜在流路和分水结构；它们是地形容器，不是河流。

### 4.4 不属于输出的结论

- 最终海洋、海岸、湖泊或湿地水面。
- 由降水、融雪或地下水供给的河流、泉水和暗河。
- 经持续流水侵蚀证明的河谷、峡谷、河曲或瀑布。
- 由搬运与沉积形成的冲积平原、河洲和三角洲。
- 植被、草原、荒漠、雪原等气候与覆盖结论。

子引擎可以输出“适于形成”的几何或材料候选，但不能把候选升级为需要后续过程证据的最终地貌。

## 六、建议的子引擎分层

`M` 表示地形与材料子引擎内部层级，与构造子引擎 L1—L7 区分。

```text
┌────────────────────────────────────────────┐
│ M7  输出与验收：快照、契约、证据、失败定位  │
├────────────────────────────────────────────┤
│ M6  容器接口：盆地、鞍部、潜在流路、海洋求解输入 │
├────────────────────────────────────────────┤
│ M5  几何拓扑：坡度、曲率、脊线、谷线、鞍部、盆地 │
├────────────────────────────────────────────┤
│ M4  多尺度起伏：构造导向形态、中小尺度变化、细化 │
├────────────────────────────────────────────┤
│ M3  基础高程：垂直基准、构造响应、长波高程、限幅 │
├────────────────────────────────────────────┤
│ M2  材料背景：材料族、基岩属性、结构方向、不确定性 │
├────────────────────────────────────────────┤
│ M1  输入契约：世界规格、球面空间、构造准入、随机流 │
└────────────────────────────────────────────┘
```

### M1：输入契约与垂直基础

**回答**：哪一份构造快照可用？行星表面和高程以什么为基准？哪些计算会改变世界身份？

**拥有**：输入能力协商、垂直基准描述、单位、高程精度、命名随机流和运行清单。

### M2：材料背景层

**回答**：构造与壳体状态允许哪些材料族和连续物性？

**拥有**：材料族资格、密度范围、抗侵蚀性、风化敏感性、孔隙率、渗透性、裂隙／层理方向和置信。

**不负责**：从“大陆性高”直接生成唯一花岗岩类型，或凭空设定绝对岩层年代。

### M3：基础高程层

**回答**：构造基底、抬升、沉降、缩短、张裂和材料浮力代理如何形成长波高程？

**拥有**：高程贡献账本、有界响应、过渡宽度、冲突指数、参考米值与不确定性。

**不负责**：直接将 L5 约束值当成高程，或对每个世界按最低点和最高点重新拉伸。

### M4：多尺度起伏层

**回答**：如何在长波骨架上生成受构造方向、材料和局部尺度约束的中小尺度形态？

**拥有**：尺度带、方向纹理、振幅包络、空间相关、边界衰减、局部细化补丁与来源账本。

**不负责**：以一张无方向噪声替代山系、盆地和裂谷成因。

### M5：表面几何与拓扑层

**回答**：地表在局部和区域尺度上有什么几何关系？

**拥有**：坡度、坡向、曲率、局部高差、脊线、谷线、鞍部、盆地、平坦面、崖壁几何候选及它们的稳定对象。

**不负责**：在无水量与侵蚀证据时将几何谷线命名为河谷或峡谷。

### M6：固体容器与水体边界接口层

**回答**：下游如何利用地形求解海洋连通、湖盆容量和潜在排水路径？

**拥有**：面积—高程分布、盆地容积曲线、最低鞍部、溢出候选、连通分量和地形屏障。

**当前建议不拥有**：全球水量账本、海平面求解和最终海陆状态。这些应由后续的水体边界求解器同时读取地形容器和 L2 水量背景后得出。

### M7：输出契约与验收层

**回答**：地形与材料结果是否连续、可重现、可追溯，且足以成为下游容器？

**拥有**：不可变 `PrimaryTerrainMaterialSnapshot`、消费者视图、证据图、失效范围、固定测试资产、跨尺度与跨平台验收。

## 七、不可破坏的基本规则

1. **构造约束不是高程**：L5 抬升资格不能直接写入最终米值。
2. **板块边界不是山脊线**：地形对边界的响应必须具有宽度、衰减、不对称、端部和多来源组合。
3. **壳体倾向不是岩性名称**：大陆性、洋性和过渡性只约束材料可能性。
4. **高程正负不是海陆**：海洋必须同时满足水量、水位和连通关系。
5. **几何候选不是过程地貌**：谷线、崖壁或盆地不能在无过程证据时升级为河谷、瀑布或湖泊。
6. **不按世界极值重标定**：不用每颗世界的最低／最高值拉伸整个高程范围。
7. **噪声不是成因**：随机场只能在已声明的尺度、方向、振幅和材料条件内补充变化。
8. **细化不改写骨架**：局部高精度结果通过新补丁发布，不回写父快照或无关区域。
9. **地貌演化不回写原生地形**：风化、侵蚀和沉积产生派生地表快照。
10. **显示不修改事实**：高程夸张、投影、阴影和纹理只属于可视化。

## 八、必需的消费者契约

| 消费者 | 允许读取 | 禁止误用 |
| --- | --- | --- |
| 水体边界求解 | 地表高程、连通、盆地容积、鞍部和屏障 | 不得把负高程直接当成海洋 |
| 气候 | 经水体边界求解后的海陆、地表高程、坡向和山地屏障 | 不得从构造抬升资格直接生成雨影 |
| 水文 | 地表、盆地、鞍部、潜在流路、渗透性和未固结覆盖 | 不得将潜在流路当成有水河流 |
| 地貌演化 | 高程、几何、材料性质、水文与沉积物账本 | 不得不经派生快照回写原生地形 |
| 地貌分类 | 地形、材料、气候、水文、演化证据和对象关系 | 不得用标签反向修改高程或材料 |
| 局部三维 | 权威高程、材料、方向结构、几何对象和显示精度提示 | 不得将网格细分或纹理假细节回写自然状态 |

## 九、首批验收场景方向

具体测试世界尚未冻结，但至少需要覆盖：

1. **汇聚高地与邻接盆地**：验证宽响应、不对称、端部衰减和无等高山墙。
2. **大陆裂谷**：验证轴部沉降、受限肩部抬升和方向连续。
3. **稳定大陆内部**：验证起伏受控，不因“稳定核心”自动变成高原。
4. **跨板块同材料背景**：验证板块标识本身不制造高程或材料台阶。
5. **低于参考海平面的封闭盆地**：验证地形容器不自动标记为海洋。
6. **跨立方球面山脊与盆地**：验证接缝、方向、坡度和拓扑连续。
7. **局部细化**：验证父级高程摘要、脊线、盆地、材料边界和无关区域不漂移。
8. **材料渐变与结构转向**：验证连续物性、类别资格、UNKNOWN 和方向字段的分界语义。

视觉检查可用于发现条带、尖刺、伪周期和过度平滑，但正式验收仍必须使用数值、几何、拓扑、变形关系和跨尺度证据。

## 十一、当前建议

M-D01 已确认：地形与材料子引擎生成 `PrimaryTerrainMaterialSnapshot`，后续自然过程通过派生的 `SurfaceStateSnapshot` 表达演化，并分别保留来源与变化账本。

M-D02 已确认：首版以 L1 权威球面向量和版本化参考半径定义垂直基准；权威高程以米表示并携带表面类型、LOD、支持尺度、误差、来源和快照语义。参考球面、固体表面、水面、冰雪表面与显示高度分别保存；局部三维坐标从全球球面位置派生；显示夸张只属于渲染状态。

M-D03 已确认：原生高程由唯一基准、大尺度形体、构造响应、中尺度起伏、局部细节和材料修饰共同形成；全部贡献进入结构化账本并声明来源、尺度、范围、方向、振幅、误差、预算和组合语义。正负贡献、净结果和冲突程度分别保存，不按单颗行星极值重新归一化。

M-D04 已确认：材料状态采用垂向材料柱，由连续物性、材料组成、结构方向、岩性族资格、派生岩性解释和分类置信度构成。连续物性是自然计算的主要输入；粗尺度保留混合与非均质性；材料只提供侵蚀、入渗、岩溶及地貌形成资格；原生与演化材料分别进入对应快照。

M-D05 已确认：多尺度地形按真实空间波长划分尺度带；每项贡献声明成因、方向、振幅、范围、材料修饰、稳定随机流和聚合规则。广域场、带状结构、区域形体及受约束残差场分工生成；随机性不越过自然资格，局部细化遵守尺度预算和父子聚合契约，原生阶段不提前生成依赖气候、水文或侵蚀的成熟地貌。

M-D06 已确认：权威高程场之上分别建立尺度相关的微分几何字段与尺度稳定的拓扑对象图。峰顶、洼地、鞍部、平坦临界区、山脊、谷线、坡面、盆地和陡崖候选具有稳定标识、来源、误差、显著性及跨 LOD 谱系；盆地与水体、基础对象与地貌名称分开；局部三维结构通过全球抽象连接扩展。

M-D07 已确认：地形与材料子引擎提供固体高程、盆地—鞍部拓扑、高程—面积—体积关系、亚格网海岸信息和材料状态；独立水体边界求解器根据版本化海洋种子、固定水位或全球海洋水量生成 `WaterBoundarySnapshot`。海洋覆盖同时要求低于水位并与海洋组件连通；内陆湖泊和湿地归水文子引擎。

M-D08 已确认：局部细化通过引用不可变父快照的派生补丁实现；查询组合父级骨架与最高有效补丁并返回实际尺度和误差；每类字段声明细化、聚合、插值与误差传播规则。依赖图控制最小失效范围，缓存与权威状态分离；后续自然过程通过读取冻结状态并生成代际 `SurfaceStateSnapshot` 实现反馈。

M-D09 已确认：`PrimaryTerrainMaterialSnapshot`、`TerrainMaterialCapabilityManifest`、`TerrainMaterialValidationPackage` 与 `TerrainMaterialReleaseManifest` 原子绑定；公共权威数据、诊断证据和缓存分层管理；TM01—TM09 作为首批固定世界。标准发布要求上游构造正式通过、地形材料结论为 `PASS` 且全部必需能力具有证据。

M-D01 至 M-D09 已全部确认，前置架构讨论完成。下一阶段进入 [M1 输入契约与垂直基底层设计](输入契约与垂直基底层设计（讨论稿）.md)，首先讨论 M1-D01 上游准入与正式生成资格。
