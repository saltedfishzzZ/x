> - 文档类型：验收规范

本文将已经确认的产品方向转化为可检查的验收要求。它不代表任何模型、公式、参数、分辨率、性能预算或技术方案已经冻结；历史原型记录也不能替代本标准中的未来验证。

适用范围：固定类地背景下的种子世界，以地图探索与观察为主，从全球、区域深入至地貌级；固定地理骨架配合可切换的代表性季节状态。地下内部只表达位置、范围与连接关系，不要求场景级漫游。

关联：[当前共识与待定事项](../项目管理/当前共识与待定事项.md) · [自然系统耦合与模型边界](../总体架构/自然系统耦合与模型边界.md) · [沟通进度与决策清单](../项目管理/沟通进度与决策清单.md)。

## 一、验收原则

1. 自然合理性优先于景观种类齐全。景观目录表示引擎支持范围，不要求每颗行星同时拥有全部景观。
2. 首先验证世界内部关系，再评估视觉表现。图片好看不能替代水量、连接、材料和季节关系的检查。
3. 对象必须能追溯到真正参与生成的条件；不得先随机画出对象，再补写成因故事。
4. 未启用的过程不能被描述为已模拟。必要条件不足时，采用候选、泛化或不生成，而不是强行生成更具体的景观。
5. 组件分别通过不代表组合通过；气候、地形、水文、材料与分类之间的交换也必须验收。

## 二、验收对象与结果状态

每个世界、区域或对象都应具备以下之一的状态：

| 状态 | 含义 | 允许的地图表达 |
| --- | --- | --- |
| 已计算 | 必要条件及核心状态由当前模型求得 | 正式对象或状态 |
| 受约束生成 | 条件已满足，局部形态使用明确近似生成 | 正式对象，说明近似边界 |
| 候选 | 部分条件满足，缺少关键过程或证据 | 候选区、潜在位置或高级图层 |
| 泛化表达 | 可确定较宽泛的地貌，不能确认精确类型 | 宽泛名称，不作强成因断言 |
| 不生成 | 必要条件不足或违反硬约束 | 不显示该对象 |

对象状态不是“真实性评分”。它表示当前模型可以对该对象作出多强的结论。

## 三、硬约束：不满足即拒绝有效输出

以下失败属于阻断级问题。发生时，世界或受影响区域不能被标记为有效生成结果。

| 编号 | 约束 | 必须检查的内容 |
| --- | --- | --- |
| H01 | 空间一致 | 单元面积、邻接、边界和跨尺度映射有效；对象不会跨越不允许的空间边界 |
| H02 | 地形连接 | 主河、湖泊出口、海洋连接、流域分水岭和地下通道的已声明连接无矛盾 |
| H03 | 水量收支 | 对已启用的水库和边界，储量变化等于输入减输出；不出现负储量或重复用水 |
| H04 | 分流守恒 | 汇合、分流、漫流、入湖和入海的水量去向完整；同一份水不会因分叉重复计算 |
| H05 | 季节连续 | 同一世界的地形和对象身份稳定；雪水、湖泊、土壤水等启用状态按规定在季节间传递 |
| H06 | 材料前提 | 依赖岩性、渗透性、可溶性或沉积物的对象具有相应材料依据 |
| H07 | 数据来源 | 每个重要对象的生成依据、模型版本、近似和未启用过程可追溯 |
| H08 | 复现 | 相同种子、完整配置和版本可得到相同权威世界数据；跨平台精度要求另行规定 |

H03 的系统边界必须写清。海洋、深层地下水、蒸发和外部水汽输入属于系统内还是外部库，不能在不同模块中采用互相冲突的定义。

## 四、代表区域验收

每类区域是“引擎应支持的场景”，不是每颗行星都必须拥有的清单。若某世界缺少该类环境，只要原因合理，不判为失败。

验收方式已确定为：**每一类代表区域准备固定的专门测试世界。** 测试世界的地形、材料、外部边界、初始状态和预期现象必须受控，以便定位模型错误；随机生成世界用于检查组合表现与探索一致性，但不承担“恰好抽到所有景观”的责任。

### R01 湿润山地流域

预期链条：海洋水汽或其他湿润来源 → 迎风山坡降水 → 积雪与融雪或降雨径流 → 山溪、支流与河谷。

必须满足：

- 山地、流域和下游去向在空间上连续。
- 降水、积雪、融雪和河流来水之间存在已记录的关系。
- 瀑布仅在满足河流、水量和河床台阶等条件时正式生成。
- 雪原或季节积雪由温度、固态降水与积雪持续性决定，不只由海拔决定。

可受约束生成：山涧、峡谷、局部崖壁、瀑布外观和山林边界。

详细固定测试世界规范见 [T01 湿润山地流域测试世界规范](测试世界/湿润山地流域测试世界规范（讨论稿）.md)。

### R02 背风内陆盆地

预期链条：山脉雨影或内陆距离 → 有效水分不足 → 草原、戈壁、荒漠或内流盆地；上游来水可在局部形成季节河、湖泊或绿洲。

必须满足：

- 背风干燥可追溯到水汽输送、降水减少或蒸发需求，而非随机标签。
- 荒漠或戈壁不能阻断已有上游大河的水量来源。
- 内流湖或季节湖的水位与流域输入、蒸发和出口条件一致。
- 戈壁除干旱外还需具备相应裸岩、砾石或粗颗粒材料依据。

详细固定测试世界规范见 [T02 背风内陆盆地测试世界规范](测试世界/背风内陆盆地测试世界规范（讨论稿）.md)。

### R03 低坡冲积平原

预期链条：大流域来水 → 低坡度与可沉积材料 → 宽河道、河曲、河滩、江洲及湿地。

必须满足：

- 主河与支流存在合理汇合关系，季节流量能追溯到上游。
- 河曲不出现在不满足低坡度、宽谷地或河岸材料条件的陡峭峡谷中。
- 湿地必须有明确水源、水文周期和最终排水或内流去向。
- 河滩、江洲与河中岛不在没有分流或沉积条件的狭窄山溪中生成。

详细固定测试世界规范见 [T03 低坡冲积平原测试世界规范](测试世界/低坡冲积平原测试世界规范（讨论稿）.md)。

### R04 河口与三角洲

预期链条：大河入海 → 多路径分流 → 沉积物输入与海岸保留 → 河口湿地、分汊河道与三角洲。

必须满足：

- 所有分流路径按水量守恒连接至海洋、湿地、湖泊或后续汇合点。
- 正式三角洲具有上游沉积物来源、河口沉积与海岸保留的简化依据。
- 未建立沉积物过程时，只能显示为河口、分汊河口或河口湿地，不得作正式三角洲断言。

暂不要求：潮汐、波浪、风暴潮、长期海岸推进和河道迁移的完整模拟。

### R05 岩溶高地

预期链条：可溶岩层 → 入渗与裂隙／地下排水 → 地下通道与出露 → 溶洞、暗河、天坑、石林、山泉或涌泉。

必须满足：

- 正式喀斯特对象具有可溶性材料和水文条件依据。
- 泉水、涌泉需要地下补给与出露条件；不能仅因位于山地而生成。
- 暗河与地表入流、地下通道、出露或下游去向的连接可追溯。
- 天坑若未模拟岩体力学，只能被说明为受条件约束的塌陷候选或形态近似。

暂不要求：洞穴内部可漫游、完整三维地下水流场、塌陷时间和洞穴长期溶蚀演化。

### R06 差异侵蚀高地

预期链条：材料差异与构造背景 → 抬升、下切或差异侵蚀的形态条件 → 山崖、山壁、峡谷、石滩、残丘。

必须满足：

- 陡崖、峡谷与残丘具有高程、坡度、材料或构造依据。
- “岱崮”必须使用项目已定义的残丘形态与近似说明，不能声称复现某一现实地区的完整地质历史。
- 石滩等材料性景观应有河流、海岸、坡积或风化来源。

## 五、对象级验收

| 对象组 | 正式生成的最低要求 | 缺失过程时的降级方式 |
| --- | --- | --- |
| 河流与大江 | 上游来源、河道连接、季节水量、下游去向 | 季节河或潜在排水路径 |
| 湖泊 | 盆地、库容／水位关系、来水、蒸发与出口或内流边界 | 盆地、低地或季节水面候选 |
| 积雪与雪原 | 雨雪分配、雪水当量、融雪或保留条件 | 寒冷高地或季节霜冻状态 |
| 湿地 | 水源、水文周期、滞水和排水条件 | 潮湿低地或候选湿地 |
| 瀑布 | 河流、水量、河床台阶和局部坡降 | 陡坡河段 |
| 河曲、河滩、江洲 | 河道条件、低坡度或沉积物／分流依据 | 一般河道或泛化河岸 |
| 三角洲 | 河口、水量分流、沉积物与海岸保留依据 | 分汊河口或河口湿地 |
| 泉水与涌泉 | 地下补给、材料传水性和出露条件 | 地下水出露候选 |
| 溶洞、暗河、天坑、石林 | 可溶材料、入渗与地下排水或差异风化依据 | 岩溶候选区、洞口候选或一般岩地 |

## 六、季节与跨尺度验收

### 季节状态

- 季节切换不重新随机生成地形、岩性、流域、主河网或对象身份。
- 温度、降水、蒸发需求、雨雪比例、积雪、河流状态、湖岸和湿地范围的变化具有同一世界内的状态传递依据。
- 积雪先进入雪水当量，融化后才进入地表或地下水量；不能同时作为积雪和河流来水重复使用。
- 季节展示可以是代表状态；内部计算时间步、初始条件、周期收敛与展示状态必须分别记录。

### 跨尺度

- 全球层确定的海陆、山系、主流域、主要河流、材料区和季节背景，在区域与地貌层保持身份和连接一致。
- 细化可以增加支流、崖壁、河滩、湖岸和洞口等局部信息，但不得无记录地改变分水岭、主要出口、海岸连通、主河流向或材料大区。
- 若局部修改确实影响上述条件，相关气候、水文、分类和对象状态必须失效并重算。
- 细化过程不依赖用户浏览顺序；同一世界、区域、版本与配置应得到相同细节。

## 七、可解释性验收

用户查询重要对象时，至少可获得：

1. 它是什么、位于什么地形与水文关系中。
2. 它与哪些上游、下游、材料区或季节状态相连。
3. 哪些条件实际参与了生成。
4. 对象状态：已计算、受约束生成、候选或泛化表达。
5. 已启用模型、采用近似和未模拟过程。

不得提供没有计算或设定依据的精确年龄、真实历史事件、流量、沉积速率或地下结构细节。

## 八、验收证据与判定

每次验收至少报告下列证据，而不只提供截图：

| 证据类别 | 最低内容 |
| --- | --- |
| 配置与复现 | 种子、完整生效配置、模型版本、数据版本和生成范围 |
| 数值证据 | 收支残差、单位检查、边界条件和异常处理结果 |
| 拓扑证据 | 流域、河网、分流、汇合、湖泊出口、地下连接和海洋去向检查 |
| 条件证据 | 每个代表区域与对象所需条件的检查结果 |
| 探索证据 | 全球、区域、地貌三级的一致性检查；季节切换与查询解释核对 |
| 现实参照 | 若声明现实有效性，说明对应数据、范围、指标和失败情况；没有则明确未验证 |

### 固定专门测试世界

每个代表区域至少对应一个固定测试世界。测试世界应尽可能只改变与目标过程相关的条件，并保留足以发现交互错误的最小上下文。

| 测试世界 | 固定内容 | 主要验收目标 |
| --- | --- | --- |
| T01 湿润山地流域 | 海洋水汽来源、迎风山地、积雪区、下游出口 | 迎背风差异、雨雪分配、融雪入流、山溪与河谷连接 |
| T02 背风内陆盆地 | 山脉、水汽路径、干燥盆地、内流或季节出口 | 雨影、水分亏缺、季节河或内陆湖收支、戈壁材料条件 |
| T03 冲积平原 | 上游大流域、低坡度谷地、可沉积材料 | 汇合、河曲条件、湿地水文周期、河滩与江洲条件 |
| [T04 河口与三角洲](测试世界/河口三角洲测试世界规范（讨论稿）.md) | 大河入海、多路径分流、沉积物来源、海岸边界 | 分流守恒、河口连接、沉积物去向与三角洲生成门槛 |
| [T05 岩溶高地](测试世界/岩溶高地测试世界规范（讨论稿）.md) | 可溶岩层、补给区、裂隙／地下通道、出露点 | 入渗、地下连接、暗河、泉水与天坑候选条件 |
| [T06 差异侵蚀高地](测试世界/差异侵蚀高地测试世界规范（讨论稿）.md) | 材料差异、抬升或高差背景、河流或风化条件 | 崖壁、峡谷、残丘和石滩等对象的材料与形态依据 |

固定不表示测试世界不允许季节变化。若测试目标包含雨雪、河流、湖泊、湿地或积雪，测试世界应在规定的代表季节或内部时间序列上验收。每个测试世界都应保存完整配置、预期结果、允许近似、失败条件和证据格式。

测试世界之间可以共享通用部件，但不得通过复制一个大型世界、只修改名称来代替不同过程测试。测试场景也不自动构成现实验证；它们主要证明实现是否遵守所选模型和项目约束。

验收结论分为：

- `通过`：所有适用硬约束通过，代表区域和对象达到已约定状态。
- `条件通过`：硬约束通过，但可选对象或模型按已约定方式降级表达。
- `不通过`：存在硬约束失败，或把候选／泛化对象错误标为正式对象。
- `未验证`：缺少所需证据；不得用“看起来合理”替代结论。

## 九、目前仍待共同确认的事项

本标准尚未确定：

- 具体行星参数、世界分辨率、地貌级精度和计算资源预算。
- 代表季节数量、季节取样时刻、内部时间步和周期稳定条件。
- 气候、水汽输送、蒸发、积雪融雪、地下水、沉积物和分流的具体模型及参数范围。
- 特殊地貌的首批清单，以及“岱崮”等项目术语的正式定义。
- 哪些代表区域必须在同一验收世界中出现，哪些应通过固定场景集分别验证。
- 现实数据对照的范围与指标。

这些问题确定后，应为每条验收要求补充具体测试方法、容差、输入场景和证据格式。
