# T04 河口三角洲测试世界规范

本文定义第四类固定专门测试世界，用于检验“大流域来水与来沙—河口水位边界—分流河网—潮汐或波浪扰动—三角洲／河口区分类”的过程链。首版使用受约束的沉积收支和海岸边界，不要求模拟真实河口的长期演变。

关联：[第一版验收标准](../第一版验收标准（讨论稿）.md) · [T03 低坡冲积平原](低坡冲积平原测试世界规范（讨论稿）.md)。

## 一、测试目标

验证一条具有明确上游来水、沉积物来源和海洋边界的河流，在河口低地中能按条件形成、降级或拒绝“三角洲”结果：

```text
上游流域来水与来沙
→ 接近海平面的河口低地
→ 可分流的河口河网与湿地候选区
→ 淡水、潮汐／波浪和海水边界共同作用
→ 沉积物收支支持时的三角洲表达
```

关键是区分“河流进入海洋”“具分流的河口湿地”与“满足简化沉积条件的三角洲”。它不把所有河口、支汊或海岸湿地都命名为三角洲。

## 二、固定空间设定

```text
上游主河入口与沉积物来源
→ 低坡度河口平原
→ 一个或多个受控分流节点
→ 河口湿地／滩地候选区
→ 近岸浅海与明确海平面边界
→ 开放海洋出口
```

固定要求：

- 上游边界同时提供可追溯的水量与沉积物供给；不可只输入河流流量却凭空生成大面积堆积地貌。
- 河口平原具有允许分流、漫流和沉积保留的低坡度地形；其高程与海平面关系明确。
- 至少设置一条进入海洋的主通道，以及一个可启用或关闭的分流候选路径。
- 近岸海域提供海平面、水位扰动或海岸再分配强度等外部边界；首版可将潮汐与波浪概括为边界扰动，不要求二维或三维海洋流体求解。
- 至少保留一个河口湿地或滩地候选区，但只有满足水文周期、材料和水位条件时才产生对应标签。

## 三、代表季节状态

| 状态 | 外部条件方向 | 应观察的主要过程 |
| --- | --- | --- |
| S1 高流量输送期 | 上游来水、来沙增加 | 主通道与满足条件的分流向海输水；湿地或低地可能受淹；沉积物供给增加 |
| S2 常态水位期 | 河流输入和海洋边界较稳定 | 河口水路保持连接；已形成的陆地与湿地边界按水位与沉积状态表达 |
| S3 低流量／高海水影响期 | 上游来水减少或海洋水位扰动相对增强 | 部分分流或湿地缩减；盐水影响只在启用相应简化边界时标注，不凭空推定 |

季节切换不得改变海岸线总体身份、主河入海去向或已经建立的分流拓扑；可以改变水道活跃度、湿地淹没范围、滩地显露与沉积资格。

## 四、必须验收的关系

### T04-C01 河流、分流与海洋水量边界

- 主河和各分流进入海洋、湿地、储水区的水量之和，加上明确损失与储量变化，不超过上游可供水量。
- 海洋边界可以抬高局部水位、影响回水或限制排水，但不能在未声明海水交换模型的情况下向河网注入任意淡水流量。
- 关闭一条分流后，其水量必须重新分配至其他水道、上游储水／回水、湿地或明确损失项。
- 河口回水、潮汐往复和盐水入侵若只作边界近似，必须标为受约束状态，不能宣称已计算完整水动力过程。

### T04-C02 沉积收支与三角洲资格

- 三角洲候选需要上游沉积物供给、河口沉积保留条件和相对可容纳空间；三者缺一时不得正式命名为三角洲。
- 首版可用“供给—输出／再分配—保留”的简化账本表达沉积收支，不要求精确粒径谱、沉积速率或地层年代。
- 海平面上升、强海岸再分配或低沉积物供给会降低陆地前积与分汊稳定的资格；系统应降级为河口、河口湿地或普通入海口，而非强行维持三角洲标签。
- 生成的沙洲、滩涂或新生陆地区必须记录其沉积物来源和边界条件；没有长期演化模型时，不能叙述具体形成时长。

### T04-C03 河口湿地、滩涂与海滩

- 河口湿地需同时具有适当水文周期、低地滞水／潮汐影响、材料背景和明确的排水或海洋交换边界。
- 滩涂需要潮位或水位周期与细粒沉积／浅缓地形条件；海滩则需要开放海岸、波浪／岸流近似与合适的沉积物条件。二者不可只按颜色或靠海位置区分。
- 首版未建模盐度、植被和潮沟细节时，可显示“受潮汐影响的湿地候选”或“滩地候选”，不得伪装为完整生态系统模拟结果。

### T04-C04 河口与三角洲的分类边界

- 只有河水入海而缺少沉积物收支或保留条件时，结果为一般河口／入海口。
- 具多路径分流和湿地但沉积资格不足时，结果可为分流河口或河口湿地，不自动升级为三角洲。
- 满足简化沉积收支、分流与近岸保留条件时，结果才可标记为“受约束生成的三角洲”。
- 未启用海洋边界或沉积物过程时，三角洲为不可验证对象；系统应停留在河流入海表达。

## 五、控制变体与方向性检查

| 变体 | 只改变的条件 | 预期变化方向 | 不应改变的内容 |
| --- | --- | --- | --- |
| V01 减少来沙 | 降低上游沉积物供给 | 稳定三角洲、滩涂和沙洲资格下降 | 上游水量、主河与海洋边界 |
| V02 增强海岸再分配 | 提高潮汐／波浪边界扰动强度 | 沉积保留资格降低，河口影响范围可扩大 | 上游输入与河口位置 |
| V03 增加高流量期来水 | 仅提高 S1 的水量和来沙 | 分流活跃度、湿地淹没与沉积输送可提高，受容纳空间限制 | 地形骨架、海平面与材料区 |
| V04 抬升海平面边界 | 仅提高海洋基准水位 | 低地淹没与回水候选扩大，陆地保留资格降低 | 上游河流来源与材料供给 |
| V05 关闭一条分流 | 移除一个河口分汊路径 | 其他路径、回水或湿地接收其水量；岛体／湿地状态随之调整 | 总输入、主河入海身份 |

## 六、阻断失败与允许降级

| 情况 | 判定 |
| --- | --- |
| 分流和湿地同时消耗同一份未拆分水量，或所有入海流量超过上游可供水量 | 阻断失败 |
| 无沉积物来源、无保留条件却显示稳定三角洲陆地 | 阻断失败 |
| 海平面／海岸边界改变后，低地水位、河口去向和滩地状态完全不受影响 | 阻断失败 |
| 未启用沉积收支 | 降级为河口、分流河口或河口湿地；不正式生成三角洲 |
| 未启用潮汐／波浪边界 | 可表达静态海平面控制的入海口；不声称具真实潮沟、滩涂演变或盐水入侵 |
| 未启用长期地貌演变 | 可表达某代表状态下受约束的三角洲资格；不输出前积速率、沉积年龄或海岸迁移史 |

## 七、证据输出

- 上游来水、分流比例、湿地／滞水储量、入海流量和损失项的水量账本。
- 上游来沙、河道输送、近岸再分配、局部保留及离开系统的简化沉积账本。
- 主河、分流、河口湿地、滩地和开放海洋边界的有向连接关系。
- 三角洲、分流河口、河口湿地、滩涂或一般入海口的分类依据与所缺条件。
- S1–S3 以及 V01–V05 的水位、活跃水道、淹没范围、沉积资格和分类变化报告。

## 八、暂不在 T04 验收的内容

- 精确潮汐波形、风暴潮、沿岸流和三维盐度／密度流。
- 真实粒径输运、沉积压实、地层建模、海平面历史和海岸线长期迁移。
- 上游山地融雪与内陆雨影成因：由 T01、T02 负责。
- 低坡冲积平原内部的完整河曲与湿地过程：由 T03 负责。
- 岩溶地下水和特殊岩性地貌：由 T05、T06 负责。

T04 通过说明模型能在受控河口条件下区分河口、分流河口和具沉积依据的三角洲，并保持水量与简化沉积收支的一致性；它不代表已完成真实海岸带动力学模拟。
