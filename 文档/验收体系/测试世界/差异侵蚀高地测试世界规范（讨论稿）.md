# T06 差异侵蚀高地测试世界规范

> **文档状态**
>
> - 文档类型：测试世界规范
> - 决策状态：讨论稿
> - 实现状态：未执行验收
> - 版本：0.1

本文定义第六类固定专门测试世界，用于检验“高差背景—岩性与结构差异—风化及侵蚀作用—坡面与谷地形态—受约束特殊地貌分类”的过程链。它覆盖山崖、山壁、峡谷、残丘、岱崮候选、石林候选与石滩等对象的材料和形态依据。

关联：[第一版验收标准](../第一版验收标准（讨论稿）.md) · [术语解释](../../总体架构/术语解释.md) · [T05 岩溶高地](岩溶高地测试世界规范（讨论稿）.md)。

## 一、测试目标

验证在同一高地内，材料抗侵蚀性、层理／节理结构、表层覆盖和作用方式的差异，能够导致不同的稳定或候选地貌，而不是由随机噪声决定名称：

```text
构造抬升或既有高差背景
→ 抗侵蚀层、易侵蚀层与结构面分区
→ 河流下切、坡面风化或表层剥蚀
→ 崖壁、峡谷、残丘、台地边缘等形态
→ 条件完整时的岱崮／石林等特殊地貌候选
```

本测试验证的是“材料与过程支持该形态”的关系。首版可用长期过程的结果性约束生成地貌，不要求从数百万年演化起点逐步模拟真实侵蚀史。

## 二、固定空间设定

```text
区域高地与明确相对高差
→ 抗侵蚀盖层／岩脊区
→ 易侵蚀夹层或谷地材料区
→ 层理、节理或等价结构控制带
→ 一条下切河谷或侵蚀通道
→ 残丘、崖壁、石林或石滩候选区
```

固定要求：

- 设置具相近气候与高差背景、但材料性质不同的对照区，以检验地貌差异确由材料与结构产生。
- 至少包含抗侵蚀层与相对易受侵蚀层；其差异可由抗侵蚀性、溶解性、节理发育、层理方向、渗透性或表层保护效应表达，但必须说明采用了哪些简化属性。
- 至少设置一个受河流或集中径流控制的下切通道，用于检验河谷、峡谷及崖壁基部的条件。
- 至少设置一个非河流主导的坡面／台地边缘候选区，用于区分一般山壁、残丘与纯河流峡谷。
- 岱崮和石林仅为候选对象：前者需定义项目内可验证的“较抗侵蚀盖层＋较易侵蚀围岩／基座＋差异侵蚀残余高地”条件；后者需定义细长岩柱／峰丛的材料、结构和侵蚀条件。名称不得替代条件本身。

## 三、代表状态

此测试世界主要验证长期地貌结果，不将崖壁、峡谷或残丘的形成过程伪装成一个季节内完成。仍可提供下列代表环境状态，检验当前表面过程与长期形态不冲突：

| 状态 | 外部条件方向 | 应观察的主要过程 |
| --- | --- | --- |
| S1 湿润径流增强期 | 降水或融雪增加 | 河谷／峡谷的流量和坡面侵蚀倾向增加；地貌身份保持稳定 |
| S2 常态期 | 水热条件居中 | 已形成的崖壁、残丘和谷地按材料、坡度与排水条件维持其解释 |
| S3 干燥风化占优期 | 径流减少、温差或干湿循环相对突出 | 表层覆盖、裸岩显露与物理风化倾向改变；不随机重塑大型高地拓扑 |

季节状态可影响溪流活跃度、表层覆盖、裸岩显露或风化倾向，不可改变抗侵蚀层分布、主谷地连接、残丘身份和已记录的结构控制关系。

## 四、必须验收的关系

### T06-C01 材料差异与形态资格

- 崖壁、残丘、岩脊或台地边缘需要相对高差、坡度／边界形态以及材料或结构控制依据；不能仅因局部高程突变而正式命名。
- 在相同作用背景下，较抗侵蚀材料应比邻近较易侵蚀材料更有资格保留突出地形，但首版不承诺定量预测侵蚀率。
- 改变材料属性时，对应候选地貌资格应改变；若完全不变，说明材料模块没有实际参与约束。
- 表层土壤、沉积覆盖与基岩性质应区分记录。裸岩崖壁、石滩或石林不能只由覆盖图层的颜色推导。

### T06-C02 河谷、峡谷与崖壁

- 河谷需要可追溯的上游来水、下游去向和沿程降低的水位／势能路径；峡谷还需要较大切割深度、狭窄谷宽或坚硬基岩控制等附加条件。
- 崖壁与山壁需要显著坡面或结构面，并有材料抗蚀性、层理出露或侵蚀边界支持；普通陡坡可降级为陡坡或山坡。
- 河流穿过硬岩高地时可以形成受约束峡谷候选，但首版不声称已重现真实下切速率、阶地年龄或所有瀑布演化。
- 断流或无水源的沟槽不能作为持续河流侵蚀的证据；可按干谷、侵蚀沟或未验证谷地表达。

### T06-C03 残丘、岱崮与石林候选

- 残丘候选需要与周围相对低地的高差、隔离程度和抗侵蚀材料／覆盖解释；不要求每个山峰都是残丘。
- 岱崮候选采用项目定义：具相对平缓或稳定的抗侵蚀顶部、较陡的周缘坡面，以及与周围较易侵蚀地层差异侵蚀形成的孤立或半孤立高地。缺少任一关键条件时，降级为残丘、台地边缘或一般山地。
- 石林候选需具有相对细长、密集的岩体形态以及受材料、节理、溶蚀或选择性侵蚀控制的依据；若未建模其专门过程，只能显示为受结构控制的岩柱／裸岩候选。
- 岩溶石林与非岩溶侵蚀岩柱需区分成因状态；前者依赖 T05 的可溶岩与地下／地表水作用条件，不能只靠外形判断。

### T06-C04 石滩、崩积与表层材料边界

- 石滩或块石堆需要坡面物质来源、运输或重力堆积条件及局部保留空间；不能把任何裸露河岸或海岸命名为石滩。
- 受崖壁风化或岩崩形成的块石坡可作为候选表层材料结果，但未建模质量运动时，不输出崩塌时间、体积或精确危险性。
- 河滩、海滩与石滩的分类分别依赖河流、海岸或坡面材料过程；它们可相邻，不能相互替代。

## 五、控制变体与方向性检查

| 变体 | 只改变的条件 | 预期变化方向 | 不应改变的内容 |
| --- | --- | --- | --- |
| V01 降低盖层抗侵蚀性 | 仅弱化抗侵蚀层 | 残丘、岱崮和崖壁资格下降 | 高地范围、气候输入和河谷入口 |
| V02 减弱结构控制 | 降低层理／节理对形态的约束 | 定向崖壁、岩柱与石林资格下降 | 基岩主体、总体高差与河流边界 |
| V03 增大河流切割条件 | 仅提高可追溯的径流／下切倾向 | 河谷、峡谷候选增强，受材料与坡度限制 | 岩性分区、山脊位置与下游出口 |
| V04 增加表层覆盖 | 仅提高土壤或沉积覆盖 | 裸岩、石滩与岩柱显露资格下降 | 基岩结构、高差与水系骨架 |
| V05 移除可溶岩属性 | 将石林候选区改为非可溶岩 | 岩溶石林资格消失；只有其他条件充分时保留非岩溶岩柱候选 | 几何形态、气候与结构控制带 |

## 六、阻断失败与允许降级

| 情况 | 判定 |
| --- | --- |
| 材料、结构、高差和侵蚀边界均无依据却正式生成峡谷、岱崮或石林 | 阻断失败 |
| 改变抗侵蚀层、结构控制或覆盖条件后，相关地貌资格完全不变 | 阻断失败 |
| 无上游水源或下游去向却以持续河流下切解释峡谷 | 阻断失败 |
| 只有陡坡或局部高差 | 降级为山坡、山壁或一般高地 |
| 未启用差异侵蚀约束 | 不正式命名岱崮、残丘或结构控制石林；可显示一般山地和裸岩区 |
| 未启用长期地貌演化 | 可生成受约束的结果性形态；不输出侵蚀时间、剥蚀量或地层年龄 |

## 七、证据输出

- 高差、坡度、谷宽、相对隔离度和河网连接等形态量。
- 基岩、表层材料、抗侵蚀性、层理／节理、可溶性、覆盖程度与结构控制区的属性图。
- 河流输入、下切候选路径、坡面排水和下游出口的连接证据。
- 峡谷、崖壁、残丘、岱崮候选、石林候选、石滩或一般地貌的分类依据与所缺条件。
- S1–S3 以及 V01–V05 对水流、裸岩显露、形态资格和降级结果的变化报告。

## 八、暂不在 T06 验收的内容

- 真实构造抬升史、地层年代、断层活动和百万年尺度定量侵蚀模拟。
- 精确崩塌、滑坡、风化速率、岩屑粒径演化和岩石力学。
- 岩溶地下连通、暗河和天坑的水文收支：由 T05 负责。
- 低地分流湿地与河口三角洲：由 T03、T04 负责。
- 山地水汽、雨雪和融雪供给：由 T01、T02 负责。

T06 通过说明模型能将材料、结构、高差和侵蚀路径共同作为特殊地貌的生成门槛，使崖壁、峡谷、残丘、岱崮与石林等对象具有可追溯依据；它不代表已经复现任何地区的完整地质历史。
