本文定义第一类固定专门测试世界，用于检验“海洋水汽—山地降水—积雪与融雪—河流与湖泊”这条过程链。它不是随机世界模板，不是现实流域复刻，也不冻结具体公式、网格、数值参数或实现方案。

关联：[第一版验收标准](../第一版验收标准（讨论稿）.md) · [自然系统耦合与模型边界](../../总体架构/自然系统耦合与模型边界.md) · [湖泊生成与季节状态推导示例](../../专题研究/湖泊生成与季节状态推导示例.md)。

## 一、测试目标

验证在固定类地背景下，模型能否在一个受控区域内保持以下关系：

```text
海洋水汽来源
→ 沿主风向输送
→ 山地迎风侧降水增强
→ 高海拔寒冷区域暂存固态降水
→ 融雪进入坡面、溪流与支流
→ 汇入主河、山间湖或海洋出口
```

本测试不要求模拟逐日天气、冰川流动、精确降水观测值、瀑布水动力学或长期峡谷侵蚀。

## 二、固定空间设定

测试世界包含一条从湿润来源到下游出口的剖面，空间关系保持不变：

```text
西侧海洋
→ 沿海低地
→ 西向迎风山坡
→ 高山脊与积雪补给区
→ 东向背风山坡
→ 山间河谷与可选湖盆
→ 东侧下游出口或海洋
```

固定要求：

- 海洋为主水汽来源和外部水文出口之一。
- 主风向由西向东；具体风速、季节变化和输送算法待模型阶段确定。
- 山脊横跨主要水汽路径，形成明确的迎风侧和背风侧。
- 山脊高处相对于两侧低地具有足以形成温度差和积雪候选的高程背景；具体高程和阈值暂不固定。
- 至少存在一条从高山补给区通向下游出口的地表排水路径。
- 可选山间湖盆必须位于该排水系统内，并明确其出口或内流边界。
- 岩性与材料区应包含可支撑一般山地河谷、崖壁或瀑布台阶候选的差异，但不要求在 T01 中测试岩溶或三角洲。

测试世界应使用稳定标识定义海洋、山脊、迎风坡、背风坡、积雪区、主河、支流、湖盆和出口；名称可以改变，空间关系不能依赖随机重抽。

## 三、代表季节状态

T01 至少包含以下三个代表状态。它们是同一世界的连续水量状态，不是三张独立随机地图。

| 状态 | 外部条件方向 | 应观察的主要过程 |
| --- | --- | --- |
| S1 寒冷积雪期 | 高山低温，固态降水比例上升 | 雪水当量增加；高地积雪保留；即时融雪有限 |
| S2 融雪补给期 | 温度上升到允许融化的范围 | 雪水当量减少；融雪进入坡面、溪流和支流；下游来水增加或滞后响应 |
| S3 温暖湿润期 | 海洋水汽输送与液态降水有效 | 迎风降水增强；河流由降雨和残余融雪共同补给；蒸发需求提高 |

可选增加 S4 相对干燥期，用于检查低流量、湖岸退缩或季节支流断流；是否进入首版代表季节集待讨论。

## 四、必须验收的关系

### T01-C01 水汽与迎背风差异

- 在其他受控条件相同或可比时，迎风坡的有效降水不应系统性低于背风坡。
- 降水增强必须受可用水汽限制；迎风山地不能无上限地生成水。
- 背风干燥应能追溯到输送后的剩余水汽、地形作用或蒸发需求，不得仅由标签决定。

### T01-C02 温度、海拔与积雪

- 高海拔区域在寒冷积雪期比相邻低地更具固态降水与积雪保留条件。
- 雪水当量是水量状态，不是仅用于渲染的雪色覆盖。
- 积雪不能同时直接作为河流入流和储雪使用。

### T01-C03 融雪与水量路径

- 融雪量不超过已有雪水当量。
- 融雪进入本地坡面、土壤、地下水或河网，不跨越分水岭。
- 上游融雪经支流汇入主河、湖泊或下游出口；每一段连接可追溯。
- 融雪季河流增加必须来自积雪释放、当期降水、地下补给或其他明确水源。

### T01-C04 河谷、湖泊与瀑布条件

- 主河具有上游来水、连续河道和下游去向。
- 山间湖若正式生成，必须有盆地、水位／库容关系、来水及出口或内流边界。
- 瀑布若正式生成，必须同时有河流、水量和河床台阶或等价地形条件；仅有陡坡不足以生成常年瀑布。
- 河谷、峡谷或山崖可使用受约束近似，但必须继承河流、地形和材料条件。

### T01-C05 季节连续与跨尺度

- S1、S2、S3 共享地形、岩性、流域、主河网和对象身份。
- 雪水、湖泊和其他启用储量按规定在状态间传递；不得独立随机重置。
- 从全球缩放到区域和地貌层时，主河、山脊、积雪补给区和出口关系保持一致。

## 五、控制变体与方向性检查

在基础测试世界之上，只修改一个明确因素，比较结果方向。它们不要求给出固定数值，但应满足相应的定性和收支关系。

| 变体 | 只改变的条件 | 预期变化方向 | 不应改变的内容 |
| --- | --- | --- | --- |
| V01 降低山脊 | 山脊高差减小 | 迎背风降水差异通常减弱；积雪候选范围可能缩小 | 海洋、水汽方向、主要流域身份 |
| V02 反转主风向 | 水汽输送由东向西 | 原背风侧与迎风侧的降水关系应相应变化 | 地形、材料和季节定义 |
| V03 升高暖季温度 | 仅提高 S2／S3 的温度背景 | 融雪倾向提前或增强；雪水储量更快减少，但不会低于零 | 初始地形和水汽来源 |
| V04 减少固态降水 | 仅减少 S1 的雪量输入 | 后续融雪补给减少；不能通过其他未声明来源补足同等流量 | 温度、地形与河网连接 |
| V05 移除湖盆出口 | 将湖盆设为明确内流边界 | 湖泊可通过储水和蒸发响应，不应继续产生地表出流 | 上游流域、湖盆地形和来水来源 |

方向性检查不是现实数值验证。它们用于发现模型中“输入改变后关系方向错误”、状态重复记账或拓扑没有更新的问题。

## 六、阻断失败与允许降级

| 情况 | 判定 |
| --- | --- |
| 融雪超过雪水当量、分流重复用水、河流失去下游去向或湖泊跨越高地 | 阻断失败，T01 不通过 |
| 季节切换后主河、山脊或流域身份改变，但没有明确地形重算记录 | 阻断失败，T01 不通过 |
| 未建立出口能力模型，不能给出精确瀑布流量或溢流时刻 | 允许降级，不提供精确流量结论 |
| 未建立峡谷长期侵蚀模型 | 允许受约束生成峡谷形态，说明未模拟年龄和侵蚀速率 |
| 不存在足够水源或河床台阶 | 不生成正式瀑布，可泛化为陡坡河段 |
| 未启用地下水 | 不将地下水解释为河流的隐含来源；可明确为未建模项 |

## 七、证据输出

T01 验收应保存并检查：

- 完整配置、模型版本、稳定对象标识和季节状态定义。
- 山脊两侧的温度、降水、水汽或等价输送状态、蒸发需求与雨雪比例。
- 雪水当量、融雪、地表径流、地下补给、河流、湖泊和出口的水量账本。
- 主河、支流、湖泊、瀑布候选与出口的连接图。
- 不同代表季节、不同缩放层级下的对象对应关系。
- 基础世界与 V01–V05 的差异报告，包括哪些变量按预期改变、哪些保持不变。
- 每个正式对象的状态、生成依据、近似和未启用过程。

## 八、暂不在 T01 验收的内容

- 三角洲、潮汐、河流分汊和海岸沉积：由 T04 负责。
- 岩溶、暗河、泉水和天坑：由 T05 负责。
- 河曲、湿地漫流和大规模冲积沉积：以 T03 为主。
- 冰川与冰盖动力学、逐日天气、真实流量预报和现实流域拟合。

T01 通过只表示系统在明确的受控条件下满足这条过程链，不表示整个世界或所有气候环境均已验证。
