# T02 背风内陆盆地测试世界规范

本文定义第二类固定专门测试世界，检验“水汽来源—山地雨影—有效水分亏缺—上游来水—内流盆地或季节湖”之间的关系。它不是随机世界模板，不要求所有生成世界都拥有荒漠或内流盆地，也不冻结具体气候或水文算法。

关联：[第一版验收标准](../第一版验收标准（讨论稿）.md) · [湿润山地流域测试世界规范](湿润山地流域测试世界规范（讨论稿）.md) · [自然系统耦合与模型边界](../../总体架构/自然系统耦合与模型边界.md)。

## 一、测试目标

验证模型能够区分以下两件事：

```text
本地气候干旱
≠
没有地表水或河流
```

一条源自湿润高山或融雪补给区的河流，可以穿过低降水、高蒸发的内陆地区；河流沿线、湖泊边缘和盆地其他区域应有不同的水分状态。测试的过程链为：

```text
海洋或湿润来源
→ 山脉迎风降水与背风水汽减少
→ 背风低地有效水分不足
→ 高山来水经河流进入内陆盆地
→ 湖泊储水、蒸发、季节退缩或明确外排
```

## 二、固定空间设定

```text
西侧湿润来源
→ 高大山脊与迎风补给区
→ 东侧背风坡
→ 干旱或半干旱内陆平原
→ 低洼内流盆地与可选季节湖
```

固定要求：

- 主水汽方向穿过山脊，使内陆盆地位于背风侧。
- 山地补给区与内陆河道属于同一连续流域，主河可由上游降水、积雪、融雪或明确地下补给提供水源。
- 内陆盆地具有明确边界：要么是内流边界，要么有明确地表出口；不能隐含两种相互矛盾的状态。
- 干旱平原、河谷走廊、湖岸和盆地其他区域可具有不同材料与覆盖状态。
- 若正式生成戈壁，应布置砾石、裸岩或粗颗粒材料依据；若只具备水分亏缺，不得仅凭干旱标签断言为戈壁。

## 三、代表季节状态

| 状态 | 外部条件方向 | 应观察的主要过程 |
| --- | --- | --- |
| S1 寒冷或积雪储存期 | 高地可积雪，内陆蒸发需求相对降低 | 高山雪水当量储存；内陆河流可能处于低流量或由基流维持 |
| S2 融雪或湿润补给期 | 上游融雪和／或降水增加 | 河流将上游水输送到干旱内陆；湖泊或湿地得到补给 |
| S3 温暖干燥期 | 本地降水较少、蒸发需求升高 | 干旱平原水分亏缺；季节河、湖岸和湿地范围可收缩 |

这三个状态共享同一山脊、盆地、河网、材料区和对象身份。具体季节数量、时段长度和内部步长待后续确定。

## 四、必须验收的关系

### T02-C01 雨影与有效水分

- 内陆盆地的水分亏缺应能追溯到水汽输送、山地作用、降水减少和蒸发需求，而不能由荒漠标签反向指定。
- 背风侧不要求在每个季节都绝对无降水；验收的是相对水分条件和收支关系。
- 山脉降低或主风向反转时，雨影关系应按模型约定发生方向性变化。

### T02-C02 外来河流与局地干旱并存

- 主河流量可来自上游补给；不能只按河道所在地的本地降水判断河流是否存在。
- 河流沿线、绿洲候选区、湿地或湖岸可以比周围干旱平原湿润，但这种差异必须由河流、地下补给或湖泊状态解释。
- 上游补给减少时，主河流量、季节湖或下游湿地应按已启用模型响应，不能保持未解释的恒定水量。

### T02-C03 内流盆地与湖泊收支

- 内流盆地的来水、储水、实际蒸发和地下或地表外排必须在同一边界内记账。
- 若没有出口，湖泊不应产生隐含地表出流；若设有出口，出口关系必须进入下游网络。
- 湖泊退缩后显露地面应保留为湖床、滩涂候选或待分类地表，不能自动变成草原或森林。

### T02-C04 荒漠、戈壁、草原与河谷走廊

- 荒漠或半干旱状态由长期有效水分不足支持。
- 戈壁还需要材料依据；不应与所有荒漠自动等同。
- 草原候选区应具有相对于荒漠更高的有效水分或不同季节性条件。
- 河谷走廊不得因区域整体干旱而自动抹除已有上游水源；但也不能把整个干旱盆地误标为湿润覆盖。

## 五、控制变体与方向性检查

| 变体 | 只改变的条件 | 预期变化方向 | 不应改变的内容 |
| --- | --- | --- | --- |
| V01 降低山脊 | 山脊高差减小 | 雨影通常减弱，内陆有效降水倾向增加 | 内陆盆地位置、材料区和流域身份 |
| V02 减少上游补给 | 减少高地降水或融雪输入 | 主河、湖泊与湿地的可用水减少 | 本地气候背景和盆地地形 |
| V03 增加蒸发需求 | 仅提高温暖干燥期蒸发需求 | 湖泊／湿地更易退缩；实际蒸发仍受可用水限制 | 上游水源与出口拓扑 |
| V04 打开盆地出口 | 将内流边界改为明确地表出口 | 储水与出流关系改变，下游获得对应输入 | 上游流域和材料背景 |
| V05 改变表层材料 | 仅将粗颗粒材料改为细粒或其他材料 | 戈壁资格、入渗或滞水候选随材料改变 | 气候水分条件和主河连接 |

## 六、阻断失败与允许降级

| 情况 | 判定 |
| --- | --- |
| 干旱区主河没有任何上游、地下或湖泊水源，却显示为常年大河 | 阻断失败 |
| 内流湖同时无记录地向下游出流，或水量在蒸发后仍不减 | 阻断失败 |
| 分流、河流、湖泊或地下补给重复使用同一份水 | 阻断失败 |
| 仅因降水低就显示正式戈壁 | 降级为荒漠或干旱裸地，直到材料条件成立 |
| 未启用盐分和化学沉积模型 | 不将内陆湖正式命名为盐湖，可表达为内流湖或季节湖 |
| 未启用地下水模型 | 不用地下水解释河谷绿洲或泉水；可显示地表水支持的湿润走廊 |

## 七、证据输出

- 山脊两侧的温度、降水、水汽或等价输送状态、蒸发需求和有效水分指标。
- 高地补给、融雪、河流、湖泊、湿地、蒸发、地下交换和出口的水量账本。
- 内陆盆地边界、主河流域、季节湖岸和下游去向的拓扑图。
- 荒漠、戈壁、草原、河谷走廊和湿地的连续变量与材料依据。
- 基础测试世界和 V01–V05 的差异报告。
- 每个正式对象的状态、生成条件、近似和未启用过程。

## 八、暂不在 T02 验收的内容

- 三角洲、潮汐和入海沉积：由 T04 负责。
- 洞穴、暗河和岩溶泉水：由 T05 负责。
- 逐株植被、盐分演化、风沙搬运和沙丘动力学。
- 长期河道迁移、真实荒漠化历史和现实流域拟合。

T02 通过只表明模型在受控条件下可解释背风干旱与外来河流、内流盆地的并存，不代表所有干旱地区或真实荒漠均已验证。
