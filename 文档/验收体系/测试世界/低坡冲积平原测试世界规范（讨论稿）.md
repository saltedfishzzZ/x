# T03 低坡冲积平原测试世界规范

> **文档状态**

> - 决策状态：讨论稿

本文定义第三类固定专门测试世界，用于检验“大流域来水—低坡度河谷—分流与汇合—湿地漫流—沉积形态条件”的过程链。它不要求完整模拟河道多年迁移、粒径级输沙或洪水水动力学。

关联：[第一版验收标准](../第一版验收标准（讨论稿）.md) · [T01 湿润山地流域](湿润山地流域测试世界规范（讨论稿）.md) · [T02 背风内陆盆地](背风内陆盆地测试世界规范（讨论稿）.md)。

## 一、测试目标

验证一条来自上游大流域的主河，在低坡度、宽谷地和可沉积材料条件下，能够形成并区分以下对象：

```text
主河与支流汇合
→ 河道展宽与局部弯曲
→ 分流、河中岛或江洲
→ 季节性漫流与湿地
→ 下游连续出口
```

测试重点不是让每段河都生成复杂形态，而是检查：水量在分流与汇合中守恒；河曲、河滩、江洲和湿地只在相应的地形、水位与材料条件成立时出现。

## 二、固定空间设定

```text
上游主流域入口
→ 两条或多条支流汇合
→ 宽阔、低坡度的冲积谷地
→ 可选分流河段与河中岛候选区
→ 泛滥平原与湿地候选区
→ 明确下游出口
```

固定要求：

- 上游入口提供可追溯的水量和沉积物来源；具体来源模型可由 T01、其他测试世界或受控边界提供。
- 主河总体具有向下游出口降低的势能或水位路径，不能形成无解释的逆向流动。
- 冲积谷地相对于 T01 山地河谷具有更低坡度、更宽的可淹没区域和可沉积材料背景。
- 至少设置一个分流—再汇合关系或等价的河中岛候选区；其存在不依赖随机曲线。
- 至少设置一个可由河流涨落、地下补给或明确水位边界维持的湿地候选区。
- 下游出口可以通往另一河段、湖泊或海洋，但不在 T03 中测试河口三角洲过程。

## 三、代表季节状态

| 状态 | 外部条件方向 | 应观察的主要过程 |
| --- | --- | --- |
| S1 高水补给期 | 上游来水、降水或融雪输入增加 | 主河流量增大；满足条件时部分水进入分流与泛滥平原 |
| S2 退水期 | 外部补给下降 | 主河维持下游连接；漫流水退去，湿地与滞水区保留部分储水 |
| S3 低水期 | 来水低、蒸发或渗漏相对显著 | 季节支汊可能断流；河滩、江洲或湿地边界显露，但主河是否常年有水取决于明确来源 |

季节状态必须继承同一条主河、分流节点、河中岛候选区和湿地范围。水位变化不能重新随机生成河道拓扑。

## 四、必须验收的关系

### T03-C01 汇合、分流与下游去向

- 支流汇入主河时，进入下游节点的水量包含已声明的上游输入、储量变化和损失。
- 分流节点的所有下游分配、局部储水和损失之和，不超过可供分配水量。
- 河中岛两侧路径可重新汇合，但同一份水不能在汇合前重复计入总流量。
- 低水期的支汊断流必须影响其下游状态；不得保留无来源的常年流量。

### T03-C02 河曲、河谷与河滩

- 河曲候选区具有相对低坡度、宽谷地和适合河岸调整的材料条件。
- 陡峭、狭窄、基岩控制的峡谷河段不应仅因随机曲率而被命名为大规模河曲。
- 河滩或裸露边滩需要水位退落与沉积物或河岸材料依据；不能只因靠近河线就生成。
- 首版可受约束近似河曲和河滩形态，但不得宣称模拟曲流裁弯或多年河岸侵蚀。

### T03-C03 湿地漫流与水文周期

- 湿地候选区具有低坡度、滞水或明确补给条件，并有最终排水、内流或蒸发边界。
- 高水期漫流进入湿地必须从河流或其他储量中扣除；退水后储量、蒸发或下游出流可追溯。
- 湿地不应简单成为河道的复制蓝色区域；需保存水文周期、水位状态和材料／覆盖条件。
- 未建模湿地植被反馈时，不以植被解释水位变化。

### T03-C04 江洲与河中岛

- 江洲或河中岛需要宽河道、分流或再汇合关系，以及材料或沉积保留条件。
- 不能在狭窄山溪中因局部噪声生成稳定河中岛。
- 江洲在低水期显露、在高水期部分淹没是允许的季节状态；岛体身份不能因季节切换任意消失或随机移动。

## 五、控制变体与方向性检查

| 变体 | 只改变的条件 | 预期变化方向 | 不应改变的内容 |
| --- | --- | --- |
| V01 增大谷地坡度 | 提高冲积谷地总体坡度 | 河曲、漫流和滞水候选通常减少；下游连接仍存在 | 上游来源、出口与主河身份 |
| V02 减少沉积物供给 | 仅减少可用沉积物 | 河滩、江洲和稳定岛体资格下降 | 水量输入、河网拓扑和气候边界 |
| V03 增加高水期来水 | 仅提高 S1 上游输入 | 漫流、湿地储水或分流活跃度可提高，但受地形容量限制 | 河谷、材料区和出口 |
| V04 关闭一条分汊 | 移除一个分流路径 | 其水量按规定转入其他路径、储水或上游回水处理；不能消失或翻倍 | 总输入、主河身份与材料背景 |
| V05 提高地表渗透性 | 仅改变表层材料传水倾向 | 地表漫流倾向和地下补给候选改变 | 总降水、上游输入和流域边界 |

## 六、阻断失败与允许降级

| 情况 | 判定 |
| --- | --- |
| 分流后各路径水量相加大于进入节点的可用水量 | 阻断失败 |
| 湿地漫流、河流或湖泊同时使用同一份未拆分水量 | 阻断失败 |
| 支汊断流后仍向下游持续输送原有流量 | 阻断失败 |
| 没有低坡度、宽谷地或材料依据却显示正式河曲或稳定江洲 | 降级为一般河段或河岸 |
| 未启用沉积物过程 | 不正式命名稳定江洲或河中岛；可显示分流河段或宽河道候选 |
| 未启用长期河道迁移 | 允许固定的受约束河曲形态，不描述迁移速率或裁弯历史 |

## 七、证据输出

- 上游输入、支流汇合、分流比例、湿地储水、蒸发、渗漏和下游出口的水量账本。
- 主河、支流、分流、再汇合、湿地出口、河中岛和下游出口的有向连接图。
- 各季节的水位、活跃河道、支汊状态、湿地范围、河滩与岛体显露状态。
- 河曲、河滩、江洲和湿地的坡度、谷宽、材料与水文条件依据。
- 基础测试世界与 V01–V05 的变化报告。

## 八、暂不在 T03 验收的内容

- 河口三角洲、潮汐和近海沉积：由 T04 负责。
- 高山融雪、水汽输送与雨影：由 T01、T02 负责。
- 岩溶地下通道：由 T05 负责。
- 逐年河道迁移、曲流裁弯、精确输沙率、洪水实时传播和现实河流拟合。

T03 通过只说明模型在受控低坡冲积环境中能保持多路径水量、湿地与沉积形态条件的一致性，不表示任何真实冲积平原已被完整模拟。
