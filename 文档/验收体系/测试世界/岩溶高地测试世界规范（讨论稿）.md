本文定义第五类固定专门测试世界，用于检验“可溶岩性—地表补给—裂隙入渗—地下连通—暗河与泉水出露—岩溶地貌候选”的过程链。首版表达地下结构的位置、范围与连接，不要求进入洞穴漫游或求解完整三维地下水流。

关联：[第一版验收标准](../第一版验收标准（讨论稿）.md) · [术语解释](../../总体架构/术语解释.md) · [T01 湿润山地流域](湿润山地流域测试世界规范（讨论稿）.md)。

## 一、测试目标

验证在具备可溶岩、裂隙或层理通道、有效入渗和低处出露条件的高地中，地表水可按受约束的路径转入地下并在下游出露：

```text
降水／融雪／上游水体补给
→ 可溶岩高地与裂隙带
→ 入渗、地下储存与连通候选
→ 暗河或地下排水路径
→ 泉水、溪流或河谷出露点
→ 条件成立时的溶洞、天坑候选
```

本测试重点是水量去向与岩性条件的对应关系。它不将低洼坑、任意山洞或普通地下水一律标记为岩溶天坑、溶洞或暗河。

## 二、固定空间设定

```text
高地补给区
→ 可溶岩主体与非可溶岩对照区
→ 裂隙／层面控制的入渗候选带
→ 地下连通与储存候选体
→ 低处出露边界（泉水、溪流或河谷）
→ 一个受控洼地或天坑候选区
```

固定要求：

- 高地补给区具备降水、融雪、上游来水或其组合的明确来源；地下水不能从无来源状态自行出现。
- 至少划分一个可溶岩主体区与一个不具相同溶蚀条件的对照区，以验证岩性不是纯视觉贴图。
- 可溶岩主体区同时具备入渗倾向与裂隙、层面或等价连通条件；只有可溶性而无水和通道时，不生成完整地下通道。
- 至少设置一个低于主要补给区、可接收地下排泄的出露点；泉水出露高度、地下路径方向和地表排水边界应相容。
- 至少设置一个封闭或半封闭洼地作为天坑候选区。首版可只判定其岩溶资格，不要求模拟塌陷事件与洞穴坍塌力学。

## 三、代表季节状态

| 状态 | 外部条件方向 | 应观察的主要过程 |
| --- | --- | --- |
| S1 补给增强期 | 降水、融雪或上游输入增加 | 入渗与地下储量增加；满足连通条件的暗河／泉水出流增强 |
| S2 常态排泄期 | 外部输入回落 | 地下储存向出露点持续排泄；泉水或受补给溪流可维持基流 |
| S3 干燥或低补给期 | 降水与来水减少，蒸发需求相对增加 | 浅表溪流可减弱或断续；地下储量和泉流只能按已记录库存或持续补给维持 |

季节切换不得随机重画地下路径、洞穴候选体或泉眼位置。它可以改变入渗量、地下储量、暗河活跃度、泉流量与洼地积水状态。

## 四、必须验收的关系

### T05-C01 岩性、通道与入渗资格

- 岩溶相关对象至少需要可溶岩性、水的化学溶蚀前提或等价的模型声明、以及裂隙／层面／连通条件；仅凭地表凹陷不可命名为天坑或溶洞。
- 入渗量受降水、融雪、地表来水、表层传水倾向和已声明的容量限制约束；它不能超过可供地表水量。
- 非可溶岩对照区在其他条件近似时，不应生成同等级的岩溶通道标签；若另有其他地下通道模型，应明确其不同成因。
- 首版若只记录“高入渗及潜在地下连通”，不得据此声称已模拟真实溶蚀速率、洞穴年龄或化学成分。

### T05-C02 地下储量、暗河与泉水收支

- 地下储量的变化可由入渗、地下入流、泉水／暗河排泄和明确损失项组成；同一份入渗水不得同时保留在地表河流和地下储量中。
- 暗河候选需有从补给端至排泄端的可追踪地下连接；没有出口时，可表达为地下储水或封闭地下洼地候选，不可强行连成下游河流。
- 泉水需要地下储量或地下路径的上游来源、出露条件和可接纳的地表去向；不能在高于全部补给水头的无解释位置持续出流。
- 泉水汇入溪流、河流、湿地或湖泊后，应成为该地表水体的可追溯输入，不得重复计入其他出流。

### T05-C03 溶洞、天坑与地表—地下连接

- 溶洞是具地下空腔或通道资格的对象；首版至少保存其候选范围、深度／高程关系、连通状态和证据，内部形状可不生成。
- 天坑候选需要地表洼地与下伏可溶岩／地下空腔或排水连通条件的组合证据。缺少地下依据时，应降级为封闭洼地或岩溶洼地候选。
- 洼地中的水可入渗、形成季节性积水、溢流或保持封闭，具体结果必须由容量、出口与季节输入决定。
- 山洞入口若仅由崖壁裂隙或侵蚀形成，不能自动归入岩溶溶洞；应保存成因状态或标为未验证洞穴候选。

### T05-C04 地表水与地下水的分类边界

- 地表河流消失于可溶岩入渗带，并在低处以泉水或溪流复现时，可形成受约束的“地表—地下—地表”连接。
- 地表河未消失、地下信息未建模时，不能仅因穿过石灰岩区域而命名为暗河。
- 地下通道未完全计算时，可显示地下连通候选、暗河候选或泉水受补给状态；其名称必须反映模型完成度。

## 五、控制变体与方向性检查

| 变体 | 只改变的条件 | 预期变化方向 | 不应改变的内容 |
| --- | --- | --- | --- |
| V01 改为非可溶岩 | 替换主体岩性 | 岩溶通道、溶洞与天坑资格下降或消失 | 地形骨架、气候输入和补给位置 |
| V02 降低裂隙连通性 | 减弱地下路径连通 | 暗河与泉水持续性降低，局部地下储水增加或受阻 | 可供水量与高地位置 |
| V03 增加补给 | 仅提高 S1 的降水／融雪输入 | 入渗、地下储量、泉流和洼地积水可增加，受容量限制 | 岩性、裂隙带与出露点位置 |
| V04 封闭出露点 | 移除一个地下排泄出口 | 地下水转入其他出口、储量、溢流或被判定为无有效排泄；不得消失 | 总补给、岩性和地表高程 |
| V05 提高表层不透水性 | 仅降低表层入渗倾向 | 地表径流增加，地下补给和泉流资格下降 | 降水、地下通道候选位置与材料主体 |

## 六、阻断失败与允许降级

| 情况 | 判定 |
| --- | --- |
| 入渗、地表径流、地下储量和泉流重复使用同一份水量 | 阻断失败 |
| 无补给、无地下来源或无水头条件却持续生成泉水／暗河流量 | 阻断失败 |
| 无可溶岩与地下连通依据却正式标记溶洞或天坑 | 阻断失败 |
| 只有可溶岩与入渗倾向 | 可降级为岩溶高地或地下连通候选，不生成正式暗河／溶洞 |
| 未启用地下储量模型 | 可表达地表入渗倾向和泉水候选，不声称季节基流或地下水量守恒已验证 |
| 未启用洞穴与塌陷模型 | 表达溶洞、天坑候选位置和条件；不生成内部结构、塌陷历史或精确深度 |

## 七、证据输出

- 补给、地表径流、入渗、地下储量、地下排泄、泉水与损失项的水量账本。
- 可溶岩、非可溶岩、表层传水性质、裂隙带、地下候选体、出露点与地表水体的空间关系。
- 补给区至暗河／地下路径、泉水、溪流或河谷出口的有向连接图。
- 溶洞、暗河、泉水、天坑、普通封闭洼地或未验证洞穴候选的分类依据和模型状态。
- S1–S3 以及 V01–V05 的入渗、储量、泉流、地表河段状态和洼地水位变化报告。

## 八、暂不在 T05 验收的内容

- 完整三维地下水流、真实裂隙网络、溶蚀化学、洞穴微气候与钟乳石形成。
- 天坑瞬时塌陷、岩体力学、洞穴内部地形与地下漫游。
- 区域气候、水汽输送和大流域河网成因：由 T01、T02、T03 负责。
- 河口沉积、潮汐与三角洲：由 T04 负责。
- 差异侵蚀高地和非岩溶石林等成因：由 T06 负责。

T05 通过说明模型能在受控岩溶条件中保持地表水、地下储量与出露关系的一致性，并让岩溶景观具有可追溯的材料与连通依据；它不代表完成真实洞穴系统或地下水动力学模拟。
