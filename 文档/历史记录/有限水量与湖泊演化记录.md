# 全球有限水量与湖泊演化 v0.1

2026-09-23。本轮沿用种子 20260923 的球面地形，接入从干燥初态开始的有限水源、湖盆蓄水、溢流、蒸发退水及重新分离。与上一版“所有湖盆预先满蓄”的参考情景分开保存语义。

## 查看与运行

刷新 球体查看器（原型文件已清理）。新增水文时间滑条与“播放演化”按钮；球体和平面显示同一时刻的湖面。图层默认展示计算终态，可以回到第 0 天查看干地初态。

```sh
python3 -m worldgen.evolution --world artifacts/world/world.json --out artifacts/world
```

默认 120 步，每步 30 天：前 60 步有效径流 300 mm/年，后 60 步为零；全部步骤湖面蒸发需求 800 mm/年。年按 365.25 天计，30 天是固定步长，不是日历月。

```sh
python3 -m worldgen.evolution --wet-steps 60 --dry-steps 60 --step-days 30 --runoff 300 --evap 800
```

时间步总数限制为 1～240。水源和蒸发参数必须有限且非负，步长必须有限且大于零。输出 `hydrology.json` 保存全部逐步湖深与水量，`evolution.csv` 提供收支和事件计数，`hydrology.png` 是终态快照。当前不提供检查点恢复；可用相同世界与参数重算。

## 计算方法

全球海洋折叠为一个海平面为 0 m 的出口，陆地保留原有高程和球面面积。使用已有 [湖盆层级算法](湖盆淹没合并与溢流验证记录.md) 建立最低洼地、鞍点、父子盆和海洋出口。局部模块默认 1024 格限制保持，全球调用显式提高层级构建上限到 150000 个节点；这仍是参考实现，非行星级生产性能承诺。

水源按每格面积产生，沿原地形最陡下降路径进入洼地或海洋，平坦区按稳定顺序排水。层级先填当前低盆，再填邻盆，达到公共鞍点后合并；父盆只保存连接水位以上的增量库容，因此不会把子盆储水重复计算。

每步使用以下顺序：

1. 加入本步有限有效径流，完成准静态分配及溢流。
2. 对各活动湖面施加统一蒸发水深。
3. 水位降过鞍点时清空父盆增量，并在各子盆上继续施加剩余蒸发水深。
4. 从库容反解水位，重新积分逐格水深，并核对累计收支。

库容使用 `V(h)=Σ A_i max(h−z_i,0)`。在湖面均匀蒸发、无同期入流的子步骤内，蒸发水深对应水位下降。跨过地形高程后水面面积会缩小；实际蒸发体积为下降前后库容差，湖泊干涸后不再消耗水。

这是已有层级模型上的数学扩展，不是新的气候经验公式。有效径流和湖面蒸发均为人为边界输入，没有声称由太阳辐射或真实降水计算得到。均匀水源对陆地单元计一次，包括后来被淹没的单元；尚未区分湿地直接降水与干地径流系数。

收支为：`累计输入 = 当前湖泊储水 + 累计入海 + 累计实际蒸发`。初始湖水为零。几何积分与层级储量也独立核对；非法输入及数值失败不提交该步。

总共记录 31 次合并、6 次分离。事件按代码中父盆增量首次大于零／退到零计数，不等于独立湖泊总数。供水停止后无继续入海，是当前“当步瞬时路由、湖泊只溢出超容量水量”的结果，不代表真实河流停止得如此迅速。

最终残差约 1.98 m³，相对于累计约 2.28×10¹⁴ m³ 输入约为 8.7×10⁻¹⁵，低于相对 10⁻¹⁰ 的累计审计容差。不能将该数值守恒证据解释为物理模型已标定。

## 图层与数据约定

演化图层显示本时刻湖面，不再显示上一版假设满蓄后的河网。动态河段通量尚未逐段计算；不能把参考流量当实际当前流量。旧结果保存在 `reference_discharge_m3_s`、`reference_surface_m`、`reference_lakes`、`reference_lake_id` 和 `steady_reference_summary`，便于比较。

每个时间帧的 `depths` 是原世界格子编号到水深的稀疏字典。海洋不在该字典里，未出现的陆地单元湖深为零。`pools` 中 ID 属于层级湖盆，不等同于上一版满蓄连通区 ID。权威地形 JSON 的摘要未改变。

## 测试与范围

新增 9 项测试覆盖有限输入、跨面积门槛蒸发、完全干涸、合并后分离、溢流守恒、非法输入、多个时间步复现、纯蒸发子步一致性、CLI 与回放导出。全套 66 项测试通过，JavaScript 语法检查通过。终态 PNG 已目视检查；浏览器工具对本地文件的安全限制仍在，未完成实际交互视觉验收。

供水与蒸发采用分步处理，因此含溢流的结果会依赖时间步；本轮只验证了纯蒸发子步一致性，不能宣称含入流的时间步已经收敛。固定地形、无土壤／地下水、固定海平面、统一气候输入、等高多分支稳定 ID 分配等近似继续存在。未实现动态河道流量、洪水传播、侵蚀或真实流域校准。

下一步优先加入时间步收敛实验和河段输水，再逐步把空间变化的降水、蒸发与现有土壤模型接入同一水量收支。
