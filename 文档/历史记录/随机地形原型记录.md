# 第一版随机行星地形

2026-09-23。水文后续工作搁置，当前主线恢复为随机地形生成。引擎模块 `worldgen` 独立于 `hydro`，Python 标准库实现，版本 0.1.0。

## 使用

默认仅需种子：

```sh
python3 -m worldgen --seed 20260923
```

打开 `artifacts/world/index.html`，默认展示 3D 球体。拖动或方向键旋转，滚轮／滑条缩放，可开启自动旋转；支持地形晕渲、高程、板块图层和平面地图切换。指针显示经纬度、高程、板块与海陆属性。页面可离线打开，数据和图片全部内嵌。Windows 可将 `python3` 换成本机的 `py -3`。

高级选项示例：

```sh
python3 -m worldgen --seed my-world --width 1024 --plates 18 --ocean 0.65 --relief 1.2 --out artifacts/my-world
```

| 参数 | 默认 / 范围 | 含义 |
| --- | --- | --- |
| seed | 20260923 / 文本 | SHA-256 转随机源，固定种子与全部参数可在本机复现 |
| width | 512 / 32～2048 偶数 | 等经纬输出宽度，高度为一半 |
| plates | 14 / 4～40 | 球面板块数量 |
| ocean | 0.70 / 0.30～0.90 | 按球面面积确定海平面的低地占比偏好，实际海洋可能略小 |
| relief | 1 / 0.3～2 | 构造起伏及纹理强度 |
| out | artifacts/world | 输出目录，重复执行会覆盖该目录内同名生成文件 |

文件包括 `world.json` 权威数组、`summary.json` 摘要与 SHA-256、三张 PNG 地图、`index.html` 查看器。高程相对生成的海平面，单位米；经纬网以单元中心采样。行由北向南，列由西向东。

## 生成流程与依据

1. 将经纬位置投到单位球面。在球面选择分散的板块中心，以最近中心划分板块，并赋予相对旋转轴。位置速度使用叉积 `v = ω × p`；这里 ω 只有相对强度，未标定为实际地质速度。
2. 球面连续场生成大陆性分布，同一板块可以同时包含大陆地壳和海洋地壳。该分布是生成先验，不是演化计算的结果。
3. 在最近两个板块的边界附近，根据相对速度在边界法向的分量区分挤压与张裂。挤压添加山带；张裂在海洋性区域添加海岭、在大陆性区域降低地势。
4. 基底高程、大陆性、构造起伏与多尺度连续纹理合成地势。纹理采用球面上的三维 Fourier 场，不在二维地图边缘拼接噪声。
5. 使用纬度面积权重的高程分位数选海平面；低于海平面的区域再做连通分析，最大球面面积连通分量标为主海洋。其他封闭低地保留，不未经水文计算就标湖泊。
6. 输出地形与诊断图层。绿色和浅灰仅表达高程，不表示森林、草原或积雪。

构造关系参考 [USGS：Understanding plate motions](https://pubs.usgs.gov/gip/dynamic/understanding.html)。该资料支持板块边界与造山、张裂等关系；本项目的距离衰减、起伏幅度、大陆性函数和纹理参数都是**工程启发式参数**，并非该资料给出的物理定律。

## 范围与已知限制

这是第一张可复现随机地形的参考引擎，不能据此声称与现实物理完整一致。没有地壳质量守恒、地幔对流、板块时间演化、俯冲海沟与火山弧配对、侵蚀沉积、真实岩性、气候、水系或生态分类。规则板块边界与纹理的方向感仍明显，后续需要改善自然形态。

海平面由偏好校准而非总水量守恒求得；主海洋之外的多个不连通海盆没有独立水位。D4 连通性、极点对向邻接和等经纬栅格都是离散近似，极区不适合直接做精细物理计算。

连续缩放当前为固定图像放大，尚无多级细节和按需生成。改变输出分辨率会重新估计海平面和海洋连通性，不保证不同分辨率的数据逐点相同。地形表面以高程表达，可作为后续三维表面来源，但没有实现洞穴、悬崖体积或地下空间。

目前只完成本机数值与图片验证；未验收查看器实际浏览器交互，未验证 Windows 位级一致性。种子和参数相同、算法版本相同是复现的必要条件，不能替代跨平台测试。

下一阶段优先完善随机地形外观与多分辨率结构，然后逐步加入气候约束下的地形分类；水文暂缓。
