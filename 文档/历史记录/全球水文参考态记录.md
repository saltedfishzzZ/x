# 随机行星上的全球水文 v0.1

2026-09-23。在现有球体地形上新增全球水文参考情景，原始高程、板块、海洋掩码及种子保持不变。水文主线恢复，本轮不更换世界。

## 使用与查看

```sh
python3 -m worldgen.hydrology --world artifacts/world/world.json --out artifacts/world
```

默认有效径流为 300 mm/年，河网显示门槛为 50000 km² 汇水面积；可以使用 `--runoff 100 --river-area 100000` 调整。有效径流是人为给定的水源输入，不等于模拟降水，也未显式计算入渗或蒸发。单位年按 365.25 天。

刷新 球体查看器（原型文件已清理），默认显示“水文 · 满蓄参考态”图层，也可切回原地形。青色为达到阈值的河网格子，蓝色为满蓄湖面；指针显示参考湖深或汇流量、汇水面积。河道像素宽度是显示符号，不代表实际河宽。球面和平面使用同一张图层。

输出增加 `hydrology.json`、`hydrology.png`，HTML 内嵌全部水文数据，仍可离线使用。水文 JSON 用 `source_sha256` 绑定原始世界，数组与世界格子逐一对应。重新运行不带水文的地形生成命令会输出普通查看器；要更新水文，需要再次执行上述命令。

## 算法与物理边界

采用 [Barnes、Lehman、Mulla 的 Priority-Flood 方法](https://arxiv.org/abs/1511.04463)所描述的优先队列填洼思路，独立实现海洋出口驱动的最小溢流面。不修改原始高程，额外保存排水面和相对原始地形的水深。

这是一项**湖盆预先蓄满、持续有效径流输入的稳态参考实验**。湖泊初始水量单独记录，并未声称这一水量由一年降水产生。它不是从干地开始的湖泊演化，也不是已有局部 Fill–Spill–Merge 模块在全球的完整移植。

1. 单元面积使用精确纬带积分：`R² × Δλ × (sin φ北 − sin φ南)`，全球面积之和为 `4πR²`。邻格距离采用球面大圆距离。经度首尾相邻，极区沿用对向经度连接近似。
2. 所有既有海洋单元是水位 0 m 的吸收出口。优先队列从海洋向内遍历，建立最低溢流面。
3. 在此表面上优先选择最大下降坡度；平坦处按稳定出队顺序建立无环路径。水在满蓄湖面内部的路径是数值记账路径，不是湖内流速计算。
4. 按拓扑反序累加陆地面积，用 `Q = A × 有效径流厚度 / 时间` 得到稳态体积通量。既有海洋不接受本实验的本地有效径流输入。
5. 水深大于零、相邻且同水位的格子构成淹没连通区；其水深乘面积给出预填充体积。分类数量不等于包含零水深鞍点连接的完整湖盆层级数量。
6. 逐次检查总输入与海洋出口通量。初始湖泊储量保持不变，不能与每秒通量直接相加。

海洋是固定水位的外部库，接收陆地输出但不更新海平面；不是全球封闭水循环。不存在蒸发退水、盐湖平衡、土壤和地下水交换、季节变化、河流惯性或洪水传播。所有陆地最终外排是本参考情景的约束，不能拿它证明现实内流盆地不存在。

## 验证与限制

新增 7 项测试，全套 57 项通过：

- 可手算洼地：水面、水深、预填库容和出口流量分别核对。
- 嵌套洼地最终溢流面与库容。
- 全球面积积分、跨经度和极区相邻关系、大圆距离对称性。
- 多个种子下所有路径无环、排水面不逆坡、最终到海洋；原始地形不被修改。
- 零径流不显示活动河网，倍增径流使通量倍增而不改变预设满蓄水面。
- 非法输入与缺失海洋出口拒绝。
- 输出及世界摘要绑定。

已目视检查水文 PNG。浏览器本地文件访问此前被工具安全策略阻止，本轮不绕过该限制，球体的实际交互显示仍需浏览器验收。Windows 和真实流域观测对照仍未验证。
