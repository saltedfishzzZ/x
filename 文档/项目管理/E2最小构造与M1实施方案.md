## 一、E2 的目标

E2 把冻结的 E1 球面空间发布接入第一条自然状态生成链：

```text
用户种子／PV01 固定输入
  → 最小 WorldSpec 与命名随机流
  → 球面主板块种子
  → L8 球面 Voronoi 型壳体域
  → 共享边界与板块邻接
  → 每板块欧拉旋转代理
  → 边界相对速度与法向／切向分量
  → 汇聚／张裂／稳定／未解析资格
  → 不可变构造原型发布
  → M1 输入束、垂直基准与准入报告
```

完成后，引擎应能稳定回答：

- 同一个完整世界规格为什么拥有同一个 WorldId；
- 一个 L8 单元和任意球面位置属于哪个主板块；
- 主板块是否完整、连通、无重叠地覆盖球面；
- 哪两个板块共享某条边界，边界在哪里，方向如何定义；
- 两侧刚体运动在边界处产生怎样的相对速度；
- 某段边界当前是否具有汇聚、张裂、低活动或未解析资格；
- 当前构造发布具备哪些能力，哪些能力仍明确不可用；
- M1 为什么接受、限制或拒绝这一组上游输入。

E2 的目标是建立可追溯的构造成因骨架，不是直接生成一张地形图。

## 二、明确不进入 E2 的内容

以下能力不在 E2 实现：

- 微板块、板内孔洞、长期板块演化和拓扑事件；
- 完整走滑、斜向混合、消减极性、三重点动力学分段；
- 大陆壳／洋壳年龄、真实地质年代和地幔对流；
- 连续材料背景、岩性、材料柱和材料属性混合；
- 山脉、裂谷、海沟、区域基底或任何高程贡献；
- 海陆、海平面、气候、水文和地貌类别；
- `STANDARD_GLOBAL` 地形材料正式准入；
- 桌面界面、球体渲染和地图展示。

未实现能力必须在能力清单中标为 `NOT_AVAILABLE`，不得使用零值、空数组或展示标签伪装成功。

## 三、E2 与既有分层的关系

完整架构中，M1 标准生成要求 L6 构造输出为 `RELEASED` 且 L7 验收为 `PASS`。E2 尚未实现 L5—L7 的完整构造地形约束和发布外观，因此采用以下诚实边界：

| 输入类型 | E2 的 M1 结论 | 允许用途 |
| --- | --- | --- |
| PV01 固定构造输入及其 E2 验收包 | `ADMITTED`，运行配置固定为 `FIXED_TEST` | 测试命名空间内验证后续接口 |
| 普通种子生成的 E2 构造发布 | `DIAGNOSTIC_ONLY` | 查询、统计、PCAL 和算法验证 |
| 缺少、损坏或身份不一致的构造发布 | `REJECTED` 或 `UNRESOLVED` | 不允许进入生成 |
| `STANDARD_GLOBAL` | 能力为 `NOT_AVAILABLE` | 等 E3 补齐最小 L5／L6 消费字段后启用 |

这不是临时绕过。M1 使用正式状态、能力和原因结构表达阶段性范围，E3 继续使用同一准入接口。

## 四、E2-D01：范围、能力和最小垂直切片

> **状态：已确认。** E2 实现受限的 L2、L3、L4 与 M1 垂直切片，不生成材料、高程、海陆、气候或水文；PV01 使用 `FIXED_TEST`，普通世界使用 `DIAGNOSTIC_ONLY`，`STANDARD_GLOBAL` 保持不可用。

### 4.1 E2 实现的最小层次

E2 同时落地四个受限部分：

1. **L2 最小世界规格**：种子、`earthlike-prototype-v1`、冻结模型清单、运行目的和固定测试覆盖。
2. **L3 最小板块状态**：主板块种子、完整球面分区、邻接、共享边界和欧拉旋转代理。
3. **L4 最小边界运动**：共享边界上的相对速度、法向／切向分解及汇聚／张裂／稳定资格。
4. **M1 最小输入契约**：世界身份、空间与构造依赖、参考半径、随机流清单、运行计划和准入报告。

### 4.2 权威状态与派生状态

| 状态 | E2 所有者 | 权威性 |
| --- | --- | --- |
| WorldSpec、WorldId、SeedKey | `world-spec` | 权威 |
| 主板块对象、板块种子、L8 单元归属 | `tectonics-core` | 权威 |
| 连续球面最近种子查询 | `tectonics-core` | 权威查询规则 |
| L8 边界边、邻接和连通分量 | `tectonics-core` | 权威离散拓扑 |
| 欧拉轴身份和角速度整数参数 | `tectonics-core` | 权威运动代理 |
| binary64 速度与局部方向 | `tectonics-core` | 可复算连续量 |
| 边界资格标签 | 版本化规则派生 | 派生但需发布 |
| M1 输入束与准入原因 | `terrain-input` | 权威契约状态 |
| 地形、材料、海陆和景观 | 无 | `NOT_AVAILABLE` |

### 4.3 首版板块范围

- 只生成主板块；微板块能力关闭。
- 普通种子的主板块数量原型范围暂定 `6—12`，名义起点为 `8`；成熟度为 `M1 ENGINEERING`，只用于验证算法链，不宣称现实统计已标定。
- PV01 固定使用 6 个主板块，确保至少存在一个预注册汇聚关系、一个张裂关系和一个低活动关系。
- 板块数量、位置序列、欧拉轴和运动幅度分别使用独立命名随机属性；改变活动度不改变分区和欧拉轴身份。

## 五、E2-D02：WorldSpec、种子与命名随机协议

> **状态：已确认。** WorldId 绑定完整世界规格，SeedKey 只绑定规范种子；种子使用 `seed-format-v1`，随机访问使用具名、长度前缀编码的 SHA-256 派生协议，所有会改变离散身份的连续裁决都必须量化并处理边界不确定性。

### 5.1 最小 WorldSpec

E2 的规范输入至少包含：

```text
WorldSpecV1
├─ normalizedSeed
├─ seedFormatVersion = seed-format-v1
├─ preset = earthlike-prototype-v1
├─ spatialReleaseId + spatialManifestHash
├─ modelManifest
│  ├─ world-spec-v1
│  ├─ named-random-v1
│  ├─ tectonics-e2-v1
│  ├─ boundary-kinematics-e2-v1
│  └─ terrain-input-e2-v1
├─ tectonicPreferences
│  ├─ plateCountPreference
│  └─ activityPreference
└─ fixedTestOverride（可选）
```

运行线程、缓存、输出路径和显示状态不进入 WorldSpec。

### 5.2 种子规范化

`seed-format-v1` 固定：

- 输入是 Unicode 文本，限制为 1—128 个 Unicode 标量；
- 转为 NFC；
- 删除首尾空白，内部连续空白折叠为一个普通空格；
- 保留大小写差异；
- 拒绝控制字符；
- 空输入由上层生成可见种子后再进入核心，不允许隐藏随机种子。

该规则需要经过跨平台 Unicode 夹具验证。实现可引入小型、成熟且锁定版本的 NFC 依赖，但必须登记许可证和锁文件变化。

### 5.3 身份和随机根

```text
WorldId = SHA256(CanonicalJson(WorldSpecV1))
SeedKey = SHA256("planet-engine/seed/v1" || normalizedSeed)
```

上述公式是逻辑表达，字节层不使用裸字符串拼接。协议为每个 UTF-8 字段写入固定字节序的长度前缀，再写字段字节；`sampleIndex` 使用固定宽度无符号整数和固定字节序。这样 `("ab", "c")` 与 `("a", "bc")` 不会产生相同输入帧。

随机访问接口固定为：

```text
sample(namespace, entityId, property, sampleIndex) -> 256-bit material
```

E2 只开放已登记命名空间：

```text
world/tectonics/plate-count
world/tectonics/plate-site
world/tectonics/euler-axis
world/tectonics/euler-rate
test/PV01/tectonics
```

整数、`[0,1)` binary64 和有界整数取样具有版本化转换；禁止共享的可变全局随机序列。

- `[0,1)` binary64 固定取 53 个有效随机位并除以 `2^53`；
- 有界整数使用拒绝采样，避免简单取模偏差；
- 最大尝试次数、最终 attemptIndex 和失败码进入证据；
- E2 不需要正态分布，不为未来功能提前加入平台相关数学取样。

### 5.4 跨平台离散化

为了避免不同数学库的最后一位改变对象身份：

- 板块种子和欧拉轴保存为 E1 `CellId`，不保存运行时随机三角函数结果作为身份；
- 欧拉角速度保存为整数 `microdegreesPerMillionYears`；
- 候选距离、单元归属分数和边界速率在离散裁决前按冻结尺度量化；
- 量化并列按 CellId 或 PlateId 规范顺序裁决；
- 未量化 binary64 只作为连续诊断和查询值，不进入跨平台离散身份摘要。

量化精度必须远小于 L8 空间解析度和边界分类死区，并在夹具中证明不会成为可见构造尺度。

## 六、E2-D03：主板块种子与球面域

> **状态：已确认。** 普通世界使用 6—12 个主板块、L6 候选位置和确定性最远点前缀序列，在 L8 形成无权球面 Voronoi 型归属；PV01 固定 6 个种子。首版不提供目标面积加权，L10 只按连续规则查询而不物化自然状态。

板块数量偏好固定为：

| 偏好 | 主板块数量 |
| --- | ---: |
| 较少 | 6—7 |
| 标准 | 8—10 |
| 较多 | 11—12 |

三个档位使用同一个具名随机分位映射，保证同一种子下“较少 < 标准 < 较多”。默认只输入种子时使用标准档。

### 6.1 候选集合

候选位置来自固定层级的 E1 单元中心，建议使用 L6 候选格。候选身份是 CellId，遍历顺序固定，不依赖线程或哈希映射顺序。

### 6.2 确定性最远点选择

普通世界使用以下流程：

1. 从命名随机材料选择第一个候选；
2. 对每个剩余候选计算到已选集合的最小球面距离代理；
3. 将距离代理量化后，选择“最远分数最大”的候选；
4. 并列按与当前选择步骤绑定的稳定随机排名，再按 CellId 裁决；
5. 检查最小间距和分区结构先验；
6. 最多执行 8 次有界重试，失败则明确拒绝该世界构造运行。

PV01 直接提供固定板块种子 CellId，但仍调用同一分区、拓扑、运动、验证和发布路径。

### 6.3 L8 Voronoi 型归属

对每个 L8 单元中心：

```text
owner = argmax(quantize(dot(cellCenter, plateSite)))
```

并列按 PlateId 处理。连续点查询使用相同的最近种子规则；L8 归属是正式全球离散覆盖和面积统计，连续查询用于位置解释。

### 6.4 PlateId 与板块对象

PlateId 从以下稳定内容派生：

```text
PlateId = hash(worldId, "plate", siteCellId, generationRank)
```

板块对象至少保存：

```text
plateId
generationRank
siteCellId
plateLevel = MAIN
actualAreaSteradians
actualAreaSquareMetres
cellCountL8
neighbourPlateIds
eulerAxisCellId
eulerRateMicrodegreesPerMillionYears
capabilityAndEvidenceRefs
```

E2 首版使用无权球面 Voronoi 型分区，因此板块对象不保存未参与计算的 `targetAreaWeight`。只保存实际面积；`WEIGHTED_PLATE_AREA_TARGETING` 能力明确为 `NOT_AVAILABLE`。未来若引入加权球面幂图，必须升级构造模型和发布模式。

### 6.5 域与拓扑硬约束

- 六个立方体面全部覆盖，无空单元和重复所有者；
- 每个主板块在 L8 四邻接图上连通；
- 每个主板块面积处于全球面积的 `2%—35%`；
- 任意两个板块种子角距不低于 `20°`；
- 全球真实面积和各板块面积和在 E1 面积容差内闭合；
- 不允许板内孔洞和微板块；
- 不满足约束时进行有界重试，不能在最终快照中静默删除板块。

E2 只物化 L8 全球归属。L10 CellId 或任意球面点可以使用同一最近种子规则查询 owner，但 E2 不写出 L10 构造字段，也不把 E1 空间补丁声明为自然状态细化。

## 七、E2-D04：共享边界、欧拉运动与资格

> **状态：已确认。** E2 在 E1 的规范 EdgeId／VertexId 上提取板块边界图，使用正角速度的有向整球欧拉轴表达板块运动，以 A→B 的三维切平面坐标分解相对速度，并只发布汇聚、张裂、稳定和未解析四类资格。

### 7.1 边界提取

枚举 L8 单元的规范共享边；两侧 owner 不同时，该 E1 EdgeId 成为构造边界边。边界边保存排序后的两侧 PlateId，但方向计算另保存明确的 A→B 约定。

相同板块对、且通过共享 VertexId 连通的边界边组成一个边界连通分量：

```text
BoundaryId = hash(worldId, minPlateId, maxPlateId, canonicalMinimumEdgeId)
```

同一板块对允许有多个不连通分量，各自拥有 BoundaryId。每个板块对分量自身不得分叉，只能形成闭环，或终止在三重点。全局边界图中的普通顶点度数为 2，三板块交会点度数为 3；度数 1 是悬空边界，直接拒绝该候选。度数不小于 4 的同点交会在 E2 视为退化候选，触发最多 8 次的整体有界重试；重试耗尽后发布失败证据，而不是按遍历顺序任意连接。三重点只保留各入射边自己的局部运动分解，不为交会顶点捏造唯一运动方向。

### 7.2 欧拉旋转代理

每个板块的运动由以下权威参数构成：

```text
eulerAxisCellId
eulerRateMicrodegreesPerMillionYears
referenceFrameId
motionModelVersion
```

局部速度按冻结的 E1 球面半径计算：

```text
v(r) = R × (ω × r)
```

欧拉轴使用 E1 CellId 保存有向整球位置，角速度只保存正整数幅度。整球轴方向已经携带旋转符号，因此禁止同时使用“对跖轴 + 负角速度”形成重复表达。活动偏好使用同一个规范分位数，并保持逐种子单调：

| 活动偏好 | 角速度范围 |
| --- | --- |
| 较低 | `0.05—0.35°/Myr` |
| 标准 | `0.20—0.70°/Myr` |
| 较高 | `0.50—1.00°/Myr` |

改变活动偏好只改变角速度幅度，不改变板块分区、PlateId 或欧拉轴。范围成熟度为 `M1 ENGINEERING`；PV01 使用固定轴与固定整数幅度。

### 7.3 边界局部坐标

板块 A、B 由排序后的 PlateId 唯一确定。每条边界边的球面中点建立：

- 外法向 `r`；
- 从板块 A 指向 B 的切平面法向 `nAB`；
- 沿边界方向的切向 `t = nAB × r`，并满足 `r × t = nAB`；
- 两侧局部速度 `vA`、`vB`；
- `relativeVelocity = vB - vA`；
- `normalRate` 与 `tangentRate`。

`nAB` 的符号必须用两侧单元中心验证，确保确实由 A 指向 B。方向只来自 E1 共享边几何、三维球面向量和两侧归属，不依赖立方体面二维坐标或显示折线。还必须验证速度的径向残差接近零，并能由法向和切向分量在统一容差内重构相对速度。

### 7.4 E2 分类范围

E2 发布原始连续分量，并只派生：

| 资格 | 条件 |
| --- | --- |
| `CONVERGENT` | 量化后的 `normalRate < -5,000 μm/year` |
| `DIVERGENT` | 量化后的 `normalRate > 5,000 μm/year` |
| `STABLE` | 法向和切向速率绝对值均不大于 `5,000 μm/year` |
| `UNRESOLVED` | 法向处于死区但切向显著，或信号临界、方向退化、证据不足 |

内部计算可使用统一的 binary64，但发布分类前必须量化为整数 `μm/year`，量化步长为 `1 μm/year`。汇聚或张裂边界即使同时存在显著切向分量，E2 仍保持其法向资格，并额外保存切向显著标志，不派生“斜向”或“走滑”类别。真实的欧拉轴附近低速和两个板块近似共动都可合法成为 `STABLE`。

走滑分量仍保存为连续证据，但 `STRIKE_SLIP_CLASSIFICATION` 能力在 E2 标为 `NOT_AVAILABLE`。斜向混合、长边界动力学分段、壳体组合和消减极性同样后置。

死区固定为 `5,000 μm/year = 0.5 cm/year`，并显式大于数值与量化误差。它是 M1 工程门槛，不是已标定的地球构造常数。

## 八、E2-D05：M1 输入束与垂直基准

> **状态：已确认。** 自然输入束、运行计划和准入报告分别保存，再由 `M1InputRelease` 原子绑定；自然身份不受执行、存储或显示状态影响。E2 建立球面垂直基准，但不生成任何表面或海平面。

### 8.1 输入、运行与准入分离

E2 使用四个职责不同的对象：

```text
TerrainMaterialInputBundle   不可变自然输入
TerrainMaterialRunPlan       本次计算范围和执行要求
AdmissionReport              针对输入与运行计划的准入结论
M1InputRelease               三者及其清单的原子发布
```

`TerrainMaterialInputBundle` 至少绑定：

- `inputBundleId`；
- `worldId` 与 `worldSpecHash`；
- E1 空间发布 ID 与清单摘要；
- E2 构造发布、构造验证包及其摘要；
- 地形材料模型清单和自然参数档案；
- 垂直基准描述；
- 地形随机流清单；
- 依赖闭包和能力要求。

运行计划、准入结论、线程数、分块顺序、缓存、输出路径、显示状态和 TestOracle 均不进入自然输入束。

### 8.2 身份层次

`GenerationIdentity` 由 WorldSpec、E1 空间发布、E2 构造发布、地形材料模型版本、自然参数档案和随机协议版本共同决定。`InputBundleId` 是完整不可变输入束的内容身份；`RunPlanId` 则标识一次计算范围和执行要求。

改变线程、缓存、输出路径、显示状态或测试 Oracle 不得改变 `GenerationIdentity`。同一自然输入束可以被多个运行计划引用，而不能因为调度差异被误认为另一个世界。

### 8.3 垂直基准

E2 只建立基准，不生成高程：

- 行星中心为原点；
- E1 权威单位向量定义径向方向；
- 参考半径为 `6,371,000 m`，来自绑定的空间发布；
- 高程单位约定为米；
- 参考球面零点与未来海平面分离；
- `solid_surface`、`water_surface`、`snow_surface` 均为尚未提供的表面能力。

因此，未来低于参考球面但仍属于陆地的盆地完全合法；海陆不能由高程正负单独判定。局部三维坐标必须从全球球面位置和这一垂直基准显式派生。

### 8.4 准入检查

准入验证至少检查：

- WorldId、种子、空间发布和构造发布身份一致；
- E1 空间模式、半径、CellId 和清单摘要匹配；
- 构造快照与验证包摘要一致且状态允许当前运行配置；
- 所需构造字段、单位、尺度和能力存在；
- 随机命名空间无冲突；
- FixedTestInput 与 TestOracle 物理隔离；
- 运行线程、缓存和输出路径未进入 GenerationIdentity；
- 缺失与未知不被替换为零。

准入报告使用 `ADMITTED`、`DIAGNOSTIC_ONLY`、`REJECTED`、`UNRESOLVED` 四种结论。能力状态与准入结论分别表达；例如 `STANDARD_GLOBAL` 能力为 `NOT_AVAILABLE` 时，对该运行配置的请求结论是 `REJECTED`，并携带 `RUN_PROFILE_NOT_AVAILABLE` 原因码。

发现身份不一致、摘要损坏、验证失败或不支持版本时明确 `REJECTED`；缺少足够证据而无法判断时使用 `UNRESOLVED`。任何缺失字段都不得通过隐式补零或未登记 fallback 获得正式准入。

### 8.5 E2 准入能力

| 运行配置 | E2 行为 |
| --- | --- |
| `FIXED_TEST` | PV01 输入通过全部 E2 条件后可 `ADMITTED`，输出只能进入测试命名空间 |
| `DIAGNOSTIC` | 普通构造发布可 `DIAGNOSTIC_ONLY`，保留限制和能力缺口 |
| `STANDARD_GLOBAL` | 请求结论为 `REJECTED`；能力为 `NOT_AVAILABLE`，原因是最小 L5/L6 消费字段尚未实现 |
| `REGIONAL_REFINEMENT` | 请求结论为 `REJECTED`；能力为 `NOT_AVAILABLE`，E2 不生成自然状态补丁 |

### 8.6 M1 原子发布

```text

├─ TerrainMaterialInputBundle
├─ TerrainMaterialRunPlan
├─ AdmissionReport
├─ CapabilityManifest
├─ DependencyManifest
└─ ReleaseManifest
```

任一引用或摘要不匹配，整个发布不可使用。失败报告必须包含稳定原因码、受影响对象和最小复现入口。PV01 的固定输入可进入测试发布，但其 TestOracle 始终保存在发布链之外。

每个查询结果至少携带 `releaseId`、`queryMethod`、`resolutionOrScale`、`sourceObjectIds`、`unit` 和 `knowledgeStatus`，明确区分 L8 已物化归属与任意球面方向的连续最近种子查询。连续查询不得宣称生成了更高层级的构造字段。

### 9.4 CLI

建议新增：


`build` 对同一规范输入产生相同内容；`inspect` 只读；`validate` 不修复；`query` 不改变发布。CLI 同时支持人工文本和规范 JSON 输出，并使用稳定退出码与原因码。不增加 `generate terrain`，因为 E2 没有高程或材料生成能力。
